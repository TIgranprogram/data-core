# C119 — разбор экранов по видам «Ход» / «Состав»

Метки: **Х** — место в «Ходе», **С** — место в «Составе», **—** — убрать или перенести, **нет** — нужно, но нет.

## Производство → Заказы → карточка заказа (эталон, заказ 11-26, стенд 15.11)

| Что на экране сейчас | Вид | Что сделать |
|--|--|--|
| Шапка: «Заказ № 11-26», заказчик · компания, этап бейджем | Х, С | оставить |
| «Что дальше» — только текст, без кнопки | Х | дать одну кнопку шага («Отгрузить остаток») |
| Сведения: Заказчик, Наша компания, Срок (красный без слова) | Х | срок — «просрочен на N дн.» текстом; компания — в шапке уже есть |
| «Подробнее»: договоры заказчика (1 · № 9), позиции (12) | С | в «Ходе» не нужно: число позиций уже на вкладке |
| Вкладки «Позиции · Выполнение · Деньги · Документы» | Х | оставить |
| «+ Договор» над таблицей | С | только в «Составе» |
| Строка договора: «+ Позиция», «⋯» | С | только в «Составе»; в «Ходе» — договор как подзаголовок |
| Строки позиций: «⋯» (заменить, отменить, перенести) | С | только в «Составе» |
| Строки позиций: этап строки | нет | метка «в работе / на складе / отгружено 2 из 5» |
| Отменённые позиции | С | в «Ходе» — свёрнуто «Отменено: N» |
| Полоса хода (этапы N из M, оплачено, срок) | нет | `progressBar` наверху «Хода» |
| «Что мешает» (без изделия, не сопоставлено, долг) | Х | один `warnCard` над сведениями (уже по C118 1.4) |
| Кнопка «Изменить состав» | нет | `.btn-ghost` в шапке; в «Составе» — «Готово» |

### Вкладки (стенд 15.11, заказ 11-26)

| Вкладка · что сейчас | Вид | Что сделать |
|--|--|--|
| Выполнение: «Отгрузить (6 готово)» — внутри раскрывашки «Отгрузки» | Х | это и есть шаг заказа → кнопка в «Что дальше»; сейчас «Что дальше» без кнопки, а кнопка спрятана во вкладке |

| Деньги: «Принять оплату» в строках | Х | оставить: это шаг хода |
| Документы: «PDF заказа», «Скачать вложения», «Печать паспортов…», «Паспорта заказа» — 4 кнопки в ряд | Х | одна главная («Печать паспортов…»), остальное в «⋯»; «Паспорта 7 (готовы 7)» при 12 позициях → «5 позиций без паспорта» предупреждением |

### Главное по эталону
1. Шаг заказа живёт во вкладке, а «Что дальше» пустое → кнопка шага всегда в «Что дальше».
2. Пустые данные выглядят как нули («долг 0», «отгрузок нет» при частичной отгрузке) → в «Ходе» пустое называть пустым и вести к заполнению.
3. Правка (С) и ход (Х) перемешаны на всех вкладках, кроме «Деньги».
