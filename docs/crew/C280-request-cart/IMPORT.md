# Сверка номенклатуры металла · 27.11.2026

Источник — лист «Номенклатура» книги «Заявки метал 2021.xlsx». Перед записью получены 650 карточек основного сайта. Размеры сопоставлены по профилю, материалу и длине поставки. Учитывались варианты с разными марками, типами проката и размерами листа.

На основном сайте созданы 76 позиций труб и 46 позиций другого проката. У 34 существующих карточек труб дополнены пустые характеристики. Для всех 156 операций сохранён идентификатор и выполнено повторное чтение через API. Закупочные цены из истории и текущие складские остатки в тела изменений не включались.

## Что осталось уточнить по книге

- В строках 132, 133, 135, 136 и 195 размеры в названии и отдельной ячейке расходятся.
- У оцинкованного листа в строке 156 указаны кубометры. В строках 198–199 отсутствует единица измерения.
- Для ряда листов совпадают габариты, но не подтверждены технология прокатки или марка. Карточки сохранены без изменений до уточнения.
- Для десяти новых труб в источнике отсутствует длина поставки. Её можно указать при выборе трубы в каталоге.
