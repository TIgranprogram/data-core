1. P1. Раздел «Документация», внутри только паспорта: подпись вкладок «Паспорта» (docs.js:147), крошка «Паспорта › …». Заглушки актов убраны (docs.js:136). Места для актов нет: пять вкладок заняты паспортами.
2. P1. Пять вкладок смешивают три разные вещи: что ДЕЛАТЬ (очередь, «Новый паспорт», «Добавить готовый»), что ИСКАТЬ (Выпущенные, По номерам, По заказам — три разреза одного журнала), что НАСТРАИВАТЬ («Шаблоны»). Кнопки действий висят над всеми вкладками, даже над «По номерам».
3. P1. Непонятные слова. «Шаблоны» — на деле список изделий с типом и текстами паспорта; менеджер ищет там «сделать паспорт», и подсказки (docs-orders.js:70, docs.js:124) сами отправляют туда. «По номерам» — это тот же журнал, отсортированный по номеру. «По заказам» путается с очередью «Нужно сделать» (она тоже по заказам). «Добавить готовый паспорт» — на деле загрузка PDF.
4. P2. Три пути «выпустить» с разным смыслом: очередь (по заказу), «Шаблоны → Выпустить паспорт» (по изделию), кнопка «Новый паспорт» (воронка). Менеджер не знает, какой выбрать.
5. P2. «Выпущенные» и «По номерам» дублируют друг друга (оба passarchive, docs.js:156–157).
6. P2. Крошки показывают вкладку хвостом (docs.js:148) и дублируют вкладки; открытая карточка в крошки не попадает.
7. P2. Полоска номеров над «Шаблонами» и «Выпущенными» нужна в основном при выпуске/правке номера, занимает верх экрана.

## 3. Новая структура (предложение)
Принцип П-1: сначала крупный выбор плитками (kit tileGrid + card S + landing, как «Продукция», DESIGN §4 строка 248), затем крошки и только нужные кнопки. Вкладки — только внутри категории и только для разрезов одного набора. Новых компонентов нет: landing, tileGrid, card S, tabs, crumbTail, button уже в kit.

```
Документация                    посадочная «Выберите документ · всего N»
├─ Паспорта                     плитка со счётчиком «К выпуску: N»
│   ├─ вкладка «К выпуску»          очередь по заказам (кнопка «Выпустить»), по умолчанию
│   ├─ вкладка «Выпущенные»         журнал; фильтры; сортировка по номеру и «№ от — до» внутри; вкладки «По номерам» нет
│   ├─ вкладка «Паспорта по заказам»
│   └─ вкладка «Настройки изделий»  бывшие «Шаблоны»: тип паспорта и тексты по изделию
│   Кнопки над вкладками: «Новый паспорт» (primary), «Загрузить готовый паспорт (PDF)»; номера — в ряд «Номера», свёрнут
├─ Акты, Накладные, Сертификаты   плитка появляется вместе с рабочим экраном и API
```
Заглушки «скоро» не делать (CANON/правило: только с записью в docs/TASKS.md).

Крошки: «Продукция › Документация › Паспорта › Выпущенные». «Документация» ведёт на посадочную, «Паспорта» — на плитку паспортов; открытая карточка — последним звеном (одна строка с ›, как docs.js:148).

Адреса: `#docs` — посадочная; `#docs?kind=passports&tab=…`. Старые `#docs?tab=queue|templates|orders|archive|numbers` и `#passports` (main.js:436) переадресовать: queue → К выпуску, templates → Настройки изделий, numbers → Выпущенные с сортировкой по номеру. Закладки не ломаются.

Решение координатору: пока видов документов один, посадочная из одной плитки лишняя. Делать шаги 2–5 сейчас, посадочную (шаг 1) включить, когда появится второй вид документов.
