# C155 — редактирование справочника в правой панели

Клик по строке справочника открывает штатную правую панель даже при `dc-popout-dict=1`. В этой панели нет кнопки отдельного окна. Другие карточки пользуются своим прежним предпочтением.

Из ранее открытого окна действие «Открыть в панели» возвращает ту же запись во вкладку приложения. Если открытая форма изменена, действие предлагает сначала сохранить или отменить изменения и оставляет ввод на месте. Если исходной вкладки уже нет, текущая открывается в обычной оболочке приложения с той же записью.

## Проверки

- 12 целевых тестов карточки и отдельного окна проходят. Отдельно проверены кнопка другого раздела, защита ввода и возвращение точного адреса.
- Прошли 347 проверок Jest, синтаксис шести изменённых ES-модулей, проверка импортов и design-lint.
- Воспроизводимый сценарий Chromium — `dictionary-panel.mjs`. Диагностическая копия `tools/logs/c155-dictionary-panel-diagnostic.mjs` с SHA-256 `816EB6879B9A88772A7EDDA3EFCA714FBAA8B8CF000D751D828918C6A93F0EDF` передана координатору. Агент доступа запускает её на изолированном стенде 3102 через `api.sh stand BROWSER` с доступом к выделенной записи `C155_DICT_PANEL_FIXTURE_ID`. Снимки и журнал этапов сохраняются в `evidence/dictionary-panel/`.
- Для двух тем сценарий устанавливает прежнее предпочтение, открывает «Поручень» из списка и сверяет положение панели, число окон и отсутствие вызова `window.open`. Затем проверяет сохранение с повторным открытием выделенной QA-записи и возвращает исходное значение. Для ранее открытого окна проверяет сохранность ввода и возврат в исходную вкладку.
- Геометрия проверяется после анимации относительно правого края `document.body`. Замер на копии дал 1425 px у панели и приложения и 1440 px у ширины окна. [Правило для повторных проверок](../../traps.md)

## Результат на изолированной копии — PASS

- Со старым `dc-popout-dict=1` «Поручень» открылся в правой панели в обеих темах. Вызовов `window.open` при открытии из списка и ошибок JavaScript не было. [Светлая тема](evidence/dictionary-panel/light.png) · [Тёмная тема](evidence/dictionary-panel/dark.png)
- В старом отдельном окне ввод сохранился до явной отмены. После неё та же запись открылась в основной вкладке.
- После сохранения выделенной QA-записи новое значение подтвердилось при повторном открытии. Затем исходное значение восстановили и сверили отдельным GET. Оба PATCH вернули HTTP 200. [Журнал действий](evidence/dictionary-panel/result.json)
- Выпущенный паспорт №611 в тёмной теме показывает «Просмотр и печать доступны в этом окне». [Снимок паспорта](evidence/dictionary-panel/issued-dark.png)
- В обеих темах Tab переводит фокус на поле родительного падежа и затем на кнопку внутри панели. У поля видна рамка 3 px. У кнопки подтверждён видимый системный фокус 1 px. Сценарий `panel-focus.mjs` выполнил только чтение, ошибок JavaScript и попыток записи нет. [Светлая тема](evidence/dictionary-panel/focus-light.png) · [Тёмная тема](evidence/dictionary-panel/focus-dark.png) · [Журнал фокуса](evidence/dictionary-panel/focus-result.json)
