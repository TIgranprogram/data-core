# C238 — минимальное решение перехода с доски

Вердикт: **PASS** для явного `view:'table'` и универсальной подписи `ещё N — списком →` в `ui/kit/board.js:276`.
`view:undefined` не задаёт переход и возвращает режим доски из default/памяти; явный режим делает действие однозначным.
Сохранить существующий patch: статус колонки, прочие фильтры и сброс page; ветку `c.portion` не менять.
Обещание месяцев убрать: `requests.js:337` включает periods только для received/cancelled; paid группировки не имеет.
Группировку received/cancelled сохранить; paid не добавлять, дату оплаты/заявки и бизнес-правила не менять.
Координатору уточнить критерий ТЗ: открытие списка; месяцы — только где они уже поддержаны, без нового общего контракта board→periods.
Приёмка: default/saved/explicit board → table с нужным статусом и фильтрами; другая общая доска; c.portion дозагружает на месте. Никаких оплат/приёмки/статусов.
Это предварительное решение по узкому стыку; код и данные не изменялись, проверку финальной дельты выполняет назначенный проверяющий.
