## Часть 1. Как устроены иконки сейчас (для того, кто будет внедрять)

- **Значки интерфейса** — один файл `pwa/ui/icons.js`: 36 штук, линейные, сетка 24×24, обводка 1.8, скругление концов. Цвет берётся из текста (`currentColor`), поэтому **один значок сам подходит к светлой и тёмной теме**. Отдельные «тёмные» версии значков интерфейса не нужны.
- **Значки кнопок** — сейчас просто символы: × ⋯ ← ‹ › ↑ ↓ + − ✎ ⚖ 😊. Выглядят по-разному на разных устройствах — заменить на SVG из общего набора.
- **Значок приложения** `pwa/icon.svg`, `icon-192.png`, `icon-512.png` — синий фон #1e415e с жёлтым кубом. **Не совпадает с фирменным зелёным** интерфейса.
- **Логотип админки** `admin/logo.svg` — цвета Python (синий/жёлтый). Тоже не в фирменном стиле.
- **Проблема меню:** 18 разделов, но значков для них всего 7. «Заказы» (`orders`) стоит у 5 разделов, «Контрагенты» (`partners`) — у 4, «Склад» (`stock`) — у 3. На узком экране (меню только иконками, 721–1100 px) разделы не различить.

## Часть 3. ПРОМПТ ДЛЯ ДИЗАЙНЕРА (копировать отсюда до конца)

Ты — дизайнер иконок. Нарисуй единый набор иконок для веб-приложения «Рабочее место» (Data Core). Это рабочая система небольшого производства тренажёров и металлоконструкций: заявки на закупку, склад, заказы, проектирование, коммерческие предложения, деньги, зарплата. Пользователи — менеджеры, кладовщики, директор. Работают с компьютера и с телефона на складе.

**Характер.** Спокойный, точный, «инженерный». Без игрушечности, без 3D, без градиентов в значках интерфейса. Ориентир по стилю — Lucide / Tabler / Phosphor Regular, но со своим узнаваемым почерком: чуть скруглённые углы, понятные силуэты, отсылки к металлу и производству там, где это уместно.

**Фирменные цвета.**
- Светлая тема: фон #f1f4f3, карточки #ffffff, текст #17201c, фирменный зелёный #0f7d55, заголовки #0e3b2b.
- Тёмная тема: фон #0f131a, карточки #171c25, текст #d3dbd8, фирменный зелёный #3fcf8e, заголовки #6fe0b0.
- Акцент меню: золото #d4ae4f на тёмном #171c26.
- Цвета разделов (светлая / тёмная): Продукция #3d5fa0 / #8fa8dc · Заказы #66499f / #b5a0dc · Снабжение #9a4f2c / #d9a086 · Склад #1f6e7c / #7fbcc6 · Деньги #8a4560 / #cba0b0.
- Состояния: успех #1f7a3f / #57c785 · внимание #965700 / #eba845 · ошибка #c2372d / #f0756d.

### А. Значки интерфейса (основная часть — около 110 штук)

Строгие технические требования — от них зависит, встанут ли иконки в код:
1. Сетка 24×24 px, рабочая область 20×20 (поле 2 px со всех сторон).
2. Только линии: `stroke` 1.8 px, `stroke-linecap: round`, `stroke-linejoin: round`, без заливки (`fill="none"`). Исключение — точки (i, !) — маленький круг или короткая линия.
3. **Один цвет — `currentColor`.** Никаких заданных цветов внутри SVG. Значок сам перекрашивается под светлую и тёмную тему, поэтому отдельные тёмные версии не делать.
4. Привязка к пиксельной сетке, без полупикселей там, где можно.
5. Читается в размере 16 px и 20 px. Не больше 3–4 деталей в значке.
6. Одинаковый оптический вес: круги, квадраты и треугольники выровнены на глаз, а не по краю.
7. Без текста и букв внутри (кроме «₽» в денежных и «?» в помощи).
8. Экспорт: каждый значок — отдельный SVG `viewBox="0 0 24 24"`, без `width/height`, без `<g transform>`, без `<style>`, без id и масок. Контуры не превращать в заливку (оставить stroke).
9. Имя файла = ключ из списка ниже, например `requests.svg`, `stock-mobile.svg`.

Список значков (ключ — что изобразить):

Разделы: home — домик; requests — лист с галочкой; stock — коробка на полке; suppliercatalog — ценник/прайс; contracts — лист с подписью; salesorders — планшет-заказ; matching — две линии, сходящиеся в одну; design — угольник и карандаш; work — шестерня в движении; products — готовое изделие-тренажёр; offers — лист с ₽; docs — папка с листами; partners — рукопожатие; money — стрелки вверх-вниз с ₽; expenses — чек; payroll — конверт с купюрой; staff — человек с бейджем; stock-mobile — телефон с коробкой.

Система: menu, admin (щит), profile (человек), settings (ползунки), crm, theme (луна), themeLight (солнце), themeAuto (полукруг), logout, help, history, bell, chat, phone, refresh, trash, moves, ops, board.

Состояния: ok, err, warn, info.

Действия: close, more, back, prev, next, up, down, plus, minus, edit, weight, emoji, add, search, filter, sort, expand, collapse, drag, copy, link, upload, download, print, pdf, eye, eyeOff, lock, pin, calendar, clip, gallery, table, catalog.

### Б. Фирменные элементы (цветные, две темы)

1. **Значок приложения.** Квадрат со скруглением 22 %, фирменный зелёный фон (#0f7d55 → чуть темнее книзу допустим), белый или золотой (#d4ae4f) знак: узнаваемый символ «ядро данных + производство» (например, куб-деталь, собранный из линий, или стилизованная буква D из профиля). Простой — читается в 48 px. Размеры PNG: 512, 192, 180 (apple-touch), а также maskable 512 с полем безопасности 20 %. Плюс исходник SVG.
2. **Favicon.** SVG + PNG 32 и 16. Два варианта: для светлой и для тёмной вкладки браузера.
3. **Логотип.** Знак + надпись «Рабочее место» (и короткий вариант «Data Core»). Горизонтальный и квадратный. Светлый (для белого фона) и тёмный (для фона #0f131a). SVG, текст переведён в кривые.
4. **Иллюстрации пустых экранов** — 6 штук, SVG ~160×120, тонкая линия в стиле значков + 1–2 мягкие заливки цветом раздела: empty («Пока пусто»), calm («Всё спокойно»), notFound («Ничего не найдено»), noAccess («Нет доступа»), offline («Нет связи»), error («Что-то пошло не так»). Каждая — в светлом и тёмном варианте (`*-light.svg`, `*-dark.svg`).

### В. Что сдать

- Папка `icons/` — все значки интерфейса SVG по ключам (пункт А).
- Папка `brand/` — значок приложения, favicon, логотипы, иллюстрации (пункт Б), светлые и тёмные.
- Один лист-превью (PNG): весь набор на светлом фоне и на тёмном, в размерах 16, 20 и 24 px — чтобы проверить единый вес.
- Если делаешь в Figma: компоненты с именами по ключам, экспорт «SVG, outline stroke — выключено».

Перед сдачей проверь: все значки одной толщины линии, одного размера на глаз, без лишних цветов, читаются в 16 px на обеих темах.
