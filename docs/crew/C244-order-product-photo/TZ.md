# C244 — фото сопоставленного изделия в заказе

Класс: L (исправление общего resolver после диагностики); одновременно максимум4: координатор, backend, QA и architect. Диагностические access/explorer завершены до реализации. Просьба23.11: в заказе22-26 строка с нашим3413 Скамья2м показывает «нет фото». Проверить причину и исправить подтверждённый дефект; публикация только после завершения проверки по текущему указанию владельца.

Scope: существующая проекция incomes/product и миниатюра строки заказа; точные пути после explorer. Access — только GET заказа/позиции/3413/источников изображений, не менять данные. Не читать/аудировать весь каталог, не трогать физические остатки/паспорта/выданную историю/сопоставление.

Критерии: установлен точныйproductId/incomeId и реальное поле изображения; объяснено отсутствие миниатюры. Если есть дефект — фото связанного изделия видно, явное фото позиции имеет приоритет, отсутствие фото безопасно, замена связанного изделия не оставляет чужое изображение. Никакой выдуманной привязки/копирования фото в данные ради интерфейса. Проверки по дельте, включая заполненный desktop сценарий; отчёт со ссылками/фактами и пределами приёмки.
