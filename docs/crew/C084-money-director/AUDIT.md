## 5. Хвосты вида (главное для директора)

1. Раскрытие статьи перерисовывает всю таблицу: рывок, без плавности.
2. Строка под курсором не подсвечивается, выбранная — не запоминается.
3. Список операций открывается под таблицей: надо листать вниз, теряется строка.
4. Колонка «%» — голое число. Долю не видно глазом.
5. Нет плашек «доходы / расходы / результат» над таблицей.
6. Текущий месяц не выделен; будущие месяцы забиты прочерками.
7. Статья с 20–30 подстатьями раскроется простынёй.
8. Нет вида «по кварталам» — 12 колонок на узком экране.
9. Шесть вкладок в «Деньгах»; директору нужна одна — «По статьям».
