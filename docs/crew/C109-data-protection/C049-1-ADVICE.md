# C049-1 — совет (opus, 13.11) и как исполнено

## Решение

- Отдельное поле `version: number` (как у счёта). Не `updatedAt`: его меняют каскады (`audit.plugin.ts:55` — любой updateOne; `syncLines` заказа, работа со счётом, сопоставление) → ложные 409; сырые записи его не ставят.
- `+1` — только правка человеком (`update()` и ручки одиночной записи). Каскады, бронь, приёмка, массовые слияния справочников — без `$inc`.
- Поле в теле, необязательное: `@IsOptional() @IsInt() @Min(0) version`. Нет — прежнее поведение (внешние ключи, старые вкладки). Не `If-Match`.
- Атомарно: условие версии в фильтре единственной основной записи + `$inc`; ранняя проверка до побочных записей. `matchedCount 0` при версии → 409.
- Тело 409 — `{message, code:'STALE'}` без записи (ошибка идёт мимо маски денег).
- CRM kppdf версию не увеличивает — её правки не ловятся; CRM заморожена, принять.
