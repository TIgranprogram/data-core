# ТЗ C009 — Единая номенклатура (источник истины)

> Пишет координатор (+ аналитик 2026-11-03). Исполнитель читает только это ТЗ и перечисленные места.

**Зачем (словами пользователя):** Каталог поставщиков и склад — не два списка одних болтов. Одна номенклатура: к позиции — поставщики и история цен; в заявке сам подставляются последний поставщик и цена; размеры вроде 10×100 удобно фильтровать. Продукция (что делаем сами) — отдельно.

**Класс:** XL · **Max agents:** 4 · **Reviewers:** analyst ✅ · architect после фазы 2–3 · qa после фазы 2 · designer если новый UI заявки · **Max review loops:** 2 · **Проверки:** smoke на фазах 2–3; full перед выкладкой если трогали `backend/src`  
**Язык менеджера (UI):** да · **Приёмка:** заявка глазами — выбрал позицию → видны поставщик и цена; каталог — связь с позицией; склад — фильтр по размеру на метизах

## Shared pack

- **Решение:** PRODUCT 2026-11-03 «Единая номенклатура»; QUESTIONS ЕН-1 / ЕН-2 приняты.
- **Договор слоёв:**

| Слой | Смысл | Коллекция |
|--|--|--|
| Номенклатура | Что покупаем и храним | `materials` (+ `storageitems`) |
| Продукция | Что делаем сами | `products` — не смешивать |
| Оферта | Поставщик + цена в прайсе | `supplieritems.materialId` → material |
| Факт закупки | Купили реально (без НДС) | `materialprices` → `lastPrice*` на material |
| Снимок заявки | Что просим сейчас | `supplyrequests` |

- **ЕН-1:** в заявку — последняя **закупка** (`GET /materials/:id/price-default`). Прайс каталога — подсказка, заявку сам не переписывает.
- **ЕН-2:** заявка без позиции склада ненормальна: выбрать или создать позицию; в заявке остаётся снимок названия.
- **НДС:** `lastPrice` / materialprices — **без НДС**; `priceHint` в заявке — **с НДС**. Не копировать число один в один без явного правила (пока: подставлять сумму как ориентир + подпись «без НДС, в заявке укажите с НДС» или оставить цену пустой и только поставщика — **решение исполнителя зафиксировать в отчёте**, предпочтение: подставить поставщика всегда, цену — только если в UI явно помечено «без НДС → проверьте»).
- **Фильтры 10×100:** не новая сущность. Уже есть `dimensions[]`, `assortment`, `materialGrade` + разбор имени (СКФ.7). Нужны заполнение и UX, не «поля фильтров» отдельной таблицей.
- **CRM:** `materials`, `supplyrequests` общие. Новые поля только необязательные. Не писать прайс в `pricePerUnit` / `supplierId` без отдельного решения (CRM показывает их как «одна цена / один поставщик»).

### Фаза 1 — M: заявка с автоподстановкой (первая к исполнению)
**Что сделать**
1. В форме новой/правки заявки при выборе позиции склада (`materialId`) вызвать `GET /api/materials/:id/price-default`.
2. Подставить `supplierId` / имя поставщика из ответа; цену — по правилу НДС выше (не ломать пустые поля, если истории нет).
3. Если есть строки каталога с этим `materialId` — показать подсказку «В каталоге сейчас …» (read-only), не затирая поля заявки.
4. Пустые: «Ещё не закупали — укажите поставщика и цену сами».
5. Не менять старые заявки пакетом.

**Файлы читать:**  
`backend/src/modules/material/material.controller.ts` (price-default ~52+) · `material-price.service.ts` (~48–60) · `backend/pwa/sections/requests.js` (suggest ~126–140, form fields, toBody ~450) · `backend/pwa/core/stock-list.js`  
**Менять:** в основном `backend/pwa/sections/requests.js` (+ точечно API только если не хватает полей в price-default).  
**Вид:** эталоны kit формы/подсказки; без новых CSS раздела.  
**Приёмка qa:** выбрал позицию с историей → поставщик заполнен; без истории → пусто + подсказка; прайс новее не затирает закупку; smoke pwa.

### Фаза 2 — M: каталог без дублей имени
1. Список/очередь строк `supplieritems` без `materialId` — «Связать с позицией».
2. Поиск позиции — только `/stock/items` / lookup (уже есть ~supplier-catalog.js:281).
3. Запрет создавать «новую номенклатуру» из каталога без явной кнопки «Создать позицию склада».
4. Не удалять и не переименовывать materials из каталога.

**Читать:** `supplier-item.schema.ts` · `supplier-catalog.service.ts` · `backend/pwa/sections/supplier-catalog.js`  
**Приёмка:** строка без связи помечается; связь сохраняется; повторная связь не плодит material.

### Фаза 3 — L: размеры и фильтры
1. Скрипт план→`--apply`: вытащить резьбу/длину/толщину из `name` в `dimensions` / assortment где пусто (осторожно, только пустые поля).
2. UX склада: фильтры СКФ.7 опираются на заполненные поля + имя.
3. Прод-скрипт — только с разрешения на `--apply`.
