## Что вернуть
- Дополнение владельца по второму снимку: узкий экран, меню скрывается влево, поля только необходимые для заполнения. На этих двух экранах при ширине до1500px меню выезжает поверх по существующей кнопке, не занимает место таблицы; закрытие кнопкой/фоном/Escape/переходом. Стили только `.shell:has(.pg-worker)`, без изменения остальных экранов/сохранённых ширин меню. Основные ячейки — размер/длина/мойка и количество; у листов ещё примечание. Название/код и примечание трубы доступны в раскрываемых подробностях, не занимают постоянную колонку. Бронь/free второстепенны, запреты пересчёта и неопределённость всегда видимы.
- Трубы — матрица, блоки профильная/круглая/нержавеющая (по подтверждённому структурному виду), внутри отдельные материал/марка и единица учёта. Строки сечения, столбцы мойка + фактические длины единицы. Длины из данных (включая нестандартные/неизвестные), не только6/12. Количество в ячейке — фактический остаток в unit, заголовок/подпись прямо называет unit, например «6м · остаток, м». Не называть вычисленный метраж штуками. Нет общего итога разных единиц/длин. Бронь и свободно рядом с соответствующим количеством.
- Нельзя терять записи из-за совпадения сечения/длины/мойки. При коллизии одинаковых координат — дополнительные явно подписанные строки (название/код); не перезаписывать ячейку Map, не суммировать разные материалы. Неизвестное сечение не становится нулём, исходное имя доступно; обрезки не скрывать.
- Пустая клетка без материала — «—», без input/POSTсоздания. Добавление/приёмка — существующими guardedдействиями. Нулевой материал виден и отличается словами, не только цветом; редактирование только при подтверждённом countMode single.
- Листы — блоки марки/поверхности/unit, строки толщины и формата; количество, бронь/свободно и примечание крупными рабочими ячейками, обрезки отдельными строками с явной пометкой; исходное имя/код доступны без длинной стены колонок.
- Чёткие границы ячеек, 48pxвысота основных полей, крупные цифры, чередование строк/видимый фокус/липкая шапка, клавиатура Enter/стрелки/Tab и Escape. После сохранения следующая ячейка не должна терять фокус из-за полной перерисовки.
- ReadOnly показывает ту же матрицу, но без writehandlers (директорский дополнительный просмотр и «Смотретькак» не разблокировать). Настоящие роли pipe/sheet сохраняют ввод. Синтетические события в readonly не пишут.
- Сохранить серверный scope зоны/поиск/фильтры/сортировку и страницы, без cap10000; матрица показывает текущую страницу явно, не создаёт впечатление полной при частичнойвыдаче. Пагинация не нужна только если настоящий набор меньше PAGE_SIZE.
