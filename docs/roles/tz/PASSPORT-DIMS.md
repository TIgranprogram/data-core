# ПЧ-4. Габариты паспорта: буквы на чертеже + таблица-расшифровка

Класс L. Автор: аналитик, 2026-10-30. Код не затронут.

## 1. Как сейчас
- Схема `product-passport.schema.ts:113-122`: плоские числа `height`, `length`, `width`, `weight` (мм, кг). Посадки, опор, объёма перевозки нет.
- PDF (`passport-pdf-v2-layout.ts:16,163`): таблица «Габаритные размеры и масса изделия» из 2 колонок (Наименование / Значение), 4 строки, только заполненные.
- Рисунок: картинка вида `dimensions` из `images[]` (`passport-pdf-v2-refs.ts:47`, группа «Габаритные размеры и виды», 4 на лист). Это готовый чертёж, загруженный как файл. Буквы на нём нарисованы заранее и с таблицей не связаны.
- Мастер, шаг «Размеры и вес» (`passport-wizard.js:17,171-200`): 4 поля, готово при height+length+width.
- «Из продукции» (`showcase/passport-defaults.ts`) размеры не переносит, список NUMS только про пользователя и площадку. Версий изделия в паспорте нет.

## 2. Решение (просто)
- Паспорт выдаётся на одно изделие, значит одна версия = один паспорт. Таблица в PDF показывает только её значения (одна колонка «Значение»). Колонки версий не нужны.
- Чертёж один на все версии: на нём только буквы (L, B, H, Bп, Hп). Хранится как обычная картинка вида `dimensions` (у модели/типа изделия), менять его при смене версии не надо.
- Значения: новое поле паспорта `dims` — массив `{ code, name, value, unit }`. Коды фиксированы: L Длина, B Ширина, H Высота, Bп Ширина посадки, Hп Высота посадки (мм); дополнительно без букв: `supports` Количество опор (шт), `shipVolume` Объём перевозки (м3), вес — существующее `weight` (кг).
- Старые `length/width/height` остаются как есть и считаются L/B/H: PDF берёт `dims`, если он есть, иначе старые поля.
- Версии на уровне изделия (витрина): значения размеров для каждой версии (1,5 м / 1,8 м) хранятся в карточке версии изделия, при «Выпустить паспорт» подставляются в `dims`. Это источник «паспорт собирается автоматически». Точное место в продукте/витрине выбирает архитектор (схемы showcase в моих файлах не найдены: в `showcase/` только `passport-defaults.ts`, без размеров).

## 3. Что меняется
- Схема: `dims[]` (необязательное, без миграции); `PASSPORT_IMAGE_KINDS` не меняется.
- Мастер: шаг «Размеры и вес» показывает строки по буквам: «Длина (L), мм», … , поля для опор и объёма перевозки; пустые можно оставить.
- PDF: под рисунком таблица «Обозначение / Наименование / Значение», подпись «Длина (L), мм — 1 500». Пустые строки не печатаются. Старые паспорта без `dims` печатаются как раньше.
- «Выпустить паспорт»: переносит размеры выбранной версии.
- Тесты: `passport-pdf-v2.spec.ts` (таблица с dims и без), `passport-defaults.spec.ts`.

## 4. Критерии приёмки
- Если у паспорта есть `dims`, то в PDF под рисунком таблица с буквой, названием и значением; пустые строки не выводятся.
- Если `dims` нет, то PDF печатает прежнюю таблицу из height/length/width/weight, без ошибок.
- Если выпускают паспорт из изделия с версией 1,8 м, то значения в мастере = значения этой версии, серым (можно поправить).
- Если сменить версию с 1,5 на 1,8 в изделии, то рисунок не меняется, меняются только числа.
- Если в мастере поле очищено, то строка в PDF исчезает; число хранится как есть, с запятой на экране.
- Старый паспорт открывается, правится и печатается без миграции данных.
