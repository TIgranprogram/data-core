# C266 — аудит списков (полировка)

**Вердикт: FAIL.** Светлая тема, стенд `http://localhost:3102/app/`, вход `api.sh stand` (менеджер). Ширина 1440×900 — все экраны; склад ещё 1920 и 1024. Телефон и тёмную тему не смотрел.

Полоска из‑под шапки — это не скроллбар. На списке шапка должна быть `position: relative` и непрозрачная (`background: var(--bg)`), страница не крутится, крутится таблица. Правило CSS срабатывает только у `.main > .page > .list-screen` (`panels.css` ~197).

Эталон **Остатки** на снимках держит норму §3.0. Ломаются списки, которые вложены не прямо в `.page`.
