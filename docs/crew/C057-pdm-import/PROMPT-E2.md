Ты — исполнитель задания **C057-Э2** в проекте data-core. Роль одна: разработчик настольного приложения на C#. Координатор — другая сессия; она параллельно делает серверную часть (Э1). С ней ты не пересекаешься по файлам.

**Прочитай и работай строго по ним:**
1. `docs/crew/C057-pdm-import/TZ-E2-APP.md` — твоё ТЗ (что сделать, приёмка, запреты).
2. `docs/crew/C057-pdm-import/CONTRACT.md` — формат `pdm-tree/1` и запросы к серверу. Не менять.
3. `docs/crew/C057-pdm-import/ANALYSIS.md` — только разделы 2, 5а, 5б (таблица «PDM → наша запись»), 5г, 5д.

**Главные правила:**
- PDM — **только чтение**. Никаких CheckIn/CheckOut/SetVar, никаких записей в локальный вид `C:\PDM`. Файлы — `GetFileCopy` во временную папку приложения (как программа «Раскладка 5.1.3», её код указан в ТЗ).
- SolidWorks не вызывать: у администраторов его может не быть. Нужен только клиент SOLIDWORKS PDM.
- Твои пути — **только** `apps/pdm-loader/`, `docs/crew/C057-pdm-import/REPORT-E2.md`, `docs/crew/C057-pdm-import/samples/`. `backend/`, `pult/`, остальные `docs/` не трогать: там работают другие.
- Коммит только своих путей: `git commit -- <пути>`; никогда `git add -A` / `commit -a`. Сообщение — по-русски, `feat(pdm-loader): …`, последняя строка — `🏠 Продолжаю работать дома` (недоделанное — строкой `⚠ Недоделано: …` перед ней). Пуш после каждого законченного шага.
- **Эталон** приёмки — подетальная спецификация `6104.0000.0000_BSUP_SD.xlsx` (берётся из PDM той же программой): количества должны совпасть 110 из 110. Без совпадения задача не готова.
- Количества — **Computed BOM PDM**. Если он не читается — остановись и опиши в REPORT, что пробовал; не выдумывай количества из дерева ссылок.
- Всё, что видно пользователю, — по-русски, без английских слов и кодов.
- Ответы пользователю — коротко, предложения ≤ 20 слов. Вопросы — только если без ответа нельзя продолжать; иначе допущение + пометка в REPORT.

**Порядок:**
1. Каркас проекта + вход в PDM + поиск 6104 → коммит.
2. Computed BOM + «Продвинуть» + сверка с эталоном → коммит.
3. Переменные, развёртка DXF, документы, картинки → пакет `samples/6104.pdm-tree.json` → коммит.
4. Окно (вход на сайт, дерево, «Сохранить пакет», кнопки сайта) → `dotnet publish` → коммит.
5. Когда сервер Э1 готов (координатор скажет или появится `POST /api/pdm-import/preview` на `http://localhost:3001`) — подключить «Проверить на сайте» / «Загрузить на сайт» по CONTRACT.

**Итог:** `REPORT-E2.md` по формату из ТЗ; в чат — ≤ 12 строк: что готово, цифры сверки, что нужно от сервера.

Начни с первой строки: «Я — исполнитель C057-Э2», затем `git pull` и чтение трёх файлов.
