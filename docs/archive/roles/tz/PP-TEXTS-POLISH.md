# Шлифовка текстов справочников «Паспорта» — таблица для решения (ПВ2, 2026-10-25)

Источник: выгрузка прода 2026-10-25 (`для анализа/паспорта-2026-10-25/pp-dicts.json`), записи в корзине не смотрели. Скрипт: `backend/scripts/passport-texts-polish.js` (план по умолчанию; `--apply` — запись; `--out` — выгрузка «до записи» для отката). Ничего не удаляет; каждая правка — по id записи и только если значение на месте равно «было».

## Сводка

- Проверено: 6 категорий, 20 нормативов, 27 элементов, 35 материалов, 15 дефектов, 6 способов установки, 39 фраз («Назначение»/«Установка»), 15 записей оформления. Не смотрели: размеры (119) и части (26) — это названия, не тексты; шаблоны `passporttemplates` и тексты «Для всех» — в коде.
- Правок в скрипте: **32**, из них **11** — заполнение пустых, остальное — исправление слабых формулировок.
- Состояние в целом хорошее: пустых текстов мало, обещаний «всегда/навсегда/гарантируем» нет, привязки к конкретному изделию нет, фразы «Назначение/Установка» менять не нужно.
- «Нормативы»: `name` уже краткое обозначение, полное в `title` — править нечего.
- Ссылки `{std:КОД}` в текстах справочников **не подставляются** (подстановка работает только в блоках шаблона «Для всех»), поэтому в справочниках ГОСТы не называем — только «указанный изготовителем» / «по схеме установки». Нормативы с кодом — в поле «Норматив» элемента.
- Выпущенные паспорта не меняются (у них снимок текста `textSnapshot`); новые тексты попадут в паспорта, составленные после записи.

## Не меняли — решает пользователь

1. **Статус «проверить»** у 12 нормативов (ГОСТ 34614.1, 34615, Р 55677/55678/55679, Р 2.601, 15150, 26653, 9.014, 12.3.009, СП 70, СП 325): без проверки актуальности по официальному источнику я не вправе менять статус и не выдумываю замен. Особо проверить ГОСТ Р 52301–2013 и ГОСТ Р 55677/55678/55679–2013 (детская площадка/спорт) и точное наименование ГОСТ Р 57538–2017.
2. **Числа по умолчанию в категориях**: «Уличный тренажёр» — рост от 1400 мм, вес 120 кг; срок службы 10 лет (5 для благоустройства); гарантия 12 мес. Это обязательства компании, в нормативе их нет — подтвердить, что именно так обещаем (правка подсказки «обычно до 120–150 кг» убрана скриптом, значение по умолчанию 120 оставлено).
3. **Норматив пуст** у элементов: скамья, баскетбольная стойка, волейбольные стойки, ворота, ограждение, урна, навес, вазон, беседка, стол, стенд, велопарковка. Для благоустройства норматива в справочнике нет; для спортивных стоек — подтвердить (ГОСТ Р 55678?) — не назначал.
4. **Норматив у элементов в нескольких категориях**: «Турник», «Брусья», «Скамья для пресса» (категории TRN, WRK, DSP) привязаны к ГОСТ Р 57538 (тренажёры); для детского спортивного (DSP) это может быть неверно.
5. **Связь материал ↔ дефект двусторонняя** (`materials.defects` и `defects.applies`). Скрипт дописывает только сторону материала (поликарбонат, композит, бетон); чтобы дефекты попали в таблицу ТО, нужно добавить коды этих материалов в «К чему относится» соответствующих дефектов (CRACKS_CHIPS, DEFORMATION, SHARP_EDGES, COATING_PEEL). Это правка тех же справочников — сделаю по «да» отдельным шагом. Сейчас, например, у стали с порошковой окраской нет дефекта «Ослабление резьбовых соединений» в списке материала, хотя в дефекте она указана.
6. Требование «ТР ЕАЭС 042 — только для DIO/DSP» в справочниках соблюдено (он в «Категориях» только у DIO); для тренажёров — ГОСТ Р 57538. Тексты «Для всех» (код `passport-texts.v2.json`) не трогал: они уже написаны по юридическому образцу (ответственность эксплуатанта, изменения конструкции — с согласия изготовителя, журнал осмотров).
