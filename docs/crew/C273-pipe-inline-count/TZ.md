# C273 — быстрый пересчёт труб

Класс M, рабочий экран «Труборез». В таблице остаток в целых штуках. Сохранение по Enter или выходу из ячейки; Escape отменяет изменение. При достоверной длине две трубы по 6 м сохраняются как 12 м. Существующие записи в штуках сохраняют свою единицу учёта. В раскрытой строке виден общий метраж, в том числе для старого некратного остатка. Обычная и нержавеющая сталь различимы по подписям и цвету шапок.

Эталон — рабочая сетка C269, §4 DESIGN. Проверить существующую и пустую ячейки, клавиатуру, некратный метраж, ошибку записи и конфликт, соседний остаток, обе темы и режим просмотра. Если координата неоднозначна из-за совпавших сечений, название материала видно в раскрытии, а пустая ячейка остаётся прочерком. Сверить открытые критические пункты по CONTROL и BACKLOG. Использовать изолированные данные для проверочной записи.
