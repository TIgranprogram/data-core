## Находки по важности
1. 🔴 «Таблица» с первого раза не срабатывает. Причина: ui/list.js:67 — кнопка делает `saveView('')` и `patch({view: undefined})` (у products нет gallery.default). Если вид «Галерея» хранится в localStorage (`dc-view-products`), а в адресе `?view` нет, адрес после patch тот же; `go()` (core/router.js:37) выходит при `url === location.hash` — перерисовки нет. Вид читается из localStorage только в `st()` при update. Поправить: «Таблица» всегда ставит явный `view: 'table'` (когда у списка есть gallery/board), `st()` трактует `table` как таблицу и сильнее saved-вида. Заодно «Галерея» — явный `view: 'gallery'`. Проверить на «Паспортах», «Проектировании».
2. 🔴 «Зелёные кружки» в начале строк = колонка галочек `td.pick` (form.css:136–143; `accent-color: var(--primary)`, opacity .3 всегда видны на ПК). Выглядят как статус. Убрать колонку из обычного режима: галочки только в режиме «Выбрать» (как на телефоне, form.css:86), либо появляются по hover. Не удалять bulk — кнопка «Выбрать» остаётся.
3. 🟡 Таблица тесная: фото `.pic` 36 px (screens.css:178), `td.pic-cell` 44 px. Нужно: фото 72×72 (`.pic-lg`, только в products — не менять общий `.pic`), `td.pic-cell` 88 px, высота строки ≥ 88 px, `object-fit: contain` на `--paper`/`--surface-3`. Название — 2 строки (не `clip` в одну), артикул под названием мелким `--muted`. Колонка «Тип · Группа» уже `md-hide`.
4. 🟡 Карточки изделий (products.js:234–239, screens.css:709–718): мелко (`minmax` в .gal — проверить ≥ 220), фото `contain` на `#fff` (ок для чертежей, но `#fff` — не токен: ввести `--photo-bg`, светлый в обеих темах), заголовок 13 px, мета склеена в одну строку «арт. · серия · цена». Новая раскладка: фото 4:3 крупно; под ним название (600, 2 строки); строка «арт. NNN · серия» `--muted`; цена отдельной строкой справа/снизу жирно (`--heading`); «нет цены» — бейдж `warn` вместо цены (уже есть «черновик»). Сетка: `repeat(auto-fill, minmax(240px, 1fr))`, gap `--s4`; 390 px — 2 колонки minmax(0,1fr), gap `--s2`.
5. 🟡 Landing (products.js:169–187) показывает ВСЕ разделы сразу с плитками групп — длинная страница. Нужно три плитки раздела, потом подкатегории (раскладка ниже).
6. 🟡 `art.innerHTML = catArt(...)` (products.js:165) — допустимо (статичный SVG), но оставить комментарий; для картинок разделов лучше `<img>` из `/pwa/img/sections/*.svg|webp`.

## Раскладка первой страницы
- h1 «Продукция». Под ним — три плитки раздела (`.sec-tile`): «Оборудование для благоустройства территории», «…для детских игровых площадок», «Спортивное оборудование». Сетка 3 колонки ≥ 1024 (плитка: картинка 16:10 сверху, название h3 600 / 2 строки, «N изделий» `--muted`, кнопка-шеврон ▾); на 390 — 1 колонка, плитка горизонтальная (картинка 96 px слева, текст справа), высота ≥ 72 px.
- Клик по плитке раскрывает под ней (на ПК — под всей строкой плиток, на телефоне — под плиткой) панель подкатегорий — те же `.cat-tile` (минимум 160 px, 2 колонки на 390). Плитка раздела: `aria-expanded`, `aria-controls`, активная — рамка `--primary`. Анимация: `grid-template-rows: 0fr → 1fr` + opacity, 180 мс, `prefers-reduced-motion` — без анимации. Без перезагрузки: все группы уже в `/showcase/groups` (parentId = раздел; count), раскрытие — переключение классом, запрос не повторять.
- В панели: заголовок «Группы раздела …», кнопка «Весь раздел →» (`btn btn-ghost`, ≥ 44 px на телефоне) и «Все изделия списком». Клик по группе — `groupId` → галерея изделий (как сейчас). Раскрытый раздел запоминать в `sessionStorage` (возврат «назад» видит то же).
- «Весь раздел»: сейчас pick(t.id) даёт галерею «раздел › группа» заголовками h3 — оставить, но добавить над галереей строку-путь «Продукция › Раздел» (ссылки) и якорные чипы групп (`.chip`, прокрутка к секции). Заголовки групп (`.gal-head`) сделать sticky нельзя — только крупнее: h3 `--fs-lg`, число справа.
- Три раздела: соответствие названий разделов категориям — по `name` из `/showcase/groups` (parentId пуст). Раздел без групп — сразу открывает галерею (без панели). Прочие разделы (если появятся) — под тремя, строкой «Другие разделы».

## Токены
Только var(--…): `--surface`, `--paper`, `--border`, `--border-strong`, `--primary`, `--muted`, `--heading`, `--shadow-sm/-lg`, `--s2…--s5`, `--radius`. Новый токен `--photo-bg` (светлый #f6f7f9 / в тёмной темы тоже светлый, чертёж на белом читается; контраст подписи не задет) — обе темы в base.css. Новый компонент `.sec-tile` внести в DESIGN §4 и §8 (запись о дате).

## 390 / 1024 / 1920
390: без горизонтальной прокрутки, плитки раздела — 1 колонка, подкатегории — 2; кнопки ≥ 44 px; таблица на телефоне — карточки (`L.card`), там `thumb` 36 → 56 px. 1024: 3 плитки раздела в ряд, подкатегории 3–4 в ряд. 1920: контейнер ограничить `max-width` ~1600, сетка изделий `auto-fill`.

## Доступность
Плитки — `button`, фокус `:focus-visible`, `aria-expanded`; изменение панели не отнимает фокус; картинки `alt=""` (название рядом).
