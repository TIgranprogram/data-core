## Что просил владелец

Левая колонка была стеной текста — нужны панели. Крестик ✕ — квадрат, чуть красный. Книжка закрывается только крестиком.

## Ок по коду

- Колонка 420px, фон `--bg`. Три карточки `.bk-panel`: «Страницы», «Сначала», «Выбор для текстов». Шапка панели `--surface-2` с нижней линией, тело `--surface`.
- Тип паспорта и путь изделия — текст в плашке `.bk-path`, не список смены группы. Воронка эталона `funnelBox` внутри третьей панели; выбранный шаг сворачивается в строку.
- Общие страницы серые (`.is-calm`). Страницы с изделием или ручным текстом — синий номер (`.is-hot`).
- Очередь до 8 строк. Слова «обязательно / срочно / желательно» рядом с цветом. Пусто, загрузка и ошибка очереди — русская фраза в панели.
- Крестик книжки: `iconButton` + `k-close`, 40×40 (на узком и пальце 44), радиус `--radius-sm`, покой `--danger-soft` и `--danger`. Подпись «Закрыть книжку». Правило `.btn.k-icon.k-close` сильнее серого `.bk-acts .btn-ghost`, в покое квадрат остаётся чуть красным.
- Фон окна без щелчка. Esc в захватчике гасит всплытие и только отменяет открытое поле. Закрытие — `requestClose` на крестике; несохранённое поле спрашивает подтверждение.
- Тот же `.k-close` на крестике правой панели карточки (`card.js`).

## Находки

### P0

Нет.

### P1

1. **Тёмная тема, белое на светло-красном.** Заливка `--danger` (#f0756d) с цветом `#fff` даёт контраст около 2.8:1. Так нарисованы: крестик при наведении (`.btn.k-close:hover`, `kit.css` 61–62), плашка «обязательно» (`.bk-focus-tag`, `kit.css` 1110), крестик уведомления при наведении (`.ntf-x:hover`, `screens.css` 1085). В светлой теме белый на #c2372d читается (около 5.9:1), покой крестика тоже читается. На заливке нужен `var(--on-danger)` (в тёмной теме это #1f0b09).
2. **Текущая страница в оглавлении не отмечается.** Стили `.is-current` и `[aria-current=true]` есть (`kit.css` 1025–1029). `book-editor.js` ставит только `is-hot` или `is-calm`. После перехода строка не остаётся выделенной.

### P2

1. Три панели в одной прокрутке, шапки не липкие и не сворачиваются эталоном `section`. На длинном паспорте «Сначала» уходит под список страниц. Заголовок панели 12.5px капитель, эталон заголовка блока — `--fs-h3` 16px.
2. Паспорт только для чтения: «Выбор для текстов» очищается, пустая рамка `.bk-panel` остаётся (`book-choices.js` 55).
3. Крестик уведомления 32×32 и класс `.ntf-x`, не `.k-close`. Своей обводки `:focus-visible` нет. На ширине ≤720 высота 44.
4. Строка страницы 40px. На телефоне зона короче 44px. Приоритет владельца 16.11 — компьютер; на 390 колонку 420px не сжимать в этой задаче не блокирует, окно книжки на узком экране обрежет лист (`overflow: hidden` у `.modal.bk`).
5. У строк оглавления нет своего `:focus-visible` (это сырая `button`, не `.btn`).
6. Ширина полосы «Сначала» задана `style` (`book-focus.js` 75) — линтер R5. Классы `bk-toc-pages` / `bk-toc-focus` без CSS.

## Глазами (прогноз по стилям, экран не открыт)

1. Слева три белые карточки на сером поле: страницы, очередь, выбор текстов.

3. Тип паспорта и путь каталога — отдельная плашка внутри третьей карточки, без выпадающего списка.
4. Общие страницы серее, страницы с правкой изделия — с синим номером. Какая открыта — не видно.
5. Крестик в шапке — квадрат со скруглением, бледно-красный, буква красная. При наведении заливается красным.
6. В тёмной теме залитый крестик и слово «обязательно» белеют на светло-красном и сливаются.
7. Уведомление закрывается таким же цветом, но квадрат меньше.
8. Esc и щелчок мимо листа книжку не закрывают — это только по коду.
