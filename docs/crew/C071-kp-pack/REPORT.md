# C071 — отчёт: пакет КП от нескольких фирм

**Исполнитель:** Cursor · **Дата:** 2026-11-11 · **Класс:** L

## Сделано

### Часть 1 — сервер
1. `offer.schema.ts` — необязательный `packId` (string, sparse index).
2. `POST /offers/:id/copies` — тело `{ companies:[{companyId, markupPercent}] }` (1–10, наценка −50…200); DTO `OfferCopiesDto`.
3. Поведение: проверки до записи; общий `packId` на исходное + копии; цены через `markedUp`; у копий — НДС и `terms` новой фирмы (`defaults`); бланк — без `bg1Id` (resolve по фирме).
4. 400 по-русски: та же фирма, повтор, не наша, нет бланка («У фирмы «…» нет бланка КП. Загрузите бланк: Контрагенты → Наши компании»).
5. `GET /offers?packId=` + поля `packId`/`packSize` в списке и карточке.
6. `GET /offers/companies` — `hasBlank`.
7. Юнит `offers.pack.spec.ts` (наценки, 400, packId); e2e `offers-pack.e2e-spec.ts` (исходное+2 → 3 КП, +3%/+5%).
8. `docs/MAP.md`, `docs/openapi.json` (маршрут + DTO).

### Часть 2 — экран
1. Действие «КП от других фирм» → модалка: `tagPick` фирм, наценка %, сумма, итог «Получится N КП», «Создать N КП».
2. Без бланка — серым в подсказке + кнопка «Наши компании».
3. Память выбора: `localStorage` `dc-offer-pack-prefs`.
4. Блок «Пакет» в карточке + «Скачать все PDF» (ZIP в браузере).
5. Список: метка «пакет из N».
6. `kp.js`: фирмы из `/offers/companies`, умолчания `/offers/defaults`, срок **10 дней** (как форма).
