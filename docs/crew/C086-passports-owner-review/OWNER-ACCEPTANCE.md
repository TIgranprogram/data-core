# Приёмка владельца — уточнение 12.11

Главный результат: утром менеджер выпускает паспорт по реальному изделию без помощи разработчика.

- Тексты выбираются по категории и назначению изделия; нерелевантные варианты не мешают.
- Размеры, масса и специфические характеристики берутся из модели/подтверждённых данных. ИИ не выдумывает их.
- У каждого места рисунка видны назначение, требуемое число изображений и понятная подпись: что именно показать.
- Ясно, нужен общий чертёж с размерами или отдельные виды; правила должны соответствовать действующему шаблону PDF.
- Перед выпуском пользователь может проверить результат печати: куда попало изображение, сохранены ли пропорции, нет ли обрезки размеров/подписей.
- Фокус и вставка Ctrl+V предсказуемы; выбор файла отдельной кнопкой.
- Проверить сохранение → повторное открытие → выпуск → PDF.

Пожелание на следующий этап: редактирование прямо на визуальном листе паспорта с местами рисунков, похожем на итоговую печать. Сегодня не переписывать редактор ради этой идеи; ясные подписи и достоверный предпросмотр обязательны.
