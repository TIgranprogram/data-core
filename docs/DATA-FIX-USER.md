# Данные, которые правит пользователь сам (напоминание)

> Решение пользователя 2026-10-21: **данные на проде агент не правит** — здесь только список, что поправить руками в приложении.
> Отметьте `[x]`, когда сделано. Агенту — не выполнять, только дополнять список.

## Склад

- [ ] **Болт M10x100 DIN 933 — ошибочная корректировка −931.** «Остатки» → позиция → «Последние движения» → у «Корректировка −931» нажать «Отменить», затем «Пересчитать (сколько лежит)» и ввести, сколько лежит **всего, вместе с бронью**. Новое окно покажет «по учёту → станет» до сохранения.
- [ ] **Гайка DIN 934 — остаток 2 894, а по движениям +2794 −1963 +1963.** Лишние +100 — похоже, остаток поменяла загрузка из Google-таблицы (лист «Склад») без движения. Пересчитать позицию по факту.
- [ ] **Вес 1 шт. у 109 позиций (метизы).** В базе записаны граммы в поле «кг». Приложение уже показывает их верно, как граммы. Если вес где-то неверный — «Изменить» → «Вес 1 шт., г». (Есть готовый скрипт, который переведёт все разом в кг для CRM: `backend/scripts/weight-grams-to-kg.js` — запускается только по вашей просьбе.)

## Склад — артикулы (АР)

- [ ] **72 позиции с внутренним кодом СКЛ-… вместо артикула поставщика**, а в заявках на них артикул есть (Микрометр Тундра → 90664165, Заглушка 57.2 → ILT57,2, Подшипник 6205 → 6205 2RS и т. д.). Видно в «Требуют заполнения» → «Артикул в заявке другой»: «Заполнить» открывает поле «Артикул». Новые заявки и приём теперь переносят артикул сами. Разом — скрипт `backend/scripts/articles-from-requests.js` (только показывает).
- [ ] **«Сиденье Forto без подвесов СФБОЧ-КсОК»** (СКЛ-2026-224): в заявке №103 тот же артикул СФБОЧ-КсОК, что у «Сиденье Forto, 465х275х220» (уже поправлено). Артикул должен быть уникальным → решить: это одна позиция (объединить) или у второй другой артикул.

## Заявки — поле «Заказчик»

Сейчас «Заказчиком» в заявках записаны в основном участки и места. Заказчик теперь выбирается из «Контрагентов», участок — в поле «Объект СМР / уточнение».

| В заявках сейчас | Заявок | Что сделать (на ваше усмотрение) |
|--|--|--|
| Производство | 104 | не заказчик — направление «Цех» / объект |
| Академия благоустройства | 13 | заказчик? → завести в «Контрагентах» или перенести в объект |
| Тахтамукай | 12 | объект / участок |
| Склад ТМЦ | 9 | направление / объект |
| Староминская | 6 | объект / участок |
| Пост ДПС | 3 | объект / участок |
| ИП Сахаджи | 2 | заказчик (уже есть в заказах) — оставить |
| ИП Сахаджи, Академия благоустройства | 2 | заказчик «ИП Сахаджи», объект «Академия благоустройства» |
| Пергола 42 | 2 | объект / участок |
| БагСтрой | 1 | заказчик? → в «Контрагенты» |
| Красивый двор Пергола 8 | 1 | объект / участок |

Как поправить: открыть заявку → «Изменить» → «Заказчик» (выбрать из списка или «+ Новый заказчик») и «Объект СМР / уточнение». Одинаковые заказчики с разным написанием — «Контрагенты» → заказчик → «Объединить с…» (заявки поправятся сами). Для массового отчёта есть `backend/scripts/customers-cleanup.js` (только показывает).
