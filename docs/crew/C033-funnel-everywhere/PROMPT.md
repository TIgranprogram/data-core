# C033 — промпт для внешнего ИИ (модель средняя: Sonnet 5.5 или похожая)

Один и тот же промпт на каждый пункт — ИИ сам берёт следующий незакрытый.

```
Ты — исполнитель проекта data-core. Работай в папке D:\data-core.
Открой docs/crew/C033-funnel-everywhere/TZ.md, возьми ПЕРВЫЙ пункт чек-листа со статусом [ ] и выполни только его по общим правилам ТЗ (эталон kit funnel, следующий шаг — только после выбора предыдущего, запретная зона не трогается, сервер не трогается).
Читай только файлы, названные в ТЗ и в пункте. Не коммить, на прод не ходи, секреты не читай.
В конце: раздел «Пункт N» в docs/crew/C033-funnel-everywhere/REPORT.md, пункт отметь [~], и ответь одной строкой: «Сделал C033 пункт N. Отчёт в docs/crew/C033-funnel-everywhere/REPORT.md».
```
