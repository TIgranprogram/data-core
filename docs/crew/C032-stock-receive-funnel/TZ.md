## Что сейчас
Панель операций склада (`stock-ops.js`, одна на 5 операций: принять, выдать, забронировать, списать, пересчитать) — блок «Добавить позицию» (`stock-ops.js:76–100`): `select` «Все категории» + поле поиска с выпадающим списком всех позиций склада. Категория — без чисел, позиции — без фото и состояния, «что недавно принимали» нет, «от кого» в примечании пишется каждый раз заново.

## Что сделать (правила П-1 — номера в скобках)
1. **Шаг «Категория» (1, 2, 3):** вместо `select` — эталон kit `segmented` с прокруткой (`scroll: true`) или `filter` mode `chips` (выбери по DESIGN §4): категории склада с числом позиций рядом («Метизы 142»), первая — «Все». Категория одна — шаг не показывать. Числа — из `GET /stock/categories` (то, что уже запрашивается в `stock-ops.js:78`; если числа нет в ответе — посчитать по `all` после загрузки).
2. **Шаг «Позиция» (2, 7):** после выбора категории — список её позиций строками kit `row` (фото — `posPic`, если есть; название; мета — остаток и единица; бейдж «нет» / «ниже минимума» — как в таблице склада), до 30 строк, клик — добавить в пачку (как сейчас `add(it)`). Поиск по названию остаётся и ищет по всему складу (шаги его не сужают). Пусто — `empty` с подсказкой «Нет в категории — найдите поиском или создайте».
3. **«Недавно» (5, 6):** над шагами — строка kit `row`-ов «Недавно: …» — последние 6 позиций, которые ЭТОТ пользователь брал в ЭТОЙ операции (запоминать в `localStorage`, ключ по операции, как уже сделан черновик `readDraft`/`saveDraft` в `stock-ops.js:60–62`). Клик — добавить в пачку.
4. **Подсказка «от кого» для прихода (6):** если для позиции уже был приход — в поле примечания строки подставить прошлое значение серым с пометкой «как в прошлый раз»; источник — тот же `localStorage` (последнее примечание прихода по `materialId`). Ручное главнее.
5. **«Дальше: …» (7):** одна строка над блоком: «Дальше: выберите категорию» → «выберите позицию» → «укажите количество» → «нажмите «Принять»» (по состоянию пачки).
6. **Размер:** новый код — в новом файле `backend/pwa/sections/stock-ops-pick.js` (≤ 200 строк), `stock-ops.js` после правки — не больше 400 строк (правило L8 линтера). Только эталоны kit, без своих классов и inline `style` (CSS-переменные можно).
7. Поведение «Создать «…»», «Отменить» пачки, брони, заявки к приходу (`receiveField`) — не менять.
