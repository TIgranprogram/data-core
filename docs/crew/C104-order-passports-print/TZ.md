# ТЗ C104 — печать паспортов заказа: те же настройки, что у одного паспорта, и выбор позиций

**Зачем (пользователь, 2026-11-13):** «Печатная реализация всего заказа паспортов — не было варианта (А4 буклет или страницы, печать, подпись и т. д.), как у нас уже сделано у единичной печати; так же выбор нескольких позиций распечатать».
**Зачем — глаголом:** менеджер в «Паспорта заказа» нажимает «Печать», отмечает нужные позиции и в одном окне выбирает формат (буклет A4 / страницы A5), печать и подпись, ч/б — получает один PDF.

**Класс:** M · **Max agents:** 2 (frontend + designer) · **Проверки:** smoke; full — перед выкладкой вместе с C103.

## Shared pack
- Сервер (делает координатор): `GET /passports/order/:orderId/pdf` дополнительно принимает `seal=0`, `sign=0` (как у одного паспорта) и `ids=<id паспорта>,<id>…` — только эти выпущенные паспорта заказа, в порядке позиций. Без `ids` — все выпущенные, как сейчас. Отменённые позиции не попадают никогда.
- Экран: `backend/pwa/sections/order-passport-plan.js:215` — сейчас кнопка сразу качает PDF с одним `variant`. Нужно окно печати.
- Окно — тот же вид, что `printDialog` одного паспорта (`backend/pwa/sections/passports/dialogs.js:99-150`): плитки формата (`pf-opt`: «Буклет A4» с подсказкой про короткий край, «Страницы A5»), «Печать и подпись» (галочки «Печать», «Подпись» — по наличию у фирмы), «Чёрно-белый». Лист для стенда для заказа не нужен.
- Сверху окна — список выпущенных паспортов заказа галочками (по умолчанию все отмечены): «№ позиции · изделие · № паспорта»; «Отметить все / Снять все». Ничего не отмечено — кнопка печати неактивна.
- Общий код окна вынести в новый модуль `backend/pwa/sections/passports/print-options.js` (плитки формата + галочки) и использовать в обоих окнах; `dialogs.js` переводится на него. После нового модуля — `node backend/scripts/pwa-preload.mjs`.
- Паспорта с готовым своим PDF (`X-Skipped-Passports`) — как сейчас: после печати список ссылок.
