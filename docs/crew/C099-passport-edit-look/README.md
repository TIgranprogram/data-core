# C099 — шаблон паспорта: один вид правки (2026-11-13)

Класс: S. Запрос пользователя: в «Шаблон паспорта» три разных вида правки рядом
(«Что это за изделие: … ✎», кнопка «Изменить», ссылка «Править текст»), строки впритык.

## Правило
- Значение правится строкой «Подпись: значение ✎» (как `fill/paint.js` filledLink и kit funnel).
- Действие с текстом — маленькая кнопка в ряд: «Развернуть», «Править текст ↗».
- Строки раздела — колонкой `k-stack` (зазор `--s3`), не впритык.

## Правки
- `backend/pwa/ui/funnel.js` — свёрнутый шаг «Назначение: … ✎» вместо «**Назначение:** … · Изменить»; «Править текст ↗» — `btn-ghost btn-sm`.
- `backend/pwa/sections/passports/fill/index.js` — `fieldHost`/`textHost` = `stack()`.
- `backend/pwa/ui/screens.css` — `.pp-ftext-act` зазор `--s2` и отступ сверху.
