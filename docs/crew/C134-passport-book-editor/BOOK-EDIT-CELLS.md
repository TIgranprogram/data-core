# C134 — правка «Где» и выбор слева

Дата: 2026-11-17

## Зачем
В окне «как PDF» клик по «Информационный стенд» (колонка «Где») ничего не делал — правилось только «Что проверить». Слева были только страницы, без смены типа/вариантов текстов.

## Сделано
1. Таблица ТО: кликабельны **Что / Где / Мера / Допуск**; у «Что» — кнопка «Удалить строку».
2. API `PATCH …/snapshot-field`: `part=where|measure|tolerance`, `remove:true`.
3. Слева после списка страниц — блок «Выбор для текстов»: тип паспорта + воронка вариантов; колонка шире (300px), плитки в один столбец с воздухом.

## Файлы
- `backend/src/modules/product-passport/passport-snapshot-field.ts` (+spec)
- `product-passport.service.ts`, `product-passport.controller.ts`
- `backend/pwa/sections/passports/book-blocks.js`, `book-editor.js`, `book-choices.js`
- `backend/pwa/ui/kit/kit.css`

## Как проверить глазами
Открыть «Изменить паспорт» → клик по «Где» (например «Информационный стенд») → правая панель → сохранить. Слева под страницами сменить вариант назначения/монтажа — страницы пересоберутся.
