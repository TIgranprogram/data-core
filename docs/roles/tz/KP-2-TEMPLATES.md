## Shared pack (решения координатора)

1. **Шаблон фирмы = бланк (`offerbackgrounds`)** + его зона текста + стандартные тексты. Новой коллекции нет.
2. **Переменные** (печатаются поверх бланка): номер, дата, заказчик, объект, таблица (№, фото, наименование + описание, кол-во, ед., цена, сумма), итого, НДС, доставка, срок действия, условия (`terms`), примечание.
3. **Константы** — в картинке бланка: название фирмы, реквизиты, «Коммерческое предложение», подпись, печать.
4. Стандартные тексты — простые строки, без подстановок `{…}`. НДС, доставка и срок действия строятся из полей КП сами, их в тексты не писать.
5. Наценка копии — округление цены строки до рубля. Копия — черновик, связь `copyOf`.
6. Предпросмотр — тот же `renderOfferPdf`, без записи в базу и без номера («КП-черновик»).

### Контракт backend ↔ frontend

- `offerbackgrounds` + поля: `textTop: number` (0–0.6, доля высоты), `textBottom: number` (0.4–0.95), `defaultTerms: string` (≤ 3000). Пусто — как сейчас (`ZONE_FIRST`/`ZONE_NEXT`).
- `POST /offers/backgrounds` — те же поля в multipart (необязательны). **Новый** `PATCH /offers/backgrounds/:id` {name?, textTop?, textBottom?, defaultTerms?, isDefault?} → фон. Встроенный — 400.
- `GET /offers/backgrounds` — в элементах ещё `textTop, textBottom, defaultTerms`.
- `commercialoffers` + `objectName?: string` (≤ 500), `vatMode?: 'with' | 'without'` (пусто → по `organizations.vatRate`: > 0 — with), `vatRate?: number` (0–30; пусто → `organizations.vatRate`, нет — 22), `delivery?: 'included' | 'excluded'` (пусто — строку не печатать), `copyOf?: ObjectId`.
- `POST /offers`, `PATCH /offers/:id` — принимают новые поля (DTO в `offers/dto.ts`; `forbidNonWhitelisted` — добавить все сразу).
- **Новый** `POST /offers/preview` — тело как у `POST /offers` (`items[].unitPrice` можно пусто) → `application/pdf`. Права — как у `GET /offers/:id/pdf`. В базу не пишет.
- **Новый** `POST /offers/:id/copy` {companyId*, markupPercent (−50…100, по умолч. 0)} → новое КП-черновик (тот же заказчик, объект, строки, условия; цены × (1 + %/100), округление до рубля; `bg1Id/bg2Id` пусто — бланк новой фирмы; `copyOf` = id). Аудит `CommercialOffer`.
- `GET /offers/defaults?companyId=` → `{ terms, vatMode, vatRate }` — стандартные тексты и НДС для новой формы.

## Что сделать

### Этап 1 — сервер (datacore-backend)
1. Схемы и DTO по контракту (`offer.schema.ts`, `dto.ts`).
2. Зоны текста бланка: `offer-layout.ts` — `zoneOf(page, zones?)`; `resolve()` отдаёт `{ jpeg, textTop, textBottom }`; `paginateRows`/`placeBlock` — с зонами бланка. Старые тесты `offer-layout.spec.ts` должны пройти без правки.
3. `offer-pdf.ts`, порядок на стр. 1 (как в образце):
   - `№ <номер>` слева, `Дата: дд.мм.гггг` справа;
   - `Заказчик: <customer>`; `Объект: <objectName>` (перенос строк, жирный);
   - таблица; фото — 80 pt, если строк ≤ 4, иначе 48 pt; строка не ниже фото;
   - `Итого: 680 000 ₽` (справа, крупно); под ним `в том числе НДС 22 %: 122 622,95 ₽` или `Без НДС`;
   - строки (серым): `Доставка до объекта включена в стоимость.` / `Доставка до объекта в стоимость не входит.`; `Срок действия коммерческого предложения — N календарных дней.` (N = validUntil − date); `Цены указаны в рублях РФ, с НДС 22 % (НДС включён в стоимость).` или `Цены указаны в рублях РФ, без НДС.`;
   - затем `terms`, `notes` (как сейчас).
   Сумма НДС — `total × rate / (100 + rate)`, 2 знака. Метки — через `common/print` (без `undefined`, `null`, `{…}`).
4. `POST /offers/preview`, `POST /offers/:id/copy`, `GET /offers/defaults`, `PATCH /offers/backgrounds/:id`.
5. Юнит: НДС (680 000 → 122 622,95), копия +3 % (680 000 → 700 400) и +5 % (→ 714 000), зоны бланка, preview не пишет в базу.
6. `docs/openapi.json` (перегенерировать), `docs/MAP.md` строка `offers`.

### Этап 2 — экран (datacore-frontend, после этапа 1, skill `datacore-design`)

Форма КП (`pwa/sections/offers.js:120–139`): в «Предложение» — «Объект» (textarea, после «Заказчик»); в «Условия» — «НДС» (с НДС / без НДС) + «Ставка, %»; «Доставка до объекта» (включена / не включена). 4. «Наши компании → Бланк КП» (`partners.js:87–125`): у бланка — «Верх текста, %», «Низ текста, %», «Стандартные тексты» (textarea); кнопка «Проверить бланк» — предпросмотр пробного КП на этом бланке.
