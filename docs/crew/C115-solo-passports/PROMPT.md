# Задание Solo

Выполни `docs/crew/C115-solo-passports/TZ.md` по `CHECKLIST.md` рядом.
Цель — закончить создание, заполнение и печать паспортов новых заказов, устранить неудобства и подтвердить полный путь менеджера.
Сначала сверь остатки C095/C096/C112/C114 с актуальным кодом; уже сделанное не переписывай.
Работай последовательно: воспроизведение → минимальное исправление → тест → проверка в браузере/PDF → отметка с доказательством.
Отдельно проверь сохранность ввода, повтор выпуска, редакции, пакет заказа, сборное изделие и книжную печать.
Изучай только точки входа из ТЗ. Не запускай собственную команду агентов; независимую приёмку передай координатору.
Данные прода, старые паспорта и общие схемы CRM не меняй; выкладку не выполняй.
Недоступную проверку отмечай PARTIAL с причиной; продолжай независимые пункты. Отчёт и доказательства сохраняй в папке задания.
