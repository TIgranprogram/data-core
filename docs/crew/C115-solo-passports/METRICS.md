# METRICS — без замеров полного пути

В этой сессии не подтверждены цели ≤3/≤5 нажатий, <1 с для открытия и плана и <10 с для выпуска 50 позиций. Для замеров нужен заполненный изолированный контур, три холодных и три тёплых повтора на каждую операцию. Длительность Jest не относится к времени менеджера.
