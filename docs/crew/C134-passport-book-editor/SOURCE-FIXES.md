# Правки источников паспортов № 601, 603 и 606

Общий шаблон: доступ при опасном дефекте или ремонте перекрывают ограждением; эксплуатацию возобновляют после контрольного осмотра; вывод по сроку службы согласован с возможностью его продления. Исправления подготовлены и для активной версии шаблона в базе: скрипт passport-templates-polish заменяет только точные совпадения, создавая новую версию. На рабочей базе не запускался.

Автоматическое описание теперь строится без согласования с родом названия: «[Название] (далее — изделие). Изделие изготовлено из …». Уже заполненные описания правятся в карточке изделия.

- № 601 / 2621: описание и назначение — в карточку изделия; правила и осмотры — только в элемент «Указатель». Исключить «Информационный стенд» из состава паспорта, если его действительно нет. Сверить способ монтажа с чертежом.
- № 603 / 2623: наименование «Стела». Описание: «Информационная стела размером 2700 × 6000 мм. Опоры бетонируют в грунте по схеме монтажа». Назначение: «Стела предназначена для размещения информации и ориентирования посетителей». До переноса описания сверить размеры и крепление по чертежу. Для стелы массой 1013,8 кг порядок подъёма и крепления брать из монтажной документации.
- № 606 / 2626: вид и категория требуют проверки изготовителем. По описанию это лаз для перелезания, а паспорт выдан как элемент благоустройства, без отдельного раздела правил пользования. До повторного выпуска подтвердить назначение, применимые требования, допустимое число пользователей, высоту свободного падения и зону приземления. Высоту изделия 1900 мм не подставлять как высоту падения. После подтверждения перенести правила из «Ухода» в правила пользования конкретного вида; в общий шаблон благоустройства эти правила не переносить.

Рабочие справочники и выданные паспорта не изменялись.
