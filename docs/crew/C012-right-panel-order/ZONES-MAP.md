# C012 — зоны карточки заказа

Оболочка не меняется: `openCard` + `.dz-main` / `.dz-side` / `.dz-wide`.
Меняется только набор блоков заказа. Один `extra` на все договоры — убрать.

Режим «одна колонка» (как сейчас по умолчанию): main, затем wide, затем side.
Режим «две колонки»: main слева, side справа, wide влит в main.
Режим «две и широкий низ»: main слева, side справа, wide на всю ширину снизу.

Пустая колонка запрещена. Если в side нечего класть (нет права на деньги и нет заказчика) — не оставлять пустой столбец: справка остаётся короткими полями в main.

## Сейчас → предложено

| Блок | Сейчас | Предложено | Зачем |
|--|--|--|--|
| Тип и заголовок «Заказ № …» | шапка ящика | шапка ящика | уже верно |
| Воронка заказа | main (`top`) | **main**, первым в теле | где заказ целиком |
| Одна фраза «что дальше» + одна главная кнопка | main, среди кнопок и полей | **main**, сразу под воронкой | следующее действие |
| Части заказа (строка на позицию) | нет на первом экране | **main**, открыто | слон на куски |
| Предупреждение «не распределено» / «не сопоставлено» | поле + плашка в extra | **main**, над списком частей, только если есть | мешает пуску в работу |
| Готовность к отгрузке | wide, после таблицы «К производству» | **main**, под частями, только пока этап «новый» или «производство» | чеклист рядом с кнопкой |
| Заказчик, наша компания, срок, приоритет | main, полями, плюс подзаголовок | **side** | справка, не фокус |
| Сумма и оплачено | main, `stats` | **side**, если роль видит деньги | деньги не впереди частей |
| Ответственный договора | только карточка договора | **side**, строка «Кто ведёт договор» или «не назначен» | не путать с человеком на части |
| Договоры: шапка, «Изменить договор», редкие действия | wide, всегда раскрыты | **wide**, группа kit на договор, свёрнута если договор не один и он не отстаёт | объём внизу |
| Таблица позиций с цветом и деньгами | вкладка «Позиции» | **wide**, внутри группы договора | широкая таблица — вниз |
| Проектирование, работа, склад, отгрузки, паспорта | вкладки, скрыты | **wide**, те же смыслы секциями kit, закрыты | не шесть вкладок сразу |
| «К производству» (сумма одинаковых) | wide, выше договоров | **wide**, закрытая секция | просмотр для цеха, не первый экран |
| История | скрыта (`noHistory`) | не добавлять в этой пачке | у заказа нет своей ленты |

## Строка части (main)

Один эталон `kit.row`, плотность как у строки списка, не вторая доска.

| Место в строке | Текст |
|--|--|
| Слева | маленькое фото, если есть |
| Название | «поз. N · название» |
| Серым под названием | «Договор …», если договоров больше одного |
| Метка этапа | одно слово по узкому месту (см. FIX-TZ) |
| Метка готовности | «сделано» или «не сделано» |
| Человек | имя или «нет ответственного» |
| Клик | карточка этой позиции, назад — «Заказ № …» |

Вкладки договора для первого взгляда не использовать. Они прячут этап части.
