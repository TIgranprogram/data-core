# Деревообработка

Настольный вход находится в группе «Склад». У роли «Деревообработка» или «Кладовщик дерева» таблица открывается после входа. Администратор может открыть её по пункту «Деревообработка» или выбрать роль в своём профиле для просмотра. Прямой адрес — `#stock?view=wood`.

Роли нужен раздел «Остатки» и доступ к зоне «Деревообработка». Для отдельного рабочего места в настройках роли оставляют только назначенную зону и выключают «Деньги». Поиск и таблица всегда передают серверу ID этой зоны и `held=1`. Если сервер не вернул доступную зону, приложение показывает сообщение и не запрашивает материалы. «Кладовщик дерева (телефон)» с единственным разделом «Склад · мобильный» по-прежнему открывает мобильный склад.

В таблице показаны материал, артикул, категория, известные размеры в мм, единица учёта, фактическое количество, бронь, свободный остаток и примечание. При пересчёте приложение отправляет штатную операцию склада с предыдущим количеством. Для просмотра роли и наблюдателя ячейки доступны только для чтения.

**Проверено 22.11.2026.** Пять сценариев в Edge прошли на синтетических данных. Проверены древесина, фанера и плита, полная бронь, поиск по артикулу, пересчёт, сохранение примечания, пустая зона, отсутствующая зона, чужая роль, мобильный режим и штатный выбор роли в профиле администратора. В отдельных тестах с MongoDB 4.4 прошли все 23 проверки физических остатков C191, зон склада и категорий. Наличие зоны в рабочей базе в этот прогон не входило.
