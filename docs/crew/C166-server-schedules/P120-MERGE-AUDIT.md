# P120: проверка двух карточек склада

Запрос владельца 20.11.2026: проверить способ объединения одного товара с разными названиями. На снимке две позиции «Круг лепестковый торцев…» при поиске P120, остатки 45 и 0, фото у нулевой позиции. Это основание для сверки, но не полный состав характеристик и связей.

Готового API объединения складских материалов в текущем stock/material контроллерах не обнаружено. Пересчёт, выдача, приём и обычное удаление не являются заменой объединения.

План безопасного объединения после сверки и отдельного согласования записи:

1. Проверить диаметр, посадочное отверстие, зернистость, тип круга, единицы и склад; P120 само по себе означает зернистость, а не уникальный товар.
2. Выбрать основную карточку; сохранить фото, дополнительные данные и прежнее название как поисковое соответствие.
3. Перенести все живые ссылки на материал с сохранением связей заявок, складских строк, броней, движений, цен и состава. Зафиксированные исходные тексты документов не переписывать.
4. Для совпадающих складских строк определить правило объединения и проверить итоговые остатки/брони. Не создавать фиктивные приход/расход и не суммировать автоматически данные разных складов.
5. Выполнить атомарно с предварительным просмотром, защитой от конкурентных операций и аудитом; дубль скрыть только после переноса ссылок.

Пока только аудит через GET. Изменений данных, удаления и объединения на сайте нет. Результаты точечной сверки API будут дописаны ниже; полную проверку всех ссылок нельзя объявлять выполненной по двум карточкам и истории.
