# Изделие 1061. Краткое описание и справочники

Рабочий `GET /api/showcase/6adaff442a8dad6034b14606/passport-template?variant=short` подтвердил вид «Тренажёр для спины» (`6af707fdc451d4c05df6a048`), категорию `TRN` из вида и отсутствие собственного описания. Источник и предложения пусты. Единственный блокер готовности — краткое описание. В проекции есть рисунки `overview`, `dimensions`, `foundation`. Из критериев выставлена только нагрузка «Собственный вес» (`6aeea9373b8b9255839ab43b`). В 158 записях `passportPhrases` ветки короткого описания для этого вида или гребной тяги нет.

| Часть в справочнике | ID | Родительный, ед. и мн. число |
| --- | --- | --- |
| Несущая рама | `6adceeeb3ca001b9b3b0e574` | несущей рамы / несущих рам |
| Рычаг | `6adceeeb3ca001b9b3b0e576` | рычага / рычагов |
| Ручка | `6adceeeb3ca001b9b3b0e575` | ручки / ручек |
| Упор для ног | `6adceeeb3ca001b9b3b0e577` | упора для ног / упоров для ног |

Все четыре части доступны в категории `TRN`. По предоставленному рисунку подходит формулировка «Тренажёр состоит из несущей рамы, подвижных рычагов с рукоятками и упоров для ног». Назначение верхней наклонной площадки по рисунку не установлено.

Критерий `6afef7611ca5b05a5ce7f2aa` `trn.contact` — «Рабочие части тренажёра». Для будущей общей фразы потребуется отдельное значение по подтверждённой конструкции. При привязке к широкому виду «Тренажёр для спины» фраза может предложиться изделиям, у которых этот критерий ещё не заполнен. Для строгой применимости к 1061 подходит описание, сохранённое в его карточке. Общую ветку можно ограничить отдельным согласованным видом. Проверка прошла только чтением, сырьё осталось в игнорируемом `tools/logs/c161-1061/`.

Первоначальный план требовал защищённого обновления `facetValueIds`. Маршрут витрины проверяет только ID и отсутствие удаления, а DTO версионируемого маршрута изделий не принимает `facetValueIds`. Согласованный план использует проверку ожидаемого пустого значения при обновлении `textChoices` в шаблоне 1061. [План записи](1061-DATA-PLAN.md)

## Результат записи

Три справочные записи созданы и отдельно прочитаны через рабочий API:

| Запись | ID |
| --- | --- |
| Значение `trn.contact.row-levers-footrests` | `6aff288afd285cf4215c7593` |
| Корень «Краткое описание — Гребная тяга» | `6aff288cfd285cf4215c759c` |
| Лист «Рычаги с рукоятками и упоры для ног» | `6aff288ffd285cf4215c75a3` |

До выбора шаблон 1061 предлагал ровно новый лист, источник оставался пустым, проверка готовности ждала подтверждения вкладки краткого описания. После одного PATCH и контрольного GET источник — согласованный словарный лист, текст совпадает дословно, паспорт готов к выпуску. В шаблоне отсутствует собственный текст. Сверка подтвердила сохранение прежней нагрузки, вида, остальных настроек, фото, размеров и веса. Паспорт не выпускался.

Повторная сверка справочников не создала дублей. По полной рабочей выдаче 492 изделий 1061 — единственное изделие этого точного вида. Отсутствие автоподстановки без явного выбора подтверждено на самом 1061 до PATCH. У 1066 словарный источник сохранился и новая фраза не появилась в подсказках. Журнал запросов и ответов хранится в `tools/logs/c161-1061/`.
