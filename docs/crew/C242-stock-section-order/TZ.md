# C242 — чистые данные и табличные представления всего склада

23.11.2026. Явное поручение владельца: привести в порядок все таблицы склада — основной, трубы, листовой материал, деревообработка. Первоначальный запрос о первом столбце и сортировке труб расширен до структурных данных, при необходимости схемы БД.

## Результат

Параметры материала, размеры, длина единицы, количество, общий остаток, бронь и свободный остаток отображаются отдельно с единицами в заголовках. Для труб первый предметный столбец «Сортамент / сечение, мм», значение вида `40×40×2`; длина одной трубы в метрах отдельно от общего метража и числа штук. Материал/состояние и идентификаторы не смешиваются с размерами. Для листов и дерева — свои подходящие параметры, без фиктивных трубных колонок.

Сортировки числовые, стабильные, по всему отфильтрованному набору до пагинации. Размеры сравниваются последовательно по компонентам; пустые/неизвестные значения явно выделены и не становятся нулём. По умолчанию трубы идут по возрастанию сечения.

## Дополнение владельца — существующая номенклатура без остатка

23.11: позицию `80×60×3` не нашли, предположительно из-за отсутствия остатка. В таблицах и поиске требуется показывать уже существующую номенклатуру с нулевым остатком: приглушённая серая строка и явная пометка «Нет в наличии». Текст остаётся читаемым и кликабельным, признак не передаётся только цветом. Позиция может быть принята штатной кнопкой; выдача/бронь при отсутствии свободного количества недоступны по прежним правилам. Полностью забронированная позиция с физическим остатком не считается отсутствующей.

Проверить по API наличие всех вариантов80×60×3,марок/длин/состояний и показать их без создания новых карточек. Не создавать storageitem ради отображения записи materials. Сохранять warehouse/category/role scope. Новый видимый ноль не должен попасть в положительный остаток итогов/счётчиков как наличие. Поиск и проверка перед «Новой позицией» должны помочь выбрать существующую номенклатуру, не дублировать её. Контракт полноты по зонам и отсутствию storageitem согласовать с архитектором до реализации; прежнее правило «только наличие» для таблиц заменено этим явным поручением владельца.
