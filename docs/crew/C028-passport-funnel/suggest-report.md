### Не определяется по названию — только ручной выбор

- wrk.size (размер комплекса) — количество снарядов в названии перечисляется словами («Пять турников-стенка»), надёжно не парсится.
- dio.age (возраст детей) — в названиях DIO возраста нет.
- dio.seats — у нынешних качелей DIO нет слов «двойные/четырехместные»; слова в seed оставлены на будущее.
- dsp.* — изделий DSP на прода 0, проверять не на чем; слова аналитика не менялись.
