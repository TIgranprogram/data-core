## 1. Перед кодом

- [ ] Нет чужой сессии на `backend/pwa/core`, `profile.js`, `main.js`
- [ ] ТЗ VIEW-AS актуален (режим B + client-only)

## 2. Порядок ролей

| Шаг | Кто | Вход | Выход |
|--|--|--|--|
| 1 | `datacore-frontend` | ТЗ | view-as + профиль + полоса + блок записи |
| 2 | `datacore-qa` | критерии ТЗ | smoke-отчёт |
| 3 | `datacore-designer` | профиль + шапка | принято / находки |

## 3. Приёмка глазами

1. Админ → профиль → «Смотреть как» → узкая роль → меню урезано, полоса «только просмотр».
2. Попытка «Сохранить» / создать запись → отказ, без запроса на сервер.
3. Снова профиль → другая роль или «как обычно».
4. Менеджер → блока в профиле нет.

## 4. Не в этой волне

- JWT `viewRole`, серверная маска денег, зоны склада
- Impersonation другого пользователя
