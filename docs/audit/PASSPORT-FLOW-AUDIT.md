# Аудит «Паспорт изделия за несколько шагов» (2026-11-01, аналитик)

Цель пользователя к 2026-11-02: Продукция → изделие → «Документация» → «Шаблон паспорта» → один редактор → печать.
Данные: копия рабочей базы `datacore-night`, только чтение. Код не менялся.

## A. Как сейчас (путь пользователя)

Входов в паспорт пять: карточка изделия, «Документация → Паспорта», «Нужно сделать паспорт», «По заказам», «Архив».
Редакторов три: шаблон изделия, полная карточка паспорта, мастер.

Путь «новый паспорт для изделия»:
1. «Продукция» → изделие. Во вкладках карточки нет «Документации». Есть строка «Категория паспорта» и блок «Паспорта» (`pwa/sections/products.js:163,379`). Кнопка «Печать паспорта» есть, только если паспорт уже выпущен (`products.js:398`).
2. Подсказка ведёт в другой раздел: «Документация → Паспорта → изделие → Выпустить паспорт» (`products.js:165`).
3. «Документация» → вкладка «Паспорта» → поиск → клик по изделию → правая панель «шаблон» (`pwa/sections/docs.js:30–110`).
4. «Изменить» → категория и выбор текстов воронкой (`docs.js:87–106`) → «Сохранить».
5. «Выпустить паспорт» → открывается ДРУГАЯ панель: черновик паспорта `of=passports` (`passports/models.js:52–65`). Там второй редактор: мастер из 7 шагов (`passports/passport-wizard.js:14–22`): изделие, категория, размеры, состав, фото, комплектность, выпуск.
6. Выпуск → номер → «⇩ PDF и печать…» (`passports/dialogs.js`).

Итог: около 12–20 кликов, 2 раздела, 3 панели. Где ломается и путает:
- Категория задаётся в трёх местах: группа каталога, шаблон изделия, мастер. Подсказка в `docs.js:76` ведёт в «Продукция → Категории», но у категорий каталога поля нет: 0 из 56 (см. B).
- Шаблон хранит только категорию и выбор текстов. Размеры, материалы и фото вводятся в черновике паспорта, а не в изделии. Следующий паспорт той же модели снова берёт их из прошлого паспорта, а не из карточки.
- «Не хватает для выпуска» видно только в черновике, на последнем шаге. Подсказки «где взять» нет.
- Печать для заказчика ничем не отличается от обычной печати. Она не создаёт отдельной записи (см. C7).

## D. Минимальный набор полей по типам

Нормативы (подтверждено ранее, `docs/PASSPORTS-V2.md` §2; сверка сегодня — частичная):
- Все изделия: ГОСТ Р 2.610-2019 (структура эксплуатационного документа), ГОСТ 15150-69 (хранение).
- Детское игровое (DIO): ТР ЕАЭС 042/2017, серия ГОСТ 34614.x (EN 1176), ГОСТ 34615 (покрытия, EN 1177), ГОСТ Р 52301-2013 (эксплуатация). Также ГОСТ Р 52169-2012: на 2026-06 числится действующим ([meganorm](https://meganorm.ru/Index/54/54076.htm), агрегатор, не официальный). Связь ГОСТ Р 52169-2012 с ГОСТ 34614.1 не подтверждена: нужна сверка по fgis.gost.ru.
- Детское спортивное и воркаут (DSP, WRK): ГОСТ Р 55677/55678/55679-2013. Статус на 2026 не проверен.
- Уличные тренажёры (TRN): ГОСТ Р 57538-2017 (изм. 2022).
- Благоустройство и МАФ (BLG): отдельного ГОСТ на изделие не нашёл. Нужен только общий паспорт.
- Роспотребнадзор (СанПиН): требований к паспорту изделия не нашёл. Не ссылаться.

## F. Вопросы пользователю

1. Срок службы по умолчанию: сколько лет для BLG, TRN, WRK, DIO? По умолчанию — 10 лет для всех (металл, порошковая окраска).
2. Рисунки «Зона безопасности» и «Фундамент» для тренажёров и воркаута — обязательны для выпуска или только «желательно»? По умолчанию — желательно: печатать типовую схему категории, если своего рисунка нет.
3. «Печать для заказчика» — один раз при отгрузке или при каждой печати? По умолчанию — запись при каждой печати с заказчиком; повтор того же паспорта тому же заказчику — та же запись.

## Решения пользователя (2026-11-01)
1. **Зона безопасности** (рисунок) — только для детских игровых площадок. Остальным категориям поле не показывать и не требовать.
2. **Фундамент** — по способу установки изделия: анкерное крепление или бетонирование. Рисунок/текст — по выбранному способу; другой не показывать.
3. **Зона размещения** (габариты места под изделие) — необязательная, только в полном паспорте.
4. **Два варианта паспорта:** *упрощённый* — только обязательное по ГОСТ, без лишнего, чтобы не было претензий; *полный* — плюс необязательные разделы (зона размещения и т. п.), если заполнены. По умолчанию — упрощённый.
5. Срок службы — 10 лет для всех; копия для заказчика — при каждой печати на заказчика (по умолчанию координатора, пользователь не возражал).
