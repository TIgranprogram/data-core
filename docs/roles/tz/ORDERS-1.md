**Язык менеджера:** да.

## Shared pack
- Решения пользователя: «Завершённые» — только закрытые, отгруженные отдельно; менеджер правит позиции в производстве (сервер — этап 3); кнопки правки директору и бухгалтеру не показывать; закрытый заказ возвращает админ.
- Сервер делает координатор: `GET /production-orders?filter=shipped` и `filter=closed`. Счётчики уже есть в `counts` по этапам: `counts.shipped`, `counts.closed`. Фильтры `active`, `done`, `new`, `all` не меняются.
- Этап 3 (отмена и перенос позиции, правила этапов) сюда не входит. Сервер не меняем, кроме строки выше.
- Ввод данных только в правой панели. Модальное окно только подтверждение или 1–3 поля.
