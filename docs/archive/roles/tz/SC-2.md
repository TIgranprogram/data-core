# ТЗ SC-2 — Каталог поставщиков: интерфейс PWA

> Пишет координатор. Файл: `docs/roles/tz/SC-2.md`. Исполнитель читает только ТЗ и перечисленные места.
> **Зависимость:** SC-1 должен быть готов (API /supplier-catalog работает).

**Зачем (словами пользователя):** в карточке контрагента-поставщика — кнопка «Синхронизировать прайс»; отдельный раздел «Каталог поставщиков» — смотреть товары, фильтровать, создавать заявку из позиции.

**Класс:** L · **Max agents:** 1 исполнитель + designer · **Reviewers:** designer ☐ qa ☐ · **Max review loops:** 2 · **Проверки:** smoke
**Язык менеджера:** да — «Каталог», «Синхронизировать», «Создать заявку» · **Приёмка:** глазами — карточка поставщика, кнопка синхронизации, список позиций, правая панель позиции

## Shared pack

- API SC-1: `GET /supplier-catalog?supplierId=&q=&page=&limit=` → `{items,total,page,limit}`, `POST /supplier-catalog/sync/:orgId`, `GET /supplier-catalog/sync/:orgId`
- Позиция каталога: `{id, vendorArticle, name, priceRetail, prices, photoUrls, sourceUrl, specs, category, inStock, stockQty, unit, syncedAt}`
- Кнопка «Синхронизировать» доступна только если у контрагента заполнен `catalogUrl` и роль `canEdit`.
- Создание заявки из позиции — в правой панели, вызывает `POST /supply/requests` с prefill полей.

## Что сделать

### 1. Кнопка в карточке контрагента

В `backend/pwa/sections/partners.js` в блок actions карточки поставщика добавить:
- Кнопка «Синхронизировать прайс» — показывается только если `r.catalogUrl` и `session.canEdit`
- При нажатии: `POST /supplier-catalog/sync/:id` → статус «running» → показать toast «Синхронизация запущена»
- Кнопка опционально меняет подпись: «Синхронизируется…» пока status=running, затем «✓ Обновлено N поз.» или «⚠ Ошибка»
- Статус проверяется `GET /supplier-catalog/sync/:id` с интервалом 3 с (не более 120 с)

В форме правки контрагента (`partners.js` → `form.fields`) добавить поле:
- `catalogUrl` — «URL каталога для синхронизации», тип text, placeholder `https://zaglushka.ru/opora`, hint «Адрес страницы категории или каталога поставщика»

### 2. Раздел «Каталог поставщиков»

Новый файл `backend/pwa/sections/supplier-catalog.js`, экспортирует `supplierCatalog`:

```js
export const supplierCatalog = {
  id: 'supplier-catalog',
  title: 'Каталог поставщиков',
  list: {
    path: '/supplier-catalog',
    sidebar: true,
    filters: [
      { key: 'supplierId', label: 'Поставщик', type: 'select',
        options: async () => (await api('/partners?type=supplier&limit=100')).items.map(...) },
      { key: 'inStock', label: 'В наличии', type: 'chips', ... },
    ],
    searchPlaceholder: 'Поиск: наименование, артикул…',
    emptyText: 'Нет позиций — выберите поставщика и нажмите «Синхронизировать прайс» в его карточке.',
    columns: [...],   // арт., наименование, поставщик, цена, дата синхр.
    card: { ... },    // правая панель: фото, название, артикул, цены-пороги, характеристики, кнопка «Заказать»
  },
}
```

**Левый фильтр:** список поставщиков (у кого есть позиции каталога).

**Правая панель позиции:**
- Фото (если есть, первое из `photoUrls`, `onerror` → заглушка)
- Название, артикул, поставщик
- Таблица цен по порогам (`prices[]`)
- Блок «Характеристики» из `specs`
- Наличие (`inStock`, `stockQty`)
- Кнопка «Создать заявку» — открывает форму новой заявки с prefill: наименование = name, артикул = vendorArticle, поставщик = supplierId, цена = priceRetail, ссылка = sourceUrl

**В меню приложения** (`backend/pwa/main.js` или где перечислены разделы): добавить «Каталог поставщиков» рядом с «Заявками» или «Контрагентами». Иконка — 📋 или подходящая SVG.
