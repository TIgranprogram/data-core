# Макет «картотеки» — как смотреть

Файл `mockup.html` — копия интерактивного макета из сессии ZCode (оригинал рендерится в чате). Открывается в браузере как есть (без сборки, шрифт Inter тянется с Google Fonts — при отсутствии сети будет системный).

Что внутри (карусель, переключение кнопками внизу):
1. **«Видение · картотека»** — как я предлагаю: список строк-карточек слева (тон-полоса, миниатюра 42px, счётчик и сумма разведены, выравнивание чисел) + правая панель сущности: контекст «Снабжение › Заявки › карточка» → главный блок с итогом в шапке → связи сеткой карточек 2×2 («Склад», «Заказ», «Счёт», «Движения», у каждой итог в шапке и ≤2 строки + «Ещё N») → свёрнутая история. Зелёные номера 1–4 — ключевые правила, расшифровка под макетом.
2. **«Сейчас (стенд)»** — для сравнения, повторяет текущий вид экрана «Заявки» с его проблемами (красные номера 1–5: слипшиеся счётчик и сумма, фильтр как пятая колонка, фото больше текста, мелкий чекбокс, обрезанная колонка).

Кнопка 🌙/☀ справа в шапке макета переключает тёмную/светлую тему (токены проекта из `tokens.css`, обе темы).

Меню слева — настоящее меню приложения (все группы и пункты, как на стенде; правка 2026-11-05 после замечания пользователя: первый вариант был схематичным). В «Видении» применены решения ZC-2/ZC-3: «Склад · мобильный», активный пункт — мягкий фон цвета раздела с полосой.

Связь с планом: не замена ORDER-MASTER-PLAN, а визуальная иллюстрация RIGHT-PANEL-V2 (ПМ-1) и STYLE-DECISION (бумага 1А / линии 2Б / сетка 3А) + правила из AUDIT.md §4.
