## Ограничения

PASS подтверждает вид и действия интерфейса в указанных контекстах, форму запросов и защиту readonly в UI. Реальные серверные ACL, транзакции, пересчёт свободного количества после настоящей записи и поведение производственных пользователей этим браузерным mock-прогоном повторно не доказываются. Сохранённые после mock-ответа значения брони/свободного на снимках — данные фикстуры, не проверка серверного перерасчёта. Серверная пагинация/полнота наборов больше страницы — предмет адресной регрессии реализации; наборы реальной копии меньше страницы.

Телефонная приёмка отложена владельцем. Выпуск не выполнялся. После изменения принятого runtime повторить затронутые состояния; первый протокол с Enter→BODY не служит подтверждением финального состояния.
