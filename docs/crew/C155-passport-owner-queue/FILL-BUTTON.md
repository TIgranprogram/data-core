# C155 · «Заполнить» для состава изделия

На карточке изделия 1067 состав был следующим шагом. Когда вкладка «Состав и работы» уже активна, повторный выбор вкладки оставлял блок «Состав» свёрнутым.

«Что дальше → Заполнить» теперь раскрывает «Состав» и переводит фокус к «Изменить состав» в этой карточке. То же работает при переходе с другой вкладки. Кнопка открывает штатный редактор состава, как пункт меню «⋯». Для пользователя без права записи фокус переходит к заголовку секции.

Проверки · 3 поведенческих теста, 347 PWA guards, ES-синтаксис, 352 файла с проверенными импортами, design-lint 0 новых. Карта сайта и инструкция по составу обновлены. Живой сценарий 1067 передан QA на стенд с проверкой активной и другой вкладки, фокуса, открытия редактора и отмены.


## Живая приёмка

Chrome manager, изолированный стенд3102: три вызова действия состава — при свёрнутом составе на активной вкладке, повторно, со вкладки «Файлы» — PASS. Во всех случаях секция открыта, «Изменить состав» видима в области просмотра и получает фокус. Штатный редактор именно1067 открыт и отменён без сохранения, серверных записей0. Обе темы сняты: `evidence/acceptance-fill-light.png`, `acceptance-fill-dark.png`; результат `acceptance-fill-results.json` (сценарий06F64B2B...).

Граница: у QA1067 отсутствует оригинальный файл фото, поэтому первым пунктом очереди стала замена фото; проверяемое действие состава находилось в «Ещё». Оно использует тот же обработчик, что основная кнопка на карточке владельца. Этот факт указан явно, данные ради теста не менялись. Переключение вкладок, раскрытие и фокус проверены настоящим DOM; основной вызов обработчика также покрыт поведенческими тестами.
