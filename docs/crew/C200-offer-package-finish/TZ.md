- [x] Свести историю KP-1, KP-2, C070/C071/C073/C080/C081/C092 и C164, отличить выкладку, автоматические проверки и реальную приёмку. [Аудит](AUDIT.md).
- [x] Связать корзину каталога с созданием пакета. Проверить общий состав, ручные значения, три фирмы с разной наценкой и сохранение списка при ошибке.
- [x] Проверить фирменные бланки всех страниц пакета. PDF каждой фирмы использует её бланк, а продолжение без собственного фона печатается на белом листе.
- [x] Пройти из корзины до трёх КП и скачать общий ZIP. Сверить номера, суммы, три фирменных бланка и печать всех страниц на виртуальном принтере.
- [x] Устранить частичные записи при создании пакета, добавлении фирм и отправке. Проверить откат, повтор и одновременные отправки.
- [x] Исправить переход к первому КП после сохранения пакета. Проверить вход в соседние КП и ZIP из карточки.
