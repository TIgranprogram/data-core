# ТЗ C063 — фирма заказа в паспорт + колонка «Заказ»

**Зачем (словами пользователя):** при выпуске с заказа подставлять нашу фирму заказа (СИЮ/ССЮ); во вкладке изделия в истории видеть заказ.

**Зачем — глаголом:** менеджер выпускает паспорт из заказа — фирма уже выбрана как у заказа; в изделии видит № заказа у выпущенных.

## Глубже
- **Результат:** фирма заказа → `supplierOrgId` при создании с `incomeId`/`salesOrderId`; история изделия показывает заказ.
- **Сырьё:** `LOGIC-AUDIT.md` (P0, P1).
- **Метод:** точечный default, явный выбор важнее; печать по-прежнему читает фирму паспорта.
- **Внешний судья:** юнит fromIncome/bindDraft; `node --input-type=module --check` pwa.
- **Смелая планка:** 0 ломаний ручного выбора и выпуска без заказа.

**Класс:** M · **Max agents:** 0 (координатор) · **Проверки:** smoke · **Язык менеджера:** да · **Приёмка:** воронка из заказа — фирма заказа; вкладка изделия — колонка «Заказ».

## Что сделать
1. Backend `fromIncome` / bind: если `supplierOrgId` не передан и у заказа есть `companyId` нашей фирмы — взять его; иначе как сейчас (одна наша / 400).
2. `orderPlan`: «Выберите фирму» не ставить, если у заказа есть наша `companyId` (черновик подставит при create).
3. PWA воронка: при `salesOrderId` подгрузить заказ и предвыбрать фирму = `companyId` (список можно сменить).
4. Вкладка изделия `passportPane`: колонка «Заказ» (№ + ссылка при `salesOrderId`).
5. Не менять: выпуск без заказа; печать; шаблон изделия; уже выпущенные паспорта.
