Проверка 16.11.2026 через GET. Справочники вернули 17 признаков и 61 значение. Значения сверены по `parentId` и с ответом `passport-gaps`.

|---|---|---|

| Перила, спинка · `blg.rail` | С перилами / со спинкой, Без перил / без спинки | Пусто |
| Материал · `blg.material` | Бетон, Стеклопластик с подсветкой | Пусто |

Поиск по `search=3601` вернул одну точную карточку «Шахматный стол со стульями». Параметр `q` вернул общий список. Категория паспорта «Благоустройство» унаследована от вида «Стол уличный» из группы «Столы». Все три незаполненных признака из таблицы необязательны, каждый допускает один вариант.

В `facetValueIds` записаны «Доска» (`blg.seat.board`) и «Дерево (или металл с деревом)» (`dio.material.wood`). У последнего другой родительский признак, поэтому он не заполняет `blg.material`.

В `materialsSpec` две позиции со ссылками на материалы и одно покрытие. `materialsText` отдаёт «Изготовлено из стальной профильной трубы, древесины лиственницы. Покрытие: цинкование и порошковая окраска.» Поле `materialIds` отсутствует в ответе карточки, `description` пусто. Материалы из техописания присутствуют в карточке, но API настроек по-прежнему возвращает бетон и стеклопластик как варианты отдельного признака.

Выгрузки в игнорируемой Git папке `для анализа/C133/`. Все запросы завершились успешно.
