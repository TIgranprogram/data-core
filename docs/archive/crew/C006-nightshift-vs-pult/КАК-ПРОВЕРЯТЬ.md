# Как вам проверять сайт (без команд)

Уже есть ярлык на столе: **«Пульт DataCore»**.

1. Откройте ярлык (или `D:\data-core\pult\Pult.cmd`).
2. Раздел проверок — три главные кнопки:

| Кнопка | Когда жать | Что делает | Сайт |
|--|--|--|--|
| **Быстрая проверка** | Перед/после правок кода | Типы, юнит, импорты | Не трогает |
| **Полная проверка** | Перед крупной выкладкой | Типы, юнит, e2e, обходы на новом стенде | Не трогает |
| **Большая проверка сайта** | Нужен отчёт по экранам | Обход, снимки, отчёт для ИИ | Не трогает |
| **Пакет выпуска: собрать показатели** | Вместе с быстрыми проверками | В том числе собственные тесты Nightshift | Не трогает |
| **Стенд на копии базы** | Посмотреть сайт на копии | Свой стенд `localhost:3102` | Не прод |

3. Итог справа в пульте; полные логи — `pult/logs/` и `tools/logs/`.
4. Прод — только отдельными кнопками «Сервер сайта» / выкладка, не этими тремя.

Папка `tests_ai_tiit\nightshift` вам руками не нужна. Пульт запускает только её собственные тесты.
