# C169 · Локальный обработчик

- `tools/document-intake/index.mjs` выполняет захват оригинала, расчёт SHA, извлечение текста, проверку цитат, запись и независимое чтение карточки и байтов. Каждое поступление хранится отдельно. Для повтора используются сохранённые реквизиты и свежая сверка через API. Незавершённые поступления восстанавливаются из журнала.
- Windows проверяет закрытие файла через дескриптор без совместной записи. Linux использует эксклюзивную аренду ядра, при недоступности оставляет файл в исходной папке. Блокировка действует между процессами одного ПК.
- Автоматически импортируются текстовые PDF договоров, КП и входящих рублёвых счетов поставщиков с подтверждёнными реквизитами и строками. Счета требуют однозначного НДС. Платежи, производство и складские движения не создаются.
- Сканы, сложные налоги, новые редакции счетов и отсутствующие реквизиты переходят в «Сомнительные». TXT, MD и CSV читаются, но для записи нужен исходный PDF. Исходящий счёт и акт требуют ручной привязки к существующему договору.
- `retry` обрабатывает выбранные исключения после сверки исходных байтов, контура и учётной записи. `resume` продолжает незавершённые поступления. При изменении байтов оригинала разбор останавливается и показывает причину.
- Локальный API модели передаёт только извлечённые страницы. Запуск рантайма, загрузка моделей и переключение между ними остаются ручными. Bearer передаётся отдельно только DataCore и отсутствует в журналах.

Для разработки можно посмотреть списки локальной очереди без DataCore и модели.

```powershell
node tools/document-intake/cli.mjs report 'D:\Документы\C169'
```

На Windows `node --test tools/document-intake/intake.test.mjs` прошёл 22 теста, включая подмену папок назначения и подмену папок при захвате второго файла настоящими junction. Извлечение из реального PDF проверено через PyMuPDF. Адресные тесты используют подмены API и модели. Linux в этом прогоне не проверялся.

LM Studio с `google/gemma-4-12b-qat` принял закрытую JSON Schema. Разбор тестового PDF и проверка цитат заняли 107,5 с без учёта извлечения текста. Валидатор подтвердил договор C169/1, одну строку, 2 × 500 ₽ и итог 1 000 ₽.
