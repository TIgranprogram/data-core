# C159 — выбор изделия позиции заказа по фото и фильтрам

19.11.2026. Класс M, интерфейсный патч без изменения API/схем. Пользователь поручил исправление и выкладку. Приоритет — этот экран; сборка текста из частей отдельный пункт C155.

## Проблема и результат

orders.js::pickProduct (строки70–103) открывает маленький modal с combobox без фотографий и фильтров. В позиции заказа владелец не может отличить похожие тренажёры. Заменить этот вход на эталонную правую панель выбора: поиск по названию/артикулу, связанные фильтры раздел→группа (зависимый выбор) и серия, список/карточки с различимыми фотографиями. Нужны увеличенный просмотр фото без выбора, артикул и полное имя/категория; явное подтверждение выбранного изделия. Фотография обязательна в представлении результата, но изделия без фото не прячутся: честная заглушка и текст «Нет фото».

## Правила

- Переиспользовать существующие kit/card/list/gallery/sideForm. Ввод — правая панель, не modal/отдельное окно. Предпочесть стандартные строки/плитки с фото достаточного размера; не изобретать новый CSS раздела.
- Каталог — GET /showcase с текущими search/groupId/series/page/limit и существующими справочниками/категориями; изучить конкретный контракт до запроса. Никакой молчаливой обрезки до500 всех записей: серверная пагинация/«Показать ещё», общее число, защита гонок запросов.
- Подсказки похожих изделий сохранить по возможности (match-products — вычисление, не автоматическая привязка), но не ограничивать ими каталог. Не требуется новая автоматизация ИИ.
- До подтверждения выбора нет PATCH. Отмена/закрытие/просмотр фото не изменяют позицию. Показать выбранное фото/артикул/название и кнопку «Привязать изделие»; во время сохранения блокировать повтор.
- PATCH /incomes/:id только productId через patchVersioned с исходной версией. Имя заказчика/title, цена, количество, договор/заказ/компания, паспорта не переписываются. При конфликте409 сохранить выбор и объяснить, не повторять запись слепо.
- После успеха обновить карточку позиции и сохранить её контекст. Повторный вход/смена изделия показывает текущую связь. Остальные места выбора пока не переписывать.
- Ошибка загрузки/пустая выдача/неисправное фото/отсутствие разрешения: понятные состояния, восстановление/сброс фильтров, не вечная загрузка. Enter/Escape/Tab, обе темы. Телефон не блокирует.

1. Открыть «Выбрать изделие» из позиции заказа: правая панель с фото и фильтрами.
2. Поиск «жим», фильтр раздел/группа/серия, сброс, пустой результат, несколько похожих результатов и без фото; фото можно увеличить независимо от выбора.
3. Выбрать точное изделие, подтвердить одинPATCH на QA; проверить сохранённую связь и прежние title/деньги/количество/заказ. Отмена нольPATCH. Повторный вход/смена текущего изделия.
4. Гонки поиска/страницы/ошибки и повторные клики не дают неверную привязку/двойную запись. Реальный конфликты версий хотя бы программно.
