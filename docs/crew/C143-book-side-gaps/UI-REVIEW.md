## Эталоны

Редакторы собраны из kit: `button`, `field`, `hint`, `select`, `buildForm`, панель `sidePanel` → `.bk-panel`. Таблица материалов — тот же `ms-table`, карточки строк как на телефоне в `screens.css`. Нового виджета вне kit нет. В витрине `#kit` этот стек колонки не показан — не блокер: это сужение уже существующей таблицы.

Заголовки слотов называют поле («Глубина Г», «Назначение», «Материалы изделия»), шапка книжки называет паспорт. Подсказки на русском. Загрузка файла на листе — прежняя зона с «Выбрать файл», не новый input.

## Дефекты

1. **Лист на 1024 становится щелью.** Слева колонка 420 px, справа `min(480px, 34vw)` ≈ 343 px, листу остаётся 222 px. Обложка и зона файла не читаются. Комментарий в `kit.css` у `.bk-side.is-wide` обещает обратное. Снимок `1024-light-materials.png`.
2. **Низ формы материалов перекрыт блоками «Проверка ИИ» и Inventor.** На 1024 текст ИИ лежит на поле «Размеры» (видна одна буква «п»). «Сохранить в изделие» в кадрах материалов нет. У коротких форм кнопка видна. Причина по коду: `.bk-side-slot { min-height: 0 }` сжимается, содержимое рисуется поверх следующих панелей. Снимок `crop-1024-mid.png`.
3. **Три зелёные кнопки сразу:** «По ширине» (активный масштаб), «Выпустить», «Сохранить в изделие». На экране одна главная. «К подсказкам» правильно серая.
4. **Ширина материалов не снимается.** После таблицы глубина, назначение, возраст и габариты остаются 480 px (лист 860 вместо 1060). Класс снимается при «К подсказкам», не при открытии следующего слота.

Телефон 390 — в отдельное ТЗ: лист 48 px, колонка 133 px, «Скачать .iLogicVb» обрезано.

Клик по живой строке «Сначала» не повторяли: на этом изделии нет пункта «Глубина Г», слот открыт функцией очереди. Сохранение и тёмная тема на 1024 не снимались.
