# История карточек — фото и заказы. Браузерная приёмка

**PASS, 4 из 4.** Отдельный headless Chromium на QA :3102, светлая и тёмная темы при 375 и 1920 px. Записи на сервер заблокированы.

- Реальный производственный заказ 36-26 появился в истории. В подписи есть номер и заказчик. Переход из истории открыл карточку по текстовому ключу. Повторный переход в изделие также сработал.
- Локальная миниатюра контрольного изделия декодировалась. У изделия 3802 с реальным HTTP 404 на копии и у изделия 1106 без фото показаны значки. Вся строка остаётся одной ссылкой. На рабочем сайте миниатюра 3802 доступна, 404 относится к копии.
- Перезагрузка сохранила порядок. Повторное открытие не создало дубль. Очистка оставила пустое меню. Открытие меню ни в одном прогоне не вызвало GET деталей карточек.
- При переходе из правки изделия в заказ на 1920 px показан диалог. «Отмена» сохранила введённый текст, «Выйти» открыло заказ. На 375 px история открывается из шапки после закрытия полноэкранной карточки.
- Меню помещается по ширине, длинные подписи переносятся, ошибок JS и телеметрии нет. На снимках строка заказа закрыта маской. Подпись проверена до маскирования.

Первый сценарий подменял 404 для уже декодированного изображения и ожидал повторной загрузки в том же документе. Этот этап убран из итогового прогона. Нужное состояние подтверждено реальным 404 у изделия 3802 на копии.
