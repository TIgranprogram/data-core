# Промпт для Codex — C095, экран модулей паспорта

Ты делаешь ЭКРАН задачи C095 «Паспорт сборного изделия» в репозитории data-core. Сервер и PDF делает Claude параллельно — `backend/src` не трогай.

Прочитай: `AGENTS.md` (раздел «Жёсткие правила»), `docs/crew/C095-assembly-passport/TZ-IMPL.md` (контракт — строго по нему), `docs/DESIGN.md` только разделы про kit-компоненты списка и формы.

## Что сделать
1. **Анкета шаблона паспорта изделия** (`backend/pwa/sections/passports/fill/*`): в разделе «Общие сведения» блок **«Модули изделия»** — для сборных изделий (экотропа: модули разной формы, количество в штуках).
   - Пусто — строка-подсказка «Изделие собирается из модулей? Добавьте модули» и кнопка «Добавить модуль».
   - Строка модуля: «Название», «Габариты» (текст, «2000×1200×90 мм»), «Количество, шт.» (целое > 0), рисунок модуля (выбрать из рисунков изделия или загрузить новый — вид `module`, механизм как у прочих рисунков паспорта, `passportSlot`), «Убрать».
   - Под списком при 2+ модулях — «Итого модулей: N шт.».
   - Запись: `putDefaults(prod, { modules })` (в `PD_KEYS` в `sections/products/data.js` добавить `modules`, иначе потеряется при следующей записи). Сохранять по уходу из поля, как остальные поля анкеты; ошибки сервера (400) показывать у поля.
   - Заполненный список — строка «Модули: 2 вида, всего 60 шт. ✎» (как остальные заполненные строки, `filledLink`, класс `k-fill-done`).
2. **Форма паспорта** (`backend/pwa/sections/passports/form.js` / окно «Новый паспорт»): поле `modules` (тот же редактор), подставляется из изделия сервером; можно поправить для этого экземпляра.
3. **Рисунок `module`** не показывать отдельным слотом в «Габариты и виды» — только внутри строки модуля.

## Правила
- Только эталоны kit (`backend/pwa/ui/kit`): `stack`, `field`, `textInput`, `button`, `link`, `hint`; новые классы — только в kit отдельным коммитом. Язык менеджера, без кодов.
- Проверки: `node --input-type=module --check < файл` каждого изменённого .js; новый модуль → `node backend/scripts/pwa-preload.mjs`; `cd backend && npx jest --silent src/pwa-guards`; затронутые `node --experimental-vm-modules --test`.
- Коммиты — только свои пути (`git commit -- <файлы>`), метки `Класс: M`, `Дизайнер: …` (приёмка — снимок анкеты 3215 на стенде :3102 в `docs/crew/C095-assembly-passport/evidence/`). Не выкладывать — выкладывает координатор.
- Отчёт: `docs/crew/C095-assembly-passport/REPORT-codex.md`, коротко: что сделано, файлы, проверки.
