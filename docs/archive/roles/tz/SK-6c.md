# ТЗ SK-6c — «Выдать по заказу»: убрать строку / уменьшить количество (интерфейс)

**Зачем (словами пользователя):** по заказу выдаю не всё, что в брони: что-то убрать, где-то выдать меньше (SKLAD §3.4).

**Роли:** backend ☑ (координатор, сделано) · frontend ☐ · qa ☐ (в общем прогоне) · дизайнер ☐ (в общей проверке)

## Контракт сервера (готов)
`POST /api/stock/reservations/issue-order` — новое поле `lines: [{reservationId, qty?}]` (1…500). `qty` нет — вся бронь; меньше брони — частичная выдача, остаток брони остаётся активным; больше брони — 400 с текстом. Есть `lines` — `reservationIds` не слать. Остальное как было (`salesOrderId`, `personId`/`issuedTo`, `clientUid`).

## Что сделать
1. `sections/order-reservations.js` — подтверждение «Выдать по заказу»: у каждой строки поле количества (по умолчанию — остаток брони, не больше его, > 0) и галочка/«убрать». Шлём `lines` с `qty`. Итог — «выдать N позиций». Ничего не выбрано — кнопка неактивна.
2. Если это уже не «подтверждение на 1–3 поля», а ввод — перенести в правую панель (DESIGN §5; по образцу `sections/reservation-edit.js`). Решение — по скиллу `datacore-design`.
3. Бронь в карточке позиции склада — выбор «под что» через `ui/target-picker.js` (как в «Выдать»), если ещё не так.
4. Компактный ввод чисел (узкие поля, единица в подписи), признак загрузки, по-русски.

- В рабочей копии ожидаются правки: `backend/src/modules/stock/dto.ts`, `stock-reservations.service.ts`, `*.spec.ts` (координатор); `backend/src/**` и `backend/admin/**` — роль backend по SK-8a; `docs/roles/tz/SK-8*.md`.

## Критерии приёмки
- [ ] Можно убрать строку и уменьшить количество; больше брони ввести нельзя; уходит одна операция (`lines`), повтор нажатия не дублирует (`clientUid`).
- [ ] После частичной выдачи остаток брони виден в «Брони заказа».
- [ ] Модальных окон для ввода нет (кроме подтверждения 1–3 поля).
- [ ] `node --input-type=module --check < файл` для изменённых, `node backend/scripts/pwa-preload.mjs`, `npx jest src/pwa-guards --silent`.

## Нельзя
- Трогать сервер, `main.js`; модальные окна ввода; коммитить.
