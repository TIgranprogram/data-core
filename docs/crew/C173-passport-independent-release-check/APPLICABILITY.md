# C173 — применимость полей и разделов

Рабочая матрица v1.984 по серверным правилам. В каждой категории обязательные поля, дополнительные рисунки и условия берутся из записи «Типы паспортов». Ниже указана применимость по коду. Фактические записи категорий и представительные изделия предстоит подтвердить для листа приёмки.

| Категория | Дополнительные необязательные поля по умолчанию | Условия |
|--|--|--|
| BLG | Параметры пользователя не добавляются | Тип: назначение → группа каталога → подходящий признак. Зависящие от типа признаки при неизвестном типе не предлагаются. Элементы необязательны. Урна относится к прочему благоустройству при подтверждённом назначении или группе. |
| TRN | Минимальный возраст, максимальный рост | Элементы требуются. Применимые конструкция и описание определяются видом и связанными справочниками. |
| DIO | Минимальный/максимальный рост, максимальный вес | Элементы требуются. Допустим рисунок зоны безопасности, обязательность задаёт профиль категории. |
| DSP | Максимальный возраст, минимальный/максимальный рост, максимальный вес, высота падения | Элементы требуются. |
| WRK | Минимальный возраст, минимальный/максимальный рост, максимальный вес, высота падения | Элементы требуются. |
| ALL | Общие тексты | Общее правило шаблонов; отдельный сценарий выпуска для изделия не подтверждён. |

Срок службы и гарантия применимы для всех, обязательность определяется профилем. Если набор рисунков содержит условие «если разборный», выбор способа поставки обязателен. **Short** не требует полного производственного состава и исключает необязательные размеры зоны размещения и дополнительные виды. **Full** включает применимые заполненные материалы, состав, сборку, размеры площадки и дополнительные виды. Журналы и рекламации применяются в обоих вариантах. Общий вид и габариты имеют разные назначения. Текст берётся из применимой словарной ветки и собственных данных; отсутствующие инженерные параметры требуют подтверждённого источника. | Способ | Допустимые монтажные виды | Обязательные монтажные виды | Глубина | Третий рисунок Inventor |
|--|--|--|--|--|
| ANCHORS (alias ANCHOR) | mounting | mounting | Нет | mounting |
| CONCRETE_POSTS (alias CONCRETE) | foundation, holes | foundation, holes по справочнику | Да | foundation |
| EMBEDDED | foundation, embedded_layout | foundation, embedded_layout по справочнику | Нет | foundation |
| ON_SURFACE / FREESTANDING / LAID | mounting | По профилю монтажного способа обязательных нет | Нет | mounting |
| FENCE_POSTS | foundation, holes | foundation и/или holes, если указаны в справочнике | Да | foundation |
| Неизвестный / отсутствует | Нет | Сначала явный выбор | Нет | Импорт 409 |

Остаток по данным: сверить фактические обязательные поля и рисунки категорий, применимые переменные текстов и условия отсутствия по каждому кандидату, включая DIO, DSP, WRK и full со сборкой. Сведения C179 подтверждают анкерный TRN и отдельные тестовые переходы способов установки. [C179 QA](../C179-mounting-applicability/QA-REPORT.md)
