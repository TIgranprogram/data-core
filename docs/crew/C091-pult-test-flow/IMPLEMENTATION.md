# C091 — реализация

12.11.2026. Незакоммиченные изменения; владение: pult/ и этот отчёт. Чужие tools/ai-tester и backend/pwa не менялись.

## Изменено

- В разделе ИИ-тестировщика одна главная карточка: состояние → длительность → «Проверить сайт» → «Результаты». «Остановить» появляется при свежем heartbeat. Служебные установки, снимки и очистка раскрываются через «Дополнительно».
- Переиспользован ait-run (--detach): существующие check/setup внутри run.mjs:638–657 выполняются один раз. risk local сохранён, общая read-only цепочка не используется.
- pult/tester.mjs читает только локальный run.json, наличие STOP, даты REPORT.md и журнал запуска пульта. Различает пустое состояние, подготовку, отправленный запуск, работу, ожидание остановки, завершение с отчётом, сбой подготовки, потерю пульса и отсутствие нового отчёта.
- Сервер запрещает второй ait-run при подготовке, маркере фонового запуска и 120-секундном ожидании heartbeat после успешной отправки. UI дополнительно закрывает повтор немедленно при клике.
- Код 0 detach и stop подписан как отправка, не как завершение проверки. STOP читается с диска, поэтому состояние сохраняется после перезапуска.
- Отчёт доступен через прежний --last; видны путь REPORT.md, папка ошибок/снимков и журнал пульта. Старый отчёт не считается итогом нового запуска, если старше запуска. Журналы ait-команд исключены из ротации pult/logs; отчёты не очищаются.
- По уточнению пользователя: windowsHide:true добавлен в фоновый respawn пульта. Видимое окно браузера не менялось.
- README и сгенерированная справка обновлены. Использованы существующие card/primary/ghost/param и токены пульта (по datacore-design с оговоркой ТЗ для desktop-пульта).

## Ограничения и приёмка

- Реальный многочасовой обход, установка зависимостей, Docker, API стенда/прода и модель не запускались. Fixture подтверждает UI и запросы, не длительную работу самого тестировщика.
- Независимая дизайнерская приёмка передана координатору; финальный UI-REVIEW.md составляет проверяющий.
- Пульт не может доказать успешность обхода по коду detach. «Проверка закончена» значит отсутствие маркера и свежий отчёт, а не отсутствие найденных ошибок; это явно написано на экране.
- Старый run.json без heartbeat консервативно блокирует новый запуск и показывает обрыв; сам пульт маркер не удаляет, восстановление разбирает агент по журналу.
- --last по текущему контракту выводит первые 40 строк REPORT.md. Полный файл и снимки остаются по показанному пути.
- Полный общий typecheck/Jest не повторялся в этом подзадании: backend не менялся; общие проверки выполняет координатор.
