## Действия (администратор, «Цвета», запись «ТЕСТ-C116 …»)

- Новая запись → ввод → «Отмена» → окно «Отменить изменения?» → «Да, отменить»: запись не создана (API: 0). ✅
- Создать → «Создано», карточка открыта. ✅
- Изменить → дописать « 2» → «Сохранить» → «Сохранено», API отдаёт новое имя. ✅
- «…» → «Удалить» → окно с подсказкой про «Отменить» → «Удалено», счётчики 31 → 30. ✅
- «Отменить» в уведомлении → «Восстановлено», счётчики 30 → 31, запись снова в API. ✅
- Тестовая запись убрана, на стенде записей C116 нет.
