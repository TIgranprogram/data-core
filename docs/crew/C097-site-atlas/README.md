# C097 — «Карта сайта» (#atlas)

**Класс:** L (новый экран). **Дата:** 2026-11-12. **Кто:** координатор (Claude).

## Просьба пользователя
Весь сайт — одной живой схемой сверху вниз, как схема «Как устроена продукция». Тексты — в схему.
Нажатие на раздел не уводит со страницы: прямо здесь открывается окно «что внутри» и с чем связано.
Цели: менеджеры видят и объясняют друг другу устройство; это общая шпаргалка с документацией для ИИ.

## Что сделано
- `backend/pwa/sections/atlas.js` — экран `#atlas`: слои (продажи → продукция → производство → снабжение → склад → деньги),
  блоки-разделы, связи; наведение подсвечивает связи с подписями; нажатие — окно справа (`entityPanel`, ширина до 1080 px).
- Окно: источники слева → раздел с частями → куда уходит; «Учитывать»; «Как работать — по шагам» (из `help-guide-data.js`);
  «Где описано» — документы и таблицы базы (для ИИ). Соседний блок в окне — переход к нему, кнопка «← назад».
  У «Изделия» — подробная схема продукции (`help-product-map.js`, экспорт `diagram`).
- Ссылка с адресом: `#atlas?n=<id>` открывает окно сразу (id — в `atlas-data.js`).
- Узкий экран (< 1240 px; окно — схема от 1100 px): плитки по слоям, окно — списками.
- Кнопка «?» в шапке ведёт на `#atlas`; пошаговые инструкции остались на `#help` (меню аватара и плитка внизу карты).

## Как править
Данные — `backend/pwa/sections/atlas-data.js`: `BANDS` (слои), `NODES` (блоки: col — колонка 0–3, inside, rules, docs, tech), `LINKS` (связи).
Поменялось устройство сайта — правится здесь же, иначе карта врёт.
