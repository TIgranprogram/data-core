# C228 — вход в тестовую копию из Пульта

- [x] На Windows Пульт запоминает вход в локальную копию по умолчанию. На диске находится только защищённый DPAPI ключ продления с привязкой к адресу и аккаунту. Пароль и access-токен в файл не записываются.
- [x] При перезапуске Пульт проверяет сохранённую сессию через штатное продление. При временной недоступности копии сохранённый вход остаётся. Выход и смена адреса снимают сохранённый вход. Для рабочего сайта остаётся сессия в памяти.
- [x] 138 тестов. В Windows проверены шифрование, перезапуск, восстановление после недоступности, явный выход и отзыв. Браузерный сценарий Пульта прошёл.
- [x] Сверили путь PDF. PyMuPDF извлекает текст, LM Studio получает текст страниц, Пульт проверяет цифры и цитаты. Координаты используются отдельно для двух колонок договора. Картинки страниц в модель не передаются.
- [x] На локальном Пульте :47811 вход в тестовую копию :3102 сохранился при перезапуске процесса. После него отчёт открылся без повторного входа. Очередь прежняя, отправлено 0. Пульт оставлен запущенным для тестов.
