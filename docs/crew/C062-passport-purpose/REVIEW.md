## Правила

- **Назначение** — вариант раздела «Назначение» по названию изделия и категории паспорта (баскетбол, брусья, кардио, ноги, отдых, ограждение…). Вариант должен подходить к категории; не подходит — вручную.
- **Элементы** — по названию: «Брусья» → Брусья, «Комплекс воркаут «Два турника-брусья»» → Турник + Брусья, «Жим ногами» → Тренажёр для мышц ног и ягодиц. Если в названии есть деталь без элемента (кольца, канат, скалодром) или элемент не подходит к категории паспорта — вручную.
- **Способ установки** — как у большинства изделий группы, где он уже выбран (не меньше 2 изделий и 80 % одного значения):
  - Информационные стенды и указатели: «Бетонирование опор» (2 из 2)
  - Навесы: «На закладные детали» (11 из 12)
  - Воркаут: «Бетонирование опор» (17 из 21)
  - Велопарковки: «Ограждение на опорных стойках» (2 из 2)
  - Тренажеры: «На закладные детали» (38 из 42)
  - Урны: «Анкеры на фундамент» (2 из 2)
  - Ограждения: «Ограждение на опорных стойках» (5 из 5)
  Остальные группы (Спорт оборудование, Качели, Скамьи, Трибуны, Благоустройство…) — вручную: у них способы разные.
