## 2. Очередь паспортов (M, backend + pwa «Документация»)
- [x] `GET /passports/queue`: позиция с изделием + задача проектирования `done` + нет выпущенного паспорта; типовое изделие без задачи — если есть фото/модель (ОП-1). Сортировка по сроку отгрузки, «горит» ≤ 3 дней.

- [x] «Документация» → вкладка «Нужно сделать паспорт» (первая), кнопка «Выпустить» в строке.
- [x] «Сегодня» → карточка «Паспорта к сроку · N»; заказ → бейдж у позиции «нужен паспорт».
