# П155-1 — как должен работать упрощённый паспорт

Основание: сообщения владельца 19.11.2026 и AUDIT-TZ.md. Это требования, не описание готовой реализации.

## Два варианта, один источник

- У изделия один шаблон с общими сведениями; упрощённый и обычный варианты используют его без второй копии изделия.
- Упрощённый вариант содержит краткое понятное описание функциональных частей. Техническая таблица материалов, производственный BOM, марки сырья и размеры сечений для этого не нужны.
- Сведения для обычного варианта сохраняются, даже когда скрыты в упрощённом. Доработка обычного варианта не блокирует упрощённый.
- Безопасные инструкции и подтверждённые ограничения не удаляются из документа только ради короткой формы.

## Что заполняется и откуда

| Сведение | Приоритетный источник | Что делает менеджер |
|---|---|---|
| Наименование, артикул, тип паспорта | Изделие, группа и выбранная категория | Подтверждает только неизвестную классификацию |
| Рисунки, габариты, масса | Существующий импорт Inventor/iLogic, затем поля изделия | Дополняет только реально отсутствующее; повторного ручного переноса нет |
| Краткое описание | Подтверждённое описание изделия и выбранные типовые функциональные части | Просматривает/корректирует предложение один раз; сохраняет в изделие |
| Названия частей, типовые формулировки | Общие существующие справочники с применимостью по категории/виду | Выбирает недостающие; новый вариант добавляет с возвратом в тот же шаблон |
| Назначение | Подтверждённый типовой текст по категории/виду | Не отвечает повторно, если выбор уже известен |
| Монтаж, глубина установки | Подтверждённый способ установки и реальные параметры изделия | Указывает только применимое; бетонная глубина не спрашивается при другом монтаже |
| Нагрузки и ограничения безопасности | Подтверждённые инженерные сведения и применимые правила | Не угадывает по картинке; неизвестное критичное значение требует адресного уточнения |
| Организация изготовителя/поставщика | Для заказа — его контекст; без заказа — явный выбор при выпуске | Не выбирает фирму для простой правки шаблона изделия |
| Номер паспорта | Существующий счётчик при успешном выпуске | Не вводит произвольный номер при каждом просмотре/скачивании |
| Покупатель, заказ, продажа | Экземпляр заказа, если есть | Отсутствие заказа не блокирует самостоятельный паспорт изделия |

Точный список реальных блокеров уточняется серверным аудитом. Массу не путать с допустимой массой пользователя; рисунок не доказывает нагрузку.

## Описание из справочников — уточнение владельца19.11

1. Категория, вид и сохранённые критерии изделия определяют применимые части и основной текст из существующих справочников. Готовый подходящий текст автоматически виден в новом short без повторного ручного подтверждения.
2. Воронка задаёт только недостающие вопросы, влияющие на выбор текста. Сохранённое и единственный применимый вариант подставляются. Недостающие полезные критерии добавляются в соответствующие категории справочника.
3. Менеджер может дополнить справочник или выбрать «Свою формулировку», сохраняя контекст паспорта. Ручная формулировка — необязательная замена словарного текста.
4. Названия функциональные, с грамотными формами: каркас, рукоятка, платформы для ног. Материалы, толщины, нагрузки и скрытые узлы по рисунку не выдумываются.
5. Материалы и подробные данные сохраняются для full. Уточнение владельца: подтверждённые мусор/дубли справочников можно убрать после проверки связей и правильной замены; неоднозначное не удаляется вслепую. Дополнения и исправления через API сайта разрешены; before/after и повторное чтение обязательны. Старые паспорта и их снимки не изменяются.
6. Рисунки и числовые характеристики остаются входом из Inventor/iLogic; внедрение автоматического распознавания на сайте сейчас не требуется.

## Кнопки и последствия

| Где | Действие | Результат |
|---|---|---|
| Изделие | Редактировать шаблон паспорта | Общие сведения изделия; нет номера, заказа и создания выпущенного экземпляра |
| Изделие / шаблон | Посмотреть / печать образца | Предпросмотр упрощённого документа; нет нового номера и побочных записей |
| Изделие | Выпустить паспорт | Выбор организации при неоднозначности → проверка → номерной экземпляр без обязательного заказа |
| Позиция заказа | Открыть / изменить паспорт | Именно экземпляр этой позиции; фирма и контекст заказа сохраняются |
| Позиция заказа | Посмотреть / печать | Текущий образец или существующий выпуск; повторная печать номер не расходует |
| Позиция заказа | Выпустить паспорт | Номерной экземпляр нужной позиции с фирмой заказа |

Не требуются все эти кнопки одновременно: у одного действия один очевидный вход; в строке остаётся главная кнопка, дополнительные — в меню. Точное размещение определяется после аудита действующих входов.

«Посмотреть» открывает последовательные страницы образца. Спуск буклета для печати выбирается явно и не подменяет обычный просмотр. Везде видно, что сейчас редактируется: шаблон изделия или номерной/черновой экземпляр.

## Очередь «Сначала» и память

- Здесь только реальные препятствия выбранному действию; рекомендации отдельно и без метки «срочно».
- В режиме образца отдельно показать незаполненные фактические данные, не выдавая документ за готовый выпуск.
- Отсутствие материалов/BOM само по себе не запрещает краткое описание простых функциональных частей.
- Очевидные и уже сохранённые ответы пропускаются. Воронка: категория → применимый вид → недостающая часть/текст.
- Изменение категории пересчитывает применимость, сохраняет ручные сведения и объясняет конфликт.
- Импорт обновляет общие данные и автоматические черновики по существующим правилам; выпущенный снимок автоматически не меняет.

## Как принимаем

Измеримый минимум для уже подготовленного изделия: ноль повторных вопросов о сохранённых размерах/массе/категории/назначении; ноль требований заполнять технические материалы и BOM ради short. Предпросмотр не требует фирмы или нового номера. При неоднозначном словарном тексте — только выбор недостающего критерия; при самостоятельном выпуске — выбор фирмы, если она неоднозначна. Неизвестные реальные данные безопасности не считаются известными ради этого показателя.

Контрольный пример — реальная копия1066. Дополнительно: изделие без материалов/BOM; изделие с бетонированием; старый номерной паспорт; две позиции одного изделия в разных заказах/фирмах.

- [ ] Импортированные реальные размеры/масса/рисунки используются без повторного ввода.
- [ ] Шаблон открывается без выбора фирмы и создания экземпляра.
- [ ] Простой текст без материалов сохраняется, возвращается после открытия и согласован с PDF.
- [ ] Образец не расходует номер и не создаёт выпуск.
- [ ] Выпуск без заказа выбирает фирму, создаёт номер один раз; повторное скачивание сохраняет номер.
- [ ] Из заказа открывается правильный экземпляр позиции; соседний паспорт того же изделия не подменяет его.
- [ ] Неизвестные технические характеристики не появляются от распознавания рисунка.
- [ ] Старые ручные данные и выпущенные документы сохраняются.
- [ ] Входы, ошибки/отмена/повтор/возврат проверены действиями; обе темы компьютера сняты и оценены.
