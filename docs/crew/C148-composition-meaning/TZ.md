## Scope

- Аналитик: только релевантные разделы docs/PRODUCT.md (каталог, паспорт), docs/PASSPORTS-V2.md; результат SHOULD.md. PRODUCT пока не менять.
- Архитектор: фактические источники состава и паспортного описания, сохранение, PDF, импорты; результат AUDIT.md, код не менять. Основной читатель кода — архитектор.
- Координатор: после выжимок зафиксировать контракт исправлений, файлы исполнителей и критерии; реализация, проверки, коммит/push и выпуск.
- Ожидаются параллельные правки только AUDIT.md и SHOULD.md разными ролями. Чужие изменения не откатывать.

## Ограничения

Сохранить старые данные, ручные описания и выпущенные паспорта. Производственный состав и паспортное описание не объединять только по совпадению названий. Доступ к данным — API через роль доступа. Прод-данные не менять; проверочные записи только на изолированном стенде. Контракт публичного API сохранять.
