# ТЗ SK-7b + SK-9 + SK-4c — «Предложено из выдач», пересчёт и списание в карточке позиции (интерфейс)

**Зачем (словами пользователя):** после выдачи под позицию с изделием — предложение «добавить в состав»; в карточке позиции склада — те же действия, что на странице «Склад», в правой панели.

**Роли:** frontend ☑ (skill `datacore-design`) · designer ☐ (после)

## Контракт сервера (SK-7a, готов)
- `GET /api/stock/composition-suggest?salesOrderLineId=` → `{salesOrderLineId, position ("552-2"), title, qty, productId, productName, reason, items[{materialId, name, unit, issued, returned, net, perProduct, rounded, current|null, status: add|change|same}]}`; деньговым ролям ещё `price`, `priceSource`, `sum`, в корне `total`, `missing`. Пустое предложение — `items: []` + `reason` (готовая фраза).
- `POST /api/stock/composition-suggest/accept` `{salesOrderLineId, materialIds?}` (admin/manager) → свежее предложение + `applied[]`. Пишет `perProduct` (замена, не прибавка).

## Что сделать (критерии — `docs/roles/tz/SKLAD.md` §6 SK-7, SK-9)
1. SK-7b: после успешной выдачи под позицию (панель «Выдать», `salesOrderLineId` есть) — плашка «Добавить в состав изделия <название>?» с кнопками «Посмотреть» / «Не сейчас»; «Посмотреть» → правая панель «Предложено из выдач»: строки «было N, станет M» (status), галочки, «Добавить в состав» (accept с выбранными). Выдача сотруднику, списание, пересчёт, позиция без изделия — плашки нет. Роли без права записи видят без кнопки.
2. Карточка изделия (`sections/products.js` / состав) и карточка заказа (позиция с изделием): блок/ссылка «Предложено из выдач» по позициям — открывает ту же панель (новый `ui/composition-suggest.js` или раздел-панель, по образцу `reservation-edit.js`).
3. SK-9 + SK-4c: кнопки в карточке позиции склада (`sections/stock.js` — модалки «Движение», «Выдать из брони», «Снять бронь») перевести на правую панель `stock-ops` (`?op=…&materialId=`), не потеряв: приход с закрытием заявки, трубу «хлыстами», по весу, снятие брони, выдачу из брони. Чего нет в панели — добавить в панель. «Пересчитать»: «было N, станет M» до записи; факт ниже брони — предупреждение с заказами. «Списать»: причина из справочника, количество, не больше остатка.
4. DESIGN §4/§8.
