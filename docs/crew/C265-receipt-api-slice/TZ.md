# ТЗ C265 — Приход по заявке + откат (одним срезом)

**После:** C263–C264 · **Класс:** L · **Старт:** в той же волне «до конца»

## Зачем
Приход и откат: `supplyrequests` + `stockmovements` + `storageitems` одной операцией. Флаг отдельно от C262 (карточка заявки).

## Сделать
1. Флаг `c265.supply.receive.api` (выкл → 409 на receive / rollback-receipt).
2. Карточка заявки (C262) и move (C263) — свои флаги, не ломать.
3. REPORT + jest supply/stock затронутого; места kppdf — чтение.

## Критерии
- [x] Флаг выкл → 409 на receive и rollback-receipt; карточка заявки остаётся под C262
- [x] Внутренний приход не спрашивает флаг движения
- [x] smoke зелёный

## Нельзя
Снимать Mongo `readWrite` у kppdf; выкладка без «да»; один флаг на все срезы.
