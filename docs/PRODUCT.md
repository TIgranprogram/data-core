## Для кого и как

- Пользователи: владелец (admin), сотрудники (роль `manager`) — снабженец, кладовщик.
- Устройства: компьютер (основное — таблицы с колонками) и телефон (те же данные карточками).
- Вход — логин/пароль сотрудника (те же, что в админке).

## Разделы приложения

Каждый раздел — **одинаковый по устройству** (см. CANON «Экран-список» и «Карточка»): список с поиском, фильтрами, сортировкой и страницами; кнопка «+ Создать»; карточка записи с «Изменить», «Удалить», историей изменений.

### 1. Заявки (снабжение) — коллекция `supplyrequests`
- Поля: №, дата, наименование, кол-во + ед., категория, поставщик, заказ/заказчик, кто подал, статус, приоритет, наша компания, цена (с НДС), сумма, № счёта, доставка, ссылка, артикул, цвет, примечание.
- Статусы: Ожидает → Заказать → В работе → Оплачено → Получено; Отменено. Смена статуса — в одно нажатие из карточки.
- Действия: создать, изменить, **удалить** (в корзину), дублировать, «Оприходовать на склад» (создаёт приход и ставит «Получено»).
- Фильтры: статус, поставщик, категория, кто подал, период. Сортировка по любой колонке.
- Сумма заявок по текущему фильтру внизу списка.

### 2. Склад — `materials` + `storageitems` + `stockmovements`
- Список позиций: наименование, категория, ед., остаток, в брони, свободно, мин. остаток, статус «в норме / к закупке / нет».
- Действия с позицией: приход, списание, бронь, снять бронь, корректировка; изменить; **удалить** (только если остаток 0, иначе — понятное сообщение); «Создать заявку» на эту позицию.
- Журнал движений: отдельная вкладка «Движения» — все приходы/списания по всем позициям, с фильтром по периоду и типу; движение можно **отменить** (создаётся обратное движение, история не стирается).

### 3. Контрагенты — `counterparties` (заказчики) и поставщики
- Один список, тип: заказчик / поставщик / оба. Поля: название, ИНН (необязателен), телефон, email, контактное лицо, адрес, примечание.
- Карточка: всё, что с ним связано — заказы, заявки, сумма оплат.
- Поставщики из заявок (`organizations`, с заглушкой ИНН `БЕЗ-ИНН-…`) — объединить в этот список (задача фазы 4, решение по модели — в TASKS).

### 4. Заказы (доходы)
- Поля: №, дата, заказчик (контрагент), описание, сумма, срок, статус (Новый, В работе, Готов, Отгружен, Закрыт, Отменён), оплачено (список платежей: дата, сумма, способ).
- Карточка заказа: оплаты, связанные заявки снабжения (расходы под этот заказ), списания со склада под заказ, итог «получено − потрачено».

### 5. Деньги (доходы и расходы)
- Операции: доход / расход, дата, сумма, статья (Материалы, Зарплата, Аренда, Доставка, Прочее…), контрагент, заказ, примечание.
- Оплаты заказов автоматически — доходы; оплаченные заявки — расходы (без двойного ввода).
- Отчёт за период: доходы, расходы, прибыль; по статьям; по заказам; по месяцам. Выгрузка в Excel (CSV).

### 5а. Продукция и паспорта изделий (2026-10-23)
- **Изделие — единый источник паспорта.** «Новый паспорт» начинается с блока «Изделие»: категория → изделия этой категории (фото, артикул, «паспортов: N»), поиск — по всем; нет нужного — «+ Создать изделие» (форма изделия справа, после «Создать» — назад в паспорт с выбранным изделием). Пока изделие не выбрано — остальное скрыто.
- Подстановка по порядку: поля изделия (наименование, артикул, размеры в мм, вес, фото, назначение, монтаж, описание) → значения по умолчанию изделия (категория, элементы, установка, ограничения, срок, гарантия) → умолчания категории (справочник) → последний паспорт этого изделия (картинки по видам, тексты). Подставленное — серым с пометкой «из изделия» / «из прошлого паспорта», ручная правка не перетирается.
- Поправили подставленное — «Запомнить для следующих паспортов этого изделия» (пишет значения по умолчанию изделия).
- **Состав изделия** («Изменить состав» в карточке): строки по разделам «Материалы со склада» и «Изделия» (вложенное изделие — его состав раскрывается в карточке на 1 уровень), количество со степпером, цена и сумма, «×» в строке; итог — позиций, себестоимость (материалы по последним закупкам, изделия — по их составу), «без цены: N». «Добавить» — один список с поиском и чипами Все · Материалы · Изделия, «Часто в похожих изделиях» сверху. Изделие не может входить само в себя (проверка по всей глубине). Модули CRM — показываются и сохраняются как были.
- Копия паспорта и правка старых паспортов — как раньше; у паспорта без изделия в карточке «Привязать к изделию» / «Создать изделие из паспорта» (одна модель; массово — только по решению пользователя).

### 6. Поиск «всё о заказе»
- Глобальный поиск сверху: номер заказа / заявки / название / контрагент → список совпадений по всем разделам.
