## Дефект и минимальная коррекция

**P1. Строка ожидания и доступный повтор попали в приглушаемую область карточек.**
Шаги: открыть доску, вернуть429 с Retry-After для «Заказать»; для варианта повтора — вернуть429 без заголовка и задержать ответ соседней колонки. Сравнить light/dark waiting и neighbor-retry.

Причина: `ui/kit/board.js:148–149` создаёт `.col-more.muted[role=status]` внутри `.col-body`; `ui/screens.css:22` задаёт `.board.loading .col-body { opacity:.55 }`. Ошибка с кнопкой добавляется в тот же body в `board.js:325–326`. Результат: важное состояние выглядит как неактивный второстепенный текст/отключённая кнопка. По `--muted` иopacity.55 на фактическом фоне снимка расчётный контраст строки примерно2.26:1(light) и2.71:1(dark), ниже4.5:1.

Нужно отделить сообщение ожидания и доступную ошибку с «Повторить» от приглушаемого body либо ограничить приглушение карточками. Предпочтительна локальная правка существующего kit без нового оформления: сообщение вне body, обычный текст существующего `.col-more`; ошибка/кнопка остаются читаемыми, пока грузятся соседи. Не менять лимиты, таймеры и принятый механизм отмены. Повторить только эти состояния обеих тем, затем сверить восстановление/соседей.

Новый компонент не нужен; используются существующие status/failBlock/button. Мобильная приёмка по решению владельца отложена. Код, карта роли и уроки не изменялись; выпуск не выполнялся.
