# Промпт для сравнения вариантов карточки

Спроектируй и реализуй самостоятельную кликабельную HTML-карточку для настольного «Рабочего места» DataCore. Дай один HTML-файл, который работает локально на учебных данных. Цель: менеджер открывает счёт и сразу меняет дату доставки и примечание, не разыскивая их по меню или вкладкам.

Исходные данные одинаковы для всех вариантов:

- Счёт № 1055, выставлен 25.11.2026, учебный поставщик, 21 750 ₽.
- Статусы для переключения: черновик, выставлен, оплачен, отменён.
- Дата доставки и примечание изначально пустые. Две позиции, один договор, один файл и три события истории.
- Для отменённого счёта поля доступны для чтения. Добавь переключатель режима «только видимые позиции», при котором изменения запрещены.

Расположи данные по частоте использования. Сразу видны номер, состояние, дата доставки и примечание. Покажи позиции, реквизиты, оплату, файлы и историю в подходящих для каждого класса компонентах. Предложи, что раскрывается по запросу, и покажи в заголовке свёрнутого блока, что в нём есть. Сделай сохранение, очистку и повторное открытие на локальных данных. Покажи состояние несохранённых изменений и подтверждение сохранения. Добавь светлую и тёмную темы. На ширине 1280 и 1920 карточка должна читаться без горизонтальной прокрутки, поля доступны с клавиатуры.

Приложи пять коротких пояснений: что видно сразу, что раскрывается, где действия, как показаны ограничения, чем решение удобно менеджеру. Дай результаты трёх сценариев: «открыл → изменил → сохранил», «очистил → снова открыл», «сменил статус → проверил доступность». Не копируй чужой дизайн. Рабочие API и данные не используй.
