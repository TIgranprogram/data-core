# C189 — форма выдачи и инструкция для ИИ

В админке по умолчанию «Только своё приложение» на семь дней. Запрашивается одно имя, клиент проверяет его и показывает, что общая база закрыта. Расширенные режимы подписаны по действительным полномочиям.

Выданный ключ показан в одноразовом окне и убирается при закрытии. Файл и предпросмотр в «Подключении» содержат адрес текущего контура, область доступа и имя переменной `DATACORE_API_KEY`. Тест скачивает реальный файл браузером и проверяет, что синтетический секрет в него не попал. Для записи с повреждённой областью показано «Доступ заблокирован», инструкция недоступна, отзыв доступен.

Синтетическая проверка Edge 1920 × 1080, [светлая форма](proof/api-key-form.png) и [тёмная форма](proof/api-key-form-dark.png). Переход проверен из «API-ключей» и «Подключения». Реальные ключи не выдавались. [Проверки API](KEYS.md) и [права в интерфейсе](ROUTES.md).
