# C096 — визуальная приёмка четырёх исправлений Э4

**Дизайнер: принято — PASS назначенного UI scope.** Финальная проверка 12.11.2026 после исправления длинной кнопки подтверждения. Рабочая версия: bc3ea81 + изменения CLAUDE-E4-FIX-REPORT и корректировки координатора (текст о незавершённом заполнении, короткая кнопка «Создать в этой группе»). Стенд :3102. Код, API и данные проверяющий не менял.

Объём: только новые предупреждения, подтверждения, группа/категория и возврат четырёх исправлений. C097/atlas/main и карта сайта на фоне снимков не принимались. Прежние 60 сценариев, PDF и физическая печать не повторялись.

## Проверка

Сначала прочитаны локальные results*.json и отчёт исправлений, затем открыта целевая выборка PNG через view_image. Access подтвердил завершение новых прогонов. Полный альбом и неизменившиеся состояния повторно не анализировались.

| Сценарий | Результат |
|---|---|
| Частичный успех → предупреждение → назад → продолжить ту же запись | PASS 390/1920 обе темы, один POST; предупреждение называет созданное изделие и незавершённое заполнение, открытие/другое изделие разделены |
| Единственная пропущенная группа | PASS 4 матрицы в results-groups.json: группа подставлена и явно видна |
| Реальные признаки выбранной группы | PASS 4 матрицы в results-groups.json. Проверено отдельно от единственной пропущенной группы |
| Старая форма: наследуемая/явная своя категория | PASS 8 сценариев results-old-entry.json: фильтр не становится скрытой своей категорией; явный выбор сохраняется |
| Старая форма: закрытие после частичного успеха | PASS 4/4 results-old-close.json: предлагается выбрать уже созданное изделие; прежние FAIL ожидания/тайминга не актуальны |
| Чужая категория группы | Desktop обе темы PASS; финальные mobile 2/2 PASS в results-category.json после F1. Отмена без POST, подтверждение создаёт одну запись, фактическая категория BLG без своей категории |

Управляемый отказ запроса нужен для проверки восстановления; это не обнаруженный серверный сбой. Промежуточные results/FAIL PNG не заменяют перечисленные завершённые результаты. Объединённая комбинация «единственная пропущенная группа + признаки» live не проверена из-за отсутствия такой фикстуры: две составляющие проверены отдельно, комбинированная логика покрыта целевыми тестами из отчёта исполнителя. Этот предел не выдаётся за объединённый live PASS.

## F1 закрыт повторной визуальной проверкой

Длинная подпись «Создать в группе …» выходила за зелёный фон/модальное окно и пересекала «Отмена» на390. Координатор сократил её до «Создать в этой группе»; полное название группы осталось в пояснении. В обоих новых мобильных снимках кнопки раздельны, надписи помещаются, текст последствий читается целиком. Live после исправления подтверждает отмену без создания и корректное подтверждение.

Незакрытых блокеров назначенного UI scope не обнаружено. Физическая печать и исходный проблемный PDF по-прежнему за пределами этой проверки. Карта роли обновлена; код не менялся, коммит/деплой не выполнялись.
