# C087-THEME — проба мягкой светлой темы

В «Рабочем месте» переключатель темы после светлой открывает мягкую светлую. Проверить заполненную витрину продукции и карточку паспорта на широком и мобильном экране. Сравнить с обычной светлой и тёмной темами. Проверить сохранение выбора после перезагрузки, читаемость подписей, ссылок и состояния фокуса. Эталоны — существующие карточки, формы и таблицы. Меняются общие токены, без стилей отдельных экранов.
