# C144 — порядок в справочниках паспорта

**Вердикт:** директор видит, к каким типам привязана запись, но по этому экрану пока нельзя понять, что предложат при заполнении и чего не хватает. Подпись «Для всех» у части обещает обратное. Пустая привязка элемента трактуется в документах по-разному. Выводы о текущем поведении основаны на отчёте проверки кода, без проверки списков на стенде.

| Сейчас | Должно |
|---|---|
| Чтобы оценить один тип, нужно обходить отдельные справочники. | За минуту: «Справочники → Паспорта → Благоустройство». В одном обзоре видны части, элементы, материалы, покрытия, тексты по разделам и места, где предложений нет. Из каждого пробела можно перейти к нужному справочнику. |
| Фильтр материалов и покрытий учитывает тип, но включает записи «Не предлагать в новых». В книжке их нет в новом выборе, а материалы чужих типов остаются в группе «Другие». | Справочник показывает те же группы, что книжка и черновик: «Предлагают сразу», «Другие», «Не предлагают в новых». Уже выбранное в изделии остаётся видимым с пояснением. |
| Пустое «кому» у материалов и покрытий означает общий доступ по типу, но у покрытия в книжке основание скрыто. | Подписать «Для всех типов». Для покрытия отдельно показать применимость к выбранной части, если она задана. «Для всех типов» говорит только о типе паспорта. |
| Пустая привязка части в списке означает отсутствие в коротком списке, а в форме подписана «Для всех». Подсказка книжки может предложить такую часть как предпочтительную. | Везде «Только через “Показать все части”». В короткий и предпочтительный списки попадают части с привязкой к выбранному типу. Разовый выбор не меняет справочник. |
| Для элементов отчёт фиксирует пустое «кому» как «Для всех», а SHOULD.md предлагает трактовать его как у частей. | До решения владельца сохранять текущий смысл и явно подписывать «Для всех типов». Изменение смысла существующих записей согласовать отдельно. |
| В дереве текстов видны отдельные привязки, но нет обзора по типу. Тип сам по себе не определяет итоговый текст паспорта. | По типу показать разделы в порядке паспорта: общий текст, вариант типа, варианты с условиями по изделию. Отметить «Нет подходящего текста» в обязательном разделе. Для точного предпросмотра учитывать группу, признаки, состав и монтаж выбранного изделия. Ручной выбор сохраняется. |
| В деталях текстов и у неизвестной привязки видны коды. У дефектов колонка может создавать впечатление прямой привязки к типу. | Везде названия типов словами. Для потерянной связи — «Тип не найден». Для дефектов показывать связь через элементы и материалы. |
| Справочник отвечает за будущий выбор, но по нему легко ожидать изменений уже оформленных паспортов. | После смены типа черновика пересчитать предложения и пометить сохранённые несовпадения. Выпущенный паспорт хранит свои данные и тексты. |

**P0** — блокирующих находок по отчёту нет.

**P1** — согласовать значения пустых привязок и подписи, привести фильтр и книжку к одному правилу предложения, добавить обзор текстов по типу с пробелами в обязательных разделах. Принять на одном типе и одном изделии: сверить обзор, выбор в книжке и предпросмотр черновика.

**P2** — заменить коды названиями, объяснить применимость покрытия и дефекта, дать переход от обнаруженного пробела к редактированию записи.

**Вопрос владельцу:** у уже заведённого функционального элемента пустое «Кому предлагают» должно по-прежнему означать «Для всех типов» или такой элемент должен быть доступен только через «Показать все», как часть? Это меняет предложения по существующим изделиям.
