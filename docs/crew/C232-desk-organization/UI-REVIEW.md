# Приёмка C232

Проверка в Chrome на тестовых данных, разрешение 1920 × 1000. Светлая и тёмная темы.

| Сценарий | Результат |
| --- | --- |
| Стопки | Создание, переименование, перенос карточки, удаление с выбором назначения. |
| Личная задача | Открытие из стопки. Добавление заказа из недавних и конкретной позиции по ссылке. Переход в карточку позиции. |
| Файлы | Загрузка файла и скачивание с исходным названием. API отдельно проверяет снятие и восстановление файла. |
| Завершение и корзина | Отмена подтверждения, удаление, восстановление. Восстановленная задача остаётся завершённой вместе со связанными записями и файлами. |
| Права | Браузерный сценарий c ограниченной ролью. API отклоняет чужую учётную запись, прямой доступ к хранилищу и вход без сессии. |
| Регрессия | Прежние сценарии переноса, конфликта версий и восстановления карточки зелёные. |

Снимки — [светлая задача](proof/soft-task.png), [тёмный стол](proof/dark-board.png), [корзина](proof/dark-trash.png). Свежие снимки сняты после подстройки ширины стола при открытой панели и положения корзины.

Проверки — 3 сценария браузера, 4 сценария E2E API на `datacore-test-c232-desk`, 24 теста DTO, TypeScript, ESLint затронутых файлов, design-lint.
