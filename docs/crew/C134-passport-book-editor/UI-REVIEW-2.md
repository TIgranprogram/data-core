# C134 — дизайн окна паспорта, проход 2 (datacore-designer, 2026-11-16)

Правка: только CSS, блок «C134 дизайн-2» в конце `backend/pwa/ui/kit/kit.css` (токены).

## Сделано (CSS)
- Шапка: вторичные кнопки (ghost) получили рамку и цвет текста — один вид «По ширине/100 %/Скачать/Закрыть»; неактивная «Сохранить и выпустить заново» — серая рамка вместо бледной заливки; «Закрыть» отделена отступом.
- Правая панель: заголовок «Текст пункта» — h3, цвет текста; поле с рамкой и фоном `--bg`, фокус — рамка `--primary`; блок «Проверка текстов ИИ» сразу под редактором (убран `margin-top:auto`).
- Лист: пункты без серой плашки — тонкая полоса источника 2px, «Общий» без полосы; фон источника — только при наведении и правке; выделенный — тонкая рамка `--primary`.
- Колонтитул: цвет `--muted`, линия `--border`.
- Список страниц: цвет текста, стиль текущей `.is-current` / `aria-current` (`--primary-soft`).

## Нужно в JS (не правил)
1. `book-editor.js` paintHead: «По ширине» / «100 %» — сегмент-переключатель (`.seg`), а не primary/ghost: сейчас выбранный масштаб залит как главное действие и спорит с «Выпустить».
2. Список страниц: ставить `aria-current="true"` текущей странице (IntersectionObserver по `.bk-page`) — CSS готов.
3. Пустота внизу листа — из разбивки `room()` (поля 18 %); менять вместе с `padding` `.bk-page`, иначе страницы поедут.
