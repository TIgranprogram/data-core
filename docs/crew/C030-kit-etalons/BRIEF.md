# C030 — новые эталоны kit для 5 экранов (ДОЛГ-L3), координатор 2026-11-07

Класс: **L** (kit + несколько экранов). Агентов ≤ 4: designer (спецификация) → frontend (эталоны kit) → внешний ИИ (перевод экранов, рутина) → designer (приёмка по снимкам).
Экономия токенов: каждый читает только файлы своего шага; полные выводы — в этой папке, в чат — резюме.

**Цель.** Экраны строятся только из эталонов kit (DESIGN §4 «Закон»). У 5 экранов свои классы, у которых нет эталона (отчёт `docs/crew/C029-lint-debt/REPORT.md`, «Этап B, пачка 1»): главная `home.js` (`td-*`), склад `stock.js` (`sec-*`, `cat-*`), каталог поставщика `supplier-catalog.js` (`sc-*`, `ls-*`), справочники `dicts.js` (`dict-*`, `pt-bar`, `pf-*`), заказы `salesorders.js` (`so-*`, `ua-*`, `rdy-*`, `tl-*`, `ol-*`, `mt-*`, `op-act`, `pic-cell`). Плюс `.hint` живёт в `ui/screens.css`, а пользуется им kit.

**Правила.** Вид экранов для пользователя не должен «поехать»: эталон повторяет нынешний вид, если он хороший; плохое — чинится по DESIGN. Новый эталон — только если существующий (с новым вариантом) не подходит. Запретная зона до понедельника: `money*`, `kp*`, `offers*`, статьи расходов, `docs/QUESTIONS.md`.
Измерение: `node backend/scripts/design-lint.mjs` (итог сейчас 7113, L3 1372; только вниз).
