# Возврат к каталогу из отправленной корзины

После неполного ответа «К каталогу» открывает просмотр номенклатуры, нижняя кнопка «Корзина» возвращает тот же пакет. Пока сервер не подтвердил отправку, позиции пакета и ключ сохраняются. При недоступном каталоге экспорт и повтор остаются доступны из корзины.

В обычной и отправленной корзине трубы имеют общие колонки штук и метров, штучный крепёж выровнен с колонкой штук. Для остальных единиц появляется количество с подписью. После отправки колонка действий скрыта. Название и пояснение занимают две компактные строки.

Проверено в Chromium на тестовом ответе с сохранением одной из двух позиций. При повторе оба тела совпадают, итог — две записи. Проверена клавиша Enter в каталоге при ожидании и закрытие с повторным открытием корзины. Все 12 браузерных сценариев и 438 правил PWA прошли. Независимая визуальная приёмка пройдена в обеих темах на обычной и расширенной панелях. Светлые снимки отдельного окна и панелей — tools/logs/c280-cart-return/.
