# C192 — заявки, каталог и дубли

При сохранении новой заявки с названием создаётся или переиспользуется карточка материала. Новая карточка имеет тип `purchased`, нулевой физический остаток и не создаёт складского размещения или движения. Поставщик необязателен. В одну транзакцию входят резервирование нормализованного имени, создание материала и запись заявки. При отказе архивного договора материал не остаётся. Материал с тем же именем из PDM не становится покупной строкой. Если выбрана существующая номенклатура, заявка использует её идентификатор. Приёмка по-прежнему добавляет физический остаток только по операции «Принять на склад».

В «Остатках» после отметки двух строк доступно «Сравнить дубли». В каталоге, где доступны и нулевые позиции, у обычного сравнения добавлен переход «Складские связи». Сравнение читает карточки, физические остатки и бронь отдельно по размещениям, число заявок, броней и движений. Предпросмотр ничего не переносит. Он доступен менеджеру и администратору только при доступе к обеим позициям.

## Что блокирует запись объединения

Механизм из C168 остался архитектурным планом. DataCore и CRM пишут в общие коллекции `materials`, `storageitems`, `stockmovements`, `reservations`, `supplyrequests`. Код CRM недоступен в текущем локальном окружении по указанному в проекте пути. Пока нет доказательства, что отдельный писатель перестанет писать по старому идентификатору после объединения. Без общего протокола конкурентная приёмка или бронь может восстановить старый остаток и раздвоить историю. Поэтому доступен предварительный просмотр, без подтверждения переноса. Для завершения сначала нужно проверить/согласовать запись через CRM и повторные приёмки по старым заявкам, затем пройти транзакционные тесты по [C168](../C168-stock-duplicate-merge/ARCH-PLAN.md).

## Проверки

Опорный C192 и четыре соседних набора на MongoDB 4.4: 45 успешных проверок. Две параллельные заявки используют один материал, повтор не дублирует запись, без поставщика и при нуле карточка есть в каталоге. Отдельно проверены существующие заявки, приход в офис без размещения, старая номенклатура, архив, предварительный просмотр двух зон и отсутствие записи. Все данные синтетические.
