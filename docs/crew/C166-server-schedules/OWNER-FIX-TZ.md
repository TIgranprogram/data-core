# Профилактика прав служебной очереди

Класс M. Один инфраструктурный исполнитель; координатор проверяет diff и Linux-доказательства. Основание и разрешённая точечная починка — POST-RELEASE.md.

- Scope: существующие setup/watch/release-artifact и их host-тесты; runtime backend, PWA, база и секреты вне scope.
- Владелец switch должен совпадать с фактическим пользователем cron, режим1777. Setup меняет только сам каталог под замком; без рекурсивного chown/chmod777 и назначения владельцем случайного пользователя выкладки.
- Runtime проверяет инвариант до heartbeat и claim; неправильные права — явный отказ. Завершённая заявка снимается без повторного исполнения; ошибки unlink не объявляются успехом.
- Root-owned файл0644 в root-owned sticky1777 должен воспроизвести реальный отказ UID службы. Linux tmpfs без сети: после точечной смены владельца каталога файл снимается, содержимое/владельцы прочих файлов не меняются, следующая заявка принимается.
- Прогнать прежние host47 и новые Linux-регрессии; сохранить выводы и краткий OWNER-FIX.md. Прод/SSH не трогать, коммит выполняет координатор.
- Внутренний Linux-тест зарегистрировать NOT_ON_BUTTONS; не превращать проверку в кнопку ремонта живого сервера.
