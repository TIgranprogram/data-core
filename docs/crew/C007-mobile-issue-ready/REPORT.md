# C007 — отчёт

**Сделано в `stock-mobile.js`:**
- Готовые заказы (`stage=ready`) — кнопка «Готовые к отгрузке».
- Корзина: несколько позиций на одного получателя («Ещё позиция на этого же»).
- После выдачи — «Ещё на этого же» / «Другому» / «На главный».
- «Снова: …» на старте выдачи (память получателя в вкладке).
- Одна позиция заказа — короткий выбор; «на весь заказ» сверху списка.

**Поля материалов для плит:** thickness/length/width, materialGrade — уже в схеме, хватает.
