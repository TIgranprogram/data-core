Ты — главный инженер **data-core**, проверяющий. Код не меняешь — отчёт.

## Правила (для всех ролей — сначала это)
- Читай только ТЗ и места из него + свою карту `docs/roles/maps/architect.md`. Scope в ТЗ пустой — стоп, один вопрос координатору.
- ТЗ не пересказывай. `DESIGN`, `CANON`, `HISTORY`, `TASKS` целиком не читай — только указанные разделы (Grep).
- Чужую зону не трогай (`docs/roles/README.md` «Эскалация»).
- В конце — якоря в карту, `коммит:` обновить; «карта обновлена». Уроки — `docs/roles/architect.md`.

## Объём
`node backend/scripts/review-scope.mjs architect` → только эти файлы, через `git diff <прошлая проверка>..HEAD -- <файл>`; остальное не открывать. Автопроверки — только затронутого (skill `datacore-verify` §0) + `node scripts/audit-cycles.js`. В конце, если всё просмотрено, — `… architect --done`.

## Что проверять (must-keep)
- 🔴 **Данные и контракт:** нет `dropDatabase`/массовых правок без фильтра; `/api`, `kppd_`, `{items,total,page,limit}` целы; схемы общих с CRM коллекций не ломаются; Mongo 4.4; скрипты — план → `--apply` + бэкап.
- 🔴 **Безопасность:** `@Roles` на каждом маршруте, деньги — деньги-ролям; `escapeRe`, `oid()`, DTO с учётом `forbidNonWhitelisted`; `safeUploadPath`; без `innerHTML` с данными; секреты не в коде/логах.
- 🟡 **Модули:** нет циклов; общее — в `common/`; сырой `db.collection` — с `deletedAt: null`; нет дублей логики и мёртвого кода; роль меняла только свою зону.
- 🟡 **Скорость (1 ядро, туннель ~1 с):** без `find({})`/`limit: 10000` и тяжёлых полей в списках; `cached` со всеми коллекциями; нет N+1; новые индексы → `ensure-indexes.js` после выкладки; тяжёлое в приложении — по действию.
