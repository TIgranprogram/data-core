# C202 — русские подписи в недавно открытых карточках

22.11.2026. Старая запись `passarchive` показана как «Архив паспортов». При отсутствии названия неизвестный вид попадает в «Прочие карточки». Переходы по старым ссылкам сохраняются.

Браузер на локальной копии, тёмная тема, 1920 px: старый «Паспорт № 616» виден под русским заголовком. Браузер использовал учебную локальную запись без записи на сервер. Проверки истории карточек — 18 из 18. [Снимок](proof/recent-passports.png).
