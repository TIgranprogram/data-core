# C131 — Карточка заказа и договора: позиции видно и можно добавить

Класс: M · Агентов: ≤ 2 (datacore-frontend + datacore-designer) · Проверка: smoke + снимки стенда.

## Что сказал пользователь (2026-11-16, заказ 22-26, договор 39 ССЮ)
1. Окно «Договор 39»: «Позиций 0», позиций не видно — **где добавить или редактировать?** Кнопки добавления нет.
2. Карточка заказа 22-26, «Готовность → В заказе есть позиции — Открыть»: **кнопка не работает**.
3. Пустой заказ показывает подсказку «"⋯" вверху → "+ Позиция"» — путь спрятан. Нужна видимая кнопка.
4. **Эталон — карточка заказа 11-26** (таблица позиций: галочка, №, фото, название + «Наше:», кол-во; низ — «Весь заказ · N позиций», «Документы», «Работа», «Файлы»). Карточки других заказов выглядят иначе → привести к эталону.

## Что сделать
- **А. Окно договора** (`backend/pwa/sections/salesorders.js`, окно договора; группа договора — стр. 200–230): блок «Позиции» со списком позиций договора (вид эталона) и видимой кнопкой «+ Позиция» (как пункт меню стр. 218). Пусто — пустое состояние с этой же кнопкой.
- **Б. «Открыть» в «Готовности»**: найти обработчик (grep «Добавьте позиции в договор»), починить. Ведёт в договор к добавлению позиции.
- **В. Пустой заказ** (стр. 259, `empty.hint`): вместо текста про «⋯» — кнопка «+ Позиция» в пустом состоянии (договор один — сразу; несколько — выбор договора).
- **Г. Единый вид карточки заказа**: сравнить 11-26 с 22-26 и 2–3 другими заказами (разные этапы, пустые/полные). Почему 22-26 другой: блоки «Что дальше», «Выполнение заказа» над/вместо таблицы. Решение: таблица позиций (эталон) всегда первой; «Что дальше» и «Выполнение заказа» — ниже или свёрнуто; низ — одинаковый. Отличие по этапу — только содержимое, не раскладка. Отметить эталон в `docs/DESIGN.md` §3.1 / `tpl` в atlas.
