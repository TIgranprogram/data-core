# C200 — пакет КП из корзины

22.11.2026. Chrome, 1440 px, вложенная правая панель шириной 576 px. Светлая и тёмная темы. Штатные клики «В КП» и «КП (1)» на изолированной браузерной модели. Выбрать три фирмы с наценками 0 %, 3 % и 5 % можно из заполненной корзины через «Собрать пакет КП».

Проверено сохранение ручных цены, количества, единицы, цвета, размера, заказчика и общих условий. Автоусловия одной фирмы убираются при переходе в режим пакета. НДС и бланки каждой фирмы вычисляются на сервере. При отказе введённые поля остаются, после подтверждённого успеха открывается первое КП. Дизайнер принял проверенные состояния. [Светлая тема](proof/light.png) · [тёмная](proof/dark.png) · [отказ](proof/refusal.png).

В локальной копии у всех трёх фирм есть бланки. На тестовой MongoDB 4.4 проверена выдача трёх черновиков и отдельных многостраничных PDF, включая бланк без отметки «По умолчанию» и белое продолжение вместо чужой страницы. 11 HTTP и 85 модульных проверок, TypeScript и ESLint модуля прошли. Реальный ZIP и три фактических фирменных образца остаются в чек-листе.
