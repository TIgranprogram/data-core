# C235 — тексты назначения и эксплуатации изделий

23.11.2026. Проверка только локального кода и документации, без обращения к рабочему API, без изменения паспортного стандарта. Наличие конкретных заполненных текстов на рабочем сайте этим отчётом не подтверждено.

Дополнение после проверки access: [один рабочий пример «Вело», артикул 1068](PROD-SAMPLE.md). Общие разделы на сайте есть, но описание/назначение/инструкция модели пусты, readiness=false; это не готовый публичный текст. Остальной каталог не проверялся.

## Ответ владельцу

Готова основа: описание изделия, назначение по подтверждённым признакам, правила пользования, монтаж и обслуживание; всё собирается в образец/паспорт. У тренажёров предусмотрены признаки групп мышц и общие фразы назначения.

Подробная инструкция конкретного тренажёра как на скриншоте — исходное положение, движение рукояток, последовательность выполнения, конкретные мышцы — отдельной готовой библиотекой упражнений в просмотренном коде не обнаружена. Существующие общие фразы и правила безопасности не доказывают эти сведения для конкретной модели. Внешний ИИ автоматически такие инструкции сейчас не создаёт: в книжке есть кнопка копирования промпта, а не встроенная генерация с проверенными знаниями о механике изделия.

Новый справочник не обязателен только ради хранения абзаца: дерево «Тексты паспорта» уже поддерживает раздел «Правила пользования», применимость и собственные формулировки. Но содержание каждого упражнения и соответствие модели необходимо подтвердить. Для структурированных упражнений с мышцами, шагами, иллюстрациями и отдельной публикацией на сайте потребуется отдельное решение/ТЗ; это не следует считать готовой функцией.

## Где получить уже имеющееся

1. «Изделия» → нужное изделие → меню «⋯» → «Шаблон паспорта».
2. В «Подготовка паспорта» выбрать тип, вид и критерии изделия; «Подобрать назначение» показывает готовые варианты и текст. «Своя формулировка» сохраняет текст изделия отдельно от общего справочника.
3. На листах книжки посмотреть описание, назначение и правила пользования. «Образец»/«Буклет образца» дают PDF без выпуска экземпляра и номера. Для имеющегося экземпляра есть «Скачать PDF».
4. Общие правила элемента: «Справочники» → «Паспорта» → «Функциональные элементы» → элемент → «Правила пользования» (по строке на шаг). Варианты разделов: «Тексты паспорта» → «Правила пользования». Общие справочники требуют права director/admin; пользовательское назначение редактируется в рамках прав на изделие.

Отдельной кнопки «Скопировать инструкцию для сайта» или экспорта инструкции в HTML в просмотренном UI нет. Текст можно получить из показанного образца/полей вручную; программно уже есть серверная JSON-проекция шаблона. Экспорт PDF — готовая функция, отдельная публикация карточки товара на внешнем сайте — не подтверждена.

## Чего не хватает для уровня примера

- Идентификация точной модели и каждого упражнения/рабочего места, подтверждённая механика движения и ограничения.
- Проверенные автором/конструктором инструкции по исходному положению и шагам, а также обоснованный список мышц. Число занимающихся брать из подтверждённых характеристик, не из похожего фото.
- Заполнение применимых текстов и признаков конкретных изделий. По одному наличию кода нельзя объявить весь каталог заполненным.
- Если нужен именно блок внешней карточки товара — формат и действие выдачи/публикации (текст/HTML/API), а не только PDF паспорта.
