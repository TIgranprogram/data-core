## Спорные (решает пользователь; скрипт их только показывает)

1. «Ограждение на опорных стойках» у тренажёров и детского игрового — предлагаю убрать (в корзину): ограждение — благоустройство (у WRK оставить: в старых паспортах воркаута встречалось).
2. Первая строка «Текста монтажа» у 4 способов установки («где ставится») — предлагаю убрать: она повторяет «Готовые тексты → Установка». 2026-10-22 вы сказали на неё «да» (П-10 1.1–1.4), поэтому без нового «да» не трогаю.
3. Норматив GOST_R_2_610 у «Благоустройства» — лишний (уже есть у «Для всех»).
4. Разные тексты одного варианта, у которых мало общих слов (пример: «Монтаж выполняется по согласованию…» против эталона) — какой оставить, решает пользователь.
5. Один текст под разными названиями варианта; одно название с разными кодами — скрипт показывает, сам не объединяет.
6. Материалы без аналога (поликарбонат, композитная панель, камыш, бетон) — уход и дефекты дописать вручную.

## Нужно от других ролей
- **аналитик** (структура «раздел → вариант → текст»): «Назначение» сейчас берётся из двух мест — «Готовые тексты → Назначение» (поле паспорта) и назначения элементов (собирается само). Сейчас это два одинаковых по смыслу набора (например, «Баскетбол» и элемент «Баскетбольная стойка»). Нужно выбрать один.
- **frontend**: если переименовывать варианты установки в «Готовых текстах», надо поправить `INSTALL_VARIANT` в `backend/pwa/sections/passports/wire-form.js:92` (подстановка ищет вариант по названию). Скрипт названия не меняет.
