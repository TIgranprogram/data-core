# ТЗ C057 — «Загрузка из PDM»: изделие из SOLIDWORKS PDM → полноценная продукция на сайте

**Зачем (словами пользователя, 2026-11-09):** «После проектирования: набираю номер → ищет в PDM → „Загрузить на сайт“ → изделие полностью: модули, детали, картинки, чертежи. Потом из него паспорта, документация. Без дублей: есть — предупредить, сравнить, обновить. Детали связаны с материалами, которые покупаем».
**Зачем — глаголом:** администратор за 2 минуты загружает изделие из PDM; сайт сам показывает, что купить для его изготовления; менеджер вписывает только названия.

## Глубже
- **Результат:** цель CONTROL «продукция и паспорта из одного источника» — изделие 6104 на сайте со всем деревом и «Что купить».
- **Сырьё:** живое PDM (6104), прод `materials` (419 позиций, разведка в `ANALYSIS.md`).
- **Метод профи:** PLM→ERP интеграция: ключ — обозначение; позиция номенклатуры одна; сортамент отдельно от формата; файлы с версиями; импорт «предпросмотр → решения → применение», идемпотентно.
- **Внешний судья:** эталон `6104.0000.0000_BSUP_SD.xlsx` (110 строк, 2145 шт) = развёрнутое дерево на сайте; повторная загрузка 6104 → 0 новых записей; e2e на тестовой базе.
- **Смелая планка:** загрузка 6104 ≤ 2 мин; 0 дублей при повторе; 110/110 с эталоном.

**Класс:** XL · **Max agents:** 5 · **Reviewers:** analyst (сделано — ANALYSIS) · architect ☑ (opus — DECISIONS) · qa ☑ · designer ☑ (экраны) · **Max review loops:** 2 · **Проверки:** full перед выкладкой
**Язык менеджера:** да. **Приёмка:** стенд — 6104 загружено, дерево, «Что купить», файлы с версиями.
