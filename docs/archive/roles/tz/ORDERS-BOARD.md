# ТЗ ORDERS-BOARD — «Заказы»: на карточке доски «что дальше» и счётчики (TASKS 2.4)

**Зачем:** открыл «Заказы» и сразу видишь, что с каждым заказом сейчас и какой следующий шаг, как на доске «Проектирования».

**Класс:** M · **Max agents:** 2 (backend-мелочь + frontend) · **Reviewers:** designer ☑ qa ☐ · **Max review loops:** 2 · **Проверки:** smoke (tsc 0, юнит salesorders, `node --input-type=module --check`)
**Язык менеджера:** да — без кодов, фразы из таблицы · **Приёмка:** `#salesorders` — доска, 3–4 заказа разных этапов: на карточке фраза «что дальше», счётчики, кнопка.

## Что уже есть (находка: переключатель и доска существуют)
- Доска уже стоит по умолчанию: `pwa/sections/salesorders.js:464–476` (`board.default`), колонки new, production, ready, partly, shipped (`:467`); «Таблица» — `?view=table`, переключатель — `ui/list.js:81–84`. Перетаскивание = смена этапа (`move: setStage`, `:475`).
- Закрытые — вкладка «Завершённые» (`:436`), на доску не идут. Фильтры — чипы «Новые / В работе / Отгруженные / Завершённые / Все» (`:436`), поиск `:429`.
- Карточка (`:468–473`): № · заказчик, договоры, поз., срок, приоритет, флаг несопоставленных. **Нет:** «что дальше», счётчиков.
- Текст «что дальше» живёт только в карточке заказа (`STAGE_NOW`, `:48–55`; `:490`), не в доске.
- Данные списка `/production-orders` (`production-orders.service.ts:176–187`): stage, deadline, lineCount, `readiness.ready` (bool), stagesDiffer. **Нет в списке:** `unassignedCount` (считается в `agg` и `sum`, наружу не отдан), числа по проектированию/заявкам/работе/броням (есть в `loadReadinessFacts`, `order-readiness.ts:10,38–54`; уже загружены в `:173`), отгрузок.

## Решение (вид)
**Колонки (оставить как есть, 5):** Новый → В производстве → Готов к отгрузке → Частично отгружен → Отгружен. Названия — `STAGE` (`:36`). «Закрыт» и «Отменён» — вкладки/таблица.
Подписи колонок на языке менеджера (подзаголовок серым, ≤ 3 слова): Новый — «проектирование»; В производстве — «изготовление»; Готов — «ждёт отгрузки»; Частично — «досдать остаток»; Отгружен — «закрыть заказ».

**Карточка:** строка 1 — `№ 25 · Заказчик`; строка 2 — срок (красный, если просрочен — `due`, `:69`) + приоритет; **строка «что дальше»** (одна фраза, жирнее серого, цвет по таблице); строка счётчиков (чипы, показывать только ненулевые): «не распределено N» (красный), «проектирование N», «заявки N», «в работе N», «брони N», «отгрузок N». Внизу — одна кнопка из таблицы. Клик по карточке — как сейчас (открывает заказ).
**Фильтры:** без изменений + один новый чип «Мои/Все» не нужен (ЗО-ТЗ отдельно). Добавить только чип «Просрочено» (срок < сегодня, этап не shipped/closed) — на клиенте по `deadline`, без сервера.
