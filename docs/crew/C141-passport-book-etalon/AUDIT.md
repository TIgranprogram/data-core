## Путаница имён (зафиксировать в UI)

| Слово на экране | Смысл | Где правда |
|--|--|--|
| Тип паспорта (BLG, DIO…) | Какой комплект текстов/рисунков PDF | `passportCategory` / справочник типов |
| Раздел / группа / подгруппа изделия | Что это за изделие в каталоге | `products` category tree |
| Выбор для текстов | Назначение, монтаж, признаки → какие абзацы | `textChoices`, facets |

Правило владельца: **группу изделия из книжки не меняем**; тип паспорта на экране — подпись (не селектор «перепридумать изделие»).

## Эталон: что уже есть vs дыры

| Тема | Есть | Дыра |
|--|--|--|
| Страницы как PDF | да | чуть уже текста |
| Лево: страницы + выбор | да (`book-choices`) | узко; тип — селект со сменой; нет пути изделия |
| Правка кликом | да | уходит в **правую** панель |
| Цифры/таблицы | клик есть | не inline в ячейке |
| Цвета источника | легенда внизу | страницы слева не подсказывают «от изделия» |
| Картинки | strip на листе | ок |
| ИИ-проверка | правая колонка | ок оставить |
| Запись в корень изделия | нет из книжки | габариты/вес/состав — волна 2 |
