- «Принять на склад» (`stock-ops-pick.js`): поиск — клиентский combo по уже загруженному складу, изменений не нужно.
- Шаг 2: тип считается на клиенте (`facetsOf` по названию, как фильтр «Тип»): `core/facets.js` `typeValues`/`byType`/`TYPE_ALL`. «Выдать» (карточка склада) и «Принять» — шаг «Тип» после категории, «Все типы» последней фишкой, <2 типов — пропуск, >7 — список (funnel).
