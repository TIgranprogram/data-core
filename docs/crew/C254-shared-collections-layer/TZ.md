# ТЗ C254 — Слой общих CRM-коллекций (мелкие поставки)

**Программа:** [C246/CHECKLIST](../C246-architecture-modularity/CHECKLIST.md) · этап 8 · ARCH-PLAN АБЗ-3  
**Класс:** L · **Зависит:** C250 · **Проверки:** на каждую поставку — свои; full перед выкладкой поставки на прод

## Ограничение
Гарантия владения — **внутри data-core**. CRM пишет shared напрямую; фиксируем совместимость схем, не «полный контроль».

## Поставки (каждая сама зелёная и откатываемая)

Отмечать в `REPORT.md` / подчек-листе здесь:

- [x] **C254-0** — слой чтения + контракт полей (без перевода всех потребителей)
- [x] **C254-a** — один потребитель (например `partners`) → слой; коммит; проверки модуля
- [x] **C254-b** — следующий потребитель (`finance` / `fill-audit` — по INVENTORY)
- [x] **C254-c** — `dicts` и прочие по одному
- [x] **C254-w** — запись shared в data-core только через `StockService`/`SupplyService`
- [x] **C254-doc** — ARCHITECTURE / UNIFY: совместимость с прямой записью CRM

Места с намеренным `includeDeleted` — явно. Не один коммит на весь L.

## Критерии закрытия C254
- [x] grep сырых записей shared вне stock/supply в backend data-core = 0 (C254-w)
- [x] все подпоставки `[x]`; full по затронутому — **перед выкладкой**, не блокер коммита doc

## Нельзя
- Править shared-схемы вразнобой с kppdf.
- Один монолитный коммит «весь АБЗ-3».
