# ТЗ QR-CODES — QR у позиций склада и изделий (класс L; совет opus 2026-11-01)

Пожелание пользователя: у каждой позиции склада и изделия — свой QR, создаётся автоматически и хранится; печать одной и пачкой на А4 (режем, клеим); один универсальный QR — приложение само решает действие по месту и роли.

1. **Содержимое:** URL `https://kppdf-crm.ru/db/q/<код>`; код — префикс типа + 8 символов base32 без 0/O/1/I/L, случайный: `S-` позиция склада (то, что выбирает stock-mobile: /stock/items), `M-` материал (если понадобится), `P-` изделие (products). Пример `S-7K3QX9TD`.
2. **Хранение:** отдельная коллекция data-core `qrcodes {code, entityType, entityId, createdAt, deletedAt}`; уникальные индексы `code` и `{entityType, entityId}`; общие с CRM схемы НЕ трогаем.
3. **Генерация:** `ensureCode(type, id)` — upsert, гонка → 11000 → перечитать; при создании позиции в data-core и при печати; скрипт `qr-backfill.js` план→--apply. Картинки не хранить: векторно на лету из матрицы npm `qrcode` (уровень коррекции M).
4. **Наклейка:** QR 25×25 мм, тихая зона 2 мм, подпись 2 строки 7 pt (название обрезано; артикул/код); ячейка 38×38 мм; поля 8 мм → 5×7 = 35 на А4; линии реза пунктиром; «пропустить N ячеек» для начатого листа. PDF — pdfkit + guardDoc, кириллица встроенным шрифтом common/print. `POST /api/qr/print {items:[{type,id}], skip?}` ≤ 350 позиций.
5. **Чтение:** `GET /api/qr/:code` → `{entityType, id, name, article, deleted}` (JWT, роли склада и менеджер, без цен; код проверять регэкспом до запроса). Публично `GET /db/q/:code` → редирект на `/db/app/#q=<код>` (без входа — форма входа).
6. **PWA:** «Распечатать QR» — галочки в «Остатках»/«Продукции» и в карточке; сканер в stock-mobile (`scanButton`): BarcodeDetector, иначе jsQR по нажатию; после скана — роль ассистента → выдать/принять эту позицию, менеджер → карточка, изделие → карточка изделия. Удалённая позиция — «Позиция удалена».
7. **Порядок:** (M) сервер qr + backfill → (M) печать + кнопки, дизайнер → (M) сканер и маршрут.
Ловушки: перепечатка не меняет код; код не удаляется с позицией; Mongo 4.4; DTO заранее (forbidNonWhitelisted).
