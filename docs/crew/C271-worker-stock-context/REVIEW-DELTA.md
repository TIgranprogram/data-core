- Адресный HTTP/Mongo `datacore-test-c271` 5/5. Первый прогон выявил сравнение BSON ObjectId со строкой в новом тесте. После приведения обеих сторон к строке прогон зелёный. Журнал `tools/logs/e2e-c271-backend-followup.log`.

Статические находки для архитектора:

- `supply.service.ts:227` публикует поля исходной заявки и обогащает `invoiceAmount` и `invoiceNote`. `MONEY_FIELDS` не включает их. Списку рабочего контекста нужна проекция по явному списку полей.
- Глобальный `IdempotencyInterceptor` (`app.module.ts:278`, `idempotency.interceptor.ts:109`) возвращает сохранённый ответ раньше `createStockRequest`. При совпадении ключа и отпечатка проверка живого материала, текущего остатка и C262 в owner action не запускается. `AuditInterceptor` пишет запись на каждый успешный вызов, дошедший до обработчика, включая 201 повтор. Текущий HTTP тест гонки использует UUID в теле.
