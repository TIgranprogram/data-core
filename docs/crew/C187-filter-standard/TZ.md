# C187 — единый вид фильтров

Пользователь узнаёт фильтры на разных экранах, видит применённые параметры и может освободить место для таблицы. Область работы — компьютерное «Рабочее место». Приёмка выполнена на изолированной локальной копии. Рабочие сценарии и точный охват перечислены в [отчёте](UI-REVIEW.md).

## Чек-лист

- [x] Найти пользовательские экраны с фильтрами и сгруппировать их по сценариям. Для каждого отметить поиск, параметры, категории, представление на широком экране и состояние при возврате.
- [x] Согласовать общий компонент и добавить его в витрину эталонов. Кнопка «Фильтры» открывает и закрывает поля слева. Выбранные значения сохраняются после закрытия. Видно, что фильтр активен, можно сбросить параметры.
- [x] Перевести складские остатки и остальные совместимые экраны на общий компонент. Сохранить смысл параметров, значения по умолчанию, адресное состояние и правила применения.
- [x] Проверить «Продукцию». В галерее один видимый путь по категориям, с поиском и понятным возвратом к уровню выше. Дополнительные фильтры сохраняются там, где дают отдельный выбор.
- [x] Пройти склад, продукцию и каждый найденный вариант фильтра в браузере. Проверить пустое состояние, несколько параметров, сброс, открытие и закрытие, смену представления, возврат и клавиатуру.
- [x] Проверить читаемость в разных темах на 1920, 2560 и 3440 px. Зафиксировать список переведённых экранов и конкретные оставшиеся исключения.

## Исполнители

- Дизайнер, Sol medium — инвентарь экранов, сценарии и визуальная проверка эталона. Артефакт — `AUDIT.md`.
- Frontend, Astra medium — общий компонент, склад, продукция и перенос совместимых экранов.
- Координатор — принимает общий вид, проверяет границы, собирает изменения и запускает локальное приложение. Данные, исходные списки и работу с общей веткой сохраняет.
