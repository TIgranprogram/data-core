## 2. Предложение: один эталон «карточка»
База (все варианты): фон `--surface`, рамка 1px `--border`, радиус `--radius`, тень `--shadow-sm` (токен уже есть), отступ `--s3 --s4`, полоса тона слева 4px (`tone`, `.k-toned`), заголовок h3-стиля `--fs` 600 `--heading`, подпись `--fs-sm --muted`.
- **Обычная** (= M/S сегодня): заголовок, 1–2 строки подписи, бейджи, ряд действий.
- **Длинная** (`variant: 'long'`): длинный текст (описание, примечание, обсуждение) на всю ширину колонки, перенос строк, до 6 строк, «Развернуть» (`aria-expanded`, как `.pp-ftext.clamp` в §4.0).
- **С таблицей** (`variant: 'table'`, слот `body`): внутри — kit `table({ mode:'list' })`; в карточке таблица без своей рамки и тени, шапка `--surface-2`, на 390 — горизонтальная прокрутка внутри карточки, не страницы.
Наведение (только карточка с `onClick`, остальные статичны): `@media (hover:hover) and (prefers-reduced-motion: no-preference)` — `translateY(-2px)` + `--shadow-lg`, `transition: transform .15s, box-shadow .15s`; `:focus-visible` — контур `--primary`. Нажатие — как сейчас (.97). Перетаскиваемые карточки доски: подъём -1px, во время переноса без движения. В `reduce` — только смена рамки на `--border-strong`.
Замечание: DESIGN §5 велит «только transform/opacity»; тень уже двигается в `.cat-tile`. Записать в §5 одно исключение: `box-shadow` для наведения карточки.
Токенов новых нет. Обе темы работают через `--surface/--border/--shadow*`.

## 3. Что в kit добавить, слить, удалить
- Добавить в `card()` параметры `variant` (`long`/`table`) и `body` (узлы); класс наведения `k-hover` ставит `card()` сам при `onClick`. Витрина `#kit`: три варианта × две темы × 390/1920.
- Слить в `card()`: `.cat-tile` и `.sec-tile` → `card({ size:'S', photo/art, onClick })` (картинка 16:10 — вариант фото); `.gcard` → `card({ size:'M', photo })`; `.go-tile` → `card S`.
- Слить стили наведения: убрать дубли kit.css:133/144/163, screens.css:757/1123, base.css:144/154 в одно правило `.k-hover`.
- Удалить после перевода: `.cat-tile/.cat-art/.cat-body`, `.sec-tile` (раскрывающуюся панель оставить — это поведение секции), `.gcard`, `.go-tile`, `.hp-card`, `.td-qcard`, `.card-block`, `.sc-card`.
- Радиус `.tcard` 7 → `--radius` 10 (общий). Не трогать: `.panel`, `.queue`, `.k-row`, печать, исключения §4.

## 4. Порядок перевода (по одному экрану, после каждого — `dc audit` + `design-lint`)
1. Эталон в kit + витрина `#kit` + запись в DESIGN §4/§5/§8 (без экранов).
2. Склад (СКЛ-1): плитки зон/категорий `sec-tile`/`cat-tile`, карточка позиции.
3. Вложения (ВЛ-1): галерея и список файлов `gcard`/`pgal` → карточка M, длинное примечание — `long`.
4. Выдача: карточки заказа/позиций и движения — `table` внутри карточки заказа (вместо `.timeline` со строками).
5. Доски «Проектирование», «Заявки», затем «Продукция», паспорта, «Сегодня» (`go-tile`, `.queue` — только шапка).
6. Справка/дашборд — последними, затем удаление старых классов (отдельным коммитом).
Каждый шаг — один экран, 390/1024/1920, обе темы, проверка наведения с клавиатуры (Tab).
