# Промпт для параллельной сессии — C057-Э2в: переменные карточки и картинки на сайт

Ты — исполнитель **C057-Э2в**, приложение `apps/pdm-loader/`. `git pull`.

**1. Главная ошибка — в приложении, не в сервере.** В `samples/6104.pdm-tree.json` у **всех 59 деталей** `Сортамент`, `Материал`, `Масса` = null. Поэтому сервер не нашёл сырьё, и лист с фанерой ушли в `missingBlank`. Проверено координатором на `0000.0000.0019`:

| Конфигурация | Сортамент | Материал | Масса | Длина | Вид_изделия |
|--|--|--|--|--|--|
| `@` (общие свойства файла) | Лист, 4 мм, ГОСТ 19903-2015 | Ст 3 ГОСТ 380-2005 | 0.532 | — | Деталь |
| `00 Стандартная` | — | — | — | 109 | — |

Правило чтения каждой переменной: **сначала конфигурация, которую использует родитель; пусто → `@`**. Так же `Вид_изделия` (тогда вид из папки PDM — только запасной путь, с `warning`). Числа — с точкой; «0» → null.
Проверка: в пакете у деталей листа и фанеры заполнены `vars.Сортамент`, `vars.Материал`, `massKg`; у `0000.0000.0019` — «Лист, 4 мм…», «Ст 3…», 0.532.

**2. Повторный прогон на стенде** (`stand-6104`, локальный `http://localhost:3001`, после `git pull` и `docker compose up -d --build`): та же загрузка должна дать **расхождения** по уже загруженным деталям (теперь есть сырьё и масса) → решить «Обновить всё из PDM» → `purchase-needs` → в `items` есть сырьё: «Лист … 4 мм», фанера 21 мм и др. (`kind: raw`, `unit` м²), `missingBlank` — только детали без заготовки. Сохранить `samples/6104.purchase-needs.json` заново.

**3. Поиск деталей.** Это не ошибка: склад скрывает детали и сортаменты. Для поиска детали — `GET /api/materials?search=<обозначение>&withParts=1`. Фильтра `?article=` в API нет (параметр игнорируется) — не использовать.

**4. Картинки на сайт.** Сервер добавляет `POST /api/pdm-import/preview-image` (multipart: `file` PNG/JPEG ≤ 10 МБ, `importId`, `designation`, `sha256` → `{photoId, stored, main}`) — смотри `CONTRACT.md` §3 после `git pull` (появится в ближайшем коммите координатора; до того — шаги 1–2). После apply загрузить превью изделия, модулей и деталей по одному, с повтором. Главное фото менеджера сервер не перебивает.
