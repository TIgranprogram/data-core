Поручение 22.11.2026. Покупная номенклатура остаётся доступной для повторного заказа с любым остатком. При сохранении новой позиции заявки одного названия достаточно, чтобы она была доступна в каталоге. Дубли, заведённые разными менеджерами, можно осознанно объединить.

- [x] Проверить каталог при нулевом остатке и без поставщика. Сохранить прежние карточки и ссылки, показывать происхождение данных с понятными подписями. В форме «Выбрать из каталога» и «Новая позиция» использовать привычный язык пользователя.

Начать с безопасного предварительного просмотра; запись включать после доказанного покрытия всех писателей общего склада, включая отдельную CRM.
