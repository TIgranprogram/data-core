# C141 — эталон правки паспорта (слова владельца, 17.11.2026 вечер)

Источник: голос + скриншот окна «Паспорт № 601 · … · выпущен» (книжка C134).

## Решение
1. **Единственный эталон** — большое окно «паспорт как в PDF» (`openBookEditor`). Любая кнопка «Изменить / Дописать / Править паспорт» (изделие, заказ, шаблон, документация) открывает **только** его.
2. **Слева «Выбор для текстов»** — шире; воронка **сверху вниз** (от главного к частному): что определяет тексты. Данные уже есть в изделии — подставляются сами.
3. **Категорию / группу изделия в паспорте не меняем.** Изделие уже определено при создании (~90 %). Путаница имён: в паспорте «тип паспорта» (BLG…), у изделия — раздел/группа/подгруппа. Исправить подписи, не давать менять группу изделия из паспорта.
4. **Нет данных у изделия** (состав, габариты…) — ссылка «добавить» или правка **здесь же** с записью **в корень изделия**, без беготни по экранам.
5. **Середина** — интерактивный паспорт: тексты как в печати; клик → правка **на месте** (в т.ч. цифры в таблице на листе). Правая колонка не дублирует основную правку (оставить служебное: ИИ-проверка).
6. **Дубли убрать:** одно поле — одно место правки (либо слева выбор, либо в листе).
7. **Картинки** — оставить как сейчас (видно раскладку).
8. **Цвета:** места, зависящие от изделия / выбора — заметны; «общие» — спокойнее/серее, чтобы быстро видеть, куда жать.
9. **Шире лист** (меньше сжатия текста) и шире левая колонка.
10. **Старые неудобные редакторы** — не вести туда пользователя; после полного чек-листа — удалить или спрятать.

## Приёмка глазами (владелец)
Стенд :3102 → паспорт 601 (или аналог) → эталон: лево шире + воронка; клик по цифре/тексту правит на листе; тип/группа изделия не редактируются; закрыть/переоткрыть — то же окно из любого входа.
