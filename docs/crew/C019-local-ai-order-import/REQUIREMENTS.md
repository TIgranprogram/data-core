# C019 — Локальный ИИ → Excel → импорт заказа

**Зачем:** менеджер кидает папку документов (ТЗ, ВОР, КП, контракт), локальный ИИ собирает Excel, на сайте — проверка полей и загрузка заказа. Без ручной сборки как с «ДСО Донбасская».

## Сценарий

1. Пульт → раздел «Локальный ИИ» → «Открыть папку входящих» → кладёт файлы.
2. В настройках раздела — Base URL LM Studio (`http://…:1234/v1`), проверка связи.
3. «Собрать Excel заказа» → ИИ читает текст файлов → пишет `tools/local-ai-order/out/заказ-….xlsx`.
4. Пульт показывает путь / открывает папку «готово».
5. Сайт → Заказы → «Импорт Excel» → выбор файла → экран проверки → «Всё ок — загрузить» → новый заказ + позиции.

## Обязательные поля Excel (шапка)

| Ключ в файле | Поле сайта | Обязательно |
|--|--|--|
| № договора | orderNo | да (или «⚠ изменить …») |
| № заказа | productionNo | нет — сайт даст last+1 |
| Заказчик | customer | да |
| Наша компания | companyName | да (СИЮ / ССЮ) |
| Предмет | title | желательно |
| Форма оплаты | paymentForm | нет |
| Срок изготовления | productionDeadline | нет |
| Окончание поставки | deliveryDeadline | нет |
| Дата отгрузки | shipDate | нет |
| Примечание | notes | нет |

## Позиции

| Колонка | Поле | Обязательно |
|--|--|--|
| НАИМЕНОВАНИЕ | title | да |
| ЕД. ИЗМ. | unit | да |
| КОЛ-ВО | qty | да (>0) |
| ЦЕНА | unitPrice | нет (пусто = 0) |

## Что делает локальный ИИ

- Берёт только изделия/конструкции для изготовления (как ВОР: ограждение, ворота, воркаут…).
- Не тащит стройработы, электрику, чужие КП из той же папки.
- Цены не выдумывает, если в смете нет.
- Пустые обязательные — заглушка `⚠ изменить …`.

## Что делает сайт

- Проверка сопоставления до записи (ошибки красным, «можно грузить» зелёным).
- Создание договора + позиций; `productionNo` пустой → сервер last+1.
- Сопоставление с каталогом изделий — после, как сейчас (очередь несопоставленных).

## Не в объёме C019

- Автозаливка на прод без человека.
- OCR сканов PDF (только текст/таблицы, которые удалось извлечь).
- Цены и оплаты в импорте.
