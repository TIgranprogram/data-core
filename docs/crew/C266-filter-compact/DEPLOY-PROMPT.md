# Промпт для выпуска C266

Выпусти завершённую C266 — плотность списков и фильтры остатков — на рабочий DataCore. Это поручение на штатный выпуск, без дальнейшей переделки дизайна.

1. Прочитай AGENTS.md, CLAUDE.md, skill datacore-deploy, `docs/crew/C266-filter-compact/REPORT-FINAL.md` и `UI-REVIEW.md`. Независимая компьютерная приёмка PASS; `evidence-final/tested-files.json` связывает доказательства с содержимым файлов.
2. Найди финальный коммит C266 с сообщением `fix(pwa): завершить фильтры и плотность списков C266`; сверь состав и наличие в origin/main. Выпускай этот проверенный кандидат вместе с его предшествующим коммитом общего kit C266: kit и sections разделены по требованию хука. В исходном checkout есть незакоммиченные чужие задания C157/C246 и изменения инструкций ролей: их не добавлять в коммит, не откатывать и не переносить на сервер. Если штатному выпуску нужна чистая копия — используй предусмотренный проектом способ изоляции, сохранив эти изменения.
3. Проверь сохранность меток review-scope и приёмки, обязательные проверки и preflight. Для неизменённой PWA действуют smoke-проверки; full backend unit/e2e повторять только если кандидат содержит новые изменения backend/src или backend/test после последнего полного прогона. Красные ворота не обходить, `--force-urgent` не использовать.
4. Выполни штатный release DataCore по datacore-deploy с резервной копией и возможностью отката. БД, Mongo-контейнер, общие схемы и настройки не менять. CRM kppdf намеренно остановлена и лишена Mongo readWrite после C260–C265: не запускать её и не восстанавливать права ради старого smoke.
5. Через datacore-access проверь фактическую версию/хэш, health/ready, вход и приложение, фильтры склада: раскрытие трубы, поиск размера, «Ещё», выбор, снятие, общий сброс. Визуальное сравнение — с C266 evidence, обе основные темы и средняя; на проде только чтение, без изменений бизнес-данных.
6. Обнови HISTORY/BACKLOG и отчёт о выпуске. Сообщи фактически опубликованную версию и результат проверок. При сбое сначала выясни состояние сервера; откатывай штатным способом, без изменения БД.

В чат — коротко: опубликованная версия, что проверено, оставшиеся ограничения. Пароли, JWT и ключи не выводить.
