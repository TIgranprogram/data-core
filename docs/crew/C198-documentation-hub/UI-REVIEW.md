# C198 — проверка «Документации»

**Браузерная проверка прошла.** Edge, средняя тема, 1920 и 2560 × 1080. Текущая рабочая копия, приложение по адресу http://127.0.0.1:41732/app/ через фикстуру Playwright. Использованы учебные заказы, два акта, заполненный реестр и отдельный тестовый PDF. Ошибок JavaScript и попыток записи 0.

- «Паспорта» сохраняют прежние вкладки, ссылки и создание паспорта. Старое tab=numbers открывает «Выпущенные». [Настройки изделий и быстрые действия](evidence/2560-passports.png).
- «Акты» ищут по номеру, заказчику, заказу и договору. Отдельный фильтр выбирает конкретный заказ или договор, вкладки показывают рабочие и архивные договоры. Фильтры восстанавливаются из адреса. Enter раскрывает сведения под строкой, выбор новой строки закрывает прежнюю. Оригинал открывается в общем просмотре PDF с печатью и скачиванием. У архивного акта запрашивается файл конкретной версии архива. [Акты](evidence/1920-acts.png).
- «Реестры» раскрываются под строкой. Видны выпущенный паспорт и пропуск. Печатный PDF реестра загрузился отдельным запросом. Сценарий передачи проверен в [C197](../C197-passport-registry/TZ.md). [Реестр](evidence/2560-registries.png).
- Для роли с «Документацией» и без «Заказов»/«Денег» доступны метаданные актов. В раскрытой строке оригинал и ссылка на договор недоступны, запрос за PDF отсутствует. [Ограниченная роль](evidence/1920-limited.png).

## Источники

| Вход | Подтверждённый источник |
|---|---|
| Паспорта | Экземпляры и шаблоны паспортов, прикреплённый PDF точной позиции |
| Акты | Сохранённые legal.documents договора с kind=acceptance. «Акт / УПД» — действующий общий вид. Номер документа отгрузки и признак УПД у счёта поставщика не содержат подтверждённого акта для этой вкладки. |
| Реестры | Действующие позиции заказа, источники паспортов и версии комплекта при передаче C197 |
| Архивы и вложения | Оригиналы договора доступны через права источника. Активная архивная версия открывает сохранённую копию C188. Исторические версии остаются в истории договора. |

Раздел переиспользует kit tabs, positionsTable, tileGrid и PDF preview. Из обзора актов нет команд редактирования и удаления. Для исправлений сохранён переход в уполномоченный сценарий договора. Новые типы актов не заведены.
