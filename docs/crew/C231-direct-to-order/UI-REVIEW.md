# C231. Проверка карточки счёта

Версия — рабочие изменения C231 поверх `5852c2d8`. Экран — существующая карточка `invoice-workspace` в стандартной правой панели. Эталоны — «Позиции» из карточки заказа, поле `select` и окно подтверждения из kit.

Браузер Edge, изолированная страница `http://127.0.0.1:41733/app/fixture.html`. Playwright подставляет обезличенный счёт № УЧ-07 с двумя строками и два учебных заказа, загружает реальные JS-модули и CSS приложения. Визуальная часть и payload проверены с подстановкой HTTP. Сохранение и остатки проверены отдельно через реальный API на тестовой Mongo. Снимки просмотрены.

| Окно и ширина панели | Состояние | Результат |
| --- | --- | --- |
| 1920, 700 px, светлая | Длинное название, две строки, отметка одной, обе кнопки приёмки под таблицей | PASS · [снимок](evidence/01-actions-light.png) |
| 1920, 700 px, светлая | Выбор объекта. Без заказа видна ошибка. Escape закрывает окно, отправки нет. Enter открывает окно заново | PASS · [снимок выбора](evidence/02-order-light.png) |
| 1440, 520 px, тёмная | Цены и количество видны при узкой панели. После выбора отправляется один POST, в принятой строке видны этап и ссылка на заказ | PASS · [выбор объекта](evidence/02-order-dark.png), [результат](evidence/03-receipt-dark.png) |

При первом снимке узкой панели сумма обрезалась из-за минимальной ширины столбца «Позиция». Убрано это ограничение в карточке счёта, сокращён заголовок суммы и уточнена подпись цены за единицу. Повторный браузерный прогон проверяет, что все столбцы вмещаются в панель.

## Приёмка направлений

Проверены отмена выбора без запроса, обязательность назначения, сохранение только отмеченной строки, один запрос при подтверждении и новый статус строки. Светлая панель 700 px и тёмная панель 520 px. Проверено, что сумма вмещается после появления длинной подписи объекта.
