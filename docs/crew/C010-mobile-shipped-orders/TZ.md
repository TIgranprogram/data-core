# ТЗ C010 — Выдача на полностью отгруженные заказы (телефон)

**Зачем (словами пользователя):** На мобильном складе в выдаче «На заказ» уже есть «Готовые к отгрузке». Часть заказов уже полностью отгружена, но забыли выдать мелочь (болты и т. п.). Нужен ещё один раздел внизу — чтобы выбрать заказ и позицию, привязка к позиции не терялась.

**Класс:** M · **Агентов:** ≤ 2 (frontend + designer) · **Проверки:** smoke · **Код пока не начинать** — только запись требования (диктовка 2026-11-03).

## Название раздела

**По умолчанию: «Полностью отгруженные».**  
Параллель к «Готовые к отгрузке». Этап заказа `shipped` («Отгружен»).  
«Завершённые заказы» не брать: звучит как `closed` («Закрыт») — слишком поздно для довыдачи.  
Вопрос ВЫД-М1 в `docs/QUESTIONS.md` — если пользователь скажет иначе.

## Shared pack (места кода)

- Экран: `backend/pwa/sections/stock-mobile.js` → `stepOrder` (кнопка «Готовые к отгрузке» ~172–184).
- Lookup: `backend/pwa/core/orders-lookup.js` + `GET /salesorders/lookup` — сейчас `filter=active` (`ACTIVE_STAGES`: new/production/ready/partly). Для отгруженных нужен `filter` с `shipped` (и при решении — `closed`) **без ломки** других потребителей.
- Позиции заказа: `incomes` — `photoIds`, thumbs в `IncomesService` (~63–83). В lookup для этого шага — мини-фото + короткое название позиции.
- Эталоны: kit `mobile` (`ui/kit/mobile.js`), `docs/DESIGN-MOBILE.md`. Новых section-CSS нет.
- Не читать: CRM kppdf, админку, другие разделы PWA.

## Что сделать (когда пойдёт код)

1. В `stepOrder` под кнопкой «Готовые к отгрузке» — ещё одна кнопка/блок **«Полностью отгруженные»** (этап `shipped`; пусто — короткая подсказка).
2. Список заказов — минимум: **номер заказа** и **название/заказчик** (без лишних полей).
3. Открытие заказа → список **позиций** с **маленькими фото** (thumb позиции; нет фото — плейсхолдер kit) + **короткое описание** позиции (номер + название), чтобы быстро выбрать глазами.
4. Выбор позиции → как сейчас: `salesOrderLineId` (предпочтительно), выдача через существующий `/stock/batch` type `out`. Привязка к позиции сохраняется.
5. «На весь заказ — без позиции» — оставить, но не главным (мелочь обычно на конкретную позицию).
6. Язык менеджера; 390 px; кнопки по DESIGN-MOBILE.
