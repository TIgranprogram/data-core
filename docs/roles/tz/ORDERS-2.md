# ТЗ ORDERS-2 — заказы, этап 2: фото продукции

**Зачем (словами пользователя):** «В заказах, где продукция, отображение красиво с фотографиями, где это возможно, чтобы интуитивно быстро ориентироваться». Аудит: `docs/audit/AUDIT-ORDERS-2026-10-31.md`, раздел «Фото продукции».

**Класс:** M · **Max agents:** 2 (backend, затем frontend) + designer · **Проверки:** smoke, перед выкладкой пульт-проверка

## Shared pack
- Один источник фото: фото позиции, иначе главное фото изделия, иначе `null`.
- Контракт: поле `photo: { url, thumb } | null` в строке позиции. Новое поле, старые не меняются. Формат ответов `{items,total,page,limit}` тот же.
- Схемы не меняются. Новых запросов на каждую строку нет: фото подгружается пачкой (`loadPhotos`, `common/photos`).
- Вид: как `matchPic` (`salesorders-matching.js:36`): клик — крупно, «нет фото» в той же рамке.

## Сервер (datacore-backend)
1. `salesorders.service.ts:188-193`: подстановка фото изделия, как `photoOf` в `production-orders.service.ts:259-266`.
2. `GET /production-orders`: `coverPhoto` первой позиции с фото.
3. Отгрузки `GET /salesorders/:id/shipments`, брони `GET /stock/reservations/order/:id`, `issuedByLine`, `toProduce`: `photo` по строке.
4. `GET /salesorders/lookup?lines=1`: `photo.thumb`.
5. Юнит на источник фото: своё → изделие → `null`.

## Экран (datacore-frontend)
1. `matchPic` перенести в `ui/pos-pic.js`, импорты поправить. Размеры: `.pic` 36 px в таблицах, `.pic-lg` 72 px в карточках.
2. Список и доска заказов: миниатюра `coverPhoto`.
3. Таблица позиций договора, «К производству», «Выдано со склада», отгрузки, брони, выбор позиций `order-design.js`, «Связать с каталогом» `matchProducts`, выбор договоров: фото слева.
4. Подпись позиции одна: «поз. N · название».
5. Классы `so-pic`, `db-pic`, `t-pic`, `thumb`, `wk-photo` в файлах заказа заменить на `.pic`. Вне заказа не трогать.

## Запрещено читать
DESIGN, CANON, HISTORY, TASKS целиком; `docs/openapi.json` целиком.

## Критерии приёмки
- [ ] Строка позиции без своего фото показывает фото изделия.
- [ ] Нет фото ни там, ни там: рамка «нет фото», столбцы не прыгают.
- [ ] Клик по фото открывает крупно.
- [ ] tsc 0, юнит, импорты, `node --test`, pwa-guards зелёные.

## Нельзя
Менять данные прода, схемы, контракт. Коммитить и выкладывать.
