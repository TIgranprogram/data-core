# C054-P — Части изделия по категориям

**Статус:** принято координатором 2026-11-10. Стенд (`local`) — apply. Прод — кнопка пульта `c054-parts-coatings`. 43/43 с непустым `categories`. `keep` 4 (Гриф, Маятник, Накопитель дисков, Ногоступ). `patch` 39. Новых имён: 29, на прод не создавать.

## Правила

1. Пустое `categories` больше не оставляем: интерфейс считал пустое = «для всех», и в тренажёр попадали калитка и дуга.
2. Коды только TRN, WRK, BLG, DIO, DSP, через запятую, порядок как в ТЗ.
3. Опора — `backend/scripts/seed-passport-types.js` (решения 2026-10-30): часть получает категорию типа, где она названа.
4. ГОСТ Р 57538 — только TRN (стационарный уличный тренажёр, рост от 1400 мм). Турник, брусья, скамья для пресса, баскетбол, ворота — не его область (универсальное спортивное свободного доступа — ГОСТ Р 56440, детское спорт — ГОСТ Р 55677/55678).
5. Рукоять 16–45 мм — это уже «Ручка» (сид: ∅25). Второе имя не заводим. Фланец сведён в «Опорную пятку». «Рама» не дублирует «Несущую раму».
6. Запрет ТЗ соблюдён, TRN нет у: Калитка, Задвижка, Зацеп, Дуга, Кольцо баскетбольное, Щит, Сетка, Крючок для крепления сетки.
7. Петля калитки тоже без TRN. Шарнир рычага — новые «Ось» и «Подшипниковый узел».
8. Разные части не слиты: рейка ≠ ламель, трос ≠ канат, ферма ≠ балка, столб ≠ стойка, щит ≠ панель, сетка ≠ приствольная решётка, ногоступ ≠ ступень.

## Спорно (решает пользователь)

- **Гиря** — свободный снаряд, 57538 его не покрывает. Пока TRN. Если это не узел — убрать из частей, не сливать с диском.
- **Тумба** — кожух стека (TRN) и парковая тумба (BLG) в одном имени. Не дробить без «да».
- **Вазон** — часто целый МАФ, не часть. В предложении новых; не создавать, если вазон не входит в другое изделие.
- **Дуга** — только брусья (WRK, DSP). Лаз-дуга площадки тем же словом не размечена: иначе брусья станут деталью ДИО.
- **Щит** — баскетбол, полоса препятствий и стела в одной записи (WRK, BLG, DSP). Дробление — только если пользователь подтвердит.
- **Весовой стек и диски** — в TRN по каталогу компании. Свободно перемещающиеся грузы область 57538 исключает; направляемый стек оставляем.

## Глазами после apply

- Силовой TRN: рама, стойка, рычаг, ручка, сиденье, спинка, ногоступ, гриф, стек, диск. Нет калитки, дуги, щита, сетки, задвижки.
- Турник WRK: стойка, перекладина, хомут. Брусья: ещё дуга. Баскетбол: щит, кольцо, ферма — не в карточке тренажёра.
- Ограждение BLG: калитка, задвижка, прут. Пергола: балка, опора, кровля, ламель — не рейка скамьи.
