# Подключение Claude к «Рабочему месту» (MCP)

Claude (приложение Claude Desktop или Claude Code) может сам искать, смотреть и разбирать данные: заявки, склад, заказы, деньги — и по вашей просьбе создавать заявки.

## Что нужно

1. **Node.js 18+** на компьютере (проверка: `node -v`).
2. **Ключ** `kppd_…`: `https://kppdf-crm.ru/db/admin/` → «API-ключи» → выдать ключ.
   - «Только чтение» — Claude только смотрит (рекомендуется).
   - «Чтение и запись» — Claude может ещё создавать заявки (инструмент `create_request`).
   Ключ — как пароль: не пересылайте в чатах; отозвать можно там же.
3. Файл `mcp/datacore-mcp.mjs` из этого репозитория (скопируйте в любую папку, например `C:\datacore\`).

## Claude Desktop

Настройки → Developer → Edit Config (`claude_desktop_config.json`), добавьте:

```json
{
  "mcpServers": {
    "datacore": {
      "command": "node",
      "args": ["C:\\datacore\\datacore-mcp.mjs"],
      "env": { "DATACORE_URL": "https://kppdf-crm.ru/db/api", "DATACORE_KEY": "kppd_…ваш ключ…" }
    }
  }
}
```

Перезапустите Claude Desktop — в списке инструментов появится «datacore».

## Claude Code

```
claude mcp add datacore -e DATACORE_URL=https://kppdf-crm.ru/db/api -e DATACORE_KEY=kppd_… -- node C:\datacore\datacore-mcp.mjs
```

## Что умеет

| Инструмент | Что делает |
|--|--|
| `search` | найти по всему: заявки, позиции склада, поставщики, заказчики |
| `stock_items` / `stock_item` | остатки (к закупке / нет / в брони), карточка позиции: заказано, поставщики и цены, движения |
| `requests` | заявки снабжения с фильтрами, сумма и счётчики по статусам |
| `create_request` | создать заявку «Заказать» (только ключ с записью, только по вашей просьбе) |
| `orders` | заказы заказчиков: в работе / закрытые |
| `money_summary` / `money_forecast` | деньги за год (факт) и прогноз вперёд с кассовым разрывом |
| `fill_queue` | «Требуют заполнения» — что поправить в данных |
| `api_get` | прочитать любой раздел API (только чтение), например `/meta/guide` — описание всех таблиц |

Примеры вопросов: «что заканчивается на складе и что уже заказано?», «сколько потратили на металл в сентябре?», «будет ли кассовый разрыв в ноябре при остатке 500 000?», «заведи заявку на 200 болтов M10×40».

## Проверка

```
DATACORE_URL=https://kppdf-crm.ru/db/api DATACORE_KEY=kppd_… node mcp/selftest.mjs
```
Покажет список инструментов и пример ответов. Деньги видит только ключ, выданный директору / бухгалтеру / администратору (права ключа = права пользователя, который его выдал).
