# Трубы в каталоге — проверка 28 ноября

В Chromium на локальном наборе данных открыты круглые и прямоугольные трубы. В свёрнутой строке видны сортамент, материал, ввод штук и метров и кнопка корзины. В раскрытой строке доступны склад, заявки, поставки и длина для пересчёта. При попытке заказать штуки с неизвестной длиной раскрывается редактор и получает фокус.

Регрессия в c280-request-cart-browser.test.mjs проверяет фактическую фильтрацию стали и нержавейки прямоугольных труб, сброс, отсутствие служебного текста в свёрнутых строках, равенство высоты и координат колонок. Предыдущие сценарии проверяют оплаченные позиции, конвертацию, сохранение длины, корзину и Excel. Результат 11/11. Импорты и синтаксис — 446 файлов без ошибок.

[Свёрнутые строки в светлой теме](./pipe-table-light.png) · [Раскрытая строка в тёмной теме](./pipe-detail-dark.png).

Независимая приёмка дизайнера — PASS по трём замечаниям. Просмотрены заполненные таблицы в светлой и тёмной темах, раскрытая труба 60×30×1,5 и редактор неизвестной длины. Поля и материал выровнены по своим колонкам, фильтр материала расположен первым, сообщение о существующей заявке видно внутри обведённой подстроки.
