**Класс:** M · **Дата:** 2026-11-11 · Основание: `REPORT-designer.md` рядом (прочитай целиком — там точные места и замены). Правила те же, что в `PROMPT.md`: только файлы КП, не выкладывать, коммит своих путей.

Дополнительно разрешено: `backend/pwa/main.js` — только регистрация новой правой панели (две строки рядом с образцом `stockop`).

## Сделать (по важности)

1. **Окно → правая панель.** «КП от других фирм» сейчас всплывающее окно с числом полей до десяти; по `docs/DESIGN.md` §4 окно — для 1–3 полей. Сделать правую панель (адрес и регистрация — как указано в отчёте дизайнера, п. 1). В подвале одна главная кнопка «Создать N КП». Окно «Копия для другой фирмы» не трогать.
2. **Поле наценки теряет фокус.** При вводе процента строки перерисовываются, число из двух цифр не набрать. Строки фирм строить один раз; при вводе менять только текст суммы.
3. **Итог** — коротко: «Получится 3 КП», без перечня фирм.
4. **Фирма без бланка** — под выбором фирм, с причиной: «Нет бланка КП: … Загрузите бланк в Контрагенты → Наши компании» и кнопка «Загрузить бланк». Если выбрать некого — показать эту же строку вместо сообщения «Других наших фирм нет».
5. **Блок «Пакет»** — ряд: название фирмы и сумма текстом, рядом статус, справа кнопка «Открыть»; текущее КП помечено «это КП», без кнопки. Лишний заголовок «Пакет из N» убрать, оставить «Скачать все PDF (N)». На ширине 390 ничего не режется.
6. Тон секции — нейтральный или как у «Изделия».
