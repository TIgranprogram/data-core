## Что сделать
1. `pwa/main.js`: `NAV` фильтровать по `sections` (null — без фильтра; «Сегодня» — всегда). Прямой адрес скрытого раздела (`#stock`) → на первый доступный с короткой подсказкой, без ошибки.
2. Блоки «Сегодня» скрытых разделов не показывать (если такие ссылки есть).
3. Офлайн/кэш: `sections` из сохранённой сессии.
