## Backend
1. Фото: `photoIds?: ObjectId[]` в `Message` (как `design-task.schema.ts:41`). `SendMessageDto`: `photoIds?` (`@IsArray @IsMongoId({each}) @ArrayMaxSize(10)`), `text` необязателен, если есть фото (пусто и без фото → 400). Загрузка — существующий `POST /photos/upload`. `present()` отдаёт `photos:[{id,url,thumb}]` (взять как `loadPhotos` в `design-board.service.ts:124`).
2. «Всем»: поле `toAll: boolean` (default false); у «Всем» `toUserId` не задан (сделать необязательным; индекс `{toAll:1,createdAt:-1}`). Видят все активные не-устройства. Новые эндпоинты: `GET /messages/all?limit&page` (лента), `POST /messages/all/read`. Отправка: `POST /messages` с `toAll:true` (без `toUserId`).
3. Непрочитанное «Всем»: коллекция `messagereads {userId, channel:'all', readAt}` (unique userId+channel). Непрочитано = чужие `toAll` позже `readAt`. Нет записи → считать прочитанным на момент первого запроса (старого не лить). Отдельных уведомлений на каждого НЕ создавать (спам); число идёт в `threads`.
4. `threads`: добавить `all: {lastText,lastAt,unread}` (рядом с `items`); `unread` = личные + «Всем».
5. `uiPrefs.lastChat` (строка: id пользователя или `all`): добавить в `UiPrefsDto` (`@IsOptional @Matches(/^(all|[a-f0-9]{24})$/)`), `UiPrefs` в `user.schema.ts`, `auth-response.dto.ts`, `prefs.js` (`clean` принимает строки). Иначе 400.
6. Тесты: unit `messages.service.spec.ts` (фото, toAll, непрочитанные), e2e: чужую переписку не видно, «Всем» видят все.
