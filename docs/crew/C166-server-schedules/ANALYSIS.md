# Требования и решения C166

Аналитик: независимые расписания, память выбора, last/next/result, общий job, никаких накопленных запусков и автоматического переключения домена. Архитектор: code-only не требуется; безопаснее ночной код+данные. Persistent CAS/runtime, immutable источник принятого релиза, staged build/rollback и свежий VPS status перед опасными шагами обязательны. Старые API/env совместимы. Неизвестные обратный путь, CRM и логины не объявлять принятыми. Подробная реализация/границы закреплены в TZ.
