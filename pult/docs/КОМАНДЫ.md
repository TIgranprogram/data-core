# Команды пульта

> Файл собран из `pult/catalog.mjs` командой `node pult/gen-docs.mjs`. Руками не править.

| Отметка | Значит |
|--|--|
| Только чтение | Ничего не меняет |
| Сайт не затрагивает | Меняет этот ПК, стенд или GitHub. Рабочий сайт остаётся как был |
| Меняет сайт | Меняет рабочий сайт. Перед запуском пульт спросит подтверждение |
| Опасно | Меняет рабочий сайт или данные. Для запуска надо ввести слово |

## Проверка

Две кнопки: быстрая и полная. Всё остальное собирается само, в конце — адрес отчёта

| Кнопка | Когда нажимать | Отметка | Время | Ритм | Что запускает |
|--|--|--|--|--|--|
| Быстрая проверка | Типы, юнит-тесты, импорты, дизайн и пульт. Те же шаги, что в воротах выкладки. Сайт не нужен. | Только чтение | 2–4 мин | — | `node tools/dc.mjs check` |
| Полная проверка | Всё сразу: быстрая проверка, сквозные тесты, тесты инструментов и обход всех экранов на стенде (стенд поднимется сам). Итог — один файл SUMMARY.md, адрес покажу в конце. | Сайт не затрагивает | 20–60 мин | — | `node tools/dc.mjs full` |
| Итог последней проверки | Короткая сводка и путь к отчёту. | Только чтение | 2 с | — | `node tools/dc.mjs audit last` |

## Выкладка

По порядку: ворота → выкладка → проверка после

| Кнопка | Когда нажимать | Отметка | Время | Ритм | Что запускает |
|--|--|--|--|--|--|
| Проверить ворота | Можно ли выкладывать: всё закоммичено, отправлено в GitHub, тесты зелёные. Сайт не меняет. | Только чтение | 1–5 мин | — | `bash deploy/synology/preflight.sh` |
| Проверить связь с сервером | Проверяет цепочку VPS → домашний сервер → сайт. Нажмите, если выкладка не может зайти на сервер. | Только чтение | 30 с | — | `bash remote-access/check.sh` |
| Выложить на сайт | Обычная выкладка. Сначала пройдут ворота. CRM kppdf не затрагивается. Копия базы делается сама. | Меняет сайт | 5–10 мин | — | `bash remote-access/deploy.sh (или release.sh)` |
| Выложить и загрузить заказы | Выкладка плюс загрузка заказов из папки «для анализа/заказы». Нужна только при новых файлах заказов. | Меняет сайт | 10–20 мин | — | `bash remote-access/deploy.sh (или release.sh) --data` |
| Срочная выкладка | Для аварии. Коммит, GitHub и тесты всё равно проверяются. | Опасно (слово СРОЧНО) | 5–10 мин | — | `bash remote-access/deploy.sh (или release.sh) --force-urgent` |
| Архив документов на сервер | То же делает каждая выкладка (шаг 7). Отдельно — когда документы перенесены в docs/archive и выкладки не будет. В конце — список файлов, которые можно удалить из проекта. | Меняет сайт | 1–3 мин | — | `node backend/scripts/devlog-import.js prod --apply` |
| Проверка после выкладки | Нажмите через 1–2 часа после выкладки. Покажет новые ошибки с сайта на этой версии. | Только чтение | 15 с | — | `bash deploy/synology/post-check.sh` |
