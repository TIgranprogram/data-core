# C233 — ложное отклонение строк договоров

23.11.2026. Исполнитель: printed_contract_rows. Зона: `tools/document-intake/proposal.mjs`, `tools/document-intake/c233-printed-contract-rows.test.mjs`.

## Причина и изменение

Подтверждено чтением оригинала и сохранённых страниц БАК-Строй: в спецификации напечатаны колонки «Цена», «Кол-во», «Ед.», «Сумма». Прежний `validateLines` требовал числовой порядок количество → цена → сумма. PyMuPDF `find_tables` для оригинала возвращает пустой массив: в спецификации отсутствует распознаваемая сетка. Поэтому штатное восстановление физических колонок не срабатывало. Названия части строк дополнительно перенесены до/после строки чисел.

Добавлен узкий разбор текстовой таблицы по полному трёхстрочному печатному заголовку и порядку колонок. Требуются нумерация с 1 без пропусков, отдельные поля цены/количества/единицы/суммы, совпадение арифметики, завершение «ИТОГО:», отсутствие неоднозначных таблиц. Сохраняются переносы названия и исходная непрерывная цитата. Обычная проверка общего итога и реквизитов продолжает действовать. Если заголовок присутствует, перестановка цены/количества в кандидате модели отклоняется даже при совпадении произведения. Правила повышены до `RULES_VERSION=4`.
