# C052 — правые панели «как в заказе»: сведения сверху, остальное во вкладках

Основа — `AUDIT.md` (дизайнер, 2026-11-08). Эталон — карточка заказа: шапка с кнопками справа (`card.actionsInHead`), блок сведений на всю ширину, остальное — вкладки сверху (`tabs({ fill, tone })`), всё раскрывается и закрывается.

**Класс:** L по волнам · **Роли:** frontend (+ designer приёмка) · **Скиллы:** design, verify, docs-sync.

## Глубже
- **Результат:** длинные панели («портянка» из 10–16 блоков) становятся компактными: 3–6 вкладок, на экране — только нужное.
- **Сырьё:** `AUDIT.md` (таблица панелей, вкладки, волны, дубли); эталон — `backend/pwa/sections/salesorders.js` (contractBlock, вкладки договора), `ui/kit/index.js` (headTabsCard, tabs), `ui/kit/card.js` (zones, arrange, actionsInHead).
- **Метод профи:** вкладка = вопрос пользователя («Что это?», «Из чего?», «Документы», «История»); первая вкладка — то, ради чего открывают; счётчики на вкладках; пустая вкладка — с подсказкой, а не скрыта (кроме «нет прав»).
- **Внешний судья:** дизайнер по изменённым панелям; `design-lint` новых 0; телефон 390 — вкладки в 2 ряда, ничего не обрезано.
- **Смелая планка:** панель изделия без прокрутки на 1080 px высоты до вкладок.
