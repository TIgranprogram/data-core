## Исправить четыре подтверждённых ветки

1. После успешного POST и сбоя следующего шага уход не должен скрывать уже созданную запись. Сохранять её ID для продолжения или явно предлагать открыть созданное изделие. Не говорить «изделие не сохранено». Повтор продолжения после возврата не создаёт второй POST; похожее существующее изделие не скрывает факт частичного создания. Не удалять созданное автоматически и не запрещать законное создание другого изделия.
2. При автоматически пропущенной единственной группе сохранять её эффективный ID/название. Создание в той же группе переносит подтверждённые признаки; реально другая группа их не наследует. Не ставить единственную группу при нулевом/неоднозначном наборе.
3. Фильтр категории старой формы паспорта не должен молча становиться собственным `passportDefaults.passportCategory` нового изделия. По умолчанию наследовать категорию выбранной группы. Собственное исключение — только осознанный выбор пользователя с понятной пометкой.
4. Выбранная в воронке категория и категория новой группы не должны расходиться незаметно. Сузить варианты или явно объяснить/подтвердить смену контекста и обновить итоговые шаги. Не записывать случайную категорию ради устранения предупреждения.
