# ТЗ C057-Э2 — приложение «DataCore · Загрузка из PDM» (C#, только чтение PDM)

**Зачем (словами пользователя, 2026-11-09):** «Набираю номер изделия → ищет в PDM → „Загрузить на сайт“ → изделие ложится полностью: модули, детали, картинки. Приложение на C#, чтобы не нужен был SolidWorks. Администраторы скачивают его с сайта».
**Зачем — глаголом:** администратор за 2 минуты загружает изделие из PDM на сайт: видит, что новое, что уже есть и где расхождения, и решает по каждому.

## Глубже
- **Результат:** один `.exe`, который на ПК с клиентом PDM читает изделие и отдаёт сайту дерево `pdm-tree/1` + файлы.
- **Сырьё:** изделие **6104.0000.0000** (хранилище «PDM», корень `C:\PDM`), разведка — `ANALYSIS.md` разделы 2, 5а–5д.
- **Метод профи:** PDM API (`EPDM.Interop.epdm`), Computed BOM вместо дерева ссылок; ничего не писать в хранилище и в локальный вид (как «Раскладка 5.1.3»: `GetFileCopy` во временную папку).
- **Внешний судья:** спецификация `6104.0000.0000_BSUP_SD.xlsx` из PDM (подетальная, 110 строк, 2145 шт) — **эталон**. Развёрнутые из `bom` количества деталей/метизов/покупных должны совпасть с ней 1-в-1. Развёртка `0000.0000.0019` = 253,1×80 мм.
- **Смелая планка:** чтение 6104 ≤ 60 с; 0 записей в PDM; совпадение с эталоном 110/110.

**Класс:** L (новая программа, сервер не трогает) · **Max agents:** 1 исполнитель (эта сессия) + проверка координатором · **Max review loops:** 2 · **Проверки:** сборка `dotnet publish`, прогон на 6104, сверка с эталоном
**Язык менеджера:** да — все надписи по-русски, без кодов и английских слов на экране.

## Shared pack
- Договор с сервером — **`docs/crew/C057-pdm-import/CONTRACT.md`** (pdm-tree/1, эндпоинты). Менять нельзя; несовпадение → в отчёт, решает координатор.
- Сервер (Э1) делает другая сессия параллельно. Пока сервера нет — приложение работает в режиме «Сохранить пакет на диск» (zip: `tree.json` + `files/` + `previews/`), этого достаточно для приёмки Э2.

## Что сделать

### 1. Проект
- Папка **`apps/pdm-loader/`** в корне репо (новая; кроме неё ничего в репо не трогать, кроме `docs/crew/C057-pdm-import/REPORT-E2.md` и `samples/`).
- .NET 8, WinForms, `net8.0-windows`, x64, `PublishSingleFile` + `SelfContained` → один `.exe`. Имя: `DataCore.PdmLoader.exe`. Версия — в `.csproj` (`1.0.0`).
- PDM: COM `ConisioLib.EdmVault` через `EPDM.Interop.epdm.dll` из папки клиента PDM (обычно `C:\Program Files\SOLIDWORKS PDM\`) — **ссылкой без копирования** в репо (`<Reference HintPath>` + `EmbedInteropTypes`), либо `dynamic`. SolidWorks не нужен и не вызывается.
- `README.md` в папке: как собрать (`dotnet publish -c Release`), что нужно на ПК (клиент SOLIDWORKS PDM, вход Windows).
- `.gitignore`: `bin/`, `obj/`, `out/`.

### 2. Чтение PDM (только чтение!)
1. Вход: `LoginAuto(<хранилище>, hwnd)`. Список хранилищ — из реестра `HKLM\SOFTWARE\SolidWorks\Applications\PDMWorks Enterprise\Databases` (как `vault_views()` в «Раскладке»). Одно — выбирать само.
2. Поиск: `CreateSearch`, `FileName = "<номер>.%"`, рекурсивно от корня → сборка `<номер>.SLDASM`.
3. **Состав с количествами — Computed BOM PDM** (`IEdmBomMgr.GetBomLayouts`, `IEdmFile7.GetComputedBOM` → `IEdmBomView.GetRows`, уровни дерева, колонка количества). В Python это не читалось (массив структур COM) — в C# читается штатно. Если Computed BOM недоступен — **стоп и в отчёт** (не изобретать из дерева ссылок: оно показывает файлы, а не спецификацию; пример — «Соединение» с 15 длинами болтов).
4. **«Продвинуть»**: сборки с «Отображение в спецификации: Продвинуть» растворяются — их дети к родителю с умножением количества. Проверить на 6104: `SMI.6104.0001`, `SM.2001`, `S.BM08.D603.01` не попадают в `items`.
5. Конфигурация — та, что использует родитель; СС-конфигурации (`СС1`, `СС2`, всё с «СС» — для «Инструкции по сборке») не читать никогда.
6. Вид позиции — переменная `Вид_изделия`: «Изделие»→product, «Модуль»→module, «Деталь»→part, «Метиз»→fastener, «Покупное изделие»→purchased. Сборочный модуль / Соединение — только если НЕ «Продвинуть» (тогда module) — иначе растворить.
7. Переменные — список в CONTRACT `vars`. Числа — с точкой. Пустое/«0» → null.
8. `designation` — имя файла без расширения и без `^…`. `aliases` — `Number`, если отличается. Расхождение `Number` и имени → `warnings` (`number-mismatch`; в 6104 у `BM08.110…085.D603` у всех `Number` = `БМ08.095.D603`).
9. **Развёртка** (только part, сортамент «Лист…», «Лист нерж.…»): найти `<designation>.dxf` (любой регистр расширения) в PDM, `GetFileCopy` во временную папку, габарит **по геометрии** (LINE, ARC, CIRCLE, LWPOLYLINE, POLYLINE, SPLINE; слои с надписями/линиями гиба — пропускать, если явно названы), не по `$EXTMIN/$EXTMAX`. Библиотека — `netDxf` (MIT) или свой разбор. `blank.source = "dxf"`. Нет DXF и деталь плоская (одна сторона = толщине из сортамента) → `pdm`. Трубы, брус → `blank.length = Длина_заготовки ?? Длина`, `source = "pdm"`. Иначе `null`.
10. **Документы** (правило 12: только product, module, part): `<designation>.pdf`, `<designation>.dxf`; у изделия — `<designation>_SS.pdf` (`assembly`), `<designation>_BSUP.pdf` (`install`). Последняя **зарегистрированная** версия через `GetFileCopy` во временную папку, `sha256`, размер. Метизы, покупные, растворённые сборки — без файлов.
11. **Картинка**: превью детали/модуля/изделия. Порядок: (а) превью из PDM (`IEdmFile` thumbnail / `IEdmVault` GetThumbnail, если есть); (б) первая страница PDF-чертежа (`Windows.Data.Pdf`) ; (в) нет. PNG ≤ 800 px. SolidWorks не вызывать.
12. Папка изделия в PDM (`61 Детские игровые комплексы`) → `folder`.

### 3. Окно (русский, крупно, без кодов)
- Сверху: «Сайт: [адрес] · Вход: [логин] [пароль] [Войти]» (адрес по умолчанию `https://kppdf-crm.ru/db`, можно `http://localhost:3001`; запоминается, пароль — нет; токен — в памяти).
- «Номер изделия: [6104.0000.0000] [Найти в PDM]» → прогресс «Читаю PDM… 34/171».
- Дерево: изделие → модули → детали/метизы/покупные; колонки: обозначение, вид, сортамент, кол-во, размер заготовки, файлы, картинка; предупреждения — жёлтым.
- Кнопки: «Сохранить пакет на диск» (zip) · «Проверить на сайте» (preview) · «Загрузить на сайт» (apply + files) — две последние активны, когда есть вход; до готовности сервера — сообщение «Сайт ещё не принимает загрузку».
- После «Проверить на сайте» — ответ сервера в дереве: новое / уже есть / расхождение (таблица «Сайт | PDM» с выбором по полю) / похоже (выбор кандидата). Кнопка «Обновить всё из PDM».
- Журнал — `%LOCALAPPDATA%\DataCore\PdmLoader\logs\`. Временные файлы — `%LOCALAPPDATA%\DataCore\PdmLoader\cache\` (чистить старше 30 дней).
- Проверка версии: при входе `GET /api/apps/pdm-loader`; новее → «Скачайте новую версию» со ссылкой.

## Критерии приёмки
- [ ] `dotnet publish -c Release` → один `DataCore.PdmLoader.exe`, запускается на ПК без .NET.
- [ ] 6104: в `items` нет `SMI.6104.0001`, `SM.2001`, `S.BM08.D603.01`, СС-конфигураций.
- [ ] **Эталон:** развёртка `bom` до листьев × количества = `6104.0000.0000_BSUP_SD.xlsx` (обозначение → К-во) для всех 110 строк. Скрипт сверки — `apps/pdm-loader/tools/check-6104` (любой язык), итог в REPORT.
- [ ] `0000.0000.0019`: `blank` = 253,1 × 80 (±0,5), `source: dxf`. Плоские листы — совпадают с PDM.
- [ ] Файлы: только PDF/DXF; у метизов/покупных — нет; sha256 верный.
- [ ] Пакет `samples/6104.pdm-tree.json` (без файлов) положен в `docs/crew/C057-pdm-import/samples/`.
- [ ] В PDM ничего не изменилось: версии файлов и «кто разрегистрировал» до и после — одинаковые (сверка в REPORT).
- [ ] Окно — по-русски, без английских слов.

## Нельзя
- Писать в PDM и в локальный вид PDM. Вызывать SolidWorks.
- Зашивать в .exe машинный ключ `kppd_` или пароли.
- Менять `CONTRACT.md` — предложения в REPORT.
