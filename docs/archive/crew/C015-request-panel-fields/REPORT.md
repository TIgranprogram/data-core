# C015 — правая панель заявки: что куда пишется

## 1. Поле «Название»

| Вопрос | Ответ |
|--|--|
| Что это | Текст **заявки снабжения** (`SupplyRequest.title`), не заказ и не отдельное «имя в счёте» |
| Куда сохраняется | `PATCH/POST /supply/requests` → поле `title` документа заявки |
| Подсказки при наборе | Только при **новой** заявке: прошлые заявки + склад (`pastItems` / suggest) — выбор подставляет `title` и часто `materialId` |
| Это «название в счёте»? | **Нет.** «В счёте» у позиции склада — поле `invoiceName` на **материале** (`#stock`), не в форме заявки |

При выборе со склада в `title` часто кладётся `invoiceName \|\| name` позиции (см. `pastItems` / Н-1) — это копия строки на момент заявки, не живая правка склада.

## 2. Связь со складом (`materialId`)

- Есть `materialId` → заявка **привязана** к одной позиции склада.
- Правка названия/артикула/категории/цвета/ссылки/единицы **должна** идти в `#stock?open=<id>`.
- С 2026-11-03 в форме «Изменить»: эти поля **только показ** + кнопка «Открыть карточку позиции»; в `toBody` при `materialId` они **не отправляются**.
- Нет `materialId` → свободный текст заявки: «Название» и реквизиты ещё правятся в заявке (позиция на складе не выбрана).

## 3. Секции формы — чья зона

### Заявка (эта покупка)
Количество, приоритет, доставка, фото заявки, примечание, статус, поставщик/сумма/тип счёта (если ещё нет `invoiceId`), кто подал, дата заявки, направление затрат.

### Счёт (если уже есть `invoiceId`)
Поставщик, № и дата счёта — **только показ** (`fromInvoice`); правка в карточке счёта.

### Склад (если есть `materialId`)
Название, артикул, единица, категория, цвет, ссылка — **только показ** + переход в карточку позиции.

### Заказ клиента (не «что заказать»)
- `salesOrderRef` — под какую позицию **нашего** заказа идёт снабжение.
- `orderLabel` — заказчик (контрагент), не название болта.
- Это связь заявки с продажным заказом, не редактирование изделия заказа.

## 4. Путаница (было / стало)

| Путаница | Было | Стало / истина |
|--|--|--|
| «Название» = переименовать болт на складе | Можно было править `title` в заявке при живом `materialId` | При связи со складом — только карточка склада |
| «Название» = имя в счёте поставщика | Похоже по смыслу | Имя «в счёте» — `invoiceName` на складе; в заявке — своё `title` (часто скопированное) |
| «Что заказать» = заказ клиенту | Заголовок секции | Это блок **заявки снабжения**; заказ клиента — блок «Для кого» |
