# C075 — «Паспорта заказа» за один проход (П10 + П7)

**Класс:** M · **Дата:** 2026-11-11 · Исполнитель: Cursor  
**Основание:** `docs/crew/C070-passports-kp-focus/PASSPORT-FIRMS.md` п. 1; `PASSPORTS.md` §1(в), §5. Чек-лист: `docs/crew/C074-cursor-queue/CHECKLIST.md` п. 2.

## Цель

Заказ из 10 позиций, половина не готова — не больше 15 нажатий (было 35–55). Всё в панели «Паспорта заказа», без ухода в другое окно.

## Сделать

1. **Фирма на весь заказ.** Если у заказа нет нашей фирмы и фирм больше одной — в панели сверху один выбор фирмы (сейчас тупик «Выберите фирму», `passport-order.ts:80-86`). Выбранную предложить записать в заказ (`companyId`). В ответе плана — `firm`, `firmChoices`.
2. **Заполнение в этой же панели.** Неготовая позиция → раскрыть → те же поля, что в выпуске (`passportFill` mode `issue`), без перехода в «Шаблон паспорта». После заполнения позиция → «готова».
3. **Сводка и кнопки.** Сверху одна строка «Готово N из M · не хватает: …»; одна главная «Выпустить готовые (N)»; после выпуска — «Печать всех».
4. **Следующий шаг заказа.** На этапах «Готов» и «Отгружено» подсказка — «Паспорта заказа» (`salesorders-next.js:38`).
