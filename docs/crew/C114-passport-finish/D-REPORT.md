## 2. Текущий путь менеджера
1. Карточка изделия → вкладка «Техописание» → «Техническое описание (PDF)».
2. В панели таблица «Из чего сделано»: часть, материал, размер, покрытие. Выбор из справочников.
3. Кнопка «Взять из состава» (`products/form-fields.js:27`, сервер `showcase-materials.ts:10-33`) переносит материалы состава склада.
4. Блок «Подставится из изделия»: габариты ±10 %, вес, назначение, монтаж. Только показ.
5. Необязательные строки только для этого PDF. Заголовок. «Сохранить и скачать PDF».
6. Без строк — ошибка «Добавьте хотя бы одну строку».

## 3. Что подставляется само
- Габариты (с допуском ±10 %), вес, назначение, монтаж — из карточки изделия.
- Стенка из размера (∅89×3 → «толщина не менее 2 и не более 4 мм»).
- Материалы из состава склада: сначала по связи `materials.passportSpec`, потом по подсказке из названия. Размер берётся из названия или габаритов позиции (`materials-text.ts:129-160`).
- Фото — главное фото изделия.
- Копия изделия переносит `materialsSpec` (`showcase-clone.ts:6`).

## 5. План доделки (по шагам, от выгодного)

Шаг 1 — часть из состава (M, backend). `specFromComposition` ставит `partIds` по названию позиции состава («Труба…» → стойка/перекладина — нужна таблица соответствий) и по `materials.passportSpec`. Добавить поле `partId` в `passportSpec`. Файлы: `common/catalog/materials-text.ts:129-160`, `showcase-materials.ts`, spec-тесты. Критерий: после «Взять из состава» у строк с известной связью часть заполнена; без связи — пусто, а не «Материал».

Шаг 2 — типовой набор частей по группе (M, данные плюс backend). Справочник «группа изделия → части → допустимые материалы» (Э4 C055 плюс AUDIT-PASSPORT-PARTS). Файлы: `dicts.defs.ts`, сид `backend/scripts/`, `materials-spec.js` (сужение списка). Чистка мусорных частей — отдельным нарядом steward, прод только по «да».

Шаг 3 — воронка техописания (L, frontend). Первый экран — «Что сделано из чего»: строки из шага 1 и 2 с кнопками «верно / изменить», затем недостающие части группы («Добавить: поручень, закладные?»). Затем габариты и вес с галочкой «из карточки». Образец — `PATTERNS.md` П-1 и `passports/funnel/`. Файлы: `tech-sheet.js`, новый `tech-sheet/funnel.js`.

Шаг 4 — «Осталось сделать» и готовность (M, backend+frontend). Серверный `techsheet-gaps` (нет частей, нет габаритов, нет веса, нет назначения) → чипы с переходом к полю, как у паспорта. Флаг «техописание готово» в списке изделий и в плане заказа. Файлы: рядом с `passport-gaps.ts`, `order-passport-plan.js`, `products.js`.

Шаг 5 — подсказки из аналога (S/M). «Взять из похожего изделия» (та же серия или группа, у кого заполнено). Фразы назначения и монтажа по группе в панель без ухода в карточку. Файлы: `tech-sheet.js`, `showcase` (поиск похожих).

Шаг 6 — единые допуски (S). Вынести `wallOf`, `range` и допуски в один источник (сервер строит строки, экран получает через эндпоинт предпросмотра). Заодно предпросмотр PDF. Файлы: `tech-sheet.js`, `tech-sheet-rows.ts`, контроллер.

Шаг 7 — документация (S). Блок «Техописание» в `atlas-data.js` и `help-guide-data.js`, строка в `PRODUCT.md` («Продукция»).

Порядок: 1 → 2 → 4 → 3 → 5 → 6 → 7. Шаги 1 и 4 не зависят от пользователя. Шаг 2 упирается в вопрос 2.
