# C189 — ключи своих приложений

**Результат.** В режиме «Только своё приложение» выдаётся `scope: { access: 'app', apps: ['myapp'] }`. Имя содержит 1–40 строчных латинских букв и цифр и начинается с буквы. `control` зарезервирован. Список приложений показывает только выданное пространство, когда в нём есть коллекции.

- В своём пространстве ключ выполняет обычные чтение, создание, изменение и мягкое удаление. Каждый запрос проверяет текущего пользователя, текущую роль и её базовую роль. Общие данные, чужие приложения, скачивание PDM, схемы, админка, выдача ключей и физическое удаление закрыты и для ключа администратора.
- Валидные `read`, `write` и `full` сохраняют прежний режим. Только отсутствующее поле `scope` означает старый полный доступ в рамках прав выдавшего. Повреждённое поле даёт 401, в списке у ключа `scope: null`, отзыв остаётся доступен.
- Заголовки `Authorization: Bearer` и `X-Access-Token` проверены. Журнал скрывает заголовки, выдача возвращает секрет с `Cache-Control: no-store`. Повторы создания записей используют кеш после проверки прав и отдельно для каждого ключа. Выдача ключей не записывается в кеш.
- Проверены пределы приложения. Тело до 16 МБ, документ до 256 КБ, пачка до 500 записей, ответ списка до 200 записей на странице. Запросы с повторными параметрами или некорректным фильтром отклоняются с 400. Превышение размера возвращает 413.
- Граница по доступности. Приложения делят одну MongoDB. Квот по суммарному объёму, количеству записей и коллекций на приложение нет. Ключ допускает изменение всех документов собственного пространства в рамках прав выдавшего.
- Общий ограничитель запросов применён и к ключу приложения. При 12 одновременных запросах на чтение 10 прошли, 2 вернули 429.

Перед выдачей выберите отдельное имя для разработчика и срок действия. Передавайте ключ в секреты серверной части его приложения и отзывайте после работы.

**Проверено локально.** TypeScript и ESLint успешно. 176 юнит-тестов и 49 HTTP-тестов на отдельной MongoDB 4.4.30 с синтетическими ключами. Проверка живого сервера и выдача рабочих ключей в этот прогон не входили.
