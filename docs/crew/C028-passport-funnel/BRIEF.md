# C028 — Паспорта «воронкой»: выжимка задачи (координатор, 2026-11-06)

Класс: **XL** (новая возможность, данные прода, `products` и `passports` общие с CRM). Порядок: аналитик (opus) → ТЗ → исполнители → designer, qa.

## 1. Что хочет пользователь (его словами, сжато)

1. Паспорта сейчас делаются **вручную**: текущий мастер «не подходит вообще» — перегружен, информация подана неправильно. **Можно переделать всё** (решение пользователя 2026-11-06). Не опираться на текущий вид.
2. Создание паспорта — **воронка**: каждый шаг сужает выбор, ошибиться нельзя, путь к цели — кратчайший. Сверху вниз: сначала то, что сразу отбрасывает лишнее.
3. Два входа:
   - «Создать паспорт» из карточки изделия → изделие уже выбрано, шаг выбора пропускается;
   - «Новый паспорт» без изделия → шаг 1 = выбор изделия: категория (выпадающий список) → подкатегория/признаки → изделие.
4. **Один раз выбранное не спрашивать второй раз.** Изделие пришло с категорией — категория паспорта и всё, что из неё следует, подставляется само.
5. **Признаки для сужения** (фасеты): пример — «Тренажёр» → вид (суставный и т. п.). Таких критериев сейчас нет. Нужен **анализ нашей продукции**: какие признаки реально её делят, чтобы точно попадать в цель. Признаки — в справочник (пользователь потом правит сам), **заполнить сразу** самыми нужными. Они же пригодятся в поиске и фильтрах «Продукции».
6. **Изделие — минимум при создании**: название, фото, артикул, обязательные поля → создано. Дальше каждый сотрудник дополняет своё: чертежи, паспорт, заказ, договор, КП. Приложение — единое хранилище: каждый знает, куда положить и где найти.
7. **Тексты паспорта — по категориям**: выбрал категорию → выпадающий список только её текстов. Не хватает текстов для нашей продукции — добавить в справочник.
8. Приложение **само подсказывает следующий шаг** (как воронка продаж).

9. **Вид (уточнение пользователя 2026-11-06):** наш дизайн — правая панель, табличные варианты, раскрывающиеся списки, красиво; иерархия сверху вниз — воронкой. Только эталоны kit (`docs/DESIGN.md` §4): `filter` mode `funnel` (`stepFunnel`, шаги сверху вниз, `always`, `icon`), `entityPanel` / `panel` (правая панель), `section` (раскрывающиеся блоки), `table` (табличный вид, `maxHeight`), `pick` single/combo (выпадающие списки), `row` + `similarBox` (выбор изделия с фото и артикулом), `empty` (пусто с подсказкой). Нет нужного варианта — запрос «нужен вариант X эталона Y», не свой CSS.
