# Наряды для локального ИИ

Наряд — задание на ночь: читать, искать, сравнивать, писать черновик. Пишет Claude, выполняет локальный ИИ (`tools/starozhil/run.mjs`), запускает владелец кнопкой пульта «Старожил → Запустить следующий наряд».

## Формат файла `NNN-слово.md`

```markdown
---
priority: 1          # меньше — раньше
status: ready        # ready | paused (paused не берётся)
repeat: false        # true — повторять не чаще чем раз в everyHours
everyHours: 24
steps: 60            # шагов модели (один шаг — один инструмент)
minutes: 120         # предел времени
prepare: [tools/starozhil/module-facts.mjs]  # программа готовит факты до модели (только tools/starozhil/*.mjs)
---
# Цель
Что выяснить — одной-двумя фразами.

# Что читать
Точные файлы и строки. Чем точнее — тем лучше итог.

# Нельзя
Чего не делать и что не считать.

# Итог (формат finish)
Таблица или список, ≤ 60 строк, каждое утверждение — с файл:строка.

# Как проверит Claude
По какому признаку итог принимается.
```

## Правила

- **Факты — программой, слова — моделью** (проба 13.11: «найди сам» → выдумки; «по готовым фактам» → карточка принята). Наряд без `prepare` — только если факты уже лежат в файле.

- Модель только смотрит: инструменты `list_dir`, `read_file`, `search`, `note`, `finish`. Секреты и `.data` закрыты.
- Память модели мала (16 тыс. токенов): наряд узкий, «что читать» — точное. Большое — несколько нарядов.
- Итог читает Claude: принял → нужное в план или карточку; не принял → наряд правится (уточнить «что читать»).
