# C137 — Паспорта без противоречий: запрос пользователя (2026-11-16, дословно по смыслу)

Генератор паспортов собирает паспорт из общего шаблона и карточки изделия; части противоречат друг другу.
Исправить шаблон и правила сборки, чтобы противоречий не было в любом будущем паспорте.
Порядок: 1) показать, где лежат шаблон, строки чек-листа, подписи рисунков и какие поля есть в карточке; 2) грамотное ТЗ; 3) чек-лист; 4) план; 5) править — только если действительно нужно.

1. Один источник фактов — карточка изделия: наименование; тип; назначение (одна фраза); узлы; материалы; покрытие; способ установки; резьба (да/нет); сварка (да/нет); металл (да/нет); поставка (в сборе / частями); высота над грунтом; глубина заделки; масса без фундамента; заводской номер. Обязательное поле пусто — паспорт не публикуется, показать, чего не хватает. Общую фразу не подставлять.
2. Условные блоки вместо оговорок («при их наличии», «если опоры бетонируют», «предусмотренных конструкцией»): способ установки (1.1, «Монтаж», основание, строка чек-листа, подпись рисунка — один способ во всём паспорте); анкеры/закладные — только при анкерном креплении; сварка/резьба/металл — швы, затяжка, коррозия, консервация, окраска; покрытие — «масло»/«лакокрасочное»/«подкраска» по полю; дерево — гниение, трещины, обновление защитного состава; поставка частями — «изделие и его части», «порядок сборки», комплектность с частями и крепежом.
3. Чек-лист: строки по типу и материалам; чужой тип не выводить; совпадающие по смыслу сливать; «Где» — узел изделия, не материал; строка без «Меры» и «Допуска» не публикуется; формулировки игрового/спортивного («места хвата», «перед использованием», «прекратить пользование») — только для них.
4. Периодичность — один источник, таблицы чек-листа: «Осмотры проводят не реже сроков, указанных в табл. N и M; эксплуатант вправе назначить более частые». Вид осмотра в тексте — только если есть таблица.
5. Структура без повторов: «Уход и обслуживание» + «Уход за изделием» → «Техническое обслуживание»; правила пользования — только раздел 2; назначение — только 1.2; 1.1 — полное предложение (состав, материалы, покрытие, установка); требования к основанию — один пункт; у каждого абзаца номер.
6. Термины — словарь по типу: опорный столб; эксплуатант (владелец); заводской номер (не номер изделия); класс бетона (не марка); схема установки (не монтажная схема).
7. Нумерация и ссылки автоматические; таблица/журнал не выводится — пункты со ссылкой на них тоже; заголовки «Таблица N — …» и номера разделов не терять.
8. Типографика: маркер «—»; Арт-объект «Деревянные указатели»; «Стела»; знак ×; согласование через «изделие».
9. Технические данные: «Высота над уровнем грунта», «Глубина заделки», «Масса без фундамента»; числа = карточка и чертёж, одно округление.
10. Безопасность по порогам (высота > [?] м, масса > [?] кг — пороги спросить): временное раскрепление до набора прочности; подъём и строповка; фундамент с расчётом на ветер; ограждение опасной зоны; демонтаж; внеочередной осмотр после шторма и наезда транспорта.
11. Автопроверка перед выпуском (ошибка — не выпускать): способ установки одинаков (1.1, Монтаж, чек-лист, подпись рисунка); стоп-слова «при их наличии», «при наличии», «если опоры», «— —», «Стелла»; нет «сварн», «лакокрасочн», «коррози», «закладн», «анкер» при пустом поле; в чек-листе нет чужих типов и пустых граф; ссылки на таблицы/рисунки ведут на существующее; наименование одинаково на обложке, 3.1, 14.1, талоне; нет одинаковых абзацев/заголовков, нет абзацев без номера.
Ограничения: смысл «Гарантии» и «Рекламации» не менять; значения, ГОСТ, СП не придумывать — спросить.
Результат: список изменённых мест, новая схема полей карточки, пересобранные паспорта № 601 и № 603, отчёт автопроверки по каждому.
