# C280 · Заявки из каталога через корзину

В разделе «Заявки» рядом с одиночным входом добавить «Из каталога». Правая панель: поиск, категория, название, артикул, единица, количество и добавление в строке. Корзина отдельным состоянием той же панели, со счётчиком, редактированием количества, удалением, возвратом к выбору, экспортом и подтверждением «Создать заявки». Одна строка на materialId, повтор складывает количество. Предел 200, положительная конечная величина по правилам DTO. Каталог берётся из действующего API, цены не показывать. Самостоятельное создание новой номенклатуры, поставщики, рассылка, складские движения и счета вне сценария.

Готовый POST /supply/requests/bulk используется без изменения публичного договора. Он пишет строки последовательно. Пока запрос не подтвердил весь пакет, держать неизменяемый снимок с одним clientUid, блокировать второй клик и редактирование после неопределённого результата. Последующий повтор отправляет исходный снимок, а не новый пакет. Видимая ошибка объясняет возможность частичной записи. По возможности хранить незавершённую попытку по пользователю в browser storage. Экспорт через существующий downloadXlsx, с количеством числом, артикулом текстом, без финансовых полей. Успех закрывает панель и показывает статус «Заказать».

Не менять одиночную форму, загрузку Excel и прежнюю пакетную форму. Код карточки счёта соседней задачи уже в индексе, не переиндексировать. Внешний эталон MB1 заимствуется как сценарий выбора, без копирования интерфейса.

## Уточнение: вход через группы

На первом экране центральный поиск и карточки с иллюстрациями. Группы расположены вертикально, карточки внутри — слева направо. После категории появляется выбор подкатегории, после него — перечень. Поиск сужает карточки, сохраняя шаг выбора. Перечень поддерживает признаки из номенклатуры и сортировку названий, размеров, толщины и остатков там, где есть данные. В нижней панели каталога только переход в корзину и отмена, отправка открывается внутри корзины.

### Закупка труб по сортаменту

- Внутри формы сечения строка показывает сортамент, например Ø21,3×3 (ВГП 15). Мойка относится к складскому остатку. Совпадающие варианты мойки одной закупочной позиции собираются в строку.
- Учитывать длину хлыста и марку стали при объединении. Рядом показывать остатки по состояниям с единицей измерения.
- Ввести можно штуки или метры. Штуки целые, заказ округляется вверх до целого хлыста. При длине 6 м ввод 6 м даёт 1 шт., 7 м — 2 шт. и 12 м к закупке.
- Проверить количество в корзине, файле Excel и запросе создания. При неизвестной длине исключить догадки о пересчёте.

В списке закупки труб одинаковые сортамент и материал занимают одну раскрываемую строку. Поля количества и добавление доступны в закрытом виде. Длина и остатки по мойке доступны внутри.

Открытые заявки и объём ожидаемых поставок видны без раскрытия. После частичной приёмки показывается остаток. Иллюстрации типов и категорий общие для графического выбора в приложении; разные конструкции крепежа имеют собственные предметные изображения.

В раскрытии слева остатки по мойке, под полями шт/м — общий остаток выбранного варианта. Для запаса в метрах штуки показываются как эквивалент по длине. Дата последнего заказа или дата его счёта указывается с основанием. Оплаченную поставку до приёмки выделять прямо в строке.

Трубы без длины в справочнике: разрешить указать штуки и длину хлыста для конкретной покупки. Поля ввода и кнопка корзины действуют самостоятельно; щелчок по остальной поверхности строки открывает либо закрывает подробности.
