## Результат и критерии
1. Новый заказ с нераспределённой позицией остаётся в очереди заказов; сам по себе stage=new не добавляет его на доску проектирования.
2. После распределения последней нужной позиции заказ/задачи появляются автоматически и однократно, при повторном сохранении дублей нет.
3. Служебные/услуги/неизделия учитываются существующими правилами, не блокируют переход ошибочно.
4. В «Заказах» менеджер видит понятную причину ожидания и следующий шаг. Упоминание проектирования только когда соответствующая работа действительно есть.
5. Существующие задачи/историю/метки не удалять при обратных изменениях автоматически. Пограничный сценарий записать отдельно, если договорённости нет.
6. Если код уже работает — отчёт PASS с доказательствами, никакой косметической переписи ради активности. Если воспроизведён дефект — минимальная правка + регрессия.
