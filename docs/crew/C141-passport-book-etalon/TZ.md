# C141 — эталонный редактор паспорта (книжка) + фокус менеджера

Класс: L · Агентов: 0–2 (frontend; designer после стенда) · Проверка: smoke на стенде :3102; `dc check` по затронутым.

Слова владельца: `OWNER.md`. Аудит входов: `AUDIT.md`. Чек-лист внедрения: `CHECKLIST.md`.

## Цель
Один поддерживаемый вход правки паспорта — книжка. Слева: воронка текстов + очередь «что заполнить/проверить». Середина: интерактивный лист (правка на месте). Правая колонка: только ИИ и подсказки, не основной ввод.

## Архитектура (не ломать)
| Модуль | Ответственность |
|--|--|
| `book-editor.js` | Каркас окна, страницы, lifecycle, **inline**-редактор поля, Tab/Esc |
| `book-blocks.js` | Разметка страниц из снимка (как PDF) |
| `book-choices.js` | Слева: путь изделия (только чтение) + воронка `textChoices` |
| `book-focus.js` **новый** | Слева: «Сначала» из `GET /showcase/:id/fill-queue` (уже есть на сервере) |
| `book-images.js` / `book-shared.js` | Картинки; замок; ИИ-промпт |
| `kit.css` `.bk-*` | Ширины, inline, тона страниц в оглавлении |

Правила:
- Один источник пробелов — **сервер** `fill-queue` / `passport-gaps` (не дублировать веса на клиенте).
- Группу/раздел изделия из книжки **не PATCH**; тип паспорта — подпись (смена типа — отдельное редкое действие или убрать).
- Правка текста паспорта — существующие snapshot APIs (C132/C134).
- Запись в корень изделия (габариты/вес/состав) — **волна B** отдельным пунктом чек-листа (ссылка в изделие / techsheet), не ломать API в спешке.
- Старые формы (`field-edit` на карточке, `of=passports` для правки) — перевести входы, код не удалять, пока чек-лист не зелёный.

## Волна A (эта поставка, стенд)
1. Левая колонка шире (~420px); лист «по ширине» шире (~1120px).
2. `book-choices`: тип паспорта и путь изделия — **текст**, не селект смены категории; воронка выборов текстов сверху вниз.
3. Правка поля — **на листе** (inline), не в правой панели; справа — ИИ + краткая подсказка.
4. `book-focus`: блок «Сначала заполнить / проверить» (обязательные сверху, до 8 пунктов); клик → прокрутка к странице или понятная ссылка.
5. Оглавление страниц: спокойнее цвет у «общих», ярче у страниц с ручными/издельными полями (эвристика по заголовку + `.k-src`).
6. Входы: «Дописать и выпустить» в архиве → `openBookEditor`; при наличии паспортов у изделия — «Изменить паспорт» → книжка.
7. Help/atlas — одна фраза: правка = большое окно-книжка.

## Волна B (после приёмки A, не смешивать)
- PATCH изделия из книжки (габариты/вес) одним API-путём.
- Удаление/скрытие карточных карандашей после перевода всех входов.
- `data-focus` на блоках страниц вместо эвристик прокрутки.

## Проверки
`node --input-type=module --check` на изменённые js; точечный `node --test` если есть; стенд: паспорт 601 или аналог — снимок + оценка владельца.
