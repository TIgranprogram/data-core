## 2. «Дубль»: один объект показан разными способами

1. **Позиция заказа** — в карточке заказа четыре места, клик везде разный:
   - «К производству» (`salesorders.js:346`) — сводная таблица, строки не нажимаются;
   - «Договоры → Позиции» (:289) — строка открывает панель дохода «Доходы по заказам» (`of:'orders'`), хотя человек ждёт позицию;
   - вкладка «Проектирование» (`order-design.js:46`) — ссылка на задачу в другом разделе, экран уходит;
   - вкладка «Работа» (`order-work.js:59`) — ссылка на карточку «В работе», тоже уход.
   Одна позиция ведёт в 3 разные сущности (доход, задача проектирования, задача производства) без общего правила.
2. **Заказ и договор.** Две сущности: две кнопки правки («Изменить заказ» в шапке, «Изменить договор» в блоке), один «Удалить» (только договор), два этапа (у заказа «самый отстающий», у договора свой). Карточка L внутри карточки L.
3. **Этап заказа** показан 4 раза: бейдж в шапке, строка «Этап» в сведениях, «Этапы по договорам», цвет вкладок договора + бейдж договора.
4. **«Не распределено / не сопоставлено»** — 5 раз: плашка над списком, плашка в карточке (`plateOf`), строка «Не распределено» в сведениях, блок `distribBlock` во вкладке «Позиции», бейдж «не сопоставлено» в строке.
5. **Паспорта заказа** — три входа: вкладка «Паспорта» в договоре (`order-passports.js`), «Паспорта по заказам» в Документации (`docs-orders.js`), панель плана (`order-passport-plan.js`).
6. **Проектирование / Работа / Склад / Отгрузки** — вкладки договора повторяют целые разделы меню; у каждой свой стиль блока и свои кнопки «Открыть в …».
7. **Счета**: вкладка «Счета» в «Заявках» и блок «Счёт» в карточке заявки; фильтры разные (`invoices-tab` — 3 select, заявки — чипы).
8. **Деньги**: «Долги» — вкладка «Денег» и отдельный экран `orders.js` «Долги»; «Прочие расходы» — пункт меню и вид «По статьям».
9. **«Договоры»** — меню Снабжение (с поставщиками) и «Договоры» в заказе (с клиентами): одно слово, две сущности.

## 4. Предложение: 7 шаблонов экранов (уровень 4)

Шаблон — порядок блоков и роль каждой кнопки; организмы берутся из kit. Раздел описывает только данные (колонки, поля, действия).

1. **Список с поиском и фильтрами** (Продукция, КП, Контрагенты, Договоры, Прочие расходы, Долги, Каталог, Движения, История, Корзина, Заказы-таблица).
   Сверху вниз: заголовок + одна главная кнопка «+ …» справа → поиск + чипы (одна строка, остальное под «Ещё») → плашки-предупреждения (только если есть что делать) → таблица / плитки / доска с переключателем → пустое состояние с подсказкой.
   Есть: `kit/list*.js`, `filter`, `list-chips`, `table`, `empty`, `auto-more`. Нет: единого места для `headActions`, единого переключателя вида (`viewKey` у 5 разделов — вручную).
2. **Доска по этапам** (Заказы, Проектирование, В работе, Заявки, Склад).
   Заголовок + «+ …» → чипы → колонки этапов → карточка доски (S/M: заголовок, подпись, одна метка, срок, одна кнопка шага).
   Есть: `kit/board.js`, card M. Нет: единого набора полей карточки доски.
3. **Карточка объекта (правая панель).**
   Шапка: сущность в заголовке («Заказ № 21-26 · Заказчик»), статус бейджем, ОДНА главная кнопка + «⋯» → строка «Что дальше» (с предупреждением, если есть) → сведения (до 6 строк, остальное свёрнуто) → вкладки по смыслу объекта, не по разделам меню → история.
   Есть: `kit/card.js`, `card-tabs`, `entity-panel`, `readonly`, `blocks`, `badges`, `links`. Нет: правила «главная кнопка одна» в эталоне; блока «Что дальше»; вложенной группы (договор в заказе) — сейчас card L в card L.
4. **Очередь дел** (Главная-блоки, Сопоставление, Документация «К выпуску», Заявки/счета, мобильная выдача).
   Заголовок + счётчик → чипы срока / ответственного → строки-задачи с одним действием справа → пусто = «Всё сделано».
   Есть: `list-rows`, `recent-cards`, `badges`. Нет: эталона `queue` (каждая очередь собирает строки сама).
5. **Пошаговый ввод (воронка)** (паспорт, КП по шагам, «Заполнить» в Деньгах, шаг заявки, мобильная выдача).
   Полоса шагов → один вопрос на экране → «Дальше» primary / «Назад» ghost → итог с переходом в объект. Правила — `PATTERNS.md` П-1.
   Есть: `kit/funnel.js`, `guide.js`. Нет: общей рамки (заголовок, выход, черновик) для 4 воронок.
6. **Сводка / дашборд** (Главная, Деньги: сводка, прогноз, по статьям; ФОТ; Гант).
   Период и компания (общая полоса) → плитки-показатели → график / таблица → «Показать записи».
   Есть: `planner*`, `list-periods`. Нет: полосы «период + компания» (у Денег своя), плиток-показателей как kit-организма (в `home.js` локальные).
7. **Справочник / Настройки** (Справочники, Тексты паспортов, Сотрудники, Зоны, Контрагенты, Настройки изделий, Профиль, Настройки доски).
   Слева выбор (дерево или список) → справа поля → одно «Сохранить». Без вкладок-«шестых экранов».
   Есть: `tree-table`, `side-form`, `form`. Нет: двухколонного шаблона «дерево + форма» (`passport-tree`, `dicts` делают сами).
Журнал (История, Движения) и Корзина — шаблон 1 только для чтения.
