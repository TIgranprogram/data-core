# Исправления финальной проверки паспортов

12.11.2026, класс L. Рабочий стол пользователя не использовался.

- Реальный PNG 3905 содержал бледные боковые границы бумаги. Обычный trim принимал их за рисунок: контур занимал около 17% ширины. Новая обработка только черновика проверяет непрерывность бледной линии, чистый внутренний промежуток и отсутствие тёмных штрихов. Обрезка копии 1184×835 → 499×732, отступ 2,5%; оба вида, стрелки и подпись целы. Исходные файлы не меняются.
- Первый синтетический тест с чёрной линией толщиной 1 px выявил сглаживание до серого 128. Нижний порог удаления поднят со 120 до 150; тесты тёмной линии и отметки у края проходят. Для узкого рисунка поиск рамки отключён. Старый путь сохранён для ранее выпущенных снимков без drawingLayout. Новые снимки фиксируют drawingLayout=2: после выпуска улучшенная обработка сохраняется. Эту границу проверяют unit и сквозной e2e.
- В списке недостающих данных назначение не учитывало автоматический выбор по группе, хотя PDF уже использовал его. Теперь использован общий resolveChoices. Чужая группа не подставляется, ошибочный сохранённый выбор остаётся видимым.
- В тесте старый mock выдавал нового родителя группы при каждом запросе; ненужный обход родителей приводил к переполнению Set. Обход выполняется только при наличии групповых привязок. Сценарий единственного варианта приведён к общему контракту: он уже выбран автоматически; подсказка по названию проверяется при двух вариантах.
- Сквозной тест материалов воспроизвёл устаревший textSnapshot черновика после смены materialsSpec. Теперь исходные поля и автоматически пересобранный снимок сохраняются вместе. editedAt и ручные значения защищены. Проверка сохранности выданного PDF описана в FINAL-MATERIALS-QA.md.

Отдельно исправляются данные текстовых справочников (FINAL-TEXT-FIX.md). Незаданные габариты, материалы, нагрузки, сертификаты и изображения не заполняются догадками.
