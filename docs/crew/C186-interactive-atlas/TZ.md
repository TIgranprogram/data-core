# C186 — интерактивная карта сайта

Вход через «?» и `#atlas`. Владелец должен видеть, откуда приходят сведения, какое действие их использует и куда передаётся результат. Пример для приёмки — «Изделие → Состав»: входы из модулей, деталей и каталога, выходы в потребность и склад.

- Общий вид слева направо показывает ход заказа. Территории занимают устойчивые места. При приближении колесом под курсором видны разделы, затем состав раздела и отдельные действия.
- Наведение и фокус клавиатуры выделяют связанные участки. Щелчок закрепляет выбор. Слой, направление и список связей дают способ прочитать подписи и точные концы связей.
- Для рассмотрения в чате адрес сохраняет выбранный узел. Старые ссылки `#atlas?n=...` открывают прежнее окно. «Путь заказа» доступен как краткий сценарий.
- В карте действующие разделы и отдельно помеченные планы. Слои различают передачу данных, порядок действий, состав и переходы по ссылкам. Источники — реестр карты и руководство. Передача включает только подтверждённые направления и условия.
- Приёмка на настольных ширинах 1024/1920/2560/3440 px. Проверить приближение к курсору, доступность управления без мыши, фиксацию, фильтры, подсветку, переход по ссылке, старую прямую ссылку и работу во всех темах. Для проверки доступов использовать разрешённую учётную запись локальной копии.

Визуальные ориентиры: [Musicmap](https://musicmap.info/) для группировки больших территорий, [Карта Средиземья](https://mapmiddleearth.com/ru) для пути внутри общей карты, [Hamilton от The Pudding](https://pudding.cool/2017/03/hamilton/) для фокусировки на выбранном сюжете.

## Пробный вид «Изделие → Состав» после отзыва владельца

Отдельный пробный вид доступен по `#atlas?view=composition&focus=products.sostav`. Колесо на схеме меняет подробность. В обзоре связи собраны в две группы. При приближении карточки раздвигаются, открываются три источника и два получателя, затем подписи передачи. При обратной прокрутке схема собирается. Размер надписей и центральная карточка сохраняются. Опорный приём — [ZUI Grasshopper](https://developer.rhino3d.com/en/guides/scripting/scripting-gh-csharp/#inputs-outputs).

## Раскрытие на общей карте

На `#atlas` колесо над карточкой раскрывает связи этой карточки. При раскрытии связанные карточки расходятся на полотне, следующий шаг показывает подписи связей. Размер текста остаётся постоянным. Входы и выходы различаются по стороне подключения, направлению стрелки и цвету. Для выбора другого блока достаточно перенести указатель к его карточке. Обратная прокрутка собирает общий вид. Проверить слои, карточки на краях, блок с большим числом связей, открытую связь из списка и клавиатуру на 1024/1920/2560/3440 px. Прямая ссылка с `focus` открывает фокус на общей карте.

Ориентиры Grasshopper — [линии между входами и выходами](https://www.rhino3d.com/docs/grasshopper2/terms/wire.html) и [выделение выбранной линии](https://developer.rhino3d.com/api/gh2/type/grasshopper2.ui.skinning.wireskin/).

## Чистое полотно по уточнению владельца

Рабочая область `#atlas` целиком занята полотном. В обзоре видны только крупные области и цепочки между ними. Колесо над областью раскрывает её разделы, следующий шаг над разделом показывает его входы, выходы и внутренние действия. Выбранная часть занимает пространство на том же полотне. Карточки раздвигаются, а размер надписей сохраняется. Колесо вниз и Escape возвращают уровень выше. По прямой ссылке на часть открывается нужный уровень; прямые ссылки `n` из справочника по-прежнему ведут в окно блока.

На старте отсутствуют переключатели, легенда, подпись под схемой, список связей и плитки разделов внутри крупных областей. Пример приёмки: «Продукция → Изделие → Состав», три источника и два получателя. Дополнительно проверить запуск с других областей, в том числе склада, где идентификатор области отличается от идентификатора раздела. Целевые ширины 1024/1920/2560/3440 px, локальная копия.
