## Как сведены e2e

В первом шарде прошли 307 тестов. Скрипт разбиения подставил лишний каталог `e2e/` в путь к набору восстановления пароля, и Jest не смог открыть этот файл. Второй шард прошёл целиком, 270 тестов. В третьем прошли 257 из 259 тестов. Два прежних ожидания для смены единицы в справочнике учитывали только заявку, хотя при создании заявки C192 создаёт ещё и материал.

На принятом снимке фактический `test/reset-password.e2e-spec.ts` прошёл 22/22. Обновлённый `test/e2e/dicts.e2e-spec.ts` прошёл 5/5. Оба сценария смены единицы проверили число перемещённых записей и новые единицы у заявки и у созданного материала. В итог вошла одна успешная запись на каждый реальный путь из списка Jest. Повторные результаты словарей заменили весь первоначальный набор.
