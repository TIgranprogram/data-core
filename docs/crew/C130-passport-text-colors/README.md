# C130 — «Текст паспорта»: всё, что идёт в PDF, и цвета по источнику

**Зачем (владелец, 16.11):** в карточке паспорта, блок «Текст паспорта»: проверить, что сюда попадают все тексты; выделить цветом тексты этого изделия и общие для всех изделий; есть ещё признак различия — ещё цвет. Плюс: галочки позиций заказа крупнее.

**Класс:** M · **Проверки:** `dc check`; вид — образец на стилях приложения (`look-fixture.jpg`), живой стенд был выключен.

## Что нашли при сверке с PDF

PDF печатает из собранного текста: описание, назначение, правила, разделы, обслуживание, монтаж (`passport-pdf-v2-layout.ts:27-33`). На экране не было двух кусков:
- «Требования к основанию» (`install.requirements`, PDF — `passport-pdf-v2-layout.ts:218`);
- допуск в таблице обслуживания (`tolerance`, PDF — `:293`).

Оба добавлены в карточку (`card-blocks.js`: `installList`, `periodBlock`).

## Цвета

| Цвет | Что значит | Откуда берётся |
|--|--|--|
| серый | общий — для всех изделий | шаблон «Для всех» |
| голубой | для этого типа паспорта | шаблон типа паспорта |
| зелёный | по этому изделию | справочники по его элементам, материалам, способу установки; выбранные варианты текста |
| золотой | вписан вручную | свой текст изделия, правка пункта в паспорте, поля «свой текст» |

## Как устроено

- Сервер: `passport-compose.ts` — у пункта поле `src`; `passport-v2-text.ts` — источники описания, назначения, монтажа (`V2Text.src`).
- Старый собранный текст без источников подписывается при открытии карточки по свежей сборке (`withTextSources`, `product-passport.service.ts` `get`). В базу не пишется. Текст выданного паспорта не меняется.
- Экран: эталон `kit.src` (`ui/kit/src.js`, стили в `kit.css`, строка в `DESIGN.md`, блок на витрине).
- Галочка позиции заказа: `.k-pick input` — 22 px.
