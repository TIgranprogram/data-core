# Поручение исполнителю C171

Реализуй «Разбор пачки документов с проверкой и отправкой из Пульта» по TZ.md в этой папке. Первый выпуск — счета с подготовкой нового ПК, живым ходом разбора, проверкой PDF рядом с черновиком и отправкой готовой пачки по кнопке. Excel сделай дополнительным способом сверки по контракту ТЗ. Договоры и опциональную головную модель принимай отдельными этапами.

Начни с проверки актуального состояния C169 и подготовки отдельного стенда. Веди чек-лист ТЗ, замерь качество на эталонной пачке и сохрани REPORT.md. После полной приёмки сделай коммит всех изменений C171 и push в согласованную ветку. Рабочий сайт и его данные в приёмке не используй для записи.
