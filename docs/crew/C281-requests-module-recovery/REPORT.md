# C281 — восстановление «Заявок» после ошибки загрузки

За три часа проверка журнала рабочего сайта показала одну группу, три сбоя при открытии «Заявок». Браузер загружал модуль без имени, которое требуется экрану. Свежие файлы рабочего сайта согласованы. При автоматическом восстановлении service worker повторно использовал кэш, уже помеченный текущей версией.

Явное обновление готовит отдельный кэш для той же версии, если новой версии пока нет. Прежняя оболочка доступна до успешной загрузки страницы и входного модуля. Механизм восстановления действует и для вкладок, открытых до выпуска исправления.

Регрессия Chromium `update-cache-browser.test.mjs` воспроизводит предыдущий отказ из кэша текущей версии, открывает «Заявки» и каталог после исправления и проверяет сохранение оболочки при неполном обновлении. Проверка C280 открывает каталог и корзину для менеджера, директора и пользователя.
