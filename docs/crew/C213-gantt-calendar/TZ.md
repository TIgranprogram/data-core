# C213 — календарные периоды Ганта

- [x] «День» показывает одну выбранную дату и работы, которые её занимают. Для почасового планирования нужны почасовые данные.
- [x] «Неделя» показывает понедельник–воскресенье. «Месяц» показывает даты одного месяца. «Обзор работ» показывает диапазон имеющихся полос.
- [x] Проверить навигацию, переход из шапки в день, один заказ, пустую дату, назначение, перенос срока и отмену.
- [x] Проверить на широких экранах и на локальной копии, сверить карту и справку.
