# C187 — приёмка общих фильтров

**PASS, изолированная локальная копия.** Edge, средняя тема при 1920 px: общая панель на 19 маршрутах. Тёмная тема при 2560 и 3440 px: панель на пяти ключевых маршрутах в каждой ширине. Проверены открытие, закрытие, Esc с возвратом фокуса, доступность поиска и сохранение адреса. На складе поиск сохранился после закрытия панели. Ошибок JavaScript и попыток записи 0.

Общие панели проверены на продукции, остатках, модулях, деталях, заявках, счетах, каталоге номенклатуры, архиве документации, проектировании, расходах, истории, договорах поставщиков, движениях, работе, Ганте, долгах, операциях, деньгах по статьям и справочнике групп продукции.

КП, контрагенты, заказы, очередь документации, паспорта по заказам и два специализированных экрана склада используют поиск и краткие переключатели. На копии каждый из семи маршрутов открыт, поиск доступен. Обоснование разделов и исключений — [аудит](AUDIT.md).

На синтетической браузерной фикстуре пройдены выбор категории, группы и подгруппы, возврат на уровень выше, фильтрация по серии, сохранение условий при закрытии, сброс и переключение в таблицу с полным списком категорий. Поиск и таблица остаются доступны через клавиатуру. Тест: `tools/design-checks/filter-panel.test.mjs`.

Дизайнер принял панель склада и галерею продукции в средней и тёмной темах на обезличенных данных. [Пример галереи на 1920 px](products-1920-soft.png).

«Журнал движений» проверен по эталону списка DESIGN §3.1: заголовок, поиск, быстрый отбор по операции, даты в общей панели и таблица по дням. В карте проставлен актуальный шаблон. Проверка карты проходит при прежнем лимите старых шаблонов.

Совокупный обход desktop при 1920 px: открылись 29 экранов и 7 первых карточек. На складе сброшены статус и поисковый запрос. Видимых ошибок, ответов 5xx и горизонтального переполнения 0. «Сопоставление» перенаправляется в «Заказы» штатно. Сценарий только для чтения блокировал фоновые записи настроек и телеметрию.
