# C197 — реестр паспортов и передача заказчику

Поручение 22.11.2026. Пользователь распечатал паспорта и хочет видеть по заказу, каких документов ещё нет, какие готовы и какие переданы. Реестр и паспорта печатаются раздельно.

- [x] Сверить действующий план состава паспортов заказа, прикреплённые оригиналы, отменённые позиции, черновики, отдельные исполнения и старые паспорта. Реестр включает привязанные позиции даже без выпущенного номера.
- [x] Показать табличный реестр из одной серверной модели. Базовые столбцы: позиция, изделие, количество, номер/файл, состояние, передача. Сделать печатную версию с заказом, заказчиком, датой и количеством строк. Печать состояние не меняет.
- [x] Явное действие «Передано заказчику» с получателем, датой и подтверждением. Различать выпуск и передачу. Проверить комплект, сохранить автора и неизменяемый состав переданных документов с версиями/идентификаторами. Повтор запроса не создаёт вторую отметку. Новая редакция выдаёт необходимость повторной передачи, старая остаётся в истории.
- [x] В рабочей очереди только паспортные действия, которые остались. Готовые к выпуску отдельно от выпущенных к передаче. Переданные доступны по заказу и через историю. Старые неизвестные передачи не считать подтверждёнными автоматически.
- [x] Проверить права, связь с архивом C188 и отсутствие записи при печати. Проверить сценарий на отдельной MongoDB и desktop 1920/2560, включая недостающий паспорт, вложенный, повтор передачи и готовый реестр.
