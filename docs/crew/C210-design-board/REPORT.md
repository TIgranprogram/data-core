# C210. Доска проектирования

Первая колонка показывает активные заказы. Шапка открывает карточку заказа, «Изделия» раскрывают вложенный список с отступом. У свободных позиций есть ручка переноса и меню. У завершённых виден статус, карточку задачи можно открыть по названию. Закрытые заказы доступны отдельным фильтром.

В рабочей сетке три колонки. «Завершены» и «Отменены» открываются с правого края в одной панели архива. Рабочие колонки принимают перенос в пустую часть. После переходов между карточками крестик возвращает на доску за один шаг.

Три сценария Playwright, 394 проверки PWA, проверка импортов и карты сайта прошли. Доска проверена при 1920, 2560 и 1024 px в трёх темах. [Проверка и снимки](UI-REVIEW.md).
