# C201 — частичная передача паспортов заказчику

Уточнение владельца 22.11.2026. Можно передавать готовые паспорта несколькими партиями. Реестр всегда показывает, что передали и что ещё требуется. Пример на локальной копии — заказ № 20-26, готово 11 из 14.

- [x] В раскрытом реестре можно выбрать конкретные готовые, ещё не переданные позиции. Подтверждение сохраняет получателя, дату, автора и только выбранные документы.
- [x] После частичной передачи в реестре и PDF видны переданное и остаток. «К передаче» показывает комплекты, в которых есть хотя бы одна готовая непереданная позиция. «В работе» остаётся до передачи всех актуальных позиций.
- [x] Снимок каждой передачи остаётся в «Истории передачи». После новой редакции выбранного паспорта нужен только этот паспорт. Повтор запроса не добавляет запись, а одновременные отметки не закрывают документ дважды.
- [x] Полная передача по прежнему запросу и чтение прежних полных передач сохраняются. Архивный договор доступен для чтения, без новой передачи.
- [x] Проверить путь на изолированных тестовых данных, PDF глазами, рабочие очереди и кнопки на 1920/2560. На локальном заказе № 20-26 проверено открытие и выбор двух строк.

Единица передачи — паспорт конкретной позиции. Если одна позиция описывает несколько изделий, количество внутри неё в реестре не делится.
