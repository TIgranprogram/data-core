# C277 — складская область в истории и блоке «Сегодня»

C275 применил область склада к истории заявки. Независимая проверка нашла такое же расхождение для истории материала и движения, а также для поставок и счётчика «Заявки» на «Сегодня». Пользователь с одним складом должен видеть данные только этого склада во всех этих местах.

**Класс** L · **Ответственный** backend · **Проверяют** access, архитектор и QA.

## Спецификация

- `GET /audit-logs/record`, типы `Material` и `StockMovement`. Для ограниченной роли проверить существующий материал и его склад по правилам `inScope` до чтения истории. Для движения использовать авторитетный `materialId`. Снятая позиция относится к тому же складу. Неподтверждённая принадлежность возвращает 403. Для полноправного чтения сохранить старые ID.
- `GET /today` и `GET /me/counters`. Для блока поставок и счётчика заявок применить существующий `docScopeMatch` до группировки, сортировки и ограничения выборки. Открытие раздела, группировка статусов, горизонт и режим «Моё / Всё» работают как раньше.

Общий журнал директора и фильтр «Кто» входят в C278.
