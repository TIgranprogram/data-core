# Формат проверки паспорта (владелец 17.11.2026)

Коротко, по пунктам. Без длинных объяснений.

- `п. X.Y — заменить: «…» → «…»`
- `п. X.Y — удалить: «…»`
- `табл. N, строка «…» — заменить где: «…» → «…»`
- `рис. «…» — Сверить: …` (если без чертежа нельзя править текст)

Сначала важное (безопасность, противоречия, цифры, ГОСТ). Не больше 25 строк. В конце: `Итог: N, важных: M`.
