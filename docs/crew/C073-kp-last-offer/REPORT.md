Сделано. На сайт не выкладывал, прод не трогал.

`GET /offers/last?customer=&counterpartyId=` — роли списка, маршрут до `:id`.
Ответ: номер, дата, объект, доставка, условия, предоплата, сроки, НДС (только показать), prices[{productId, unitPrice}] или null.
Сначала id контрагента, иначе имя без регистра и лишних пробелов. `counterpartyId` и `description` уже были в DTO. `docs/MAP.md`, `docs/openapi.json`.

Корзина `kp.js` и форма `offers.js`: комбо, «Недавние» сверху, новое имя текстом. «Подставить» / «Нет»; ручное не затирается; доставка вместе с объектом. НДС из прошлого КП не копируется.
Цена не сама: «в прошлом КП было … — взять?». Описание изделия само, пометка «из изделия». Условия и НДС фирмы как в форме. Итог «с НДС N %». Объект и доставка свёрнуты, пока пусто.
Общие куски — `offer-memory.js`: иначе `offers.js` длиннее 400 строк (линт L8).

Допущения: не cancelled (отклонённые входят, deletedAt нет). Новее: date, createdAt, _id; id важнее даты по имени. Кривой id не 400. Выборка ≤ 40. Регэкс без флага i (Mongo 4.4). Контрагенты 200 + поиск 30; 403 — «Из заказов» без id. Автотекст фирмы «Подставить» может заменить. Строка без id в старой корзине без описания. Форма: combo, id по подписи (`partyPick.id`). Дизайнер не смотрел — «не нужно» по заданию.
