# Запросы GLM-5 к kit (нужные варианты/параметры, которых нет)

Формат: что · зачем · файл:строка (после правки). Claude делает в kit, потом экраны заканчиваются второй итерацией.

1. **`button({ cls })` — доп. класс поверх `.btn`.** Для переходных случаев, когда у кнопки осталась парная стилистика экрана: `td-more`-обёртки, `td-chip`, `go-tile`. Сейчас `button()` не принимает лишний класс, обхожусь обёрткой или оставляю как есть. Пример: `sections/home.js` (`td-chip` — пилюля-метрика с крупным числом, `mk()`), `home.js:~329` (`td-day` — день недели).
2. **Вариант карточки-строки «tile-действие» (`.go-tile`, `.td-pass`, `.td-q`).** Крупные кликабельные строки-плитки «Сегодня» (паспорта к выдаче, договоры, быстрые действия на телефоне): заголовок + подпись + модификатор `hot`. `card S` не подходит (другая композиция), `row` — другой ритм. Нужно: `row({ variant: 'tile' })` или `card({ size:'S', twoLine:true, tone })` с допуском доп. класса. Файлы: `home.js` (td-pass, td-q, go-tile).
3. **`empty()` компактный вид.** Внутри очередей «Сегодня» пусто — одна строка `--fs-table --muted`; полный `.state`-блок разрастается и двигает сетку. Нужно `empty({ compact: true })` → тонкая строка без крупных отступов. Файл: `home.js` (`emptyLine`).
