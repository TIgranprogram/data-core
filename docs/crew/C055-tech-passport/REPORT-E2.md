# C055 Э2 — печать: паспорт / техописание / вместе

Статус: API готово. UI не трогал.

## Режимы

| pack | Что | Куда |
|--|--|--|
| нет / `passport` | прежний PDF паспорта | `GET /passports/:id/pdf`, `POST /passports/preview` |
| `tech` | только техническое описание из `materialsSpec` | те же |
| `combined` | один PDF: страницы паспорта, затем листы A4 техописания | те же |

`POST /showcase/:id/tech-sheet` {title, rows} — как раньше (окно шлёт свои строки). `variant=short|full` не связан с pack. `mode=stand` и pack `tech|combined` — 400.

Состав пустой (нет строк, габаритов, назначения) — 400 «Нет состава для технического описания». У паспорта берётся его снимок `materialsSpec` (черновик перед этим синхронизируется с изделием). Допуски как в окне: стенка ±1 мм, габариты ±10 %.

`pack=tech` выпуск не отмечает. `combined` отмечает выпущенный, как обычная печать паспорта.
