## Решения пользователя (2026-11-16)
- Автопроверка: сначала **предупреждение** (неделя, отчёт по всем паспортам), потом запрет выпуска.

## Этап 2 — правила сборки (выкладка 2) · datacore-backend
2.1 Чек-лист (`maintenanceTables`, `passport-compose-parts.ts:138–190`): «Где» = узел/элемент; фильтр по виду изделия; слияние по нормализованному названию; строка без Меры и Допуска не печатается.
2.2 Периодичность: фраза «Осмотры проводят не реже сроков, указанных в табл. N и M; эксплуатант вправе назначить более частые.» — из кода, номера из layout; вид осмотра — только при наличии таблицы.
2.3 Ссылки: нет цели → пункт выпадает целиком; журналы по условию; заголовки «Таблица N — …» не теряются (тест).
2.4 Техданные `specRows`: «Высота над уровнем грунта», «Глубина заделки», «Масса без фундамента»; одна функция округления.
2.5 Убрать общую фразу-подстановку (`compose-parts:100–105`); пустое обязательное → `missingFieldsV2`.
2.6 «Заводской номер» вместо «Номер изделия» (обложка `passport-pdf-v2-cover.ts:100`, окно).
