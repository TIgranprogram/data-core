# Право директора на создание заявок из каталога

**PASS для интерфейса.** 28 ноября 2026 года, Chromium, 1440×1000, рабочая дельта над `c7e8c7f0`. Проверены светлая и тёмная темы. Использованы настоящие форма роли и экран «Заявки», учебный профиль директора и заполненная доска с заявкой «Балка 10». Проверка приложения с реальным API ведётся отдельно.

| Сценарий | Что увидел и проверил |
|---|---|
| Настройка роли | В карточке «Снабжение» виден отдельный флажок «Создание заявок из каталога» с пояснением. У директора по умолчанию он включён. Снятие оставляет доступ к разделу «Заявки», показывает «Вернуть по умолчанию», в данных формы появляется `requestCartCreate: false`. [Светлая тема, разрешено](evidence-role/admin-light-on.png) · [Тёмная тема, запрещено](evidence-role/admin-dark-off.png). |
| Директор с разрешением | В панели действий видна кнопка «Из каталога» рядом с переключателем вида. Щелчок открыл диалог в обеих темах. [Светлая](evidence-role/requests-light-on.png) · [Тёмная](evidence-role/requests-dark-on.png). |
| Директор с запретом | На той же доске кнопка «Из каталога» отсутствует, доступны «Ещё» и «+ Заявка». Проверено по снимку и списку доступных для взаимодействия кнопок. [Светлая](evidence-role/requests-light-off.png) · [Тёмная](evidence-role/requests-dark-off.png). |

Шесть браузерных проверок прошли. Для обеих тем отдельно проверены форма роли, разрешённый и запрещённый входы. Сохранение формы здесь проверено до формирования тела запроса.
