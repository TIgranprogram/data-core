# C188 — проверка интерфейса архива

Вход — карточка договора и меню «⋯». Выбранные эталоны: секция карточки, группа реквизитов, короткое подтверждение и окно PDF. Блок показывает причины отказа, версии с датой и сохранённые файлы. Новая раскладка или собственные стили не понадобились.

**PASS на браузерной фикстуре.** 1920 px, средняя тема: причины готовы до отправки, ошибка сохранила введённую причину, выбор акта обновил готовность, поля выровнены. 1024 px, тёмная тема: история раскрывается, PDF загружен по адресу версии, команда возобновления появилась у администратора, причина передана на сервер фикстуры. Ошибок JavaScript 0.
