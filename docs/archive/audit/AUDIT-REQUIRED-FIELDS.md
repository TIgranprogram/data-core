## Главные расхождения

1. Заказ: `productionNo`/`customer`/`company` обязательны только при флаге `requireFields` (флаг шлёт pwa, импорт — нет). Это намеренно, оставить.
2. Заявка: количество с `*`, но сервер не требует (qty опционально).
3. Счёт: `*` у «№ счёта» всегда, а проверка — по статусу.
4. Изделие и паспорт: `*` на экране, сервер принимает пустое (все поля Optional).
5. Приоритет заказа и заявки: `*` без смысла (есть умолчание).

## ТЗ правок

### Backend (A — безопасные, при создании/правке)
- B1. `supply.service.ts:~383`: при создании заявки `qty > 0` (после `title`), текст «Укажите количество». Старые не трогать.
- B2. Паспорт `product-passport.service.ts` (create) — требовать `name`, `date`, `passportCategory`; в `update` — не пусто, если поле пришло. Режим «черновик на весь заказ» (`passport-draft-all`) не затрагивать (проверить spec).
- B3. Изделие: pwa-путь создания — требовать `name` и `type`; проверить, какой контроллер принимает pwa, DTO `CreateProductDto.name` Optional не менять без проверки CRM.
- B4. Счёт `supply-invoice.service.ts` create: `supplierId` обязателен (если пуст в проде — после заполнения); `pay` уже требует плательщика.
- B5. Заказ: опционально `title` (предмет) при `requireFields` — только после очистки данных (см. «сначала заполнить»).

### Frontend
- F1. `invoice.js:194`: `*` у «№ счёта» зависит от выбранного статуса (`state`); `Поставщик` пометить `*` и проверять в save до запроса; `Наша компания` — `*` при «Оплачено».
- F2. `contracts.js:188`: виджет «Поставщик» пометить `required` (визуально).
- F3. `salesorders.js:524,619` и `requests.js:166,176`: снять `required` с Приоритета/Статуса (есть умолчание) или добавить значение по умолчанию в `initial`.
- F4. Паспорт `passports/form.js`: `*` на «Категория паспорта» и проверка до запроса.
- F5. Изделие `products.js:462-463`: подтвердить `*` на name/type (уже есть); сообщение с сервера выводить как есть.
- F6. `partners.js:231`: ИНН — подсказка «нужен для счетов и паспортов», без `*` (сначала заполнить).

### Сначала заполнить (не включать обязательность)
Заказ.title, срок изготовления, паспорт.заказчик/заказ, ИНН контрагентов. Перед включением — `tools/dc.cmd data` или доступ через `datacore-access` оценить долю пустых; порог включения — <5% пустых.
