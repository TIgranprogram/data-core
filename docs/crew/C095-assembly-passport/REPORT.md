# C095 — Паспорт сборного изделия: отчёт

Дата: 2026-11-12. Ветка `worktree-c095-assembly`. Класс L (сервер + экран). Примеры утверждены пользователем ([EXAMPLES.md](EXAMPLES.md)).

## Что сделано

| Где | Что |
|--|--|
| `product-passport.schema.ts` | Необязательное поле `moduleVariants` [{ name, size?, qty, photoId? }]. Нет поля — обычный паспорт. |
| `dto/create-product-passport.dto.ts` | `ModuleVariantDto`: название обязательно, количество — целое 1…100000, рисунок — id фото. До 50 вариантов. |
| `product-passport.service.ts` | Сохранение: только заполненные варианты, пустой список → `null`. Карточка отдаёт `url` рисунка. Копия паспорта переносит варианты (`MODEL_FIELDS`). |
| `passport-modules.ts` | Чистые функции: чистка списка и сумма модулей. |
| `passport-pdf.service.ts`, `passport-pdf-v2-layout.ts` | Обычный выпуск PDF: таблица «Варианты модуля» сразу после «Комплектности». Рисунок — колонкой при наличии, без пустой рамки. При ≥ 2 вариантах — строка «Всего модулей». Второго пути печати нет. |
| `pwa/ui/kit/module-variants.js` + `kit.css` (`.mv-*`) | Виджет формы: на вариант — название, габариты, количество, один рисунок (`photoField`). «+ Вариант модуля»; первому варианту габариты подставляются из L × H × B изделия. Строка «Модулей / Всего модулей» и предупреждение о неполном варианте. |
| `pwa/sections/passports/form.js`, `module-variants.js` | Раздел формы «Варианты модуля (сборное изделие)». Неполный вариант не даёт сохранить (сообщение с номером варианта). Выпущенный паспорт без «Новой редакции» варианты не меняет (как остальные поля). |
| Витрина `sections/kit.js`, `docs/DESIGN.md`, `docs/MAP.md`, `pwa/index.html` (preload) | Обновлены. |

Нумерация, выпуск, аннулирование и повторная печать не менялись. Модули номеров не получают. Данные вариантов хранятся в паспорте; у выпущенного они заморожены, повторная печать даёт то же.
