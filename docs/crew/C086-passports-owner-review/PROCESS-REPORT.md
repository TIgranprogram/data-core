# C086 — настройка процесса

Статус: правила и ТЗ подготовлены; реализация паспортов открыта. Дата: 2026-11-11.

- Подтверждено: C075 и C078 проходили тесты, но отчёты прямо исключают приёмку глазами.
- C074/EYES: на стенде 0 заказов/паспортов; выпуск с заполненным изделием не проверен.
- Инструкции designer одновременно требовали снимки и разрешали проверку по коду; skill ограничивал проверку одним снимком одной темы.
- BOARD содержит исторические «принято по коду». Их не переписали задним числом.
- Введён единый UI-ACCEPTANCE; ссылки в CANON, AGENTS, DESIGN, ролях и шаблоне ТЗ. Обновлены designer и design skill.
- PATTERNS дополнен применимостью, приоритетом ручного значения и пересчётом при смене контекста.
- Подготовлены NOTES, ТЗ, промпт и исходные снимки. Кодовые причины уточнил отдельный читатель без доступа к прод-данным.
- Исходные ошибки: общий набор полей без фильтра, select без видимой подписи/зазора, растянутый segmented, перехват клика фотослота, неоднозначный получатель вставки.
- Автоматические ворота пока проверяют только метку коммита. Новый протокол — обязанность ролей, не заявленная программная гарантия.
- Код приложения и прод не изменялись; готовность выпуска паспортов не подтверждена.
- Следующий шаг: исполнить TZ, затем независимая приёмка по UI-REVIEW. Идеальную работу всех будущих агентов документация гарантировать не может.
