## Важно: «карточка позиции» и «пункт меню» — разные вещи
- Клик по строке заказа открывает позицию через `of: 'orders'` (З:247), клик по операции в календаре — тоже (op-row.js:11). Это КАРТОЧКА из orders.js, не пункт меню.
- Панели `incpay`/`incprice` привязаны к пункту меню `orders` (main.js:110, OWNER). Убрать пункт из NAV (main.js:107) без перепривязки — права на них перестанут проверяться (`allowed` пропускает всё, чего нет в NAV_IDS, main.js:118).
- Ещё привязано к `orders`: бейдж «ждём оплату» (main.js:307-308), `session.sees('orders')` для «+ Позиция» (З:436), home.js:55, поиск, корзина.

## Вывод
Список как экран — **почти дубль**: «что и когда пришло» есть в календаре, «цены» — в «Требуют заполнения». Но три вещи нигде больше не существуют: (1) приём оплаты частями и список платежей, (2) список долгов (ждём оплату / частично) с фильтром по компании и датам и итогом «долг», (3) дата отгрузки строки-дохода и экспорт. Поэтому удалять пункт меню вслепую нельзя, а **карточку позиции удалять нельзя вообще**.

Рекомендация: пункт меню убрать, карточку и панели оставить; ответственный за оплаты — бухгалтер/директор (`canMoney`), менеджер вводит цены в «Требуют заполнения».

## Что перенести ПЕРЕД удалением пункта
1. «Деньги» → новая вкладка «Долги» (рядом с «Требуют заполнения»): список позиций «ждём оплату + частично» с компанией, периодом, итогом сумма/оплачено/долг, клик → карточка позиции. Кнопка экспорта — там же (admin). Вид и данные — те же `/incomes?status=…`, ничего нового на сервере.

4. Ссылка «все строки заказа №» (О:236) вести в карточку заказа, а не `#orders?orderNo=`.
5. «Новая строка заказа без карточки» — решение пользователя (вопрос ниже); по умолчанию — только внутри заказа.
