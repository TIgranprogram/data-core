# C184 — аудит и настройка ответственности агентов

**Архитектурная приёмка прошла.** Первичная сверка: Git отслеживал 5 279 путей, прежний просмотр архитектора и дизайнера охватывал 2 025. Семь карт превышали 80 строк. У менеджера сайта указания о прямом входе расходились с границей агента доступа.

Реестр [ownership.json](../../roles/ownership.json) назначает одного владельца и, когда нужно, проверяющих на каждой из девяти зон. Все девять профилей Claude/Codex имеют короткие карты. Предыдущие карты хранятся в Git на `3929ea33`. Менеджер получает рабочие сводки от агента доступа и проверяет сценарии пользователя в изолированной среде.

`owners --staged` показывает фактическую дельту и готовые строки для проверок. Ворота сверяют их с Git-индексом перед коммитом и с Git-коммитами перед выкладкой. Замена проверенной правки меняет её отпечаток. Содержание подтверждения и решение о допуске остаются ответственностью роли и координатора.

Девять тестов прошли. Проверены неизвестные и пересекающиеся пути, кириллица, режим файла, частичный индекс, перенос между зонами, удаление профиля, `amend`, разрешение конфликта и исчезновение обязательного реестра при слиянии со старой веткой. Независимый архитектурный прогон подтвердил отказ для исчезнувшего реестра и допуск исторического коммита. Временные репозитории были изолированы. Рабочий выпуск не запускался.
