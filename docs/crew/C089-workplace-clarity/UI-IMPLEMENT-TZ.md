# C089 — внедрение компактного паспорта и правой панели

Владелец 12.11 разрешил закончить дизайн паспортов/правой панели, проверить и выложить.
Класс L-UI, max agents 3, review loops 2. Scope только frontend, бизнес-правила и PDF не менять.

## Результат
Паспорт без длинной пустой полосы справа от рисунков; на широкой панели группы стоят рядом, на узкой сохраняют порядок в одну колонку.
Resize плавный, без автоматического прыжка на весь экран. Основная область на широком экране доступна рядом с панелью, сетка реагирует на оставшееся место.
Компактная навигация остаётся доступна при прокрутке, последний элемент формы достижим.

## Приёмка
- Общий компонент раскладки в kit. Фото и относящиеся поля/действия рядом при достаточной ширине панели, без утраты подписей, логического tab-порядка.
- В полях габаритов именно длина/ширина/высота; не подменять толщиной. Тексты/применимость прежние.
- Кнопка замены постоянно доступна, paste-target не открывает файловый диалог при фокусе. Отмена выбора не удаляет картинку.
- Широкий экран: панель не закрывает всю рабочую область; карточки перестраиваются. Узкий: один читаемый экран с возвратом.
- Проверить 390/1024/1600/1920, панели на промежуточных ширинах, обе темы, длинные подписи, скролл и клавиатуру. Не сжимать текст в вертикальные буквы.
- Внешний вид/поведение по UI-ACCEPTANCE: реальные заполненные состояния и независимый дизайнер после. Для входа только datacore-access, активный стенд Claude не пересобирать.
- Автопроверки PWA imports/guards и существующие целевые тесты; CSS tokens по design-skill. Не добавлять тесты, проверяющие только имя класса.
