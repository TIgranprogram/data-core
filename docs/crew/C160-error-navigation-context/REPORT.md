**Выпущено вместе с C159, v1.946, UI033850dc; принято архитектором.** HTTP4xx реальных API-запросов включены в журнал, сообщение формы остаётся прежним. Исключены auth4xx, самоотправка журнала и локальный запрет режима просмотра.

- В существующий stack добавляется до12 стандартных действий/переходов: раздел/of/open/tab. Метод/код/версия и путьAPI без query сохраняются прежними полями. DTO и backend не менялись.
- Поля форм и тело запроса не читаются. Текстовый ключ заказчика скрыт. Отражённое сервером значение поля в4xx не копируется: в журнале безопасная причина/код, у пользователя исходное сообщение. Обычный JS Error сохраняет сообщение и стек.
- След вRAM до выхода; постоянная offline-очередь хранится без истории действий. Logout снимает след и с RAM-очереди, поздний отказ старой отправки учитывает поколение сессии.
