## Правила
- Цвет только `#000` на белом. Заливки — нет, кроме фото изделия.
- Разделители: линии 0.5–1pt; заголовки — полужирные.
- Шрифт один (`gost`, `gost-i` для курсива). Поля страницы — без изменений.
- Фото изделия не трогать, рамок-заливок вокруг фото нет.
- Переключатель `bw` убрать: ч/б всегда.

## Приёмка
- Заливка < 5 % площади листа, кроме фото, на обложке, в таблице ТО и на стенде A3.
- Нет серого и цветного текста.
- Проверка: выпустить PDF одного паспорта и стенда, посмотреть обложку, таблицу ТО, стенд.
