# ТЗ C103 — «Тип паспорта» вместо «категории паспорта»: одна цепочка, без двусмыслицы

**Зачем (пользователь, 2026-11-13):** «Можно сопоставить категорию паспорта и Раздел → группа → серия у изделия, или слово «категория» грамотно заменить — путаница. В паспорте менять категорию или вообще показывать смысла нет, она уже должна быть выбрана в изделии. Грамотно исправь, чтобы двусмыслицы не было в будущем».
**Зачем — глаголом:** менеджер видит одну цепочку «Раздел → Группа (тип паспорта) → Вид (что за изделие, назначение) → Изделие» и нигде не встречает слово «категория» в смысле набора правил паспорта; тип паспорта задаётся только в группе или в виде изделия.

**Класс:** L · **Max agents:** 4 (frontend, backend, access, designer) · **Проверки:** full перед выкладкой
**Язык менеджера:** да.

## Shared pack (решение координатора)
- Термин: **«Тип паспорта»** — набор правил и ГОСТов паспорта (Благоустройство, Воркаут и спорт, Уличный тренажёр, Детское игровое, Спорт). Ключи данных и API НЕ меняются: `passportCategory`, `categories`, `passportCategories` остаются (контракт, общая база с CRM).
- Справочник `passportCategories`: заголовок «Категории паспортов» → **«Типы паспортов»**. Поля «Для каких категорий» → **«Для каких типов паспорта»**; «Категория паспорта» → **«Тип паспорта»**; подсказки и тексты ошибок — то же слово.
- Слово «категория» остаётся только там, где это действительно категория склада/каталога (`categories` склада, «Категории» номенклатуры).
- Где задаётся тип: **группа изделий** (поле есть) и **вид изделия** (поле есть). В анкете паспорта и в карточке изделия — только чтение: «Тип паспорта: Благоустройство — из группы «Скамьи»» / «— из вида «…»» / «— своё у изделия». Нет типа — предупреждение + ссылка «Задать в группе ↗» (`#dicts?d=productGroups&of=dict&open=<id группы>`, новая вкладка). Своё у изделия (старые данные) — строка + кнопка «Брать из группы» (снимает своё: `putDefaults(prod, { passportCategory: null })` или как принимает сервер).
- Справочник **«Типы изделий» (`passportTypes`) удалить**: 0 записей, подбирал тип по словам в названии (угадывание, запрещено с C100), путается с «Видами изделий». Вместе с ним — кнопка «Подставить по типу» в таблице материалов паспорта.
