# C028 — 16 цифр в текстах паспортов: ответы по ГОСТ и практике (аналитик, 2026-11-07)

Как проверял: ГОСТ — по текстам на meganorm.ru, СанПиН — legalacts.ru (страницы разбирал веб-инструмент; цифры сверить по оригиналу перед печатью). Не подтверждены: ГОСТ Р 56440 (воркаут), ГОСТ 34614.3 п. 4.8 в оригинале, ГОСТ 34614.2-2024. В СанПиН 2.1.3684-21 прочитаны п. 118, 121, 275, 276. Роспотребнадзор готовит изменения СанПиН (поправки с 01.09.2026, новые правила с 01.03.2027) — про песочницы не проверено.

**Вопросы (вариант по умолчанию):**
- В2, В6, В13, В15 — нагрузки: по умолчанию «значение указано в паспорте изделия»; цифру вписывает конструктор в карточку каждой модели.
- В3 — высота соскока: по умолчанию без цифры.
- В8 — снеговой район: по умолчанию «район установки в паспорте», расчёт — проектировщик.
- В10 — покрытие геопластики: по умолчанию «материал и толщина по паспорту».
- В12 — зона выката горок: не вставлять, пока не сверено с оригиналом ГОСТ 34614.3.
- Пункт 4 — допуск разметки ГТО: убрать.

**Юридически важно:**
1. Цифра в паспорте — обещание покупателю. Для нагрузок и снега безопаснее «по паспорту изделия / по расчёту»; общая цифра на категорию — только расчёт на худший случай.
2. Не писать «соответствует ГОСТ…» без сертификата или протоколов; «изготовлено с учётом» тоже обязывает. Нормативные цифры (350/400 мм, осмотры) — только с номером пункта.
3. Редакции меняются: ГОСТ 34614.2-2019 → 2024 (с 01.03.2025), СанПиН 2.1.3684-21 — замена с 01.03.2027. Статусы в справочнике норм сверять раз в полгода.
4. Цифру, которую не подтвердил конструктор или оригинал ГОСТ, — заменить словами «по паспорту» или убрать предложение.
