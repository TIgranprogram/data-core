# ТЗ C008 — Склад «Плитные материалы»

**Имя склада:** «Плитные материалы» (не «Листовой…» — так называется металл).  
**Категории:** под «Дерево» — Фанера, ДСП, ДВП, OSB, МДФ.  
**Поля позиции:** уже есть толщина/длина/ширина (`dimensions`), сорт (`materialGrade`), сортамент — хватает.  
**Роль:** «Кладовщик плит (телефон)» — только `stock-mobile` + этот склад; пароль сотруднику в админке.

**Скрипт:** `backend/scripts/stockzones-boards.js` (план / `--apply`).  
**Админка:** пресет роли с тем же именем.  
**Основной** склад: категории плит вычитаются, чтобы другие кладовщики их не видели.
