## 3. Структура по ролям (3–5 блоков, порядок сверху вниз)
Общее: шапка (приветствие, Моё/Всё), затем блоки. Пустое состояние каждого — одна строка «Нет …», блок не прячем только если он главный для роли.
- **user (кладовщик/снабженец)**: 1) Поставки: ждут приёмки/просрочены (delivery); 2) «Мои задания в работе» (work-tasks, assigneeId=я); 3) Выдать/отгрузить (shipment, zone); 4) Договоры поставщиков: истекают ≤14 дн.; 5) кнопки быстрых действий.
- **manager (менеджер/мастер)**: 1) Срочно: просрочено; 2) «В работе»: просроченные и без исполнителя; 3) Вопросы проектирования без ответа; 4) Отгрузки сегодня/неделя; 5) Паспорта к выдаче.
- **accountant**: 1) К оплате (payment); 2) «Требуют заполнения — счета»; 3) Деньги 14 дн. (плитка); 4) Не сопоставлено позиций.
- **director**: 1) Просрочено (всё); 2) «В работе» сводка по колонкам + просрочка; 3) Отгрузки на неделю; 4) Вопросы без ответа; 5) Деньги. Режим по умолчанию «Всё» (уже так: zs.management).
- **admin**: как director + диск/целостность внизу; «Показатели» свёрнуты.
