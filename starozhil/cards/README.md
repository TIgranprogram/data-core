# Карточки знаний

Одна карточка — одна «полочка»: модуль, процесс или правило. ИИ читает карточку вместо кода.

## Формат

```markdown
---
id: module-fill-audit            # тип-слово: module-, process-, rule-
kind: module                     # module | process | rule
sources: [backend/src/modules/fill-audit/fill-audit.service.ts, backend/pwa/sections/fill.js]
hash: 1a2b3c4d5e6f               # ставит `node tools/starozhil/cards.mjs --stamp <файл>` — только после проверки Claude
checked: 2026-11-13
---
# Название по-русски

**Зачем:** одна-две фразы языком менеджера.
**Где:** маршруты, коллекции, экран — с путями.
**Правила:** что нельзя и почему (с файл:строка).
**Связи:** [[другая-карточка]] — что берёт и что отдаёт.
**Ловушки:** что ломается, если не знать.
```

## Правила

- Без `sources` карточка сломана (`dc check` — ошибка). Источник изменился → «устарела» → наряд пересобирает, Claude принимает.
- Только устройство и правила. Бизнес-данные (имена, суммы, контрагенты) не копировать.
- Черновик от локального ИИ — без `hash`. `hash` ставит только Claude после проверки.
- Ссылки `[[…]]` — формат Obsidian: папку можно открыть в Obsidian и видеть граф.
