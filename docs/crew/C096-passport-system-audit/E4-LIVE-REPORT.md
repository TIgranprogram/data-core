## Старый issued: повтор PDF

`evidence/new-product/issued-repeat.json` и `issued-repeat-{1,2}.pdf`: два PDF по12 страниц, извлечённый текст полностью одинаков (PyMuPDF). Снимок, номер, категория и все содержательные поля API полностью совпадают до/после.

GET PDF штатно вызывает `markIssued` и меняет **pdfIssuedAt/updatedAt**. Первый диагностический запрос выявил это, проверка была остановлена; координатор явно уточнил критерий и разрешил повтор на той же QA-записи. Эти два служебных поля исключены из сравнения, даты вручную не откатывались. Поэтому данный тест нельзя описывать как «вообще без записей»: было три GET PDF суммарно с штатной отметкой скачивания, без POST/PATCH и без новых номеров.
