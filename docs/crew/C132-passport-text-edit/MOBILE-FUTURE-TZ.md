# Телефонный вариант — будущее ТЗ

Владелец 16.11.2026: «всё что касается просмотра в телефоне просто пишем ТЗ на будущее; телефонный вариант сейчас не интересен».

Статус: отложено, не блокирует компьютерный интерфейс и выпуск. Не начинать без отдельного поручения.

Будущий объём: проверить раскладку карточек на телефоне, раскрытые списки с длинными именами, основные действия, клавиатуру и фокус, перекрытие уведомлениями. Использовать общий kit и DESIGN-MOBILE; отдельный дизайн экранов не изобретать. Критерии и матрицу заполнить при возвращении к задаче.

В C132 до этого решения уже выполнены перенос подписи подтверждения, размер общих кнопок и короткое имя источника с полной подписью ниже. Их не откатываем; новых мобильных доработок не добавляем.
