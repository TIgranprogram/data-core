## Границы доказательств

Координатор исправил текстовый P2: пустой журнал теперь говорит «После запуска здесь появится журнал выполнения», без ссылки на неправильное имя кнопки. Раскладка и поведение не менялись.

Реальная работа длительного тестировщика, содержимое его отчёта, перезапуск процесса пульта и интеграция с реальными журналами не проверялись этим визуальным прогоном. Axe, численный контраст и pixel-diff не запускались; принятых pixel-эталонов этого потока нет. Проверка основана на действиях браузера, измерении горизонтального переполнения и трёх открытых снимках, не на одном чтении кода.
