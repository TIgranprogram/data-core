## Как заполнять

1. Открыть изделие → Паспорт → шаблон → Упрощённый.
2. В «Подготовке паспорта» выбрать тип и вид изделия, затем известные критерии. Выбор сохраняется у изделия.
3. Назначение предлагается из применимой ветки справочника. Краткое описание берётся из готовой ветки или собирается по выбранным частям. Собственную формулировку вводят отдельным действием.
4. Проверить рисунки, размеры, массу и действительно нужные сведения эксплуатации/монтажа. Неизвестные безопасные характеристики система не выдумывает.
5. Посмотреть образец без номера. Выпуск экземпляра с номером — отдельное действие.

Общий вид из паспортных рисунков виден в карточке, когда собственного главного фото нет. «Сделать обложкой изделия» явно принимает его в собственные фотографии. Уже выбранная обложка не заменяется автоматически.
