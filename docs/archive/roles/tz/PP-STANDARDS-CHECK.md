# Сверка нормативов паспортов (аналитик, 2026-10-25)

Что это: предложение по справочнику «Нормативы» (`passportStandards`). Статус в данных подтверждает менеджер. Прежняя сверка — `docs/PASSPORTS-V2.md` §2.

**Честная оговорка.** Официальные базы (fgis.gost.ru, docs.cntd.ru, protect.gost.ru, rst.gov.ru) через поиск мне недоступны, часть страниц не открылась. Статусы взяты из каталогов-зеркал (stroyinf, meganorm, gostinfo, normacs) — они показывают «действует/заменён» по данным Росстандарта, но это не сам реестр. Перед выпуском паспорта менеджеру: открыть карточку в [ФГИС «Росстандарт»](https://fgis.gost.ru) и поставить дату проверки. Где подтверждения нет — «не нашёл, оставить проверить».

## Ответы на отдельные вопросы

**1. ГОСТ Р 57538 для DSP (турник, брусья, скамья для пресса) — неправильно.**
Область применения 57538: «стационарные уличные тренажёры свободного доступа, для пользователей ростом не менее 1400 мм». Не распространяется на: оборудование детских игровых площадок, **универсальное спортивное оборудование свободного доступа**, тренажёры с электроприводом, установки с свободно перемещающимися грузами ([meganorm](https://meganorm.ru/Index2/1/4293744/4293744774.htm)). Турник, брусья, скамья для пресса — спортивное оборудование, а не тренажёр с нагрузкой, и **детское** (DSP) оно попадает под другое:
- DSP (детская спортплощадка) — **ГОСТ Р 55677–2013** (конструкция, общие), **ГОСТ Р 55678–2013** (спортивно-развивающее: турники, брусья, лестницы), **ГОСТ Р 55679–2013** (эксплуатация, ТО). Предлагаю: у DSP убрать 57538, оставить 55677 + 55678 + 55679 (+ 34615 для покрытия).
- Для взрослого/подросткового «универсального спортивного оборудования свободного доступа» (воркаут WRK, турники и брусья для взрослых) в нормативе 57538 прямо названо **ГОСТ Р 56440–2015** («Оборудование спортивное универсальное свободного доступа. Требования безопасности и методы испытаний»; действует, введён 01.07.2016, основа EN 15312-2, для детей старше 3 лет и подростков — [meganorm](https://meganorm.ru/mega_doc/norm/gost-r_gosudarstvennyj-standart/15/gost_r_56440-2015_natsionalnyy_standart_rossiyskoy.html), [legalacts](https://legalacts.ru/doc/prikaz-rosstandarta-ot-15062015-n-658-st-ob-utverzhdenii-natsionalnogo/)) и **ГОСТ Р 56446–2015** (гимнастическое оборудование; название и статус **не проверял**). Предложение: **добавить ГОСТ Р 56440–2015 в справочник** для WRK (и DSP по решению менеджера). Это новая запись — менеджер решает.
- Что именно относить к DSP, а что к WRK, — решает менеджер/производство (что значит «воркаут» у вас в каталоге). Я не нашёл определений в данных.

**2. 55677–55679 — «проверить»**: подтверждение «действует» есть у 55677 и 55678 (stroyinf), у 55679 — косвенное; отмен и замен нигде не найдено.

**3. ТР ЕАЭС 042/2017**: ссылаться только для ДИО. Для тренажёров/спорта регламент не указан; не нашёл прямого исключения — оставить как есть, вопрос менеджеру (нужна ли декларация ЕАС на спортивное).

**4. Числа по умолчанию категорий**
- **Рост ≥ 1400 мм у тренажёров (TRN)** — нормативная основа есть: это область применения ГОСТ Р 57538 (пользователи ростом не менее 1400 мм).
- **Вес до 120 кг, срок службы 10/5 лет, гарантия 12 мес.** — в открытом описании ГОСТ Р 57538 я их **не нашёл** (страница meganorm срок службы и гарантию не указывает; полный текст не читал). Пометить как **значения изготовителя**, не как требование ГОСТ; в паспорте не писать «по ГОСТ». Единственное, что стоит проверить по полному тексту, — предельная нагрузка (если в ГОСТ есть расчётная масса пользователя). Гарантийный срок вообще устанавливает изготовитель (ГК РФ / закон «О защите прав потребителей»), срок службы — изготовитель (ст. 5 закона о защите прав потребителей для товаров длительного пользования).
- Возрастные/ростовые значения для DIO и DSP: по ТР и ГОСТ они зависят от конкретного элемента — в категории не задавать как «норму».

## Рекомендуемая привязка нормативов к категориям (для справочника категорий, поле «Нормативы»)

- DIO: ТР ЕАЭС 042/2017, 34614.1, 34614.5-2024 (если карусель), 34615, Р 52301.
- DSP: 55677, 55678, 55679, 34615.
- TRN: Р 57538.
- WRK: Р 56440-2015 (новая запись, решение менеджера), 55679 — по решению.
- BLG: ничего из этого списка не подходит прямо (не нашёл нормативов для благоустройства) — оставить только общие.
- Все: Р 2.610, Р 2.601, 15150, 26653, 9.014, 883н, СП 70, СП 325 (12.3.009 — после проверки).

## Что делать менеджеру

1. Поправить `name`/`title` по столбцу «Станет» (особенно 55677, 55679, 52301, 34615, 34614.1).
2. Статусы «проверить» → «действует» у 34614.1, 34615, 55677, 55678, 2.601, 15150, 26653, 70, 325; 55679 и 9.014 и 12.3.009 — сначала проверить в ФГИС.
3. 55674 — оставить «не применять», в title указать «заменён ГОСТ Р 55674–2024».
4. Убрать 57538 у категории DSP; решить про ГОСТ Р 56440–2015.
5. Дату «проверено» ставить только после открытия карточки в ФГИС.
