# C227 — сверка документов в Пульте

- [x] Спорное поле видно сразу. Значение Пульта слева, текст из PDF справа в той же строке. В браузере проверен пример с итогом 101 и напечатанным 100,00. Если цитата не совпала с текстом PDF, виден переход к исходной странице.
- [x] Остальные реквизиты, позиции, действия и замечания раскрываются по запросу. Проверены клавиатура, переход на страницу, возврат в отчёт и отсутствие горизонтальной прокрутки окна на ширине 1024.
- [x] «Разобрать входящие» недоступна при пустой папке без незавершённых поступлений. «Повторить проверку сомнительных» работает из отчёта с прежними файлами. В отчёте указано «Отправлено на сайт».
- [x] 137 тестов Пульта и обработчика. Браузерный сценарий на отдельном локальном HTTP-порту с учебными данными. Рабочий Пульт на :47811, тестовая копия на :3102. Пустой запрос входящих отклонён до запуска; в отчёте 12 на сверке, 0 отправлено.
