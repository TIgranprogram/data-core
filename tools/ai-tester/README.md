# ИИ-тестировщик

Локальный ИИ (LM Studio на этом компьютере) ходит по «Рабочему месту» как менеджер. Он создаёт заявки, контрагентов и расходы, открывает карточки и ищет ошибки. В конце он пишет отчёт.

**Безопасно:** он работает только на **стенде этого ПК** (копия базы, `localhost:3102`). Рабочий сайт он не трогает: программа запрещает чужие адреса. Каждая запись, которую он создаёт, начинается с **«ТЕСТ-ИИ»**. В конце он сам убирает эти записи.

## Как запустить (пульт → «ИИ-тестировщик»)

1. **«0. Установить ИИ на этом ПК»** — один раз на каждом компьютере (дом, работа). LM Studio должен быть установлен (сайт lmstudio.ai). Кнопка сама включит его сервер, подберёт модель под видеокарту, скачает и загрузит её. Окно LM Studio открывать не нужно.
2. Откройте **Docker Desktop** и дождитесь надписи «Engine running». Стенд тестировщик поднимет сам.
3. **«1. Проверить готовность тестировщика»** — все строки должны быть ✅. Строка с ❌ сразу пишет, что сделать.
4. **«2. Запустить тестировщика»** — выберите время. Первый раз — «15 минут (проба)», потом «Рабочий день».
5. Остановить раньше — **«Остановить тестировщика»**.
6. Итог — **«Отчёт тестировщика»**. Затем скажите Claude: «посмотри отчёт тестировщика».

LM Studio упал или выгрузил модель — тестировщик сам перезапустит его и продолжит.

## Если оборвётся

- **Сторож.** При первом запуске тестировщик ставит задачу в Планировщик Windows «DataCore AI tester watchdog». Она срабатывает при входе в Windows и раз в 10 минут. Тестировщик должен работать, а его нет (перезагрузка, пропал свет, сбой)? Сторож запускает его снова до назначенного времени. Отчёт дописывается, в нём строка «обрыв: продолжил сторож». Журнал сторожа — `tools/logs/ai-tester/watchdog.log`.
- **«Остановить»** — сторож больше не запускает. Срок вышел — тоже.
- После перезагрузки сторож сработает только после входа в Windows. Docker Desktop должен запускаться вместе с Windows. Пока Docker не готов, сторож пробует снова каждые 10 минут.
- **Без сна.** Пока тестировщик работает, Windows не засыпает. Настройки питания не меняются: после остановки сон снова разрешён.
- Второй запуск, пока первый работает, — отказ «Тестировщик уже работает».

## Что в отчёте

- **Ошибки сайта** находит программа, без догадок ИИ: сбой сервера, сбой страницы, отказ при сохранении, медленный ответ (больше 3 с), «undefined» на экране. Им можно верить.
- **Замечания ИИ** — то, что модели показалось неудобным или непонятным. Среди них бывают ложные: Claude проверяет их глазами.

Файлы: `tools/logs/ai-tester/<дата>/REPORT.md`, снимки экрана — `shots/`, все шаги — `steps.log`.

## Настройки

`tools/ai-tester/settings.json` создаётся при первом запуске. Файл не идёт в git.

| Поле | Что это |
|--|--|
| `baseUrl` | адрес LM Studio, по умолчанию `http://localhost:1235/v1` |
| `model` | модель; кнопка «0. Установить» ставит её по видеокарте (16 ГБ — Gemma 4 12B) |
| `stepsPerTask` | сколько шагов на одно задание (20) |
| `stand` | только `http://localhost:3102` |

Задания — список `TASKS` в `run.mjs`. Новое задание — одна строка.
