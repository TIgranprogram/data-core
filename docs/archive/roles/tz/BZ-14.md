## Что сделать
1. По каждой таблице: кто пишет / кто читает (data-core — grep по `backend/src`, kppdf — по `D:\kppdf-8.0`, если есть; никто), сколько записей, дата последней записи. Пустые и давно не меняющиеся — кандидаты в «мёртвые».

3. «Без kppdf»: какие из таблиц CRM нужны data-core (напрямую или по смыслу) — что перенести в модули data-core.
4. Отчёт → `docs/DB-AUDIT.md` (простым языком, таблицами). Вопросы пользователю — в конце `DB-AUDIT.md` (в `QUESTIONS.md` не писать — его сейчас правит аналитик).
