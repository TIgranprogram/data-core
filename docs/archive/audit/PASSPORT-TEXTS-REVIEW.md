# Тексты паспорта: проверка по нормам (2026-11-01, аналитик)

Цель: паспорт по любому изделию без претензий проверяющих. Упрощённый — только обязательное, полный — плюс необязательное.

## 4. Разделы «только полный» (предложение для `passport-variants.ts`, код не правил)

```ts
export const OPTIONAL_SECTIONS: readonly string[] = ['claims'];          // рекламации: порядок задаёт закон и договор
export const OPTIONAL_TABLES: readonly string[] = ['storage', 'faults']; // журналы хранения и неисправностей
```
Обязательны в упрощённом: general, use, mounting, service (+ moving / checks / inspections / care), repair, storage, transport, warranty, disposal, acceptance; журналы `service` и `repairs` (для DIO журнал осмотров требует ГОСТ Р 52301). Если журналы `storage`/`faults` уйдут в «полный», в ALL·Хранение п. 8 и ALL·ТО п. 11 ссылки `{tab:storage}`/`{tab:faults}` надо выводить только в полном — к архитектору.

## 5. Вопросы пользователю
1. Номер сертификата/декларации ТР ЕАЭС 042 для детских игровых — добавить поле в изделие и печатать? По умолчанию — да, поле необязательное, печать «Сведения о подтверждении соответствия», если заполнено.
2. Рекламации и журналы хранения/неисправностей — только в полном паспорте? По умолчанию — да.

## 6. Юридическая проверка 2026-11-01
Проверено: общие разделы `passport-texts.v2.json` (ЗоЗПП, ГК РФ ст. 469–477, ТР ЕАЭС 042/2017). Абсолютных обещаний («полностью безопасно», «исключает травмы») нет; условия прекращения гарантии, срок гарантии с условиями, право изготовителя менять конструкцию — уже есть.
Критичное и исправленное (ключи и структура JSON сохранены):
- ALL·general: обязанности эксплуатанта были одной фразой — расширены (осмотры, ограничения по возрасту/массе/числу, присмотр за детьми, правила пользования); добавлено: изготовитель отвечает при соблюдении паспорта, за вред от нарушения — не отвечает.
- ALL·general: срок службы — добавлено «при соблюдении условий эксплуатации и обслуживания».
- ALL·warranty: в исключения добавлено «нарушение правил эксплуатации».
- DSP·use: «рекомендуется присмотр» заменено на обязательный присмотр, ответственность — родители/сопровождающие (в DIO уже было).
Шаблоны категорий: те же правки добавлены в таблицу `scripts/passport-templates-polish.js` и применены на стенде-копии (dcnight: ALL_V2 v4, TRN v4, DIO v3, DSP v3; повторный план = 0); прод не трогали. Тесты: passport-texts, compose, blanks — 81 зелёных. Это не юридическое заключение; финальную редакцию гарантии стоит показать юристу.
