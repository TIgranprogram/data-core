# C186 — интерактивная карта сайта

Вход через «?» и `#atlas`. Владелец должен видеть, откуда приходят сведения, какое действие их использует и куда передаётся результат. Пример для приёмки — «Изделие → Состав»: входы из модулей, деталей и каталога, выходы в потребность и склад.

- Общий вид слева направо показывает ход заказа. Территории занимают устойчивые места. При приближении колесом под курсором видны разделы, затем состав раздела и отдельные действия.
- Наведение и фокус клавиатуры выделяют связанные участки. Щелчок закрепляет выбор. Слой, направление и список связей дают способ прочитать подписи и точные концы связей.
- Для рассмотрения в чате адрес сохраняет выбранный узел. Старые ссылки `#atlas?n=...` открывают прежнее окно. «Путь заказа» доступен как краткий сценарий.
- В карте действующие разделы и отдельно помеченные планы. Слои различают передачу данных, порядок действий, состав и переходы по ссылкам. Источники — реестр карты и руководство. Передача включает только подтверждённые направления и условия.
- Приёмка на настольных ширинах 1024/1920/2560/3440 px. Проверить приближение к курсору, доступность управления без мыши, фиксацию, фильтры, подсветку, переход по ссылке, старую прямую ссылку и работу во всех темах. Для проверки доступов использовать разрешённую учётную запись локальной копии.

Визуальные ориентиры: [Musicmap](https://musicmap.info/) для группировки больших территорий, [Карта Средиземья](https://mapmiddleearth.com/ru) для пути внутри общей карты, [Hamilton от The Pudding](https://pudding.cool/2017/03/hamilton/) для фокусировки на выбранном сюжете.

## Пробный вид «Изделие → Состав» после отзыва владельца

Открывается по `#atlas?focus=products.sostav`. Колесо на схеме меняет подробность. В обзоре связи собраны в две группы. При приближении карточки раздвигаются, открываются три источника и два получателя, затем подписи передачи. При обратной прокрутке схема собирается. Размер надписей и центральная карточка сохраняются. Проверить переход к общей карте и кнопки для клавиатуры. Обновление общей карты в эту пробу не входит. Опорный приём — [ZUI Grasshopper](https://developer.rhino3d.com/en/guides/scripting/scripting-gh-csharp/#inputs-outputs).
