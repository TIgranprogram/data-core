# C094 — выпуск исправлений паспортов, 12.11.2026

Класс M. Область: модуль product-passport; готовые ссылки редактирования в PWA приняты отдельно в UI-REVIEW-ORDER-LINKS.md.

## Причина и исправление
- У 3905 группа «Информационные стенды и указатели», но старый признак спинки определял тип раньше группы. Конкретная группа теперь сильнее признаков; явно выбранное назначение остаётся первым. Неопределённая группа сохраняет запасной выбор по признакам. Данные изделий и выпущенные снимки не переписываются.
- Регрессия: указатель со старой спинкой предлагает только материал и назначение «Информирование», без мест и сиденья; проверены конфликты ограждений и скамей.
- Маленький рисунок: одиночный габаритный чертёж получает всю ширину области PDF; белые внешние поля обрезаются только в копии изображения для печати, оригинал сохраняется.
- Одна строка ремонта на новой странице: шесть строк журнала и заголовок удерживаются вместе, если помещаются на страницу.

## Приёмка
Полный unit/e2e — TEST-LOG; live 3905 — API стенда; сохранение и PDF на тестовой копии, снимки — UI-REVIEW-FINAL.md. Перед выпуском обязательны штатные ворота. Данные прода не исправлять автоматически.

## Границы
Старый выпущенный паспорт не получает новые картинки из шаблона. Новые тексты по назначению выбираются осознанно; исправление типа не записывает назначение за пользователя. Автоматическая обрезка не удаляет внутренние пустоты и не может убрать рамку, нарисованную в исходном изображении.
