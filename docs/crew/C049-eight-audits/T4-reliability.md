# T4 — Надёжность и ошибки

**Охват:** что видит пользователь при сбое сети/500/409 (`core/api.js`, `ui/kit/errors.js`), офлайн (`sw.js`, `write-retry.js`), глобальные фильтры (`http-exception.filter`, `version-conflict`, `multer-exception`), сбор ошибок (`core/errors.js`, модуль `client-errors`), повтор запросов и идемпотентность. Код не правил, живых проверок сети/офлайн не делал.

## Находки

## Сомнения

- Не проверял вживую: поведение при обрыве связи в момент сохранения (форма реально держит ввод после 3 минут ожидания?) и корректность восстановления из очереди `client-errors` после перезагрузки вкладки.
