# C089 — проверка автономного прототипа

12.11.2026. Прототип открывался с `file:` в headless Edge через Playwright из `tools/design-checks`. HTTP-запросы были заблокированы, данные тестовые. Проверки ниже относятся к макету.

| Проверка | Результат |
|---|---|
| Окна 390×900, 640×900, 960×900, 1600×1000, обе темы | Горизонтального выезда документа нет. Последняя секция достижима прокруткой панели. На 390 Escape закрывает панель. |
| Ширина панели | При окнах 390 / 640 / 960 панель имеет ширину 359 / 440 / 480 px и одну колонку. При 1600 проверены широкая панель 650 px с чертежом рядом с полями и узкая 428 px с одной колонкой. |
| Перетягивание мышью при окне 1600 | Проверены ширины 320, 450, 579, 580, 650 и 760 px. Компоновка переключается на 580 px. |
| Фото и клавиатура | Tab переводит фокус на видимую кнопку выбора файла. Enter открывает выбор, после загрузки кнопка сохраняет фокус и меняет подпись на «Заменить». Space открывает повторный выбор, превью обновляется. Синтетическое событие paste обновляет целевой слот. Ошибок JS нет. |
| Контраст фотослота | Основная подпись 5,34:1 в светлой теме (`#5d6964` на `#f6f7f9`), 6,25:1 в тёмной (`#8ea89c` на `#1c222d`). Подпись обязательности 5,35:1 и 7,77:1. Обводка фокуса на поверхности панели 5,06:1 и 11,32:1. Это измерения указанных пар. |
| Компоновка при уменьшенной области | 800×500, обе темы, как приближение к доступной области окна 1600×1000 при 200%. Масштаб браузера 200% отдельно не проверялся. |

На кадрах видны «Длина / Ширина / Высота», общий заголовок с единицами и отдельная кнопка выбора файла. Кнопка «Заменить» после загрузки доступна постоянно. Замена касанием, системный буфер обмена, отмена и ошибки выбора файла, открытое меню native select, длинные подписи, полный аудит контраста и единое поведение с карточкой изделия требуют отдельной проверки. Сохранение через API и выпуск паспорта к автономному прототипу не относятся.
