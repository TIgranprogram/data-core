# T8 — «Остатки»: фильтр категории показывает число, а список пустой (баг, пользователь 2026-11-08)

**Класс:** M · **Роли:** backend + frontend · **Скиллы:** verify, docs-sync, design (если меняется вид).

## Что видит пользователь
«Склад» → вкладка склада «Трубы» → слева «Категории»: «Круглая труба 37», «Профильная труба 51». Выбираешь «Круглая труба» — список пустой: «Ничего не найдено», во вкладках «Все 0», «В наличии 0»… Заголовок «Склад 0». Принцип пользователя: **фильтр показывает только то, что реально есть в списке**, числа у фильтра = число строк, которое откроется.

## Где смотреть
- Экран: `backend/pwa/sections/stock.js` — список (`query: (P) => ({ priority: 1, ...zoneQuery(), …ftIds/ftParams })` ~строка 160), вкладки-статусы (`count: resp.counts…` ~181), плитки категорий слева (`tiles.load` → `GET /stock/categories?zoneId` ~203), склад-вкладки `zoneBar()` (~20-30), `core/zone.js` (`zoneQuery`, `zoneNow`).
- Сервер: `backend/src/modules/stock/stock.controller.ts:71-75` (`categories` → `stock.categorySummary(narrowToZone(own, zoneId))`), список позиций — тот же контроллер (`GET /stock/items`), фильтры склада/зоны, `StockScoped`.
- Карта: `docs/MAP.md` строка `stock`.

## Гипотезы (проверить, не верить)
1. `categorySummary` считает номенклатуру (materials) категории, а список — позиции хранения (storageitems) выбранного склада: у «Круглой трубы» позиции есть в справочнике, но не лежат на складе «Трубы» (или лежат на другом).
2. Склад-вкладка «Трубы» и `zoneId` в списке и в сводке передаются по-разному (один с `zoneId`, другой нет / разные ключи).
3. `priority: 1` или `ft…` параметры отсекают всё.

## Что сделать
- Найти причину на тестах (юнит на `categorySummary` и фильтр списка с одинаковыми входами) — числа категории и выдача списка с той же категорией и складом **совпадают**.
- Исправить так, чтобы: счётчик категории = число строк списка при этом складе; категории с 0 строк в фильтре не показываются; вкладки-статусы считают по тому же отбору.
- Если позиции есть в справочнике, но не на складе, — это не «Ничего не найдено»: показать подсказку «В справочнике 37 позиций этой категории, на складе „Трубы“ их нет — показать все склады» (кнопка снимает выбор склада).
- Проверить и другие категории: «Профильная труба», «Листовой материал», «Метизы» — тот же принцип.
