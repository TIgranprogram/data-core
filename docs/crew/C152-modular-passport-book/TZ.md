# C152 — перенос модульного паспорта в эталонную книжку

Статус: ТЗ по поручению владельца 18.11.2026; полная реализация не начиналась. Класс L. Старую возможность C095 нельзя считать перенесённой по одному дереву состава.

## Что найдено

modules.js modulesEditor умеет до 20 строк name/dims/qty/photoId, добавление/удаление, рисунки kind=module, общий итог. Подключён к старым form.js и fill/paint.js. В новой книжке нет этого редактора; legacy-таблица показывает название/габариты/количество, но не рисунки, а ветка compositionSheet её скрывала. Сервер/PDF умеют сохранять и печатать богатые modules[].

## Немедленная защита до полного переноса (в текущем выпуске)

- [ ] Не удалять modules[] при первом выпуске. Рисунки, размеры, количества и несовпавшие строки сохраняются.
- [ ] Не скрывать богатые/несовпадающие сведения только из-за наличия BOM. Показывать их отдельным сохранённым описанием модулей.
- [ ] Подавлять только доказанное простое повторение названий и количеств без размеров/рисунков; решение фиксировать как представление, а не удалением данных.
- [ ] Старые выпущенные документы сохраняют прежнее представление; новые draft→issued не возвращают подавленный дубль и не теряют богатые сведения.

## Полный перенос — открытый чек-лист

- [ ] Аналитик/архитектор определяют связь конкретного BOM-модуля с паспортными размерами/рисунком. Сопоставление по похожему имени не считается связью.
- [ ] В книжке один понятный вход «Модули изделия»: реальные модули из состава, их количество, паспортные размеры и рисунки; без второго производственного состава.
- [ ] Добавление/удаление и редактирование доступны в эталонной книжке, с сохранением в изделие для будущих паспортов и явным переопределением экземпляра.
- [ ] Рисунок можно выбрать из файлов модуля/изделия или загрузить, заменить и убрать; файл и выпущенные снимки не удаляются.
- [ ] Для старых modules[] без физической связи — понятный безопасный режим: сохранить строку, связать с существующим модулем явно или оставить ручной.
- [ ] Изменение количества/BOM не теряет рисунки, размеры, ручные названия; расхождение объясняется до сохранения.
- [ ] Общий итог модулей, книжка, одиночный PDF и общая печать согласованы; размеры/рисунки не пропадают после выпуска.
- [ ] Проверка: пустое изделие, 2 модуля с разными рисунками/размерами, повторное открытие, старый паспорт, draft→issued, пакет, ошибка загрузки.
- [ ] Обе темы на компьютере, QA/e2e, архитектор и дизайнер с доказательствами.
- [ ] Коммит/push/выпуск и обновление карты сайта/справки/PRODUCT.
