## Задачи

### Д5 — Складские кнопки в шапке и строках

**Файл:** `backend/pwa/sections/stock.js`

Шапка (примерно строки 58–72): сейчас 4+ кнопок.
**Нужно:** оставить одну синюю «Принять на склад» (кнопка создания прихода, `+ Принять`) и одну серую «Ещё» с выпадающим меню (туда: «Бронь по списку», «Пересчёт», «⇩ Excel»).

Строки списка (примерно строки 120–130): сейчас до 3 кнопок-ссылок.
**Нужно:** ≤ 2 кнопки. Главная по состоянию позиции: если есть бронь → «Выдать»; иначе → «Забронировать». Вторая — «+ Принять» (маленькая). «Списать» убрать из строки — только из карточки.

`backend/pwa/ui/home.js` (строки 319–323): «Принять машину», «Списать», «Бронь по списку» — убрать эти три кнопки; оставить только ссылки-плитки «Склад», цифры остатков, очередь на выдачу.

### Д6 — Журнал «История» → «Настройки»

**Файл:** `backend/pwa/main.js` (меню) + `backend/pwa/sections/history.js`

«История» (`#history`) убрать из основного меню; добавить ссылку в «Настройки» (`#settings`).
`movements.js`: «Движения» оставить вкладкой в «Склад» (`#stock/movements`), если такой вкладки ещё нет — добавить.

### Д9 — Сопоставление: один экран с вкладками

**Файлы:** `backend/pwa/sections/matching-queue.js`, `salesorders-matching.js`, `salesorders-unassigned.js`

Объединить в один экран `#matching` с двумя вкладками:
- «Позиции» — содержимое `salesorders-matching.js` (текущий список несопоставленных позиций заказов)
- «Без договора» — содержимое `salesorders-unassigned.js` (заказы без договора)

`matching-queue.js` — проверить, что он делает; если это просто очередь заявок на сопоставление — можно убрать как отдельный экран, переведя содержимое в вкладку «Позиции».

В меню: одна запись «Сопоставление» (вместо двух или трёх).

### Д10 — Бронь/выдача: одна панель stockop

**Файлы:** `backend/pwa/sections/reservations.js`, `order-reservations.js`, `reservation-edit.js`, `issue.js`, `order-issue.js`

Все окна (`modal`) с формами бронирования/выдачи (> 1 поля) перевести в правую панель `of=stockop` (уже существует в `stock-ops.js`, `stock-ops-res.js`).
Строчные ссылки «изменить» / «выдать» → кнопки «Изменить» / «Выдать» (с заглавной буквы, как стандарт словаря AUDIT-UI §4).
Подтверждения (1 выбор, «Вы уверены?») — в `modal` оставить.

### Д11 — «Выпустить паспорт»: один вход

**Файлы:** `backend/pwa/sections/docs.js`, `passports.js`, `docs-orders.js`, `docs-queue.js`, блок в `products.js`

Единственный вход — кнопка в правой панели паспорта (`passports.js`).
Из карточки изделия (`products.js`) убрать кнопку «Выпустить паспорт»; заменить ссылкой «Паспорт →» (открывает список паспортов изделия, `of=passports&productId=…`).
Из карточки заказа убрать кнопку «Выпустить паспорт»; заменить ссылкой «Паспорт →» (открывает `docs-orders` отфильтрованным по заказу).
Плитку «Паспорта» на «Сегодня» оставить — она ведёт в раздел, не дублирует кнопку.

### Д12 — Импорт изделий: один пункт «Импорт»

**Файл:** `backend/pwa/sections/products.js`

В шапке списка изделий сейчас до 3 кнопок («Загрузить каталог», «Из заказов», «Из паспортов»).
**Нужно:** убрать все три из шапки. Добавить в меню «Ещё» один пункт «Импорт» с подменю или ведущий на отдельный экран `#products/import` с вкладками:
- «Из файла» — текущий `kp.js` buildImportForm (каталог Excel)
- «Из заказов» — buildFromOrdersForm
- «Из паспортов» — buildFromPassportsForm

`kp.js`: KП и импорт изделий — разные задачи. Вынести импорт-формы из `kp.js` в `products.js` (или отдельный `products-import.js`), а `kp.js` оставить только для КП.
