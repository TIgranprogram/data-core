# ТЗ C036 Ш4–Ш5 — «В заявку» галочками: склад, каталог, «Заказать у поставщика»

**Зачем:** снабженец отмечает позиции галочками и создаёт заявки одним нажатием; у поставщика — выбрал поставщика, отметил его позиции, «В заявку».

## Глубже
- **Результат:** массовый заказ в 2 касания (галочки → «В заявку» → «Создать») со склада и из каталога.
- **Сырьё:** сервер готов — `POST /api/supply/requests/bulk` (Ш3, `REPORT-SH3.md`): тело `{clientUid, items:[{materialId, qty, supplierId?}]}`, ответ `{items,total}`; поставщик и цена подставляются сервером, если `supplierId` не задан.
- **Метод профи:** одна общая функция `orderBulk(rows)` + одна правая панель; экраны только зовут её.
- **Внешний судья:** `node --input-type=module --check`, design-lint 0, `npx jest src/pwa-guards`; дизайнер.
- **Смелая планка:** 20 позиций — 3 касания, повторное нажатие «Создать» не плодит дублей (один `clientUid` на открытие панели).

**Класс:** M · **Max agents:** 1 frontend + designer · **Проверки:** smoke. **Язык менеджера:** да.
