# C220 — восстановление из корзины

- [x] Закрепить компактную кнопку восстановления в правой колонке. Подписать действие для клавиатуры и чтения с экрана.
- [x] До записи показать название и запросить подтверждение. Для защищённых записей сохранить запрос пароля.
- [x] Показать название восстановленного объекта и дать переход к нему. Возврат в корзину выполняется после подтверждения обычным удалением с проверками исходной карточки.
- [x] В истории дать прямую ссылку на восстановленную запись. Для договора открывать карточку договора.
- [x] Проверить на изолированной браузерной фикстуре отмену, восстановление и возврат с текущими правами.
