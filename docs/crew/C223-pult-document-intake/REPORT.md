# C223 — разбор документов в Пульте

## Локальная приёмка

- [x] Текстовые PDF проверяются локальной Gemma. В отчёте видны тип, назначение, исходные цитаты и причина остановки.
- [x] Счёт поставщика — в «Снабжение → Счета» по прежней серверной проверке. Договор и КП — проверенные черновики с оригиналом, реквизитами и строками.
- [x] Заказ покупателя — отдельный документ в комплекте договора. Пульт сверяет номер и дату ссылки, обе стороны и оригинал действующего договора. Сервер проверяет актуальный договор в транзакции добавления. Отмена, смена номера или даты блокируют запись. Состав договора, его суммы и производственное назначение сохраняются.
- [x] Подготовка коммерческих документов читает справочник и проверяет дубли. Запись идёт после подтверждения показанной версии. Источник и строки имеют устойчивые ключи, вложение проходит контроль версии договора. Успех требует повторного чтения карточки и сверки байтов оригинала.
- [x] ИИ и настоящий PDF: три учебных документа, три верных назначения. На первом прогоне ИИ исказил букву в цитате ИНН. Восстанавливается только единственная полная строка оригинала с теми же ролью, названием и ИНН. Для ссылки на договор учтено преобразование № при нормализации PDF.
- [x] Пульт → Nest → изолированная Mongo: один договор, одна его позиция, один заказ в комплекте. После потери ответа от сервера на каждом из двух этапов повтор не создал дублей. Счёт прошёл исходную проверку версий и восстановления с квитанцией.
- [ ] Повторить с обезличенными рабочими шаблонами. Проверить отдельно сканы, разные формулировки срока и заказы без явной ссылки. Если договор и заказ пришли вместе, сначала загрузить договор, затем повторить разбор заказа. Срок, подпись и факт оплаты требуют сверки.

## MAX

Официальный API использует токен бота из «MAX для бизнеса». Бот получает адресованные ему сообщения и вложения. Чтение истории группы через GET /messages требует прав администратора бота в этой группе. Для пилота подходит бот, которому сотрудник пересылает документы, либо выделенный рабочий чат. Подключение зависит от доступа к боту и согласованного чата. [Документация API](https://dev.max.ru/docs-api/) · [История сообщений](https://dev.max.ru/docs-api/methods/GET/messages).
