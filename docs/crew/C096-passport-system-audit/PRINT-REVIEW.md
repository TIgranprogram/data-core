# C096 Э3 — проверка книжной печати

Дата: 2026-11-12. Код и виртуальная печать: PASS. Физическая печать и исходный проблемный файл: PARTIAL.

## Исправления

- Длинный абзац делится по фактической высоте ГОСТ-шрифта. Остаток продолжается на следующей логической странице.
- Строка таблицы выше страницы делится на фрагменты. Шапка повторяется, отметки и картинки не дублируются.
- Заголовок таблицы удерживается с первой строкой. Высота шапки измеряется тем шрифтом, которым она рисуется.
- После размещения очереди рисунков повторно проверяется место. Пустой текущий лист не добавляется в раскладку.
- Техническая добивка сохранена: 0–3 пустые позиции перед гарантийным талоном. Талон остаётся задней обложкой.
- Спуск полос не менялся: алгоритм оказался корректным для подготовленного числа страниц, кратного четырём.
- Новые снимки с `sizeLayout:2` сохраняют таблицу размеров при выпуске. Старые issued без метки сохраняют прежние строки.
- Поле `layout:2` само по себе таблицу не меняет: оно давно использовалось для нумерации разделов.

Владение соблюдено: изменены `passport-pdf-v2-common.ts`, `passport-pdf-v2-layout.ts`, добавлен `passport-pdf-v2-pagination.spec.ts`.
По дополнительному согласованию координатора точечно расширен `PdfV2Text` в `passport-pdf-v2-types.ts`.
Сервисы, живые данные, деплой и коммиты не затронуты.

## Причины пустых половин

П1/П2 подтверждены устройством прежней раскладки: переносился целый блок независимо от его высоты.
Исправленные длинные примеры больше не создают страниц PDFKit сверх рассчитанной раскладки.
Это проверено сравнением фактического числа PDF-страниц с `layoutV2` в обоих режимах.
Короткий паспорт содержит 5 логических страниц: необходимы 8 позиций, из которых 3 пустые.
Такие пустые половины являются добивкой; их нельзя убрать без нарушения буклета.
Пустой оборот обложки отдельно не резервируется.
Без файла владельца нельзя установить, какая причина вызвала именно его жалобу.
