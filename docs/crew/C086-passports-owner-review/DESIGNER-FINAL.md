Минимальное решение без нового CSS: одна существующая kit `link` с подписью `Заполнить: <первое поле> →` и прежним `focusGap`; общее число пробелов остаётся в полосе. Проверить клик и фокус, обе темы и 390 после правки.
2. **Количество рисунков объяснено не везде.** Подсказка «Рисунок — один: чертёж с габаритами. На нём можно показать сразу все виды…» удачна. Добавить понятное общее правило «В каждое место — одно изображение; * — обязательное» и проверить полный режим с отдельными видами. Соответствие фактическому PDF подтверждает координатор.
3. **Открытые списки пока PARTIAL.** Нужен фактически открытый список на снимке, видимая подпись до выбора и выбранное значение после. JSON `cut:false` при снимке верха формы этого не заменяет.
