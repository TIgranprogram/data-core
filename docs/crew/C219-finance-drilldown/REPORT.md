# C219 — результат

В отчёте исходный переход суммы через смену вкладки заменён вставкой под строкой. Шеврон раскрывает дочерние статьи и операции, подчёркнутая сумма показывает операции за свой период. Нажатие суммы не меняет параметры отчёта. Вставка сворачивается повторным нажатием, кнопкой «Скрыть» или Escape. Статические итоги не реагируют на наведение.

Фильтр производственного заказа охватывает входящие договоры. Позиции отбираются по явной связи, сотрудник — по фактическим выплатам ФОТ с соответствующим доступом. Точный отбор при раскрытии «заказчик → заказ» использует исходные текстовые ключи; прежние значения вида ord:… не отправляются как ObjectId. Суммы берутся из API.

Аудит календаря. Прежняя матрица показывала пустые дни, повторяла показатели для каждой компании и разворачивала операции далеко внизу. «Платежи по дням» показывает только даты с движением и раскрывает факт на месте. Расчётный остаток появляется только при настроенном остатке на старт. Ожидаемые оплаты и оценка валютных обязательств сохранены отдельно от факта, «Прогноз» сохраняет будущие сроки, «По месяцам» — сравнение с прошлым годом.
