## Очередь и готовность

- `GET /api/showcase/:id/fill-queue` возвращает **2/9**, `scope: passport+techsheet`, три незаполненных пункта техописания. Единственный пункт с `required: true` — «Материалы». Состав изделия, вид тренажёра, группа мышц, нагрузка, исполнение и монтаж идут с `required: false`. У всех семи стоит метка срочности этой очереди.
- `GET /api/showcase/:id/passport-gaps`: для «Материалов» стоит `required: true`. Четыре признака TRN и поля минимального роста и максимального веса отмечены `required: false`, у роста и веса есть значения по умолчанию.
- `GET /api/showcase/:id/techsheet-gaps`: `ready: false`. Обязательны материалы и покрытия. Назначение и монтаж помечены как необязательные.
- `GET /api/passports/template?category=TRN` отдаёт категорийный шаблон с разделами, таблицами, версией и спецификацией материалов. Раздельная готовность short/full через перечисленные GET не наблюдается. В живом OpenAPI `/api/passports/check` доступен только через POST. Выпуск и PDF на проде не проверялись.

## Что переиспользовать для функциональных частей TRN

| GET | Что подтверждает ответ |
|---|---|
| `/api/dicts/passportParts?search=Каркас` | Точное наименование «Каркас» уже есть. Поля записи включают `name`, `categories`, `genSingular`, `genPlural`. У найденной записи ограничение по категории пустое. Запросы «Рукоят» и «Педал» дали ноль совпадений. |
| `/api/dicts/passportElements?search=Рукоят` | Поиск находит пять записей с `kind: product`. Четыре из категории `TRN`, включая «Кардиотренажёр». В структуре есть `kind`, `categories`, `inDescription`, `inspect`, `usageRules`. Отдельной записи-части в этой выдаче нет. |
| `/api/dicts/passportKinds?search=Тренаж` | Шесть совпадений, среди них «Кардиотренажёр» и «Комплексный тренажёр» для `TRN`. Вид связывает категорию, элементы и конечную фразу назначения через `passportCategory`, `elementIds`, `purposeLeafId`. |
| `/api/passports/funnel?category=TRN&q=1066&productId=…` | Возвращает изделие, разделы «Назначение» и «Установка», шаги категории, группы, вида тренажёра, мышц, нагрузки и исполнения. Среди профильных шагов активна «Нагрузка» с двумя вариантами. |

| `/api/dicts/passportPhrases?search=Ноги` | Один текст назначения `TRN`. В записи есть `section`, `parentId`, `text`, `facetValueIds`, `groupIds`, `installTypeId`, `isDefault`. |

Из этой выборки подтверждены словарь названий частей, типы элементов, типизация тренажёров и два готовых текста изделия. Готовая раскладка функциональных частей «Хипса» и отдельный каталог типовых описаний этих частей в проверенных ответах не установлены.
