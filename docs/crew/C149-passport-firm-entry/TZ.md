# C149 — срочно: выбор фирмы перед открытием новой книжки

Класс M. Владелец 18.11.2026 требует исправить и выпустить отдельно от C148.

## Scope

Общий вход backend/pwa/sections/passports/open-book.js и новый локальный helper создания черновика; funnel/index.js — повтор входа без закрытия панели. Существующие common.js firmFor/ourCompanies/rememberFirm и kit modal/select использовать, не переписывать. API и серверную проверку фирмы не менять. C148 код не входит в выпуск.

## Причина

Нет паспорта → POST без фирмы → сервер требует выбор при нескольких наших фирмах. Общий вход перехватывает ошибку и возвращает null; воронка показывает тупик без выбора фирмы.

Дополнительный scope: book-editor.js показывает окно только после загрузки фирм и повторной проверки актуальности. Ранее крестик появлялся до окончания асинхронного открытия, что позволяло закрыть окно до возврата в воронку.

## Решение и приёмка

- [x] Существующий паспорт открывается без нового выбора фирмы и без POST.
- [x] Создание сперва использует серверные правила (фирма заказа/единственная наша). Только ответ «Выберите фирму» запускает недостающий выбор.
- [x] Последняя использованная фирма предлагается в поле; при нескольких фирмах выбор подтверждается явно. Никакой случайной первой фирмы.
- [x] После подтверждения создаётся ровно один черновик, книжка открывается; фирма запоминается только после успеха.
- [x] Отмена не создаёт черновик; из воронки можно повторить без закрытия панели. Ошибка сети/сервера не скрывается выбором фирмы.
- [x] Закрытие или смена изделия во время выбора не создаёт паспорт для устаревшего контекста.
- [x] Регрессионные тесты PWA267/267, guards339/339, импорты344/0, стенд (3101 и изолированная фикстура), обе темы; финальная приёмка UI-REVIEW.md.
- [ ] Отдельный коммит/push/выпуск на реальный сервер, version/health/smoke.

## Данные и роли

Координатор — helper общего входа и тесты. Frontend — только retry состояния funnel/index.js. Access — readonly prod и проверочные записи на изолированном стенде. Designer — отчёт UI-REVIEW.md. Не менять реальные паспорта/изделия. Другие агенты сохраняют аудит C148; его код не реализуется до этого выпуска.
