# C096 — источники данных паспорта

| Данные | Источник истины | Поведение |
|--|--|--|
| Название, артикул, размеры/единицы, масса, описание, назначение, монтаж, материалы | Изделие (`products`, API `/showcase`) | Общие для следующих паспортов. Размеры переводятся в мм при подстановке; неизвестное не заполняется догадкой |
| Раздел, группа, подтверждённые признаки | Каталог и изделие | Сужают варианты и применимость. Признаки прежней группы не переносятся без подтверждения |
| Нормативная категория | Собственное `passportDefaults.passportCategory`, иначе правило группы/раздела | Каталог и нормативный профиль различны. Собственное переопределение явно; случайная похожая модель не источник |
| Выбор текстов, элементов, установки, соединений, гарантия/срок | Умолчания изделия; подходящие справочники предлагают варианты | Предложение принимается явно. Смена категории не разрешает молча стереть ручной текст |
| Рисунки модели | Файлы изделия по видам; применимые стандартные схемы | Отсутствующий файл остаётся пробелом. Чертёж другого изделия не подставляется |
| Номер паспорта, выпуск, серийные/экземплярные сведения | Экземпляр паспорта | Не становятся общими умолчаниями нового изделия |
| Заказ, покупатель, фирма | Выбранная позиция/заказ и экземпляр паспорта | Сохраняются в контексте возврата. Не переносятся в каталог |
| Текст черновика | Текущие источники плюс ручные пункты снимка | Автоматическое обновление, перенос ручного по ключам; конфликт 409 до записи/номера |
| Выданный текст | Сохранённый `textSnapshot` | Автоматически не пересобирается; изменение через явную новую редакцию |
| Дата скачивания PDF | Служебное `pdfIssuedAt` | Скачивание issued штатно обновляет её и `updatedAt`, не содержание снимка |

Похожая запись — предложение выбрать существующее изделие. Она не означает разрешение копировать его размеры, нагрузки, сертификат или рисунки. Воронка создания уже продолжает ввод через `passportFill`: спрашивает применимые сведения и записывает их в изделие. Э4 исправляет потерю состояния и повтор многошагового сохранения после полученного ID; новый универсальный редактор справочников не создаётся. Внутренние повторы HTTP используют существующий Idempotency-Key. Полный разрыв связи с неопределённым исходом первого POST и новое ручное действие после него отдельно не воспроизводились.

Проверка неизменности issued: `evidence/new-product/issued-repeat.json` — два PDF по 12 страниц, извлечённый текст одинаков, бизнес-поля и снимок не изменены. Служебные даты исключены явно. Это QA-проверка, не проверка всех исторических паспортов на проде.
