## 1. Как должно быть
| Уровень | Код | Док (одно место) |
|--|--|--|
| 1 атомы | `ui/tokens.css`, классы `.btn/.chip/.field` | DESIGN §2 |
| 2 молекулы | `ui/kit/*.js` малые (searchbox, qty-input, badges, links, mark) | DESIGN §4 (каталог) |
| 3 организмы | `ui/kit/*.js` крупные (list, card, card-tabs, entity-panel, side-form, funnel, board, planner, table) | DESIGN §4 |
| 4 шаблоны | **новое: `ui/kit/screens/*.js`** — `screenList()`, `screenCard()`, `screenQueue()`, `screenFunnel()`, `screenSummary()`, `screenDict()`, `screenSettings()` | **новый раздел DESIGN §3 «Шаблоны экранов»** (заменяет текущий §3) |
| 5 страницы | `sections/*.js` — только данные + конфиг шаблона | реестр (ниже) |

- Шаблон = функция kit с жёстким порядком блоков и слотами: `screenCard({head:{title,sub,status}, primary:{label,run}, actions:[≤3], tabs:[...], foot})`. Порядок, веса кнопок, поведение клика, правая панель для ввода — внутри шаблона; экран их выбрать не может. Корень ставит `data-k="screen-card"` и `data-tpl` — так же, как фабрики kit ставят `data-k` (site-audit A1).
- «Поменял эталон — поменялось везде» получается само: экраны не копируют разметку, а вызывают функцию. Запрет — на собственную шапку/порядок в `sections/`.
- Реестр: **`backend/pwa/sections/atlas-data.js`** — добавить поле `tpl:'card'|…` и `tplStatus:'ok'|'legacy'|'plan'` к шагам/вкладкам. Отдельный файл-реестр не заводить: атлас уже проверяется `dc check` и связан с кодом.
- Автофильтр (три слоя, без новых документов):
  1. `dc check` (статика): для каждой записи атласа с `tplStatus:'ok'` файл экрана обязан импортировать `ui/kit/screens/<tpl>.js`; новый `sections/*.js` без `tpl` — ошибка. `legacy` — список-долг, число печатается и не должно расти (храповик, как счётчик A1).
  2. `tools/site-audit.mjs` (живой обход): правило A4 — видимый экран без `[data-tpl]` на корне; в `screen-card` ровно одна `.btn-primary`; клик по строке одного объекта ведёт в одну и ту же карточку (сверка по `data-entity` + `data-id`) — ловит «дубль» заказа.
  3. Хук `.githooks/pre-commit`: правка `sections/*.js` → `dc check` части «шаблоны» (быстро, без браузера).
