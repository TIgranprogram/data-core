# ТЗ C105 — «Глубина Г» на схеме установки и в паспорте

**Что хочет пользователь:** на схеме установки есть размер «Г» — от земли до низа опоры. Его значение должно попасть в паспорт: под схемой написано «Глубина Г = … мм».

**Класс:** S · сам, без агентов.

## Что сделать

1. **Изделие хранит глубину.** Новое число в умолчаниях паспорта изделия: `foundationDepth`, мм.
2. **Паспорт берёт глубину из изделия**, как другие числа: срок службы, гарантию.
3. **PDF:** под рисунком «Схема установки опор» первая строка подписи — «Глубина Г = N мм». Нет глубины или 0 — строки нет.
4. **Анкета паспорта:** в разделе «Способ установки» есть поле «Глубина Г (от земли до низа опоры), мм». Оно необязательное и видно для любого типа паспорта.
5. **iLogic «Картинки для паспорта»:** при загрузке рисунков правило передаёт глубину вместе с габаритами. Сервер обновляет отдельное поле глубины в умолчаниях паспорта.

## Проверка

- Типы и тесты паспорта зелёные.
- Тест PDF: есть глубина — подпись под схемой «Глубина Г = 850 мм»; нет — подписи нет.
- На стенде: вписать глубину в анкету и открыть предпросмотр PDF.

## Нельзя

- Менять другие поля паспорта и общие с CRM поля изделия.
