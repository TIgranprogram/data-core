# C229 — Пульт смотрит спорные страницы PDF

- [x] При ошибке чтения добавили повторную сверку до четырёх страниц с локальной моделью. Скриншоты создаются в памяти. В черновике сохраняются страницы, отдельный ответ модели и список полей, которые подтвердились по оригиналу.
- [x] Подтверждённые реквизиты сохраняются. Визуальный ответ без доказательства по тексту остаётся отдельно, документ на ручной сверке. Ошибки справочника и маршрута сами по себе не запускают визуальную сверку.
- [x] Для счетов Пульт может запомнить шаблон строки валюты, итога или НДС. На следующем счёте того же поставщика ищет уникальную строку знакомого макета и заново проверяет значение, цитату и суммы. Шаблоны хранятся локально как данные.
- [x] Учебный сценарий показал подтверждение итога по PDF и новый итог на повторяющемся счёте без картинки. Отдельный тест проверяет отказ от неподтверждённых изменений.
- [x] Повтор на тестовой копии прошёл по 12 сомнительным. После подготовки окружения 9 PDF дали 22 изображения страниц и 9 ответов. Подтверждены НДС и валюта в двух документах, в третьем снято сомнение модели. Все 12 остались на сверке по другим причинам.
