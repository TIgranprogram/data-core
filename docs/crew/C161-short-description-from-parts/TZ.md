## Контракт до начала кода

Расширить существующий атомарный simpleDescription, не новыймодуль/справочник/эндпоинт:
- auto: `{mode:'parts',partIds:[...]}` — строка вычисляется сервером по актуальным живым passportParts, text не обязателен и не источник для auto.
- manual: прежний `{text:'...',partIds:[...]}` остаётся совместимым ручным значением. Допустим явный mode:'manual' при необходимости, но отсутствие mode всегда прежняя семантика, без миграции.
- PATCH шаблона по прежней CASпареchanges/expected, два объекта сравнивают собственное значение целиком. Пустая авто-выборка/неживойid/невалидныйmode — адресный400 без записи. Дублиidsубрать, порядок сохранить.
- source.kind дляавто `parts` (добавочное значение), partIds и готовый текст в существующей проекции. APIготовность/preview/выпуск/PDF используют одну сервернуюсборку. Olddefaults/PUT/bulk не теряют новое значение. Full/legacy поведение не меняется.
- auto.mode хранится, names/text вычисляются для новых шаблонов и новых выпусков. У выданных неизменяемые textSnapshot/renderSnapshot; читать/печататьстарый документ не пересобирать по текущим именам.
