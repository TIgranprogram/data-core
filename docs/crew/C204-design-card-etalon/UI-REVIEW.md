# C204 — проверка карточки проектирования

Локальный [D-22](http://localhost:3102/app/#design?open=6ae0c6e1169d13a2c1f36b5e), Edge, тёмная тема, окно 1920 и панель 420 px. Требования, количество и исполнитель видны целиком. Для связанной позиции производство уже запущено в W-22, хотя задача проектирования ещё открыта. Это показано рядом с действием «Завершить проектирование». Открывались обсуждение, галерея, меню и история. Живое состояние читалось, без переходов и записей.

На учебных данных, 1920/1024, проверены раскрытие исходного текста, фото, обсуждение, завершение с единственным PATCH статуса и доступ под ролью просмотра. [Средняя тема](proof/soft.png) · [тёмная тема](proof/dark.png). Дизайнер принял вид.

38 проверок модуля, 10 HTTP по задачам, 18 тестов аудита и отдельный HTTP по правам на историю. История возвращает 200 под ролью с проектированием и 403 под кладовщиком. OpenAPI обновлён, 555 маршрутов.
