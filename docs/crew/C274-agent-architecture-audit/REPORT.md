# C274 — результаты и решения

База аудита `ac33fa20`. Три независимых разбора охватили серверные модули и записи в общие коллекции, приложение и API, Git и автоматические проверки. Проверены соответствующие дельты и подтверждённые регрессии.

## Что исправлено

- **P1 · Денежные поля.** Общий список заявок скрывает `invoiceAmount` и `invoiceNote`, карточка счёта — `lineAmount` для роли без денежных прав. HTTP-тест проверяет пять ролей, пагинацию и видимость складских данных. Адресно 17 серверных наборов и 300 тестов, отдельно 81 сценарий на одноразовой MongoDB в Docker, без рабочей базы.
- **P2 · Складские сетки.** Повтор нуля после сбоя записи отправляет пересчёт с проверкой версии на тот же ID. Конфликт остаётся виден в текущей ячейке. Новый материал с начальным нулём по-прежнему создаётся одним запросом. Убраны две настройки колонок без потребителей. Целевые 119 тестов, после удаления настроек дополнительно 4 теста, импорты PWA/admin 429/429.
  Независимая приёмка дизайнера на Chromium и изолированных ответах API прошла 22 сценария. Проверены три темы, шкала штук и метры в раскрытии, первичный ноль и повтор в состоянии конфликта. После раскрытия соседней строки подсказка оказалась за границей прокрутки. При сохранённом фокусе она теперь полностью видна в трёх темах. После успешного сохранения сетка перерисовывается и браузер снимает фокус, как при штатном успешном вводе.
- **Автоматика.** `node tools/project-guard.mjs` переиспользует проверки зон и профилей, карты, импортов, дизайна, циклов и границ, плюс юниты механизма зон. В локальной копии без хуков прошли 7 групп. staged-файл без владельца дал код 1 с именем файла, неправильный SHA примерки CI отклонён. GitHub Actions проверяет точный SHA на PR и push в `main`. Проверка отметок `--range` остаётся отдельным режимом на воротах выпуска. Настройка обязательного статуса GitHub отдельна от файла workflow.
- **Ворота выпуска и ночь.** Конфигурация сервера включает типы и юниты, дизайн проверяется на дереве выпуска. Ночной прогон фиксирует проверяемый SHA, сверяет манифесты перед использованием общих зависимостей, запускает тестовый код из нужной копии. Рабочий сайт и текущий Docker-контур не менялись.
- **Локальная уборка.** Удалены 14 960 213 байт воспроизводимой сборки старого клона и кэша ночной копии, плюс два пустых журнала. Выпускной клон оставлен, в нём уникальный stash `cc22126d` c 43 изменёнными путями. Сохранены данные, ссылки на общие зависимости и журналы проверок. В `.git/objects/pack` остались четыре временных pack-файла. Для ранее созданных трёх Git-файлов прежняя попытка принудительного удаления была отклонена автоматической проверкой. Происхождение четвёртого не подтверждено.

## Журнал ошибок по версии · 27.11.2026

На базе `2294a0f9` два новых адресных теста воспроизвели общий счётчик вместо отбора версии и приём неверного фильтра. В первой правке глобальный Nest ValidationPipe преобразовал повторный query-параметр в строку. Получение исходного значения как `unknown` позволило отличить строку от массива и вернуть 400. Итоговый адресный прогон на MongoDB 4.4.30 rs0 прошёл 9 из 9. Журналы в `tools/logs/c274-client-errors` и `full-e2e/targeted.json`.

Отбор теперь выполняется до группировки. Существующие клиенты делают общий запрос с прежним результатом `{items}`. Пульт и `doctor` требуют подтверждения версии в фильтрованном ответе. Архитектор выявил два края ложного нуля. Длинная hex-строка может быть замаскирована ещё при записи, а первые 100 групп могут состоять только из шума. Автоматическая проверка использует короткий SHA и отмечает заполненный шумовой топ. Все пять сценариев скриптов прошли на фикстурах. Изолированный экспорт OpenAPI изменил только `GET /api/client-errors/top` из 578 путей. [ТЗ и критерии](HYBRID-AGENTS-TZ.md#проверка-ошибок-конкретного-выпуска).

`doctor` передаёт обе выборки через stdin. Фикстура со 100 группами и стеками по 4 КБ подтвердила обработку большого ответа и предупреждение о неполной выборке. `run-all` подтвердил TypeScript, 4 338 модульных тестов и 126 тестов инструментов.

Независимый полный E2E прошёл 116 наборов и 965 тестов без пропусков. Сверены все пути манифеста и 2059 файлов актуального снимка с индексом Git. Итог и машиночитаемые доказательства лежат локально в `tools/logs/c274-client-errors/full-e2e`.
