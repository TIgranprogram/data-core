# C218 — личный рабочий стол

Первый экран для локальной приёмки. Пункт «Рабочий стол» рядом с «Сегодня». Пример: менеджер открывает заказ, переносит его из недавних в «В фокусе», закрепляет назначенное задание и переносит заказ в «Жду». После перезагрузки и входа с другого ПК остаются карточки и их порядок.

- [x] Провести аудит и выбрать реальные источники карточек, задач и связей.
- [x] Собрать рабочую область с тремя стопками «В фокусе», «Дальше», «Жду», правым списком «Мои задачи» по срокам и недавними слева. Вход из меню, эталоны kit: кнопка, карточка доски, пустое состояние, меню действий.
- [x] Переносить карточки из истории и задач, сортировать в стопках. Меню дублирует перенос с клавиатуры и позволяет убрать карточку со стола.
- [x] Сохранять отдельный стол пользователя на сервере, бережно применять параллельные правки. Хранить ссылки на записи и личные задачи, подробности брать из исходных карточек с действующими правами.
- [x] Проверить свежий и заполненный стол, разные роли, недоступную запись, порядок после перезагрузки, перенос и повтор, среднюю и тёмную темы. «Сегодня» продолжает работать.
