# C053 — решение и порядок: один Гант «как в kppdf-8.0, только лучше»

Основа — `AUDIT-claude.md` (2026-11-08). Второй анализ (DeepSeek) не делался: модель недоступна; решение принято по одному разбору.

## Решение
- **Паттерн:** дерево-Гант со сводными полосами и переключаемой осью (tree-grid + summary bars + resource lens) — как в kppdf-8.0.
- **Один Гант:** вкладка «Гант» в «В работе» (`#workschedule` монтируется туда). `ui/gantt.js` и `.gt-*` из `screens.css` — удалить; `PATCH /work-tasks/:id/plan` — deprecated (уже), код остаётся.
- **Берём из kppdf:** дерево и раскрытие (по умолчанию свёрнуто, запоминание), сводные полосы узлов, цвет = вид работ (7 оттенков) + легенда, масштабы День / Неделя / Месяц и «Уместить», «Сегодня» с центровкой, непрерывная лента, ресайз правого края, баннер «Без исполнителя: N».
- **Оставляем наше (лучше):** подсветка перегрузки людей, факт «Начал / Закончил», срок и просрочка, проверка вида работ при переносе, 409 по `rev`, касание на телефоне, воронка-фильтры (П-1), ввод только в правой панели.
- **Статус** — рамкой/иконкой, не заливкой (заливка = вид работ).
- **Не берём:** рейку заказов (у нас воронка), скрытие «сборка/упаковка» по названию, перетаскивание сводных полос (двигаются только листья).

## Порядок (чек-листы — `AUDIT-claude.md` §4, «Наше сверху» — §6)
1. **Э1 сервер** — фильтр планов в БД (скорость, < 300 мс на 100 планах), поля для дерева (`orderId`, `productName`, `people[].workTypeIds`), `legend` с цветом вида работ, юнит, openapi/MAP. Класс M, backend.
2. **Э2 эталон `planner`** — дерево, сводные полосы, раскрытие, цвет + легенда, масштабы, «Сегодня», ресайз, витрина `#kit`, дизайнер. Класс L, frontend.
3. **Э3 экран «В работе → Гант»** — линзы «По заказам» (заказ › позиция › часть › вид работ) и «По людям» (человек › позиция › шаг), верхняя панель, баннер «Без исполнителя», удаление `ui/gantt.js`, помощь «?». Класс L, frontend + designer.
4. **Э4 «Наше сверху»** — строка «Что горит», ромб срока, план против факта, перегрузка на свёрнутом узле, «Распределить свободных», «Список дня» на телефоне. По одному, M.

Проверка: замер 200 полос < 300 мс; глазами — свёрнутый вид, раскрытие, смена линзы, «Сегодня», 390 px, тёмная тема.
