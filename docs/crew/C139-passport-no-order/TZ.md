# C139 — Паспорт с изделия без заказа и без договора

**Класс:** M · **Кто:** Cursor · **Дата:** 2026-11-17

## Цель
Из карточки изделия выпускать паспорт **без заказа и без договора**; скачать — только выпущенный PDF, не черновик.

## Сделано в коде
1. Меню: «Скачать паспорт» только если есть выпущенный; иначе подсказка «Выпустить паспорт».
2. Вкладка «Паспорт»: кнопка «Выпустить паспорт», если списка ещё нет.
3. Воронка с `productId` без заказа: сразу `noOrder` (ПР-2); не подставлять молча единственную позицию.
4. Шаг «Для заказа»: кнопка «Без заказа» — primary.
5. Глубина Г: скрыта при анкере и если пусто (раньше в сессии).

## Как пользоваться сейчас
1. Изделие → ⋯ → **Выпустить паспорт** (или кнопка на вкладке «Паспорт»).
2. Проверить недостающее → выбрать **фирму** → **Выпустить**.
3. Откроется PDF с номером. Повторное скачивание — ⋯ → **Скачать паспорт**.

## Не трогать
Заказ/договор как вход; выпуск из заказа; серверный контракт API.
