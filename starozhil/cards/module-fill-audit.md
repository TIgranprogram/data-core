# «Требуют заполнения»

**Зачем:** одна очередь пробелов в данных: что не заполнено, зачем это нужно и куда идти. Менеджер закрывает пробелы прямо в списке.

**Где:**
- Сервер — `FillAuditService.report` (`fill-audit.service.ts`): группы — массив `defs` (ключ, раздел, поле, запрос Mongo). Маршрут `GET /fill-audit`.
- Экран — `#fill`, `backend/pwa/sections/fill.js`; `?g=<ключ>` — одна группа.
- Быстрый ввод в строке — группы с `quick` (заявки: № счёта, дата, сумма) → `PATCH /supply/requests/:id`.

**Правила:**
- Денежные группы (`money: true`) видны только с правом «Деньги» (`canSeeMoney`).
- Группы закрытых для роли разделов не показываются (`onlyOpenGroups`).
- Результат кэшируется по версиям коллекций `FILL_COLLS`. Новая коллекция в запросах группы → добавить в `FILL_COLLS`, иначе список не обновится.
- У счёта, где уже была приёмка на склад, менеджер не меняет сумму (`lockedInvoices`, то же правило, что `SupplyInvoiceService.lockReason`). Строка показывает причину вместо полей; администратор правит с причиной.

**Связи:** [[module-supply]] — заявки и счета; [[module-control]] — сводка «Требуют заполнения» в «Разборе».

**Ловушки:** паспорта в очереди — только черновики: у выпущенного поля не меняются.
