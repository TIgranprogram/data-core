# ТЗ C013 — Аудит: два сервера (Дом ↔ Sportin), автосинхрон и переключение домена

**Зачем (словами пользователя):** Два сервера, один домен. В админке — кто главный. Второй почти в реальном времени обновляется. Сбой питания — автопереключение домена на живой сервер, данные не теряются. Вручную в админке тоже можно сменить главного без потери данных. Автообновление второго сервера на Windows (Sportin) — незавершённая задача: разобрать, что есть, что осталось, реализуемо ли.

**Класс:** XL (аудит) · **Max agents:** 1 (architect — основной читатель) · **Код:** не трогать · **Проверки:** нет
