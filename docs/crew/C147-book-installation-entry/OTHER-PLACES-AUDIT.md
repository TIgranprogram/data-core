## Конкретные находки

- **P1 — быстрый второй выбор текста может потеряться.** `book-choices.js:29` пропускает сохранение при `saving=true`, а `40` перечитывает первый сохранённый вариант и перерисовывает выбор. Сценарий: выбрать А, после старта запроса выбрать Б, его таймер срабатывает до окончания А. Б не ставится в очередь. Исправить последовательной очередью или повторным сохранением последнего значения после завершения текущего запроса. Браузерный тест с задержкой ответа 1–2 с, итог Б после повторного открытия.
- **P1 — снятый способ установки старой формы не отправляется на сервер.** `form.js:45` добавляет id только если он непустой. При выборе «—» существующий id остаётся в документе и продолжает влиять на монтаж/схемы. При редактировании отправлять явную очистку, согласованную с DTO и серверной обработкой. Проверить PATCH, повторный GET и исчезновение старой схемы. Само наличие пустого пункта в select не очищает документ.
- **P2 — очистка таблицы материалов оставляет прежний автоматический текст.** `materials.js:73–75` принимает новый текст только при непустом `t`; `materials-spec.js:384` при пустой таблице выдаёт пустую строку. На экране остаётся «Изготовлено из…» от уже удалённого состава. Для автоматически собранного текста применять и пустой результат, ручной текст сохранять с явной пометкой. Проверить сохранение и повторное открытие пустой таблицы.

## Что считать корректной подстановкой

Сервер берёт монтаж из записи способа установки, затем из выбранного варианта дерева текстов; собственная правка раздела и ручной текст имеют приоритет (`product-passport/passport-v2-text.ts:104–130`). Элементы дают описание, правила и обслуживание (`136–141`). Поэтому отсутствие копирования слов в обычное поле выбора само по себе не означает ошибку: проверять итоговый раздел и источник его текста.

После выкладки пройти основной путь нового паспорта, редактирование существующего черновика, шаблон изделия и старую форму, если вход ещё доступен. Для каждого — выбор А → Б, ручная фраза → смена выбора → «Вернуть», очистка, сохранение и повторное открытие. Выпущенные снимки автоматически не пересобирать.
