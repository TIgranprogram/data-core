# Аудит фильтров «Рабочего места»

Сверено по точкам входа в `backend/pwa/main.js`, маршрутизации `core/router.js`, общему списку `ui/kit/list.js` и контроллерам разделов. Ниже описано исходное поведение в `D:/projects/data-core`. Проверка в браузере фиксируется отдельно.

## Общий вид

- Быстрый поиск доступен при закрытой панели. Кнопка «Фильтры» открывает поля слева, повторное нажатие и клавиша Esc закрывают их. В режиме наложения на узком экране доступны также «Закрыть» и подложка. При закрытии через Esc фокус возвращается на кнопку. Список и служебные элементы видны до и после выбора.
- Выбор действует сразу. «Показать», если эта кнопка присутствует, закрывает панель. Счётчик показывает выбранные дополнительные параметры. Сброс возвращает к принятым значениям раздела; отдельно проверить статус по умолчанию в «Заказах», «Проектировании», «В работе», «Заявках» и «Контрагентах».
- Параметры общих списков уже хранятся в URL, поиск использует `q`. Смена отбора обновляет текущую запись истории и начинает с первой страницы. Открытие и закрытие панели состояние URL не меняет. При очистке сохраняются представление и сортировка, если на прежнем экране они не входили в сброс. Для отдельных экранов ниже отмечено, где состояние хранилось локально.
- Верхние вкладки задают режим или рабочую очередь. Счётчики и быстрое переключение состояний остаются доступны там, где они помогают работать с очередью. Дополнительные условия выводятся в общей панели. Одно поле с тем же назначением показывается в одном месте.
- По возможности используем общие `searchBox`, `filter`, `enhanceSelect`, `stepFunnel`, `funnel`. Выбор записи внутри формы, календарный период, режим представления и меню раздела имеют самостоятельный смысл.

## Остатки и «Продукция»

**Остатки.** Начать с `#stock` → выбрать зону и категорию → раскрыть тип позиции. Затем проверить «Все позиции», поиск по названию или размеру, признаки вместе с поиском и состоянием. Адресные `categoryId`, `ft`, `q`, `status` и `all` применяются при повторном входе. Зона живёт отдельно в `core/zone.js` и задаёт доступную номенклатуру; при смене зоны категория сбрасывается. Сверить счётчики, категории с заказанными/заканчивающимися позициями и выдачу по брони. Признаки строятся по наименованиям и отбирают позиции через рассчитанные IDs либо прежние параметры запроса. Общее оформление не должно менять эти варианты. Подбор внутри «Выдать / Принять / Пересчёт» использует `stock-ops-pick.js` и остаётся частью операции.

**«Продукция».** Чистая галерея выводит стартовые плитки из `products/landing.js`. Раньше одновременно отображалась воронка с теми же корневыми категориями. В самой выдаче `ui/kit/list-rows.js` визуально объединяет карточки заголовками Раздел › Группа. Эти заголовки описывают результаты и не меняют отбор. Стартовые плитки и поля панели вместе должны давать один видимый путь по категориям в каждом состоянии. Следует сохранить поиск с закрытой панелью, текущую ветку и один способ вернуться к родительскому уровню. URL с `sec/grp/sub/series` работает в галерее и таблице; старый `groupId` преобразуется в путь. Проверить «Все изделия», поиск из чистой галереи, поиск внутри ветки, выбор серии, возврат уровнем выше, переключение таблицы и возврат из карточки. Отдельно проверить «Требует уточнения» и отсутствие фото.

## Повторяемые шаги проверки

1. По очереди открыть перечисленные экраны с применимыми правами. Проверить пустой набор и несколько совместимых условий. Выдача обновляется на месте, страница начинается с первой, панель открывается и закрывается без потери отбора.
2. Открыть карточку из отфильтрованного списка, вернуться, обновить страницу и проверить прямой URL там, где параметры входят в адрес. На экране с локальными полями отдельно проверить закрытие панели и возврат из карточки, пока экран не размонтирован.
3. Повторить Esc, крестик, клик вне панели, повторное нажатие кнопки и переход клавиатурой. Выпадающее меню внутри панели должно закрываться отдельно. После полного закрытия фокус на кнопке; результаты доступны.
4. Основные состояния на 1920, 2560 и 3440 px в обеих темах. Проверить ширину панели, длинную категорию, строку с несколькими условиями, отсутствие горизонтальной прокрутки и видимость таблицы при закрытой панели.
