# Номер финансового дополнения

Финансовое дополнение C158 окончательно имеет номер **C162**, папка C162-money-articles-structure. Первоначальный локальный номер C159 занят main-каталогом изделий; промежуточный C161 оказался одновременно занят опубликованным main C161-short-description-from-parts (0e54edef), появившимся перед нашим выпуском. Обе реализации сохраняются, финансовые ID/API/данные не меняются.

Исторические run IDs, fixture UID, имена PNG/JSON, исходные QAрезультаты и часть комментариев C159/C161 сохранены для проверяемости доказательств. В финансовом scope они относятся к C162. Это не доказательства приёмки паспортного C161. C158 сохраняет исходный номер; входящие счета — C157.
