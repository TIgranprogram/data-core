**Проверка готовности — 3215 «Экотропа 120 м.п.»:** в шаблоне паспорта изделия заданы модули (например «Прямой модуль 2 м» — 50 шт., «Поворотный модуль» — 10 шт.); новый паспорт берёт их из изделия; PDF печатает раздел «Состав изделия: модули» — по каждому названию, габариты, количество, рисунок (если есть) — и «Итого модулей: 60 шт.».

## Контракт (общий, не менять без согласования)

Модуль: `{ name: string (1–120 зн.), dims?: string (до 60 зн., «2000×1200×90 мм»), qty: целое 1–10000, photoId?: string (id фото изделия) }`. Список — 0–20 модулей.

| Где | Поле | Как пишется |
|--|--|--|
| Изделие (шаблон паспорта) | `passportDefaults.modules: Module[]` | `PUT /api/showcase/:id/passport-defaults` (PUT заменяет умолчания целиком — слать свежие + `modules`). Пустой массив — модулей нет. |
| Паспорт | `modules: Module[]` | `POST/PATCH /api/passports…` (как прочие поля паспорта). Новый паспорт без своих модулей получает их из изделия (сервер). |
| Рисунок модуля | вид рисунка `module` | загрузка как у прочих рисунков паспорта: `POST /api/photos/upload?purpose=passport`, затем привязка к изделию `POST /api/products/:id/photos {photoId, purpose:'passport', kind:'module'}`; в модуле — `photoId` этого фото. |
| Чтение | `GET /api/showcase/:id` → `passportDefaults.modules`; `GET /api/passports/:id` → `modules` | — |

Ошибки сервера — 400 с русским текстом («Модуль 2: укажите название», «Модуль 1: количество — целое от 1 до 10000», «Не больше 20 модулей»).

## Сервер и PDF (Claude)
1. `passportDefaults.modules` — проверка и запись (`showcase/passport-defaults.ts`).
2. Паспорт: схема `modules`, DTO, подстановка из изделия (`passport-from-product.ts`), копия при «новой редакции».
3. Вид рисунка `module` (`PASSPORT_IMAGE_KINDS`), в обычные слоты анкеты он не выводится.
4. PDF: раздел «Состав изделия: модули» после описания — блок на модуль (название, габариты, «Количество: N шт.», рисунок при наличии, без пустой рамки) и строка «Итого модулей: N шт.» при 2+ модулях.
5. Тесты: 1 модуль; 3 модуля (20 + 5 + 2 = 27); модуль без рисунка; паспорт без модулей не меняется; проверка ошибок ввода.
