## Как координатор теперь реагирует на «сделай всё: аудит + интерфейс + тексты + выкладка»
1. **Паспорта «наведи порядок, сделай всё»** → класс L (не XL: схемы общих коллекций не меняются): 1 основной читатель (architect) делает выжимку → backend + frontend по контракту → qa; designer — только на новый вид. Тексты-данные — отдельный M: steward, план → показать → запись. Ответ: `L | агентов 4 | … | Выложено v1.N | Глазами: форма паспорта, справочник текстов | риск: … | жду: —`.
2. **«Подписи непонятные, меню разное, дубли висят — поправь всё»** → пачка S, сам, без агентов: правки по чек-листу «язык менеджера», одна выкладка на пачку, в ответе — версия и 3–5 мест «посмотреть глазами».
3. **Уточнение на ходу («и ещё дубли по смыслу убери»)** → дописать в текущее ТЗ и отправить работающей роли одним сообщением; нового аудитора не звать; при лимите > 80 % — доделать текущий S/M, коммит, эстафета, остальное — в TASKS.
