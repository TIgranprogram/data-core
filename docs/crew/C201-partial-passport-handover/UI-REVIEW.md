# C201 — проверка частичной передачи

22.11.2026. Edge на [локальной копии заказа 20-26](http://localhost:3102/app/#docs?tab=registries&registryState=handover&search=20-26), тёмная тема, 1920 px. В «К передаче» доступен заказ с 11 готовыми из 14. У готовых есть галочки, у трёх остальных — состояние «Не выпущен». После выбора двух строк подтверждение показывает две позиции. Окно закрыто, состояние заказа осталось 0 переданных из 14.

В изолированной браузерной модели на 1920/2560, средняя тема: отправляется один выбранный идентификатор, реестр остаётся раскрытым, новая партия завершает комплект. В истории видны разные даты двух передач. Пустая вкладка «К передаче» предлагает перейти «В работе». На 1024 px в тёмной теме раскрыта старая ведомость, проверены обычный и повторный запросы печати. Дизайнер принял оба состояния. [После частичной передачи](proof/partial.png) · [история на 1024](proof/history.png).

PDF A4 отрисован из того же генератора на учебных данных. Видны готовность, одна частично переданная позиция и её дата. [Печатный лист](proof/print.png).

На отдельной MongoDB 4.4.30 прошли 4 HTTP-сценария, включая повтор/гонку, чужой договор, обновление одной редакции, прежний полный запрос и сохранение истории. 819 юнитов, TypeScript и ESLint модуля прошли. OpenAPI сверён с локальным рантаймом.
