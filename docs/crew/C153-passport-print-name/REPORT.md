# C153 — срочное исправление печати имени

Код готов. Изолированный выпуск содержит только печатный путь и его тесты.
Причина: input() безусловно подставлял incomes.title и recursively менял textSnapshot. Удалена эта подмена и мёртвый withContractName/renameDeep; улучшение читаемости рисунков boostFaint сохранено.

Проверки: tsc PASS; полный unit 349 наборов /3621 тест PASS; целевые2/6 PASS. Тест старых issued без manualText передаёт разные сохранённые имена в single и batch, не читает incomes и не создаёт новые паспорта. textSnapshot не меняется.

Реальные PDF той же исправленной цепочки уже получены на изолированном стенде в C148: два одиночных и общий24стр содержат свои имена, не названия позиций. Копии компактных логов — evidence; на стенде были также другие изменения C148, они не входят в этот срочный выпуск.

Схемы, эндпоинты, данные и интерфейс не меняются. Дизайнер не нужен: вид PDF прежний, исправляется источник имени. Названия сами в базе не переписываются. После выпуска проверить версию и реальные PDF только чтением.
