## Браузерная проверка разработки

19 ноября 2026 года. `http://localhost:3102/app/`, копия `datacore-2026-11-18_031040.tgz`. Перед входом проверены отдельная БД, внутренняя сеть и тома Docker. API и публичные метаданные режима ответили HTTP 200. Сценарий запущен под обычным менеджером через `api.sh stand BROWSER`.

- **Итог 9 PASS.** Баннер виден до и после входа в двух темах на ширинах 1024 и 1920 px. Service worker оставил API и метаданные вне Cache Storage. Карточка 1066 открылась, оригинал PNG загружен из сети. PDF выпущенного паспорта получен с HTTP 200, номер и статус сохранились, служебное поле `pdfIssuedAt` обновилось на копии. При имитации HTTP 503 браузер остался на localhost.
- Выход очистил постоянную и временную сессии, DOM и форму входа. После выхода из постоянной сессии и перезагрузки приложение осталось на форме входа. Повторный сценарий перед выходом закрыл открытую карточку клавишей Escape. [Первый прогон с таймаутом](evidence/baseline/qa-results.json)
- Страница и service worker не обращались к внешним origin. Прокси заблокировал до пересылки 55 фоновых обращений Chromium к сервисам Google. Семь запросов метаданных прошли без авторизации. Неожиданных запросов записи не было. Обновление токена во время прогона не понадобилось.
