# C076 — свой вид паспорта у каждой фирмы (П11)

**Класс:** L · **Дата:** 2026-11-11 · Исполнитель: Cursor  
**Основание:** `docs/crew/C070-passports-kp-focus/PASSPORT-FIRMS.md` п. 2; чек-лист C074 п. 3.  
**Решение владельца:** по фирме — логотип, реквизиты, фирменный цвет и **свой бланк-фон, если загружен; фона нет — печать как сейчас**. Картинки владелец загрузит сам. Вопросов не задавать: до загрузки картинок вид не меняется.

## Сделать

1. **Хранение у нашей фирмы** (образец — бланки КП `offerbackgrounds` и «Наши компании → Бланк КП»):
   - фон обложки, фон обычной страницы;
   - фирменный цвет заголовков и линий;
   - поля отступа текста от краёв фона.
2. **Экран:** «Контрагенты → Наши компании» — блок «Вид паспорта» рядом с «Бланк КП»: две картинки, цвет, предпросмотр первой страницы.
3. **Печать** (`passport-pdf.service.ts` и соседние): фон и цвет по фирме паспорта; нет фона — прежний вид; выданные паспорта не перепечатываются автоматически.
4. **Тест:** PDF для фирмы с фоном и без; размер PDF не растёт больше чем на вес картинок.

## Места

- образец КП: `offer-backgrounds.service.ts`, экран бланка в partners/наши компании;
- `passport-pdf.service.ts`, `passport-pdf-v2-cover.ts`, `passport-pdf-v2*.ts`;
- схема организации / слоты файлов; `backend/pwa` партнёры;
- тесты PDF; openapi/MAP при новых маршрутах.

## Не делать

Выкладка, прод, ИИ. Контракт API — только необязательные поля. Неясное — допущение в REPORT.
