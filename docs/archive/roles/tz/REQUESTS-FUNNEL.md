# ТЗ: Заявки — воронка с подсказкой «что дальше» (ЗВ)

Класс L · агентов ≤ 3 (designer-ревью → frontend → qa) · пожелание пользователя 28.10.2026 · сервер — только если не хватит полей.

## Цель
Менеджер открывает любой этап («Заказать», «Заказано», «Оплачено», «Получено», «Ожидает») и сразу видит: что нужно сделать, чтобы заявка ушла на следующий этап, и кнопку для этого. Как воронка продаж.

## Требования
1. **По умолчанию — доска** (колонки = этапы `STATUS_ORDER`, `backend/pwa/sections/requests.js:34`, доска уже есть — `:253`). Таблица — переключателем; выбор запоминается (prefs).
2. **Шапка колонки:** название этапа, число заявок, сумма (для денежных ролей), одна строка «что здесь делать».
3. **Карточка на доске:** название, кол-во/ед., поставщик, сумма, срок, заказ (№ заказа), **чек-лист недостающего** до следующего этапа (серым — что не заполнено) и **одна главная кнопка** следующего шага. Если не хватает данных — кнопка открывает правую панель сразу на нужных полях.
4. **Условия перехода (ворота этапов)** — одна таблица в коде, сервер проверяет то же (400 с понятным текстом):
   | Из → в | Нужно | Кнопка |
   |--|--|--|
   | Заказать → Заказано | поставщик, кол-во, ед. | «Заказал у поставщика» |
   | Заказано → Оплачено | № и дата счёта, сумма счёта; (для денежных ролей) компания-плательщик | «Счёт оплачен» |
   | Оплачено → Получено | — | «Принять» (существующий приём на склад / без склада, `:52`) |
   | любой → Ожидает / Отменено | причина (коротко) | в меню «⋯» |
5. **Открытая заявка (правая панель):** сверху полоса этапов (пройдено/текущий/дальше), блок «Следующий шаг» с полями, которых не хватает, и главной кнопкой; остальное — ниже, свёрнуто.
6. **Перетаскивание** между колонками — то же правило ворот: не хватает данных → панель с недостающими полями, а не ошибка.
7. **Пустая колонка** — подсказка одной строкой, что сюда попадает.
8. Массово: выбрать несколько в «Заказать» → «Заказал у поставщика» (один поставщик) — как сейчас пакетные действия, если они есть.
9. Язык менеджера, без служебных кодов; цвета этапов — `SUPPLY_STATUS` (`ui/badges.js`); skill `datacore-design`.
