# «Наша компания» обязательна для счёта

Дата: 2026-11-17. Решение владельца: без компании финансы («Деньги») некуда отнести.

## Было
Оплата уже требовала `payerCompanyId`. Выставление счёта — только №, дата, сумма. Поле в карточке можно было оставить пустым до отказа при «Счёт оплачен».

## Стало
- `ISSUED_GATE` + тест: добавлено «Наша компания».
- Карточка счёта: поле обязательное (*), проверка перед «Выставить» / «Счёт оплачен».
- Внесение счёта: компания нужна для любого этапа кроме «Заказано».

Выкладка вместе с правкой показа паспортов в позициях (см. UI-FIX-PRIMARY.md).
