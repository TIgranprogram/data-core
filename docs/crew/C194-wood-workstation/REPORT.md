# Деревообработка

Настольный вход — «Склад → Деревообработка», прямой адрес `#stock?view=wood`. У рабочей роли переход после входа, у администратора — пункт меню.

**Почему было пусто.** Экран передавал `held=1` и повторно отбрасывал строки с нулём. В импортированных карточках короткое имя иногда совпадает с артикулом. Теперь таблица показывает материалы назначенной зоны с любым количеством и использует полное название из карточки, если короткое содержит код. Детали PDM и сортаменты исключены на сервере. Обычные «Остатки» по-прежнему запрашивают физически положительное количество.

**Добавление.** У сотрудника с правом записи «Добавить материал» открывает правую панель. В ней выбирают категорию зоны, единицу и название, при необходимости вводят артикул, размеры и примечание. После сохранения новая строка появляется с 0. Фактическое количество меняется пересчётом в таблице. Сервер проверяет зону, категорию и одноимённые записи. Режим просмотра роли и наблюдатель видят таблицу без записи.

Семь сценариев Edge и девять проверок API на изолированной MongoDB 4.4 прошли, включая фильтр физических остатков C191, чужую и исключённую позицию, создание и дубль. Снимки — [UI-REVIEW.md](UI-REVIEW.md). Состав рабочей зоны и данные рабочего сервера в локальную проверку не входили.
