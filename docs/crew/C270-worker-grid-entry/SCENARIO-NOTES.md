# C270 — границы испытания

Стенд owned :3102, существующая копия данных. Сессия только через datacore-access и stdin, код сценария координатор проверяет перед запуском.

Настоящие GET читают копию, а профиль native pipe/sheet/director подменяется только в браузере, как в C269. Все POST/PATCH и прочие nonGET перехватываются, включая создание материала, пересчёт и клиентские ошибки. Созданная позиция/новый остаток существуют только в памяти сценария. Это проверка интерфейса и формы запроса, не повторное доказательство серверных транзакций/ACL. Схема/API не менялись.

Копия сценария C269 адаптирована под opt-in подтверждение количества: Enter не пишет, затем явное «Сохранить»; blur/Отмена/Escape без записи. Создание имитирует createOnly201/409 с zoneId и отдельный count, повтор count не должен повторно создавать материал. Проверяются контекст и тип материалов приёмки, прежняя C269 подстрока, матрица истории, цвета, одна открытая строка, клавиатура и readonly. Светлая/тёмная1440/1920, узкая1024, readonly2560. Телефон не принимается по решению владельца.

Актуальные результаты после freeze — evidence/metrics.json, снимки и tested-files.json. До прогона этот документ не является утверждением PASS.
