# C089 — оценка прототипа

Обзор ниже относится к первой версии. Три замечания устранены в автономном прототипе. Актуальные проверки и их границы описаны в [REPORT.md](REPORT.md).

**PARTIAL. Компоновку можно взять за основу. Приёмка интерфейса по текущим доказательствам отклонена.**

**Видно на трёх снимках.** На широкой панели чертёж и короткие поля помещаются рядом, поэтому под фотографией меньше пустого места. Шапка компактна, действие следующего шага выделено. На узком тёмном снимке основная область остаётся рядом с панелью, видимые элементы формы идут столбцом. Крупный план показывает подписи полей, звёздочку у обязательного рисунка и отдельную кнопку выбора файла.

**Сверено по коду.** В прототипе есть переключение компоновки по ширине панели, обработчики перетягивания, фокуса и вставки. Заявленный PASS контраста неверен: в тёмной теме текст `#8ea89c` на фоне фотослота `#f6f7f9` даёт 2,38:1 при требуемых 4,5:1. Светлая золотая рамка фокуса `#d9ab33` на белом даёт 2,14:1 при ориентире 3:1 для индикатора. «Заменить» появляется только по `:hover`, хотя план обещает также `:focus-within`. Действие должно быть видно с клавиатуры и на сенсорном экране. В макете «Ширина / Высота / Толщина», а в действующей форме «Длина / Ширина / Высота». Сохранить действующие поля и единицы. Толщина требует отдельного обоснования применимости.

**Нужно проверить в браузере перед PASS.** Промежуточные ширины при перетягивании, узкий экран с возвратом, масштаб 200%, длинные подписи, доступность последнего поля и прокрутку. В обеих темах проверить Tab, видимый фокус, реальное раскрытие списка, выбор файла, вставку и замену с клавиатуры и касанием. Одинаковое фото подтвердить в паспорте и карточке изделия с общим компонентом kit. Проверка класса обёртки и axe сами по себе этих сценариев не закрывают. Снимки показывают макет с тестовыми данными, поэтому заявления об интеграции и сохранении остаются за пределами оценки.
