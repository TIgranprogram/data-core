# МЦ-7 — завершение по поручению владельца 12.11.2026

Класс L, до трёх параллельных исполнителей плюс координатор. Рабочий стол запрещён, C088 и его worktree/стенд не трогать. Проверки — независимый headless и собственная QA-копия. Прод — только стандартная выкладка после приёмки; тестовые записи на прод запрещены.

## Контракт

Ручные passportText/techText (до 2000 знаков) из materials.passportSpec переносятся в предложение materialsSpec только через существующее «Взять из состава». Сохранение — после подтверждения. Строки: прежние materialId/sizes/partIds плюс optional passportText/techText. Разные тексты одного материала не объединять. Для покрытий сохраняется coatingIds и добавляется optional coatingTexts:[{materialId,passportText?,techText?}]; текст относится только к выбранному покрытию, несколько вариантов одного ID не теряются. Удаление покрытия удаляет его текст. Нет текста — прежнее поведение. Текст не склонять, не дописывать к нему автоматически размеры. Старый issued печатается из сохранённых значений, без чтения живого склада.

## Ответственность

Backend: common/catalog/materials-text/materials-table, showcase-materials, паспортное описание и тип DTO, серверный tech-sheet-rows, соответствующие unit/e2e. Frontend: materials-spec виджет, существующее экранное техописание и их тесты. Координатор: отдельная проверка/реализация «Недавно открытых карточек», документация, интеграция и выпуск. Доступ и QA — datacore-access; независимая визуальная приёмка — designer после реализации.

## Проверки

Разбор/вывод обоих текстов, пустой fallback, разные фразы одного материала, покрытия, копирование таблицы, отмена, повторное редактирование, смена материала, сохранность ручного снимка и старого issued. Полная цепочка через UI: заявка → счёт/приёмка → позиция со связью и ручным текстом → выдача → предложение состава → принятие → таблица материалов → паспорт → PDF. Только собственные QA-записи, уборка по ID. Оба размера 375/1920 и обе темы для изменённых экранов. Все ошибки и решения — в MC7-REPORT.md и доказательствах. Full unit/e2e + TEST-LOG до выкладки; DTO/openapi/MAP обновить по фактическому контракту.
