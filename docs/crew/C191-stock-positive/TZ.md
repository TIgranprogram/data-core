# C191 — остатки и происхождение записей

Поручение 22.11.2026. В «Остатках» пользователь видит карточки PDM с нулём, например 0000.0000.0020 и 0000.0000.1001. Артикулы — след для проверки происхождения, для фильтрации нужны признаки сущности и физического количества.

- [x] Проследить PDM → материалы/каталог → остатки. Различие физического количества, свободного остатка и брони подтверждено на изолированном складе. Происхождение артикулов из сообщения — в аудите выгрузки PDM.
- [x] Положительное физическое количество и полная бронь согласованы со списком, поиском, фильтрами и счётчиками.
- [x] Собственные PDM-детали, модули и изделия вне рабочих остатков. Покупные изделия доступны как материалы.
- [x] Приёмка, резерв, несколько полок и зон, журнал, каталог и расчёт закупки проверены в HTTP.
- [x] Нулевая покупная позиция найдена в каталоге, но не в остатках; PDM-деталь видна в «Деталях»; зарезервированный физический остаток виден; чужая зона закрыта. Синтетические HTTP и браузерные проверки прошли.

## Аудит складских фильтров (дополнение 22.11.2026)

- [x] Источник «Сечения» и обозначения самореза, заглушки и шайбы подтверждены по выгрузке PDM. Сценарий смены выборки с открытой карточкой проверен в Edge.
- [x] Профиль и размер трубы, толщина листа и структурированные характеристики метизов разделены. Наименование и код отображаются раздельно.
- [x] Синтетические проверки, снимки и границы проверки рабочих карточек описаны в [отчёте](REPORT.md) и [аудите](FACET-AUDIT.md).
