# C273 — проверка таблицы трубореза

Код в локальной копии поверх `bf9303c9`. В браузере проверены заполненные сетки, светлая тема 1440 px и тёмная 1024 px. Обычная сталь и нержавейка различимы по цвету шапки и подписи. В ячейках количество штук. Общий метраж, бронь и история открываются по сечению.

- 54 браузерных проверки и проверки модели прошли. Ввод по Enter, Tab и выходу из ячейки, Escape, целые числа, конфликт пересчёта, частичный сбой создания, совпавшие сечения, соседний остаток и права просмотра.
- Настоящий HTTP и временная MongoDB, 37 проверок. Под ролью «Труборез» браузер сохранил две трубы по 6 м как 12 м, соседний остаток подтвердился отдельно, после перезагрузки видно две штуки. Проверка выполнена на тестовых материалах.
- 4 300 модульных тестов, включая 422 проверки PWA, и 26 проверок складских маршрутов прошли. Вкладка меняет котиков на собачек при смене роли и сохраняет текущую анимацию при повторном выборе той же роли. Рабочие таблицы в режиме «Смотреть как» доступны только для чтения. TypeScript, импорты и проверка дизайн-системы прошли. Снимки первой проверки в `tools/logs/c273-ui`.
- По чтению рабочего каталога до выпуска 22 из 92 труб имеют явную марку нержавеющей стали, 70 позиций без марки остаются в нейтральной группе. У 11 позиций без длины виден учётный метраж, ввод штук недоступен. В восьми из них остаток нулевой.
- Открытый риск проекта — общий список заявок отдаёт сумму и примечание счёта через поля, которых нет в списке маскирования. По отчёту v2.69 внешняя копия и контроль восстановления требуют внимания, последнее состояние восстановления независимо не проверено.
