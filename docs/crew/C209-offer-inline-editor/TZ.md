# C209 — правка КП на листе A4

Поручение 22.11.2026. Менеджер открывает КП и редактирует дату, текст и значения таблицы на листе. В верхней полосе видны команды добавления позиции и текста. Щелчок по фото или таблице показывает ручки для мыши. Свободные тексты размещаются в потоке печатного документа и переходят на другие листы вместе с соседними блоками.

- [x] Взять координаты ячеек, фото и текста из печатного PDF. Сохранить один расчёт предпросмотра и печати.
- [x] Двойным щелчком изменить дату, цену и текст. Проверить Escape и открытие по Enter.
- [x] Добавить позицию и произвольный текст с листа, удалить текст, переместить строку, изменить размер фото и ширину таблицы мышью.
- [x] Проверить сохранение и повторное открытие. Сверить печать, работу больших КП, старые записи и защиту исходной даты.
- [x] Пройти компьютерные состояния в обеих темах на фикстуре и открыть учебное КП локально.
