# Аудит информационных классов · первая версия

Обход продуктовой карты: снабжение, склад, производство, заказы, справочники, деньги, изделия, паспорта, поиск и рабочий стол. Это карта отображения, а не перечень полей каждой коллекции.

| Класс | Вид в списке | Вид в карточке | Пример |
| -- | -- | -- | -- |
| Идентификатор, название, код | Главный текст и короткая подпись | Заголовок и сведения | Счёт, задача, изделие |
| Статус, приоритет, блокировка | Подписанная метка | Состояние рядом с заголовком, причина ограничения рядом с действием | Счёт оплачен, задача просрочена |
| Дата, срок, период | Дата с ролью, сортировка | Частый плановый срок открыт; прочие даты в сведениях | Доставка, оплата, выпуск |
| Короткое примечание и длинное описание | Краткий отрывок при наличии | Частое примечание открыто; описание читается отдельным блоком | Условия поставки, описание изделия |
| Категория, справочник, связь | Название; фильтр по набору | Выбор с поиском либо ссылка на связанную карточку | Склад, контрагент, договор |
| Количество, размер, единица, остаток | Число с единицей, сравнимые колонки | Таблица позиций или складская сетка, детали под строкой | Труба, бронь, состав |
| Деньги, валюта, налог, итог | Сумма с валютой и выравниванием | Итог и остаток, ниже платежи и детализация; по правам | Счёт, касса, ФОТ |
| Этап, исполнитель, приоритет | Таблица или колонка доски | Ближайший шаг, план и ответственный | Проектирование, производство |
| Документ, изображение, файл, версия | Название и вид файла; миниатюра где помогает | Превью и список приложений, версия и действие открытия | Паспорт, договор, чертёж |
| Событие, комментарий, уведомление | Время, автор и короткий смысл | Хронология; подробности по событию | История правок, вопрос, напоминание |
| Показатель, предупреждение, пустое значение | Показатель с единицей или явная причина | Объяснение рядом с местом действия | Поставки сегодня, отсутствует дата |
| Настройка, роль, разрешение, операция | Сводное состояние | Настройки отдельно; постоянные действия рядом с объектом | Права, параметры, отмена |

Первая гипотеза для обсуждения: открываем важное для текущего действия, показываем содержимое блока в его заголовке, а редкие детали сворачиваем. Быстрые поля счёта — эксперимент отдельной витрины и требуют решения владельца до изменения стандарта карточек.
