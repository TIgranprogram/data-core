# C054 — Покрытия и материалы по категориям

**Статус:** принято координатором 2026-11-10. Стенд (`local`) — apply. Прод — кнопка пульта `c054-parts-coatings`. 40/40 записей `passportMaterials`. Покрытия `kind=coating`: 8/8 `patch`. Материалы и записи без kind: 31 `patch`, 1 `keep`.

## Правила

1. Пустое `categories` интерфейс читает как «для всех». У покрытий пустых не оставляем.
2. Горячее цинкование, порошок, цинк+порошок, цинконаполненный грунт — металл: `TRN,WRK,BLG,DIO,DSP`.
3. Масло и пропитка — дерево: `WRK,BLG,DIO,DSP`. TRN нет (сиденье тренажёра — фанера ламинированная). WRK берётся из `seed-passport-types.js`: скамья воркаут (`COAT_OIL`), полоса (`COAT_IMPREG`). DIO/DSP — брус, ФСФ и пеньки площадок.
4. Резина металла `COAT_RUBBER` — `TRN,WRK` (ручки). Крошка `RUBBER_SURFACE` — `BLG,DIO,DSP`, это другое.
5. Грунт и ПУ-эмаль — только `BLG` (навесы, 3 паспорта). Это не порошок.
6. Порядок кодов: TRN, WRK, BLG, DIO, DSP. Опора: типы изделий и `docs/audit/AUDIT-PASSPORT-PARTS.md` §2–3.

## Спорно (решает пользователь)

- **Эмаль.** Если кроют не только навесы — дописать категории к `COAT_PRIMER_PU`.
- **DSP у дерева.** Снять с масла, пропитки, хвойных и лиственницы, если детский спорт в компании только металл.
- **Крошка.** Имя «Резиновое покрытие» не ставить в TRN,WRK: для ручек уже есть «Резиновое покрытие металла».
- **Мало свидетельств:** полиэтилен низкой плотности (BLG), HPL (BLG,DIO), трос (TRN,WRK), круг (TRN,WRK,BLG).
- **Гибриды.** `STEEL_POWDER` скрыт (`hideInNew`), категории проставлены на случай показа. Лист+порошок оставлен `BLG`.
