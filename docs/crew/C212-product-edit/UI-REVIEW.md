# C212. Карточка изделия и форма «Изменить»

22.11.2026, **PASS**. Изолированный Nest `127.0.0.1:62068`, MongoDB 4.4 `rs0`, база `datacore-test-c212-browser`. Вымышленные изделия с заполненной карточкой, без раздела и в архиве. В карточке скамьи две фотографии, профиль габаритов, строка модуля и настройки паспорта. Проверялось рабочее приложение с настоящим API. На локальной копии `:3102` отдельно открыли заполненную форму существующего изделия. Записи проверили на тестовой базе.

Версия `a705cbb6` с правками в `backend/pwa/sections/products`, `backend/pwa/ui/kit/card.js`, `backend/pwa/ui/kit/form.js`, подсказках и карте сайта.

| Сценарий | Результат |
|---|---|
| «Продукция → карточка изделия → ⋯ → Изменить» | Менеджер видит правую панель со значениями изделия. У «Короткого названия» и «Раздела» стоят звёздочки. Enter на «Сохранить» при пустом названии показывает ошибку, возвращает фокус к полю и не отправляет PATCH. При новом вводе ошибка уходит. Повтор после исправления сохраняет изделие. |
| Новый пустой раздел «Уличная мебель» | Раздел доступен в раскрытом списке. Изделие без раздела сохранено в него. Используемые разделы остались доступны, совпадающие записи показаны одной строкой. |
| Произвольное название раздела, сразу Enter на «Сохранить» | Проверка выполняется при отправке формы. Ошибка осталась у поля, фокус вернулся к нему, запрос PATCH не отправлен. После выбора «Уличная мебель» повтор сохранения прошёл. |
| Правка названия, цены и гарантии | Сохранились название, цена 7 200,50 ₽ и гарантия 24 месяца. Глубина монтажа 300 мм, габариты и строка состава сохранились. У архивного изделия остались статус, цена и старая серия, которой больше нет в справочнике. |
| Фотографии и состав | Обе миниатюры загрузились, клик открыл первоначальное изображение новой обложки. После сохранения и повторного открытия главное фото осталось первым. На вкладке «Состав и работы» видна строка «Каркас скамьи», идентификатор модуля и количество остались прежними. |
| Директор и наблюдатель | У директора форма открывается, отмена сохраняет прежние значения. Допустимая правка директором получила HTTP 200. У наблюдателя нет изменения, добавления фото и цены; прямое сохранение возвращает HTTP 403 и оставляет данные прежними. |
