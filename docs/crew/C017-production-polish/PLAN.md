# C017 — довести раздел «Производство» (оркестратор)

**Зачем:** пользователь — пройти подразделы, починить кривое аккуратно, по сопоставлению — меню и похожие; отчёт → спросить выкладку.

**Подразделы:** Заказы · Сопоставление · Проектирование · В работе (группа «Производство»).

**Ограничения:** не удалять без замены; не менять поведение без причины; деплой/коммит — после отчёта и «да».

**Порядок:**
1. Сопоставление (C016): убрать из меню; вход из заказа; похожие при «+ Изделие».
2. Заказы: точечные UX/логика (уже WIP: coverPhoto, раскладка карточки).
3. Проектирование + В работе: аудит → точечные правки.
4. Связки: заказы ↔ сопоставление ↔ design ↔ work.
5. Отчёт по каждому · вопрос про коммит/выкладку.

**Не в scope:** HA --enable, массовый рефактор API matching.
