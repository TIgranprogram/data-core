# Резервные копии: минимальное улучшение C167

Владелец 20.11.2026 поручил выполнить рекомендации без усложнения системы. Реализация относится к C167 в соседнем финансовом чате; C166 не дублирует его файлы. Основание — [аудит](BACKUP-AUDIT.md).

## Что сделать

- Сохранить действующую ротацию; не удалять копии вручную только из-за количества строк.
- Показать подтверждённые настройки хранения сервера: срок, последние копии и сохранение одной копии за день. Значения по умолчанию не выдавать за прочитанные настройки.
- Подписать размеры в таблице как объём содержимого. Пояснить, что одинаковые фото могут использовать жёсткие ссылки и сумма строк не равна занятому месту.
- Отдельно показать фактически занятое копиями место по замеру с учётом общих файлов, время замера и свободное место диска. Недоступный замер обозначать «Нет данных», не подменять суммой логических размеров.
- Если очистка отключена, явно показывать это состояние. Ошибку замера не представлять как нулевой размер.

## Приёмка

Проверить включённую и отключённую очистку, неизвестные настройки, недоступный/устаревший замер, общие файлы фото. Физический размер считать для всего набора копий без повторного учёта общих inode; GET страницы не должен запускать очистку. Проверки и снимки — в C167, выпуск согласованный с C166. Новую платформу бэкапов и дополнительные расписания в эту правку не добавлять.
