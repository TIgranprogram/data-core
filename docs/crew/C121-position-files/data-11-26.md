# Заказ 11-26 — почему «Частично отгружен», а отгружено 0 из 12

## Причина

Этап «Частично отгружен» — это **ручная запись поля `stage` заказа**, а не расчёт по отгрузкам.
- Отгрузок нет: `shipmentCount: 0`, `GET …/shipments` → пусто, `legacyShipped: false`.
- Движений склада «отгрузка изделий» нет. Есть 3 движения «Выдано» 2026-11-02 (болт M10, гайка M10, шайба M10) — это выдача материалов, к отгрузке не относится.
- «Отгружено» по позиции считает `remaining()` (`backend/src/common/text/shipment-calc.ts`) из документов отгрузки (`salesorders.service.ts:206`, `shipments.service.ts:53`). У позиций (`incomes`) отдельного поля `shipped` нет — в ответе API оно вычисляется, значение 0 везде.
- Этап меняется сам только при отгрузке (`shipments.service.ts:97`). Без отгрузок `stageAfterShipments` вернул бы «Готов к отгрузке», а не «Частично».
- Вручную вперёд этап ставить можно (`salesorders.service.ts:421-430` — назад только админ с причиной). Ставка «Частично» без отгрузки не блокируется.
