# Синхронизация документации

Правило: доки короткие, факты — проверенные. Не дублируй одно и то же в нескольких файлах — ставь ссылку.

| Что изменилось | Обновить |
|--|--|
| Добавлен/удалён модуль, маршрут, коллекция | `docs/MAP.md` (строка модуля), `docs/openapi.json` (регенерация — skill `datacore-verify` §4) |
| Поля схемы | `docs/data-model.md` (раздел сущности); `/api/meta/schema` обновится сам (из моделей). Новая служебная таблица — добавить в `META_HIDE` (`backend/admin/admin.js`), если её не нужно показывать клиентам |
| Пайплайн запроса, auth, guards, плагины, инфраструктура | `docs/ARCHITECTURE.md` |
| Команды, правила, новая ловушка, нормы тестов | `AGENTS.md` (кратко, 1 строка) |
| Подключение клиентов, формат ключей/ответов | `docs/CONNECT.md` |
| Закрыт пункт бэклога | `docs/TASKS.md`: `[x]` + «что сделано / как проверено» одной строкой |
| Найдена новая проблема, которую не чинишь сейчас | `docs/TASKS.md`: новый пункт `T<N>` с файлами и критерием готовности |
| Завершён крупный этап | `docs/HISTORY.md` (журнал) и при необходимости `ROADMAP.md` |
| Новый скрипт запуска, новая подкоманда `dc`, изменён смысл команды | `pult/catalog.mjs` (кнопка или `NOT_ON_BUTTONS`), затем `node pult/gen-docs.mjs` |
| Новый скилл/процесс | `.claude/skills/<name>/SKILL.md` + строка в `AGENTS.md` |

Мёртвые ссылки проверять так (из корня):
```bash
git grep -ohE "docs/[A-Za-z0-9_./-]+\.md" -- '*.md' | sort -u | while read p; do [ -e "$p" ] || echo "MISSING $p"; done
```
