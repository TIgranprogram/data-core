# C143 — промпт «Проверка ИИ»

**Проблема:** «Сверьте… / Карточка изделия → 1.3» — менеджер сам гадал.

**Правило:** клик в книжке + ЗАМЕНИТЬ / УДАЛИТЬ / ВПИСАТЬ. Запрет «сверьте». PDF/фото в чате → читать размеры и видимые части, сразу давать готовые тексты.

## Два уровня (не дублировать всё в один)

1. **Общий** (`aiPrompt` + кнопка «Промпт для ИИ») — весь паспорт + правила формата + коротко про фото/чертеж.
2. **Мини у раздела** (`aiFocusPrompt` + кнопка в правой панели) — части / материалы / габариты / монтаж: текущие строки, допустимые имена из справочника, «прикрепите фото». Нужен, потому что при правке общий блок ИИ скрыт (компактная колонка).

**Контрпример (отклонён):** «Карточка изделия → табл. 1 | Сверьте…» / «Похоже на стойку, уточните…».

**Файлы:** `book-shared.js` (`RULES`, `TASK`, `aiFocusPrompt`), `book-side-edit.js` (кнопки в панелях).
