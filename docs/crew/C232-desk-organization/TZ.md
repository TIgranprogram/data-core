# C232 — Стопки и личная задача на рабочем столе

## Что было

- Три фиксированные стопки, порядок карточек и личные задачи на обоих компьютерах.
- Правая вкладка «Завершённые», отметки выполнения и список подзадач.
- Название и срок личной задачи менялись из меню карточки. Связанные записи и файлы внутри неё отсутствовали.

## Сценарии приёмки

- [x] Стопку можно создать, переименовать и удалить. Если в ней есть карточки, нужно выбрать стопку назначения. Последняя стопка сохраняется.
- [x] По названию личной задачи открывается штатная правая панель. В ней видны срок, статус, связанные карточки и файлы.
- [x] Конкретную позицию и её заказ можно прикрепить из «Недавних» или по адресу карточки из приложения. Ссылки открываются с текущими правами пользователя.
- [x] Файлы прикрепляются, скачиваются и восстанавливаются внутри задачи. Максимум 20 файлов на задачу до 10 МБ каждый, включая удалённые.
- [x] Удаление задачи требует подтверждения. Вкладка «Корзина задач» возвращает задачу, ссылки и файлы. Завершённая задача возвращается в «Завершённые».
- [x] Старые стопки и задачи открываются без переноса данных. Файлы и структура стола доступны только владельцу учётной записи.

## Данные

До девяти стопок, 60 карточек вне корзины и 600 личных задач в корзине. Названия стопок редактируются для одного личного стола. При удалении стопки её карточки переносятся в выбранную пользователем стопку с сохранением их относительного порядка.

Разметка хранится в `users.privateDesk`. `GET/PUT /api/auth/me/desk` сохраняет совместимость с прежними записями и проверяет версию при записи. Без `lanes` старый клиент продолжает использовать сохранённые стопки. Ссылки хранят тип записи и её идентификатор.

Файлы записываются в приватный бакет GridFS `private_desk`. Путь `/api/auth/me/desk/tasks/:taskId/files` обслуживает список и загрузку. `/:fileId` скачивает или помечает удаление, `/:fileId/restore` возвращает файл. Доступ проверяется по идентификатору из сессии и по принадлежности активной личной задачи. Сохранение раскладки и загрузка выполняются отдельными запросами. После завершения файловой записи появляется строка в списке. При удалении личной задачи её файлы остаются в приватном бакете и снова доступны после восстановления.
