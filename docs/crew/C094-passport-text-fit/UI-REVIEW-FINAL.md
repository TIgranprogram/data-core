# C094 — тип указателя и раскладка PDF

12.11.2026, заполненная одноразовая копия на `http://localhost:3102`, обновлённый backend поверх `6099b322`. Проверены только шаблон 3905 и затронутые листы PDF.

## Шаблон указателя — PASS

Живой API для 3905 вернул тип `other` из группы каталога и исключил признаки мест и сидений. В браузере «Арт объект Деревянные указатели · 3905» показывает **«Прочее благоустройство»**. Поля мест или сидений отсутствуют. Ширины 390 и 1920 px, обе темы. Матрица 4/4, горизонтальное переполнение панели 0 px, ошибок JavaScript нет.

Открыты четыре снимка: [390 светлая](evidence/ui-final-template/template-light-390.png), [390 тёмная](evidence/ui-final-template/template-dark-390.png), [1920 светлая](evidence/ui-final-template/template-light-1920.png), [1920 тёмная](evidence/ui-final-template/template-dark-1920.png). [Измерения](evidence/ui-final-template/results.json). Браузерный сценарий read-only в incognito, только GET/HEAD/OPTIONS к стенду, токен в памяти.

## Сохранение и PDF — PASS

Через штатный API тестовой копии сохранён один черновик указателя 3905. Повторный GET подтвердил статус `draft` и прикреплённый рисунок `dimensions`. Номер не выдавался. На копии не было рабочего чертежа 3905, поэтому к QA-черновику добавлен явно подписанный тестовый рисунок с белыми полями, рамкой и четырьмя угловыми метками. На проде записи и выпуск не выполнялись.

| Проверка | Файл А5 | Буклет А4 |
|---|---|---|
| PDF открывается | 12 физических страниц, 419,53 × 595,28 pt | 6 физических страниц, 841,89 × 595,28 pt |
| Журнал ремонтов | Стр. 9: шапка и шесть строк вместе | Лист 4: шапка и шесть строк вместе |
| Одиночный чертёж | Стр. 11, ширина 357,53 pt, 85,2% страницы | Лист 2, ширина 357,53 pt, 84,9% половины листа |
| Обрезка | Из 1600 × 1100 px осталось 841 × 501 px по внешней рамке. Все метки и подписи видны | Та же рамка и метки, подпись видна |

На всём документе не найдено текстовых блоков с границами за пределами листа. На четырёх целевых рендерах рамка, надписи и таблицы видны целиком. Подпись к одиночному рисунку остаётся внизу отведённого места, поэтому на вытянутом рисунке между ней и самим чертежом есть заметный промежуток. Это не мешает прочитать единственный рисунок и подпись.

Рендеры: [А5 — журнал](evidence/ui-final-pdf/pages/repairs-page-9.png), [А5 — чертёж](evidence/ui-final-pdf/pages/dimensions-page-11.png), [А4 — журнал](evidence/ui-final-pdf/print/repairs-page-4.png), [А4 — чертёж](evidence/ui-final-pdf/print/dimensions-page-2.png). Метрики [А5](evidence/ui-final-pdf/pages/results.json) и [А4](evidence/ui-final-pdf/print/results.json).

Первая попытка передать тестовый PNG через multipart завершилась `curl 26` до записи. После преобразования пути для MSYS загрузка и повторный GET прошли. Первый сохранённый PDF без тестового рисунка также подтвердил шесть строк журнала на одной странице. Подтверждён рендер в двух форматах и сохранение черновика на копии. Выпуск паспорта не проверялся. По отдельной живой сверке агента доступа, 24 общих условия уже применены. Нейтральные формулировки `INFO_STAND` и привязка назначения «Информирование» проверяются отдельно от этой приёмки раскладки.
