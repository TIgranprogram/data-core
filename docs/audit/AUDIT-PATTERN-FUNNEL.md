## Наброски для топ-3

**1. Позиция заказа.** Тип → Группа → признаки → Изделие (переиспользовать `funnel/product-list` C028, с числами, пропуск очевидного) → вариант изделия, если есть → само: название (`orderName`), единица, цена, заказчик и № договора из заказа (помечено «подставлено») → спрашиваем только количество и срок. Память: цена и вариант — в позицию; «название в договоре» — в `products.orderName`. Кнопка «Добавить позицию».

**2. Заявка снабжения.** Категория склада (плитки с числом и остатком) → позиция (поиск + «Заказывали уже» сверху, остаток и «в пути» рядом; нет — «Завести новую позицию», C022) → само: единица, артикул, цвет, ссылка, категория → спрашиваем: количество, приоритет, «под заказ» (заказчик подставится) → поставщик: «Похоже: последний — X — верно?». Поля счёта — под «Подробнее». Кнопка «Подать заявку».

**3. Новый заказ / договор.** Заказчик (с числом прошлых заказов) → подставлено из прошлых заказов: наша компания, форма оплаты, приоритет («Похоже: … — верно?») → № заказа: «существующий / новый» двумя кнопками → спрашиваем: № договора, предмет, сроки. Память: обычные компания и форма оплаты — в заказчика (новое поле data-core, не общая с CRM схема без архитектора). Кнопка «Создать заказ».

## Где паттерн НЕ нужен
«Куда пошло» и «Объект СМР» в заявке (3 варианта); приоритет, статус, форма оплаты (≤ 7); маршрут работ (подсказка уже есть); тип позиции (3 варианта); печать, просмотр, таблицы; свободный текст; реквизиты контрагента (ввод один раз); договор поставщика (6 полей); справочники, сотрудники, настройки; мобильная выдача (уже эталон шагов).
