# Взять задание

Аргумент — код задания (например C058). Открой `docs/crew/<код>-*/TZ.md`, выполни его по шагам, отчёт — в `REPORT.md` той же папки, статус — строкой на `docs/crew/BOARD.md`. Запись на прод/VM/Sportin — только по явному «да» пользователя. В конце: `tools/dc.cmd check`, коммит своих файлов с метками (CLAUDE.md), пуш.
