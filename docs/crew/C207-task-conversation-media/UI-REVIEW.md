# C207. Обсуждение и фото в карточках заданий

Проверка выполнена на рабочем дереве `main` с правками C207. Браузерная фикстура открывает штатные маршруты `#design?open=…` и `#work?open=…` на `http://127.0.0.1:41736/app/`. Данные D-22 и W-11 синтетические. Проверка сохранения идёт отдельно через API и изолированный MongoDB 4.4.

Нажатие «Отправить» с пустым сообщением оставляет поле доступным и обходится без запроса. Файлы в сообщении отображаются через `photoStrip`, отдельные фото задачи — через `taskPhotos`, оба используют `openZoom`. Кнопка «Закрыть фото» и Esc проверены действиями. Снимки открыты и просмотрены.

Решение по старому флагу «Вопрос менеджеру». Флаг создавал запись «Без ответа» в общих списках, адресат отсутствовал. В стандартном сценарии используется обычное сообщение. Ранее открытые вопросы, ответы и прежний API сохранены.

Проверки C207. Playwright — 2 сценария. Проверки карточек на Node — 19 тестов. Jest по проектированию и правилам PWA — 430 тестов. API e2e по C207 и существующему проектированию — 12 тестов, в том числе запрет записи наблюдателем, запрет удаления сообщения через другое задание и повтор загрузки без лишнего события. Typecheck, импорты PWA и точечный ESLint прошли.

Итог проверки интерфейса **PASS**. На локальной копии открыты фактические D-22 и W-11. В D-22 оставлено одно настоящее сообщение, открытие и закрытие фото проверены. В W-11 обсуждение пока пусто. Сохранение и права проверены на фикстурах и изолированной базе.
