# C269 — проверка стенда

Стенд: owned :3102, существующая копия. Запущены только существующие owned-контейнеры после старта Docker, без восстановления/переноса БД.
Сессия manager от агента доступа только stdin. Настоящие GET читают копию; native/director профиль интерфейса подменён только в браузере. Все POST/PATCH (включая журнал ошибок) перехватываются и не уходят на сервер; изменения количества/примечаний хранятся только в памяти браузерного сценария. Это проверяет интерфейс и форму запроса, не повторно доказывает серверные ACL/транзакции.
Первый прогон: 93 PASS, 1 FAIL, JS0. FAIL — Enter с последней ячейки отдельного блока листов терял фокус. Начальный metrics сохранён как metrics-before-fix.json. Исправление подтверждается отдельным новым прогоном; старые изображения не служат доказательством нового кода.
Пограничные данные (разныеID с одинаковыми координатами, нестандартная/неизвестная длина, разные unit, multiple/unknown, обрезки/нули) только в GET-перехвате браузера. Настоящие данные: 91 труба, 46 листовых материалов. Проверка происходит в полном main.js/shell, включая штатный dc:changed/reload после записи.
Телефон не принимается по отдельному решению владельца; 1024/1440 — компьютерный интерфейс.
