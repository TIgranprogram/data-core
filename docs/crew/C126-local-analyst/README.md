# C126 — локальный AI как независимый аналитик

## Что проверили (2026-11-15, ноутбук)
- **Железо:** ASUS TUF A17, RTX 4060 Laptop 8 ГБ, 30 ГБ ОЗУ, Ubuntu 26.04.
- **Модель:** `qwen3-coder:30b` (MoE, ≈3 млрд активных параметров, 19 ГБ q4) в Ollama; свои правила — модель `pomoshnik` (temperature 0.7, top_p 0.8, top_k 20, контекст 32k, ответ до 2500 токенов). Скорость ≈ 22 ток/с, 97 % в видеокарте.
- **Обвязка:** чат Open WebUI + инструмент «Терминал Ubuntu» (`run_command`, `set_folder`, `set_mode`, `append_report`) + служба `ai-runner` (127.0.0.1). Подробно — память координатора, на ноутбуке `~/.config/ai/`.
- **Задания:** `TASKS.md`, команды только через `scan.sh` (только чтение), отчёт `REPORT.md`, проверка координатора `REVIEW.md`.

## Итог
- 5 задач за ≈ 6 минут, оценки 4–9 из 10 (`REVIEW.md`). Польза есть: нашлись `GET /users/:id` без ролей, 41 настройка без описания в `.env.example`, 11 модулей без описания в `docs/MAP.md`.
- Хорошо: идти по готовому скрипту, пересказывать короткие списки. Плохо: считать, отличать «нормально» от «опасно», держать длинную проверку. Числа и оценки модели — только подсказка.
- Что сработало в устройстве: точный поиск — `scan.sh`; выбор следующей задачи — `scan.sh next` (модель сама повторяла задачу 1); запись — только `append_report`; находки в чат не писать (упиралась в длину ответа); встроенные инструменты Open WebUI выключить (`builtin_tools: false`, иначе +5k токенов и вызовы несуществующего `display_file`); temperature 0.2 → зацикливание.
