# Вопросы C041 (координатор перенесёт в docs/QUESTIONS.md)

Q1. Где хранить состав «по умолчанию» (части с видами работ)? По умолчанию: новое поле `products.parts[]` (необязательное, CRM не читает), старый `workTypes[]` дублируется. Альтернатива — сразу в `composition` (рискованно: читает CRM).
Q2. «Части изделия» — новый справочник `productParts` или взять `passportParts`? По умолчанию: новый, `passportParts` не трогать (там мусор и падежи для текста). Связь с паспортом — позже.
Q3. Можно запускать в работу с непроверенным составом? По умолчанию: да, с предупреждением, не запрет. (Кто ставит «Проверено» — менеджер и админ.)
Q4. Деньги за работу: платим по ставке человека (`persons.rate`), по ставке вида работ (`worktypes.hourlyRate`) или сдельно за изделие? По умолчанию: зарплата — как сейчас через табель (ставка человека), ставка вида работ — только для себестоимости изделия. Решает только пользователь (деньги), нужно до Э3.
Q5. Норма часов — на единицу изделия или на всю позицию? По умолчанию: на единицу, время позиции = норма × количество.
Q6. Нужны ли параллельные работы (сварка стоек и покраска навеса одновременно)? По умолчанию: нет в Э1, да в Э2.

Не вопросы (допущения): нет привязки норм к отделам; уволенных/в отпуске сотрудников не предлагаем (как `work.service.ts:265`); данные прода о покрытии маршрутами нужны координатору до старта Э1 (числа: `products.workTypes`, `worktasks`, `worktypes.days/hourlyRate`).
