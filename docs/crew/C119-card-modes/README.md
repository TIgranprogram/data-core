# C119 — карточка: смотреть, правка — в «⋯»

Решение владельца 2026-11-15 (после пробы): переключатель «Ход / Состав» отклонён как лишняя сложность. Карточка — смотреть «что это и из чего состоит»; всё, что меняет объект, — в «⋯» шапки или в своей панели правки. Закон — `docs/DESIGN.md` §3.1 «Карточка — смотреть, правка — в «⋯»».

## Порядок работы
1. ✅ Закон в DESIGN.md (15.11, переписан после пробы).
2. ✅ Эталон — карточка заказа 11-26 (15.11, стенд 1700/375):
   - шапка одним блоком: № + «заказчик (ссылка) · компания» слева; справа «Срок» на линии номера, «Отгружено N из M» на линии подписи (`screenCard({ side })`);
   - без сведений, «Подробнее», «Что дальше» без кнопки и без вкладок: сразу таблица позиций (`screenCard({ body })`);
   - таблица — только чтение, тонкая рамка; цвет и описание — второй строкой; при одном договоре без строки договора; «К производству» — только если позиции сложились;
   - клик по позиции раскрывает её под строкой (`positionsTable` `expand`): «Состав · Выполнение · Вложения · Документы» колонками на всю ширину (заготовки — C121);
   - «Выполнение заказа», «Документы заказа» — свёрнутыми блоками; «⋯»: Изменить заказ, + Договор, «Договор» (деньги и правка позиций — внутри договора), PDF, вложения.
3. ⏳ Аудит по меню сверху вниз (по эталону заказа): Производство → Продукция → Склад → Снабжение → Деньги → Управление. Каждый экран: что на виду меняет объект → перенести в «⋯». Разбор заказа — [INVENTORY.md](INVENTORY.md) (часть строк о видах устарела).
4. ⏳ Автопроверка: правило `site-audit` — в таблицах карточки нет кнопок и «⋯» в строках; «Что дальше» без кнопки — находка.
