## Исправлено дизайнером
1. Цвета источника и заголовки на листе брали токены тёмной темы → тёмные плашки и серый текст на белом, не читалось (снимок 03). Лист теперь «бумага»: светлые значения токенов внутри `.bk-page` (`kit.css`), `.bk-h` — цвет `--text`.
2. Список страниц слева: подписи по центру, обрезались с обеих сторон, двойная нумерация «2. 1 Описание». Теперь по левому краю, многоточие, подсказка с полным названием, «стр. N · раздел» (`book-editor.js:341`, `kit.css .bk-toc .bk-toc-i`).

## Остаётся (не блокирует, в очередь frontend)
- В тексте видны ссылки `{tab:faults}`, `{tab:service}`, `{tab:repairs}` — в PDF они становятся «табл. N». Показывать как в PDF (только вид, правка — исходный текст).
- Лист растёт по тексту: разбиение на страницы не совпадает с PDF один к одному (раздел 5–8 на одном листе). Порядок разделов совпадает.
- В шапке только номер и статус, названия изделия нет (ТЗ п. 1).
- Неактивная «Сохранить и выпустить заново» без видимой причины рядом («сначала измените поле»).
- Сверка с самим PDF — по раскладке кода и снимкам окна; PDF рядом не открывался.
