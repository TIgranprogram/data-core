# C108 — анкета паспорта: заполнено / нужно; хвосты паспортов (2026-11-13)

Пользователь: «поля, где заполнено, немного отличить цветом, а что нужно — пометить золотой окантовкой аккуратно».

- `.k-fill-done` — спокойный зелёный фон у заполненных строк (и у выбранного шага текстов); `.k-fill-need` — золотая рамка у обязательных незаполненных.
- Окно «Новый паспорт»: тип паспорта из изделия — строка-источник, переключатель скрыт; тип у изделия не задан — выбор остаётся.
- Окно печати заказа: список паспортов в `kit.scroll` (не выше 40 % экрана).
- Данные: тексты 11 функциональных элементов (правила, ТО; у приствольной решётки и описание).
- Нормативы «Указателя» / «Информационного стенда»: подходящего ГОСТа в справочнике нет — поле пустое.
