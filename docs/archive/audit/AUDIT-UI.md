# Аудит интерфейса «Рабочее место» (2026-10-29, дизайнер, по коду)

Основа: `docs/audit/ui-inventory.md` (скрипт), DESIGN §2–§8, CANON §2. Снимков нет — где по коду не понять, стоит «проверить глазами». Код не менялся. Ссылки `файл:строка` — на 2026-10-29.

## 1. Стандарт (одно правило на каждый вид экрана)

**Образцы «где хорошо»:** список — «Заявки» (`requests.js`: вкладки статусов, подсказка под вкладками, слева воронка, кнопка шага в строке) и «Остатки»; форма — «Заявка» (блоки `fixed/collapsed`, `span`); карточка просмотра — «Задача проектирования» (`design.js topBlock`: чипы, `kv-grid`, действия, «⋯», сворачиваемое).

1. **Клик по строке везде = правая панель** (`onOpen` → `openRecord`, `list.js:434/442/506`). Исключение убрать: `fill.js:62` (строка ведёт на другую страницу). Плитки «Сегодня» ведут в разделы — допустимо (плитка не строка).
2. **Ввод и правка — только правая панель** (DESIGN §5). Окно `modal` — только «Вы уверены?» и 1–3 поля. Нарушают — см. §3 (оплата, выплата, старт учёта, прайс, приёмка заявки).
3. **Список:** заголовок + счётчик · вкладки статусов · подсказка · поиск/фильтры · таблица · пагинация. В шапке — **одна** синяя «+ Сущность» и **не больше одной** серой кнопки/меню «Ещё» (импорт, Excel, КП, «Из таблицы», «Счёт без заявок» — туда). Сейчас в шапке до 3–4 кнопок (`requests.js:254`, `products.js:308`, `stock.js:58–72`).
4. **Карточка (панель):** шапка (h2 + подпись + «⋯») → чипы-итоги → тело в зонах (§5) → внизу «Изменить» (одна) и «История». Один «⋯» на панель (сейчас два: в шапке `card.js:143` и рядом с действиями `card.js:121`).
5. **Форма:** блоки `section/tone`, обязательные `*`, ошибка под полем, «Сохранить / Отмена».
6. **Окно подтверждения:** заголовок-вопрос, что случится, кнопка = глагол (не «OK»), опасное — красная; удаление — в корзину + «Отменить» 10 с.
7. **Пустое состояние:** что это + что сделать + кнопка (`emptyText/emptyHint`). «Пусто» без подсказки быть не должно (доска проектирования — проверить глазами).
8. **Действие не уводит со страницы**; переход — только ссылкой «Все →» или пунктом меню (CANON §2 п.1).
9. **Один объект — одно место правки.** Правится в своей панели; в чужом экране — ссылка «Открыть», а не вторая форма.
10. **Кнопка на телефоне ≥ 44 px, тексты по-русски, статус — только `badge()`.**

## 5. Правая панель: раскладки и переключатель

**Сейчас** (`card.js:63–66`, `list.css:70–76`, `screens.css:18,33`): `.drawer` = шапка · `.drawer-body` (одна колонка: `.fields` 160px/1fr → `extra` → «История») · `.drawer-foot` («Изменить»). **Три раскладки.** Панель меняет ширину мышью, поэтому колонки — по ширине самой панели (container query на `.drawer-body`), а не по окну (`@media`).

| Раскладка | Когда | Вид |
|--|--|--|
| **A. Одна колонка** | панель уже 760 px, телефон, либо выбор «Одна колонка» | как сейчас: главное → второстепенное → широкое |
| **B. Две колонки** | панель от 760 px, широких таблиц нет | слева (60 %) главное; справа (40 %) второстепенное |
| **C. Две + широкая снизу** (по умолчанию от 760) | то же + есть «большая таблица» | B, а под ними блок `wide` на всю ширину |

**Правило «что куда»** (в описании карточки у поля/блока `zone: 'main' | 'side' | 'wide'`; без зоны = `main`):
- **main (слева):** что это, статус, кто/сколько/когда/срок, сумма, главные действия, поля, которые правят каждый день.
- **side (справа, по категориям):** контакты, реквизиты, примечание, фото, связанные записи (ссылками), назначенный, служебное. Заголовки категорий — `h3`; свёрнуты, кроме первой.
- **wide (снизу):** таблицы больше 3 строк / 5 колонок: позиции заказа, оплаты, движения позиции, состав изделия, счета контрагента; последней — «История изменений» (свёрнута).
- **Шапка** (на всю ширину): h2, подпись, чипы-итоги (статус · срок · сумма), «⋯». **Подвал** — «Изменить» (одна), как сейчас.
- В узкой панели порядок: main → wide → side (таблицы важнее справочного); подтвердить с аналитиком.

**Точки ширины (по панели):** до 760 — A; 760–1100 — B (3:2); от 1100 — C (1:1, `wide` на всю). Проверить глазами: с шириной по умолчанию (480–760) все карточки окажутся в A, раскладка B/C заметна только после «растянуть». Предложение: при выбранной C ставить панели начальную ширину около 960 px (если пользователь не задавал свою).

**Переключатель:** пункт «Раскладка: две колонки / одна колонка» в меню «⋯» шапки панели (`menuBox`, `card.js:60,143`). Второй «⋯» (`act-more`, `card.js:121`) убрать: редкие действия переезжают в меню шапки.
- **Хранение:** `core/prefs.js` — добавить в список строковых настроек `STR = ['lastChat']` (`prefs.js:21`) ключ `panelLayout` (`'auto'` по умолчанию | `'one'`). `getPref/setPref` уже пишут в браузер сразу и на сервер через 1 с (`PATCH /auth/me/prefs`). **Зависимость для архитектора:** сервер принимает только известные ключи `uiPrefs`; нужно разрешить `panelLayout`, иначе 400 и тихий сбой (`prefs.js:166`).
