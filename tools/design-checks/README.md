# Локальные проверки вида

Пакет инструментов тестирования, не зависимость приложения. Установка на ПК: `npm ci --prefix tools/design-checks` (кнопка пульта «Установить проверки дизайна»). Новые браузеры не скачиваются: тест использует установленный Edge.

- `compare.mjs --baseline <принятый.png> --current <новый.png>` — пиксельное сравнение PNG, без LLM. Эталон выбирается явно; автоматического принятия нет. Изменения данных/шрифта/браузера тоже дают различия, поэтому фиксировать данные, тему, ширину, масштаб и браузер.
- `axe-core` — проверка доступности при штатном `site-audit` на средней ширине. Отсутствующий пакет и ошибки запуска отмечаются как непроверенное.
- `browser.test.mjs` — локальная HTML-фикстура: дефектные и исправленные подписи, расстояния, проверка axe. Не подключается к приложению и БД.
- Снимки модели — отдельный `tools/ai-tester/vision-review.mjs`; результаты только гипотезы.

Коды сравнения: 0 совпало, 1 изменилось, 2 проверка не выполнена. Изменилось ≠ стало плохо. Эталонные снимки сайта пока не утверждены: сначала исправление и приёмка C086.
