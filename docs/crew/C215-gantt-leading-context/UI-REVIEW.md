# C215 — один день перед началом работ

Локальный Edge, заполненная браузерная фикстура `gantt.test`, 1920 × 1080. Операция с 31.10 по 06.11.2026 пересекает границу недель и месяцев.

| Режим | Видимый период |
|---|---|
| Месяц | 30.10–30.11. Вместо 61 ячейки осталось 32, полная ширина ленты сохранена. Ячейки стали шире более чем в 1,8 раза. |
| Неделя | 30.10–08.11. Ширина дневной ячейки выросла более чем в 1,3 раза. Стрелка выбирает 30.10, затем 02.11. |
| День | 30.10–07.11, по одному соседнему дню с обеих сторон работы. |
| Занятые дни | 31.10–06.11, только даты работы. В эталоне планировщика на витрине сохранено название «Обзор работ». |

В коротком октябрьском блоке подпись «Окт 2026» читается целиком, полное имя месяца доступно при наведении. [Месяц в мягкой теме](proof/c215-month-soft.png).

Прошли 12 браузерных сценариев, включая расстановку исполнителей, растяжение через разрыв, отмену и проверку шкалы при 1920, 2560 и 3440 px. После сокращения заголовков отдельно повторена проверка короткого октября без обрезки текста.

Запись проверена на фикстуре API. На локальной копии `:3102` перепроверено «В работе → Гант → По людям» с восемью операциями. Месяц показал 32 даты с 30 октября по 30 ноября, неделя — 10 дат с 30 октября по 8 ноября. «Занятые дни» оставили 8 дат. Ячейки месяца стали шире в 1,91 раза. Заголовок октября помещается. Данные в этом прогоне не менялись.
