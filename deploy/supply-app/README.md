# «Рабочее место» — инструкция

**Адрес:** `https://kppdf-crm.ru/db/app/` — компьютер и телефон (можно «Установить приложение» / «На экран Домой»).
Вход — логином сотрудника (тот же, что в CRM). Менять данные могут роли admin и manager, смотреть — все.
Код — [`backend/pwa/`](../../backend/pwa/) (без сборки), правила — [docs/CANON.md](../../docs/CANON.md), что умеет — [docs/PRODUCT.md](../../docs/PRODUCT.md).

## Разделы

| Раздел | Что делать | Данные |
|--|--|--|
| **Сегодня** | Список дел: «Нужно заказать» → «Заказано»; «Ждём поставку» → «Оплачено», «Принять»; «Ждут решения» → «В заказ» / «Отменить»; «Закончилось на складе» → «Заказать»; «Ждём оплату от заказчиков» → «Оплачено». Быстрая заявка одной строкой (Enter). | всё ниже |
| **Заявки** | Таблица или доска по статусам (карточку можно перетащить в другой статус). В строке — кнопка следующего шага. В карточке — № и **дата счёта**, сумма с НДС, наша компания (нужны для платёжного календаря). | `supplyrequests`, `/api/supply` |
| **Остатки** | Плитки категорий, вкладки «К закупке / Нет / В брони». В строке: «+ Приход», «− Списать», «Заказать». В карточке — бронь, инвентаризация, история. | `materials` + `storageitems`, `/api/stock` |
| **Движения** | Журнал по дням; ошибочное движение — «Отменить» (обратное движение, история сохраняется). | `stockmovements`, `/api/stock/movements` |
| **Заказы** | Строки заказов = доходы: заказчик, наша компания, кол-во × цена (или «доход вручную»), даты отгрузки и оплаты. В строке — «Отгружено», «Оплачено». | `incomes`, `/api/incomes` |
| **Платёжный календарь** | Деньги по дням за месяц: остаток на начало, поступления, выплаты (СИЮ / ССЮ), остаток на конец. Клик по сумме — операции дня. «Сводка» — по месяцам и категориям. «Требуют заполнения» — что не попало в расчёт и чего не хватает. | расчёт, `/api/finance` |

**Правила расчёта денег:** выплата = заявка с датой счёта, суммой (сумма строки с НДС) и нашей компанией — ложится на дату счёта; отменённые не считаются. Поступление = строка заказа с суммой — на дату оплаты, иначе отгрузки. Начальный остаток месяца вводится в поле «остаток на 1-е» (запоминается в браузере).

- **Удаление** — всегда в корзину (меню слева «Корзина»), сразу после удаления есть «Отменить».
- **Клавиши:** `/` — поиск, `N` — новая запись, ↑ ↓ — соседняя запись, Esc — закрыть.
- **Связь:** приложение работает онлайн; без связи сверху красная полоса, изменения не сохраняются.

## Google-таблицы

Пока команда ведёт таблицы, сервер каждые 10 минут подтягивает листы «Снабжение», «Заказы», «Склад», «Движение склада» (админка → «Google-таблицы»). Запись, изменённая или удалённая в приложении, таблицей больше не перезаписывается. «Реестр счетов» не загружается (копия «Снабжения»). Когда команда перейдёт в приложение — автозагрузку выключить (TASKS 0.5).
