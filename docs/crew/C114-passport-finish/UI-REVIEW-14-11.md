2. Мелочь: у позиции 19 («изделие не привязано») нет рамки — заголовок выступает левее остальных; у выпущенной строки 3 рамка на ~3 px левее, чем у раскрывашек. Не блокер; выровнять при случае (рамка-пустышка для строки без изделия).

Блокером не считаю.
