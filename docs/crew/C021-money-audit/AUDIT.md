# C021 — полный аудит «Деньги» (2026-11-04)

Перед визитом финансового директора. Источники: PRODUCT §5, MAP finance, analyst, site-manager (прод), designer.

## Вердикт одной фразой

Раздел показывает **факт оплат и счетов**, не банк и не остаток на счёте. К показу годится **вкладка «Сводка»** с честным сценарием; «Прогноз» не открывать, пока остатки нулевые и цен в заказах нет.

## Канон (как задумано)

1. Отдельной таблицы денег нет: доход = платежи по позициям заказа (`incomes.payments`), расход = оплаченные заявки (+ ФОТ).
2. Календарь и сводка считаются на лету (`/finance/cashflow`, `/summary`, `/forecast`, `/needs-fill`).
3. СИЮ и ССЮ раздельно. «Старт учёта» задаёт дату и остаток по компании.
4. Склад и отгрузка деньги сами не двигают.
5. Отчёт за период + выгрузка CSV — в PRODUCT; у календаря/сводки выгрузки ещё нет.

## Связи с проектом

| Стык | Оценка |
|--|--|
| Заказ → платежи → календарь | Работает; частичный платёж в календаре есть, в шапке заказа «оплачено» — только полные |
| Заявка → оплата → расход | Работает; частичной оплаты поставщику нет |
| КП «Оплачено» | Вручную, денег не создаёт |
| Склад / выдача | Денег не касается (верно) |
| ФОТ | В календарь/прогноз заложен; на проде в сводке пусто |
| Предоплата в прогнозе | Читает «…%» из текста формы оплаты |

## Мнение координатора (что улучшить)

**Сегодня (показ):** сценарий + честные подписи + вид сводки; данные — менеджеры (цены, остатки, счета).  
**Скоро:** шапка заказа с суммой платежей; просрочка в шапке календаря; CSV сводки; прибыль «по заказу» (поступления − заявки с этим orderId).  
**Позже:** банк/выписка, частичная оплата поставщику, налоги, срок оплаты из договора.

## Границы волн

- **Волна 1 (сегодня, код UI + мелкий finance):** вид сводки/календаря, язык, пустые состояния, метрики просрочки в шапке календаря, сценарий показа. Данные прода не чистим скриптом без «да».
- **Волна 2:** шапка заказа / CSV / прибыль по заказу / сверка старта со сводкой.
- **Не обещать на встрече:** банк, налоги, Excel календаря, прибыль заказа.
