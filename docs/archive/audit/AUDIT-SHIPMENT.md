## 2. Где предлагается лишнее / невозможное
1. `order-shipments.js:72,77` — позиция, которую ещё не начали делать (нет worktask или `waiting/work`), стоит в списке отмеченной на полный остаток.
2. Позиции из склада/покупные (без производства) тоже без проверки: есть ли остаток на складе или выдана ли бронь (`order-readiness.ts:24` считает брони только на уровне заказа).
3. `service.create` `:105-115` принимает любую позицию с остатком — API-клиент тоже отгрузит неготовое. Предупреждения нет, причина требуется только при неполной отгрузке.
4. Кнопка «Отгрузить» (`:37`) доступна на этапах new/production, хотя ничего не готово. Заказ без `qty` в позиции — пустая панель «Отгружать нечего» без прямой ссылки на исправление.
5. Паспорт для отгрузки не проверяется (паспорт «не готов» не мешает и ничего не говорит).
6. Список изделий в «Новый паспорт» — см. п.5.

## 3. Правило «можно отгрузить» (по позиции `incomes`, `left` > 0)
Позиция = «производимая», если у неё есть `worktask` не cancelled/удалён (или `productId` с маршрутом); иначе «со склада/покупная».
- Производимая: готова, если последний `worktask` позиции `status = done` (количество считаем целиком: 1 задание = вся позиция; частичных нет — вопрос 1).
- Со склада: готова, если нет активной брони по позиции/заказу (`reservations.status='active'`, `salesOrderId`) и есть остаток — `storageitems`/`stockmovements` (вопрос 2: учитывать ли остаток склада или только выданную бронь).
- Паспорт: не блокирует; в строке — статус «паспорт: готов / черновик / нет» (`passport-queue.ts:94-102` уже считает по `incomeId`). Блокирует — только по решению пользователя (вопрос 3).
- Статусы позиции: `ready` (можно), `blocked` (нельзя) + `missing[]` — «чего не хватает»: «Не изготовлено: шаг "Сварка" (W-12)», «Нет задания "В работе" — запустите», «Бронь не выдана со склада», «Не указано количество в заказе», «Отгружено полностью».
- По умолчанию в панели: отмечены только `ready`; `blocked` показаны свёрнуто серым с причиной и ссылкой (`#work?...`, `#salesorders?open=`), галочка недоступна. Исключение: кнопка «Всё равно отгрузить» только admin, с причиной (иначе срыв у «отгрузили без документа»).
