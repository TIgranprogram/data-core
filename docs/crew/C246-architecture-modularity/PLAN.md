## Как работаем (правило владельца 24.11.2026)

1. Сначала план и ТЗ. Потом код по одному этапу.
2. Этап = законченная работа: зелёные проверки, коммит, при необходимости выкладка.
3. Следующий этап не обязан существовать, чтобы приложение работало.
4. Недоделанное **не** выкладываем. Откат = не деплоить / откатить коммит(ы) этапа.
5. Лимит ИИ кончился → отметить `[ ]`/`[x]` в CHECKLIST, коммит готового, эстафета. Другой ИИ читает CHECKLIST и ТЗ этапа.
6. API-контракт, данные прода, схемы общих с CRM — не ломать.
