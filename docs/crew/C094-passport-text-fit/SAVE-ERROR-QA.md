# C094 — проверка кнопки «Готово» в шаблоне

12 ноября 2026. В поведенческих тестах загружаются реальные `card.js`, `dom.js` и `toast.js`. Адаптер воспроизводит независимые обработчики `addEventListener('click', …)` и `onclick`: один клик запускает оба, если они назначены. Вызовы сохранения и отправки отчёта о сбое заменены контролируемыми заглушками.

1. **Запись ожидается.** Пока `beforeClose` не завершён, карточка остаётся в правке, кнопка отключена, второй клик не создаёт повторную запись. После завершения открывается просмотр.
2. **Ошибка записи.** Карточка остаётся в правке, пользователь видит сообщение, сборщик получает исключение и действие «сохранить». Повторное нажатие успешно завершает правку.
3. **Без изменений.** `beforeClose` вызывается один раз, запись не выполняется, карточка возвращается в просмотр без ошибки.

На прежнем `card.js` из HEAD все три сценария ожидаемо упали. На исправленной версии — 3 из 3. Вместе с тестами PWA прошло 121 из 121. Импорты и синтаксис — 285 файлов без ошибок.

Первый прогон `pwa-guards` обнаружил 409 строк в `card.js` при лимите 400. Остальные 280 проверок прошли. Браузерная приёмка проводится отдельно.

Финальный прогон: после сокращения вводного комментария без изменения логики pwa-guards 281/281 PASS. Все поведенческие тесты 121/121 и визуальная приёмка — PASS. Рабочий стол пользователя не используется; дальнейшие проверки и выпуск — только CLI/API и изолированные тесты.
