# DECISIONS — решения и допущения

Формат: Вопрос / Принятое допущение / Как изменить.

## 2026-11-02: uv недоступен, Python 3.15
- Вопрос: ТЗ требует uv и Python ≥3.12; на ПК только Python 3.15 и нет uv/winget.
- Допущение: используем python -m pip для установки; pyproject.toml сохранён для uv; простой парсер YAML (simple_yaml) вместо pyyaml; CLI на argparse вместо typer (typer падает на 3.15 из-за ctypes ABI).
- Как изменить: установить Python 3.12 + uv, тогда заменить simple_yaml→pyyaml и argparse→typer.

## 2026-11-02: пакет nightshift
- Вопрос: проверка `import nightshift` из папки проекта.
- Допущение: импорт работает из родительской папки tests_ai_tiit; добавлен __init__.py.

## 2026-11-02: изоляция сети стенда
- Вопрос: internal: true блокирует публикацию портов, но обеспечивает изоляцию.
- Допущение: стенд использует internal network (порт не опубликован); доступ к Mongo стенда — через docker exec; изоляция проверяется попыткой доступа к google.com:80 из контейнера.
