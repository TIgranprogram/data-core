# C211 — сроки, исполнители и шкала Ганта

22.11.2026. Проверка в Edge на заполненной локальной браузерной фикстуре `http://gantt.test/app/`. Входы `#workschedule` и `#work?view=gantt`. Проверены рабочее дерево, общая панель фильтров и карточка шага. Эталон — `planner` на витрине `#kit`. Серверный контракт взят из существующих маршрутов плана позиции и старых заданий.

| Сценарий | Результат |
|---|---|
| Два входа | В отдельном Ганте заказ выбирается по идентификатору. Старая ссылка с номером остаётся рабочей. Два заказа с одинаковым номером и разными производственными номерами можно разделить. Во «В работе → Гант» заказ и исполнитель выбираются общими фильтрами, воронка показывает позицию, часть и вид работ. При возврате в список восстановлены его фильтры. |
| Люди и карточка шага | В дереве остаются исполнители видимых операций и группа «Без исполнителя», если есть такие полосы. В карточке предложены сотрудники с видом работ шага и сохранён выбранный ранее сотрудник. Офисный сотрудник без вида работ недоступен для назначения. |
| Шкала | На 1920, 2560 и 3440 px проверены «День», «Неделя», «Месяц» и «Обзор работ». Границы шапки и дорожек совпали, двухдневная полоса заняла ровно два дня, полосы отцентрованы по строкам. На мягкой теме проверена читаемость второй строки над красной отметкой просрочки. |
| Изменение срока | Правая ручка меняет конец без переноса строки. Клавиатура поддерживает Shift + ←/→. При увеличении пятничного срока до субботы новая дата переносится на понедельник. План позиции отправил начальную и конечную даты с `rev`. Старое задание отправило начало и календарную длительность. Отмена вернула срок. У выполненной операции нет ручки и полей редактирования. |
| Перетаскивание старого задания | При известном виде работ неподходящий исполнитель отклонён с пояснением, запрос записи отсутствует. Задание без указанного вида по-прежнему переносится с сохранением дат. |
