# Пульт исполнителей (Crew)

Одно место для **всех заданий** (с 2026-11-07): свои роли (`.claude/agents/`) и внешние ИИ (Manus, OpenCode, Cursor и др.).  
Другой параллельной документации по задачам нет: ТЗ (по `docs/roles/TZ-TEMPLATE.md`), промпт и отчёт лежат в папке задания. `docs/roles/tz/` — только старые открытые ТЗ, новых не создавать.

## Кто есть кто

| Роль | Где | Что делает |
|--|--|--|
| Координатор | основной чат (Claude Code или Cursor) | класс задачи, ТЗ, промпт, приёмка, коммит/выкладка |
| Manus | отдельный чат | задачи сложнее (M/L, разбор, сервер, границы) |
| OpenCode | отдельный чат | рутина (S/M: инвентаризация, тесты, мелкие правки по ТЗ) |

Пользователь только копирует короткий промпт из чата координатора агенту и говорит координатору «сделал — проверь».

## Папка задания `docs/crew/Cxxx-…/`

| Файл | Кто пишет |
|--|--|
| `TZ.md` | координатор |
| `PROMPT.md` | координатор (полный промпт; в чат пользователю — 2–4 строки) |
| `REPORT.md` | исполнитель (≤ 20 строк; статус PASS/FAIL/PARTIAL) |
| прочие артефакты | исполнитель, только если ТЗ просит |

## Доска

Текущая очередь и статусы — [`BOARD.md`](BOARD.md). Законченное задание: статус `done` на доске; папку позже уводит в архив координатор (`docs/archive/crew/…` по правилу AGENTS 9а).

## Правила исполнителей

1. Читать только `TZ.md` + файлы из раздела «Читать» в ТЗ. Не читать весь репо.
2. В начале: `MANUS.md` (Manus) или этот README + `AGENTS.md` краткий блок «Что это».
3. Не коммитить и не выкладывать, если ТЗ явно не поручило.
4. Не трогать прод-данные, `/opt/kppdf*`, чужие незакоммиченные файлы.
5. По окончании: заполнить `REPORT.md`, коротко сказать пользователю: «Сделал. Отчёт в docs/crew/Cxxx/REPORT.md — передайте координатору».
6. Спор с ТЗ → PARTIAL в отчёте, не «улучшать от себя».

## Экономия токенов

Правило — `AGENTS.md` «Экономия токенов» (единственная копия). Коротко: в чат — путь к `TZ.md` и суть; длинное — в файлах папки.
