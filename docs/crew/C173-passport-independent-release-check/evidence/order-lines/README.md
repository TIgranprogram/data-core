# C173. Две позиции заказа от образца до второй редакции

**PASS в границах сценария.** Код из git archive ac5ef648c8161dfe0d1cf18d7dbd29eb2182ba3c, локальный Nest с реальными контроллерами и строгой валидацией, MongoDB 4.4 rs0 в собственном временном контейнере. Контейнер остановлен. Сценарий работал от тестового администратора. Фикстура BLG — одно изделие, одна организация, один заказ, две строки, анкерный монтаж. Три синтетические роли изображений используют один цветовой образец.

| Проверка | Наблюдение |
|---|---|
| Шаблоны и образцы short/full | GET шаблонов 200, образцы PDF 201. В БД по-прежнему 0 паспортов и исходные счётчики. |
| Создание и повтор | По каждой позиции два POST вернули один id. До выпуска хранится техническая метка draft-…, счётчики прежние. |
| Выпуск и повтор | Для двух строк выданы № 1 и 2, талоны 202611-1 и 202611-2. Повторный POST вернул тот же id/номер/талон и оставил счётчики прежними. Итог — ровно 2 документа. |
| Вторая редакция | PATCH имени каждого экземпляра. По GET сохранены номер и талон, редакция 2. В БД ровно одна историческая версия с прежними именем, снимком текста и снимком печати. |
| PDF из HTTP до и после | Все четыре ответа 200 application/pdf. В каждом 7 страниц. Извлечение текста сверило имя, фирму и номер изделия на обложке и талоне, номер паспорта на внутренних страницах, номер талона, габариты и наличие идентификатора заказа. |

[Сценарий Jest](order-lines.e2e-spec.ts) · [Связи и номера](trace.json) · [Проверка реквизитов PDF](check-pdf.py) · [Имена, страницы и SHA-256 четырёх PDF](pdf-check.json).

**Воспроизведение.** Подготовить новый локальный git archive указанного backend без .env, зависимости этой версии и Mongo 4.4 с пустым томом, rs0 и случайным портом на 127.0.0.1. Поместить сценарий в backend/test/e2e копии. Из backend запустить Jest с test/jest-e2e.json, --runInBand --forceExit --runTestsByPath test/e2e/order-lines.e2e-spec.ts. Передать MONGO_DB_TEST=datacore-test-c173, MONGO_URI с портом собственного контейнера, этой БД, replicaSet=rs0&directConnection=true, отдельные UPLOAD_DIR и C173_EVIDENCE. Скрипт check-pdf.py читает trace.json и PDF из своей папки. Итог прогона Jest 1/1 PASS за 11,67 с, извлечение pypdf 4/4 PASS.

**Остаток.** Повтор отправлен после успешного ответа. Сетевой обрыв, параллельный выпуск, разные фирмы, standalone, реальный проход менеджера и последовательные редакции CAD остаются самостоятельными сценариями. Исторические снимки сверены в БД, отдельная повторная печать из истории здесь не проверялась. Рисунки, инженерное содержание, вёрстка и физический отпечаток не проходили предметную приёмку в этом прогоне. ПС-08 и утверждение владельцем открыты.
