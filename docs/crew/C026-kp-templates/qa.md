### Ошибки (рабочий код не правил)
1. ❌ **Предпросмотр пуст на сайте.** `backend/src/main.ts` helmet CSP (~стр. 95–102): `default-src 'self'`, `frame-src` не задан, `object-src 'none'`. Окно `pwa/ui/kit/pdf-preview.js:14,22` грузит `blob:` в `<iframe>` → в консоли нарушение `frame-src blob` (поймано `securitypolicyviolation`), в окне значок «запрещено». Воспроизвести: стенд/прод, КП → «+ КП» → заполнить → «Предпросмотр». Ожидалось: PDF в окне. Нужно `frameSrc: ["'self'", 'blob:']` (проверить, нужен ли ещё `objectSrc 'self'` для встроенного просмотрщика Chrome). Без правки критерий «Предпросмотр» не принят. Кнопка «Скачать PDF» работает независимо.
2. ➖ Новое КП у фирмы без ставки НДС открывается с «Без НДС» (поле подписано «из настроек фирмы», ставка показана 22). По ТЗ верно (vatRate фирмы пуст → не with); для критерия 1 менеджеру нужно явно выбрать «С НДС» либо заполнить ставку у СИЮ (данные пользователя, `DATA-FIX-USER.md`).
3. ➖ `copy()` (`offers.service.ts` ~317) не переносит `vatMode/vatRate` — у копии НДС берётся по новой фирме. Похоже на задумку (разные фирмы — разные ставки), в ТЗ не оговорено; подтвердить.
4. ➖ «Действительно до» в новой форме пустое и обязательное — срок по умолчанию (10 дн.) не подставляется. Не критерий ТЗ.
