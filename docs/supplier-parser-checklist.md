# Чек-лист: парсер сайтов поставщиков

> Для обсуждения с пользователем. Дата: 2026-10-25.

---

## ✅ Делать

- Читать `robots.txt` перед парсингом.
- Использовать User-Agent браузера — Chrome 120+.
- Делать паузы между запросами: 1–2 с.
- Хранить дату последней синхронизации в БД.
- Помечать пропавшие позиции `active:false` — не удалять.
- Логировать каждую ошибку парсинга с URL.
- Ограничивать число позиций за один прогон (сейчас: 2000).
- Хранить фото локально — внешние ссылки нестабильны.
- Проверять SSRF перед каждым запросом с сервера.
- При 429 — ждать 30 с, повторить один раз.

---

## ❌ Не делать

- Не запускать параллельные запросы к одному сайту.
- Не хранить сырой HTML в БД.
- Не удалять позиции при синхронизации — только `active:false`.
- Не делать более 1 запроса в секунду.
- Не игнорировать изменение структуры сайта — адаптер сломается тихо.
- Не хранить пароли/куки от поставщика в коде.

---

## ⚠ Риски для обсуждения

### 1. Юридические
- Парсинг может нарушать ToS сайта поставщика.
- Уточни у поставщика: есть ли API или прайс-лист в Excel/CSV?
- API или прайс-лист надёжнее парсера на 100%.

### 2. Хрупкость адаптера
- Поставщик меняет вёрстку — адаптер ломается без предупреждения.
- Нужен мониторинг: если синхронизация вернула 0 позиций — алерт.
- Каждый новый поставщик требует отдельного адаптера.

### 3. Фото
- Фото хранятся в `uploads/` — нужно следить за дисковым пространством.
- Лимит: 5 фото на позицию × 2000 позиций = до 10 000 файлов.
- Обсудить: нужна ли очистка фото при `active:false`.

### 4. Частота синхронизации
- Сейчас: вручную по кнопке.
- Обсудить: нужна ли автоматическая синхронизация раз в неделю?
- Ночная синхронизация — меньше нагрузка на сайт поставщика.

### 5. Несколько поставщиков
- Каждый сайт — отдельный адаптер в `adapters/`.
- Обсудить: сколько поставщиков планируется подключить?
- Более 5 поставщиков — нужна очередь задач (Bull/BullMQ).

### 6. Изменение цен
- Парсер перезаписывает цены при каждой синхронизации.
- Обсудить: нужна ли история изменения цен?
- История цен поможет видеть динамику и торговаться.

## 💡 Лучший сценарий (рекомендация)

1. Запросить у поставщика прайс-лист в Excel/CSV — проще парсера.
2. Если нет — парсер с адаптером, как сделано сейчас.
3. Добавить мониторинг: 0 позиций после синхронизации → уведомление.
4. Ночная автосинхронизация — обсудить с пользователем.
