# C157 — сохранённые проверенные исполнители

Это побайтовые копии проверенных временных скриптов, а не новые команды пульта. Запись выполняет только роль доступа после конкретного разрешения координатора; прямой запуск копии из crew не предусмотрен. Для продолжения восстановить соответствующий файл в tools/logs, сверить SHA и выполнить его review/guards по RECOVERY-PLAN.md.

Планы, оригиналы и журналы с бизнесданными остаются в локальном data и Downloads, в Git не добавляются. Их отсутствие на другом ПК требует переноса разрешённым способом и read-proof; нельзя пересоздавать оплаченные документы по памяти. Шаблоны approval FALSE не являются разрешением. Старый next10 helper с ошибочным header.version запрещён.
