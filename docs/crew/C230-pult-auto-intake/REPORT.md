# C230 — проверенная отправка и разбор позиций

- [x] Отчёт показывает одну строку на исходный файл. 24 записи на сверке относились к 12 оригиналам, 4 записи об отправке — к двум оригиналам. Повтор подтверждён по SHA-256.
- [x] Для PDF с ясной сеткой Пульт читает название, количество, единицу, цену и сумму в физических ячейках. Структура проверяется по заголовкам, арифметика — по строкам и общему итогу. Сомнения о прочтённой таблице снимаются после независимой полной проверки.
- [x] Действие «Разобрать и отправить проверенное» доступно на тестовой копии. Отправляются подтверждённые документы этого запуска и ранее начатые им отправки. Похожие номера и неподтверждённые файлы остаются в отчёте. Тот же PDF с подтверждёнными реквизитами отмечается «Уже на сайте».
- [x] 144 локальных теста, браузерный сценарий и 7 изолированных E2E. Учебный счёт прошёл автоотправку до записи в MongoDB. Прежний проверенный счёт, похожий номер и файл неподдерживаемого формата пропущены. Входящие владельца через новый режим не отправлялись.
- [x] Действия «Подтвердить», «Исправить» и «PDF» доступны в строках таблицы отчёта. Номер, дату и итог можно исправить под строкой, если значение найдено в PDF. [Браузерная приёмка](UI-REVIEW.md). Ответ подтверждается текущей сессией пользователя, сохраняет новую версию черновика и повторно проверяет справочник. Проверенное вручную остаётся в обычной очереди подтверждения отправки.
- [x] Отдельная группа «Проверить оформление» показывает арифметическое расхождение, подтверждённое по напечатанным строкам. PDF открывается из защищённого оригинала папки, отметка «Вернуть менеджеру» действует в локальном отчёте и отменяется оттуда.
- [x] Три PDF из прерванной очереди были читаемыми повторными поступлениями. После Windows EPERM в журнале добавлены ограниченные повторы записи и распознавание уже перемещённых оригиналов. В повторной проверке на копии новых ошибок файловой операции нет.
- [x] Проверено на локальной копии без отправки: из 11 уникальных файлов на сверке все 11 по-прежнему требуют подтверждения или данных из справочника. Число отправленных осталось прежним. Старый запуск учитывал 59 физических поступлений. Новый цикл повторной сверки выбирает по одному документу на исходный файл. Изменения счётчика проверены отдельным тестом.
