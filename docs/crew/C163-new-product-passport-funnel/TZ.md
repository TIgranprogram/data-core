# C163 — новое изделие из Inventor: фото и воронка упрощённого паспорта

Класс L. Поручение владельца 19.11.2026, изделие 1068 «Вело». Сначала проверить фактические источники и связки, затем исправить доказанные дефекты. Полный паспорт и старые выпуски не изменять.

## Сценарий и критерии
- Загруженные из Inventor рисунки паспорта видны. При отсутствии главного фото изделия предложить общий вид либо безопасно использовать его как резервное изображение; уже выбранное главное не заменять. Можно явно выбрать главное изображение.
- Новый short ведёт сначала к виду/категории и применимым критериям. Назначение и описания приходят из справочников, ручной ввод только по отдельному выбору.
- Не смешивать паспортные элементы с производственным составом. Проверить необходимость технических обязательных полей (соединения, материалы) именно в short; обязательное не скрывать без проверки серверной модели/печати.
- Сохранение критериев в их источниках, отмена/повтор/409 не теряют ввод. Проверить с пустого изделия, повторное открытие, образец. На проде только чтение, никаких тестовых паспортов.

Data steward: только readonly API-выгрузки через access, классификация coverage/точных дублей, тексты по подтверждённым данным, план→apply. Access: снимок dictionaries и reference usage, затем только согласованные координатором точечные изменения API с readback. Не дублировать UI/серверную реализацию C163.

## Контракт конструктивного уточнения и сохранность общих признаков

Новые уточнения конкретного вида используют существующие productFacets с `step=false` и кодом, заканчивающимся `.form`. Только для них форма ограничивает значения по kindIds всей цепочки применимой simple-description ветки. Нулевые ветки скрываются; общие trn.kind/load/muscles/build/contact остаются доступны независимо от неполноты словаря. Отсутствие готового текста не доказывает неприменимость общего признака. При смене значения контролируется вся семья родителя; чужие категории и нетронутые скрытые значения сохраняются.

Дизайнер нашёл обрезание высокого рисунка в общем zoom: исправить конечным grid-треком в kit, проверить bbox полного изображения и закрытие. CTA резервной обложки — «Сделать обложкой изделия».
