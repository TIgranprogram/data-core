# Меню: «Настройки» + шапка (дизайн, 2026-10-28)
Код: `main.js` shell() 166–179, themeButton 208; шапка `.topbar` 189; стили — base.css (.side-foot), panels.css.

## 1. Распределение
Низ меню слева: один пункт «Настройки» (иконка шестерёнка) + версия. Видим всем.
Popover «Настройки» (группы, заголовок группы — как `.side-group`):
- Данные: Справочники (всем, кто видит), Корзина (всем).
- Система (группа скрыта, если пуста): Администрирование (только admin), CRM (только если PREFIX, т.е. прод).
- Приложение: Установить на телефон (всем; скрыть, если уже установлено).
- Отдельно внизу, разделитель `--border`: «Выйти» (красный текст, `--danger`).
Не-админ видит: Данные, Приложение, Выйти. Место под будущее: новая группа = ещё один блок, высота растёт до max-height со скроллом.
Шапка справа от колокольчика, порядок: История (иконка, только seesHistory: owner/admin/director) · Тема (иконка: циклично система→светлая→тёмная, title/aria-label «Тема: <имя>») · Аватар (круг с инициалами).
Меню аватара (`.menu`, по клику): имя (жирно), роль (muted), разделитель, «Выйти». Всё остальное из popover — не дублировать.
Счётчики/переходы: ссылки внутри popover закрывают его и `nav-open`.

## 2. Поведение popover «Настройки»
- Кнопка: `aria-haspopup="menu"`, `aria-expanded`. Открытие — клик/Enter/Space.
- Вырастает над кнопкой (bottom: 100%+8px, left: 8px), поверх меню, z-index 45 (выше drawer 41, ниже modal).
- Закрытие: Esc (фокус вернуть на кнопку), клик вне, выбор пункта, смена раздела, resize/открытие другого popover.
- Фокус: при открытии — на первый пункт; Tab циклится внутри; ↑/↓ — по пунктам; role="menu"/"menuitem"; :focus-visible обязателен.
- Один открытый popover за раз (аватар и настройки закрывают друг друга).
- Телефон (≤ 760): нижний лист на всю ширину, левый/правый 0, радиус `--radius` сверху, подложка затемнения как `.side-back`, ручка-полоска сверху, пункты высотой ≥ 44px, отступ снизу safe-area; закрытие — тап по подложке/Esc. Меню аватара на телефоне — тоже нижний лист.

## 3. Размеры и токены
Ширина 264px (в узком меню — 240px, выезжает вправо от иконок, left: 100%+8px). max-height: min(70vh, 520px), overflow-y auto. Фон `--surface`, рамка 1px `--border-strong`, радиус `--radius`, тень `--shadow-lg`, padding `--s2`. Пункт: высота 40px (телефон 44), иконка 18px, gap `--s2`, hover `--surface-2`/как .side-link:hover. Заголовок группы: 11–12px, uppercase как `.side-group`. Иконки шапки: `btn btn-ghost btn-icon` 36px (телефон 44px). Аватар шапки 32px (как `.avatar`), на телефоне зона нажатия 44px. Новых цветовых токенов нет.

## 4. Узкое меню (иконки, base.css:56)
Есть режим `--sidebar-icons-w`: «Настройки» показывается иконкой с title/aria-label; popover выезжает вправо (см. §3), подписи в нём остаются полные. Аватар/«Выйти»/тему из низа меню убрать совсем — они теперь в шапке.
