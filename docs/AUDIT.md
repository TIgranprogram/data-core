## Этап 1 — «черновик не сохраняется» (сделано 23.10, `4a045fa`)

- **Текст ошибки и файл:строка показать нельзя:** журнал прежнего контейнера удалён выкладкой (пересоздание `datacore-backend` в 13:00 UTC; изделие 3_5_19 правили в 12:56 UTC). После выкладки — ни одного 5xx; последнее создание паспорта на проде — 201.
- **Вероятная причина:** сохранение попало на перезапуск сервера при выкладке (502 → приложение писало «Ошибка на сервере»).
- **Проверено на QA (карточка 3_5_19 перенесена с прода):** воркаут (12 пустых), детское игровое «Качели двойные» (16), благоустройство «QA Скамья» (8) — черновик сохраняется, открывается заново, номера нет, «Выпустить» → 400 с тем же списком, что в «Готовности».
- **Сообщения:** ошибка данных → 400 «Поле «…»: нужно число (сейчас «…»)» + подсветка поля (`backend/src/common/filters/http-exception.filter.ts`); 500 → код сбоя (тот же в журнале); 502–504 → «сервер перезапускается, введённое не потеряно» (`backend/pwa/core/api.js`). Форма при ошибке не закрывается.
- **Проверка по ТЗ:** валидация выпуска к черновику не применяется (`svc:272` create, проверка только в `svc:495` issue); NOT NULL нет (Mongo, поля необязательные); пустые числа → `null` (тело запроса — `maxUsers` и т. п. не отправляются пустой строкой); пустые рисунки — `images: []` допустимо.
