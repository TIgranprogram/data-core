# ТЗ C039 — типы позиций: группы «по полочкам», плитки как у категорий, простые понятные иконки

**Зачем (словами пользователя, 2026-11-07):** «Типы хорошо получились. Карточки типов почему-то больше, чем категории — сделать поменьше. Группировка: все болты, потом все шайбы-разновидности, потом гайки, саморезы — по полочкам, чтобы не вчитываться. То же во всех разделах, где показываю типы. Картинки у типов — проще, понятнее, графичнее; другой вид, красиво, и все типы прикрепить к картинкам.»
**Зачем — глаголом:** кладовщик за 1 взгляд находит «Шайба гроверная» среди 30 типов, потому что все шайбы стоят одной полкой под заголовком «Шайбы» с одной понятной иконкой.

## Глубже
- **Результат:** во всех местах шага «Тип» (Склад — раскрытая категория; «Выдать материалы»; «Принять на склад») типы сгруппированы по семействам, у каждого типа — иконка, плитки того же размера, что категории.
- **Сырьё:** реальные имена позиций прода — выгрузка через datacore-access в `tools/logs/c039-stock-names.tsv` (не в git; name, category, quantity). Тип сейчас извлекается из имени: `core/facets.js` `index()` → `_f.type`, список — `typeValues()` (:113). Иконки — `ui/cat-art.js` `TYPE_SETS` (:109) и `typeArt()` (:126). Плитки — `sections/stock-types.js` (card S artCover в tileGrid внутри `expand` категории), фишки шага «Тип» — `sections/stock-issue-card.js`, `sections/stock-ops-pick.js`.
- **Метод профи:** сначала прогнать все имена из TSV через `index()` (node-скрипт в `tools/` или тест) → таблица «тип → сколько позиций → семейство → иконка»: покрытие иконками = 100 % типов с ≥ 1 позицией; без совпадения — иконка семейства, без семейства — иконка категории. Семейство = первое слово типа, нормализованное (болт/болты → «Болты»; шайба гроверная/плоская/увеличенная → «Шайбы»; саморез/шуруп → «Саморезы и шурупы»…). Порядок семейств — по числу позиций (больше — выше), внутри — по числу позиций.
- **Внешний судья:** скрипт-отчёт `tools/logs/` или раздел в REPORT: число типов, % с собственной иконкой, % с иконкой семейства, 0 без иконки; юнит/node-тест на `typeGroups()`; блок «Иконки типов» в `#kit` показывает все иконки разом.
- **Смелая планка:** 100 % типов прода с иконкой; плитка типа по размеру = плитка категории (±0 px на 1024 и 390).

**Класс:** M (экран + kit-иконки, без сервера) · **Max agents:** frontend + designer · **Проверки:** smoke. **Язык менеджера:** да.

## Что сделать
1. **Размер:** найти, почему плитка типа больше плитки категории (вероятно, `tileGrid` внутри тела `expand` получает другую ширину колонки или `artCover` растягивается). Привести к тем же размерам, что у плиток категорий на `#stock`: решение — в kit (`tileGrid`/`card` S в expand), не своим CSS раздела.
2. **Группы:** в `core/facets.js` — `typeGroups(items)` → `[{ family, label, count, types:[{id,label,count}] }]` (правила семейств — таблица регулярных выражений рядом с `TYPE_SETS` или в facets; одна копия). В плитках `stock-types.js` — заголовок полки (эталон kit «подзаголовок секции» — какой уже есть) + плитки её типов. В фишках шага «Тип» (`stock-issue-card.js`, `stock-ops-pick.js`) — та же группировка: фишки семейства подряд, между семействами — подпись или разрыв (эталон funnel/segmented — что уже есть в kit; нового компонента нет). Семейство с одним типом — без заголовка, просто плитка.
3. **Иконки:** новый простой графический стиль: плоские пиктограммы, одна линия/заливка, единый цвет `currentColor` или токен, на прозрачном фоне, крупный узнаваемый силуэт (болт сбоку, гайка-шестигранник, шайба-кольцо, гровер — разрезное кольцо, саморез с острым концом, шуруп, анкер, дюбель, заклёпка, шпилька, винт, хомут, уголок, профиль, труба, лист, лента, кабель, клей, краска…). Набор покрывает все семейства из TSV; внутри семейства разновидности отличаются деталью (гровер ≠ плоская шайба, мебельный болт ≠ DIN933), где это возможно. Иконки — inline SVG в `ui/cat-art.js` (`typeArt` сохраняет сигнатуру), без внешних файлов и библиотек. Обновить блок «Иконки типов» в `#kit` (все иконки с подписями), DESIGN §4 — одна строка о стиле.
4. Пройти TSV: в отчёт — таблица семейств и покрытие (см. «Внешний судья»).
