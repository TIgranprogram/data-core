# C224 — входящие и настройки Пульта

- [x] Центральная карточка «Входящие» содержит только «Открыть входящие». При первом открытии используется локальная стандартная папка.
- [x] Точный путь, выбор папки, копирование и отключение доступны справа в настройках. Отключение сохраняет оригиналы и журнал. Фоновое чтение не создаёт удалённые папки.
- [x] Проводник повторно показывает скрытое окно. Два вызова для одной папки дали одно видимое окно.
- [x] Зелёный статус LM Studio появляется после реального ответа выбранной модели по схеме. Логин admin подставлен, пароль вводит пользователь.
- [x] Локальный прогон через Пульт с Gemma и двумя учебными PDF: читаемый в «Проверенных», повреждённый в «Сомнительных», входящие пусты. Отключение сохранило оригиналы.
- [x] Пройдены браузерные сценарии старта, остановки, возобновления, смены темы, сверки исходника, отмены и подтверждения. Приёмка внешнего вида на светлом и тёмном снимке.
- [x] Изолированная Mongo: 7/7 e2e. Прогоны Node: 55/55. На рабочий сервер запросов записи не было.
