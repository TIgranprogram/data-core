# ТЗ C041 Э2–Э3 — Гант для планирования, факт времени и себестоимость, нормы учатся сами

Старт — после слияния Э1 (`TZ-E1.md`). Решения — `DECISIONS.md`, модель — `ADVICE.md`.

**Зачем (пользователь 2026-11-07):** «Открыл Гант — вижу, как заказ распределён, занятость рабочих, распределяю задачи, меняю рабочего, переигрываю. Гант пересмотреть целиком: удобный подбор, распределение, фильтры, быстрая правка. Когда работы выполнены — в аналитике остаётся, сколько реально делали; в продукции хранится срок, правится вручную; новые заказы получают оценку сразу. Главная боль — себестоимость и сроки.»
**Зачем — глаголом:** мастер за 2 минуты раскладывает новый заказ по людям на неделю, видя перегрузку; через месяц изделие само предлагает реальную норму, а заказ — срок и себестоимость.

## Глубже
- **Результат:** планирование по шагам и людям; накопленная база факта → нормы → сроки и себестоимость.
- **Сырьё:** текущий Гант `backend/pwa/ui/gantt.js`, `work-plan.ts`, `worktasks`, табель `payroll_timesheets` (см. `AUDIT.md`); планы позиций из Э1 (`orderlineplans.steps[].assigneeId/plan`).
- **Метод профи:** планировщик цеха: строки — люди (ресурсы) или заказы (переключатель), полосы — шаги, перетаскивание = дата, перенос на другую строку = другой исполнитель, перегрузка подсвечена; факт — из отметок «начал/закончил» и табеля; норма = медиана факта последних N.
- **Внешний судья:** юнит на расчёт сроков (последовательность внутри части, параллель между частями, выходные), медианы нормы, себестоимости; e2e: назначить → сдвинуть → завершить → факт записан → изделие показывает «Фактически»; дизайнер; замер Ганта на 200 шагах < 300 мс отрисовки.
- **Смелая планка:** раскладка заказа на 5 позиций — ≤ 10 действий; переназначение — 1 перетаскивание.

**Класс:** XL · **Агенты:** backend (sonnet), frontend (sonnet, skill datacore-design), qa (haiku — прогоны), designer · **Проверки:** full.
