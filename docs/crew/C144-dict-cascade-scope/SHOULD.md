# Как должно: каскад типов паспорта в справочниках (C144)

Директор за одну минуту по одному типу видит, что предложат в паспорте, и где дыра. Те же правила режут списки в паспорте и в книжке материалов. На экране — слова. Латинские коды типов не показываем.

Источники: ТЗ C144 (пустое «кому» у материалов и покрытий = для всех; у частей = не в коротком списке); PRODUCT §5а; PASSPORTS-V2 §3.1–3.5; QUESTIONS П1, П2, П4, Т-14; PATTERNS П-1. Код не смотрел.

## Сценарий директора

1. Открывает «Справочники → Паспорта» и выбирает тип словами: «Благоустройство» или «Воркаут».
2. Сразу видит четыре ответа: какие части, какие материалы, какие покрытия и какие тексты этому типу предлагают.
3. Видит дыры: короткий список пуст или у включённого раздела нет текста.
4. Нехватающий тип добавляет названием. После сохранения тип можно ставить в «Кому предлагают».
5. Пока к новому типу ничего не привязано, в справочнике написано «ничего не предлагается». В паспорте короткий список пуст, рядом «Показать все».

Менеджер в паспорте только выбирает из уже предложенного. Привязку «кому предлагают» и новые типы правит директор.

## Правила словами

- Тип паспорта — вид изделия для документов: какие части, материалы, покрытия и тексты предлагать. Полка каталога — другое. Списки режет тип паспорта.
- «Часть» паспорта (стойка, перекладина в описании) — не деталь, которую делают в цехе.
- Колонка «Кому предлагают» всегда видна у материалов, частей и элементов.
- У материала и покрытия пустая привязка на экране читается «Для всех»: строка есть в коротком списке каждого типа. Пустую клетку не оставляем — её примут за дыру.
- У части и у элемента пустая привязка читается «Только „Показать все“»: в коротком списке выбранного типа их нет.
- Несколько типов в колонке — строка есть в коротком списке каждого из них и отсутствует у остальных.
- «Показать все» показывает остальное с пометкой «не для этого типа». Выбор оттуда попадает в этот паспорт. Сам выбор не дописывает тип в «Кому предлагают». Дописать может директор.
- Покрытие в списке части есть, если оно для этого типа (или «Для всех») и относится к этой части. Чужие покрытия этой части не показываем. Иначе снова «все покрытия сразу».
- Текст «Для всех» есть у каждого типа. Свой текст типа встаёт на место общего пункта. Дальше текст сужается частью, материалом и способом установки.
- Смена типа у черновика пересчитывает списки. Уже выбранное, которое типу не подходит, остаётся с пометкой «не для этого типа» и ждёт решения. Само не стирается.
- Выданный паспорт от правки справочника не меняется.
- Подвиды благоустройства (ограждение, навес) — не новые типы. Их отличают части и элементы внутри «Благоустройство». Детское игровое и детское спортивное — два типа.
- Для благоустройства дыра по тексту — нет описания, монтажа, гарантии или срока (ни своего, ни «Для всех»). Отсутствие обслуживания и правил дырой не считаем.

## Порядок: главное → следующее

Каждый следующий список уже отсечён предыдущим. Весь справочник подряд не показываем.

1. **Тип паспорта** — главное.
2. **Части** этого типа (короткий список).
3. **Материалы** — свои для типа и «Для всех».
4. **Покрытия** — у этой части, свои для типа и «Для всех».
5. **Тексты** — «Для всех», затем свой пункт типа на том же месте, затем условие по части, материалу и установке.

В паспорте тот же порядок. Очевидный единственный вариант подставляется и помечается. Ручной выбор главнее.

## Если … то …

- Если директор выбрал «Благоустройство», то видит части, материалы, покрытия и тексты этого типа и отдельно дыры.
- Если выбрал «Воркаут», то набор другой, не копия благоустройства.
- Если у материала или покрытия «кому» пусто, то в колонке «Для всех», и строка есть в коротком списке любого типа.
- Если у части или элемента «кому» пусто, то в колонке «Только „Показать все“», и в коротком списке типа их нет.
- Если в колонке названы типы словами, то короткий список паспорта и книжки содержит строку только для этих типов.
- Если директор смотрит покрытия у части, то видит покрытия этой части для текущего типа и «Для всех», не весь справочник покрытий.
- Если покрытие ни к одной части не относится, то в общем списке типа оно с пометкой «не у части», а в коротком списке части его нет.
- Если на экране справочника, паспорта или книжки, то латинских кодов типов нет.
- Если типа в списке главных нет, то директор добавляет его названием, без кода. После сохранения тип есть в «Кому предлагают».
- Если у типа нет ни одной части в коротком списке, то в справочнике дыра «нет частей», в паспорте список пуст с подсказкой добавить части, и есть «Показать все».
- Если сменили тип черновика и выбор больше не предлагается, то значение остаётся с пояснением и просит решение.
- Если паспорт уже выдан, то правка «кому предлагают» его не меняет.
- Если подвид благоустройства, то отдельный тип не создаётся.
- Если полка каталога и тип паспорта называются по-разному, то списки режет тип паспорта.

## По умолчанию

- На экране «Благоустройство», не код и не старое «МАФ». Скрытый код не переименовываем: это отложено (Т-14).
- Пустое «кому» у элементов — как у частей: не в коротком списке. В ТЗ это прямо сказано для частей; для элементов принято так же, чтобы горка не предлагалась всем типам. Пустую привязку не читаем как «Для всех».
- «Для всех» у материала — все типы паспорта, не все части. В список части покрытие попадает только вместе с этой частью.
- Выбор из «Показать все» не меняет справочник.
- Новые обязательные разделы, кроме уже решённых для благоустройства, не выдумываем. Дыра текста — включённый раздел типа без своего текста и без «Для всех».
- Общие с CRM таблицы и смысл пустого «кому» у материалов не переворачиваем.

Вопросов владельцу нет: спорное закрыто допущением выше. Техническую карту каскада делает архитектор.
