# C101 — печать паспорта: без пустых листов, рисунки по центру (2026-11-13)

Класс: M. Замечания пользователя по паспорту № 603 «Стелла».

| Замечание | Сделано |
|--|--|
| ИНН на обложке не нужен | `passport-pdf-v2-cover.ts` — строка контактов без ИНН/КПП |
| Плашка категории («Благоустройство») не нужна | обложка — только знак возраста |
| «Коротко об изделии» — пустой лист | `shortPage` считает высоту; `layout` — основной текст сразу под блоком |
| Пустые листы в буклете | добивка до кратности 4 — листы «Для заметок» с линейками |
| Рисунок приложения мелкий, не по центру | лист делится на фактические ряды; высота по пропорциям; ряды по центру листа |
| Строка «Габаритные размеры (Д × Ш × В)» на рисунке | печатается подписью из размеров изделия; `tools/passport-images.iLogicVb` её больше не рисует |
| Буклет печатался «вверх ногами» | подсказка в окне печати: с двух сторон, переворот по короткому краю |
| Нет ФИО директора в талоне | код берёт `directorName` компании; у «СпортИН-ЮГ» и «СпортСтройЮг» на проде поле пустое → заполнить в карточке («Для паспортов (наша компания)») |

Проверка: юнит паспортов PDF 46/46; образец «Стеллы» отрисован (evidence). Полный юнит — после C100 (идёт параллельно).
