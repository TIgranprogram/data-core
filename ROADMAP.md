## Где мы (2026-10-18)

- **Единая база** `datacore` (MongoDB 4.4 rs0, `--auth`) на Synology VM — одна для всех клиентов:
  - CRM **kppdf** (`https://kppdf-crm.ru`) работает с ней напрямую;
  - таблицы, скрипты, новые приложения, ИИ-агенты — через **API data-core** (`https://kppdf-crm.ru/db/api`, ключ `kppd_`).
- API: платформенное ядро + канонические справочники + универсальное хранилище `/api/apps/:app/:collection`; ключи с правами (read / write / full + приложения); единый `id` в ответах.
- Админка `https://kppdf-crm.ru/db/admin/`: пользователи, API-ключи, таблицы.
- Бэкапы: VM ежедневно 03:00 (14 дней) + копия на Windows-ПК (`D:\datacore-backups`, 30 дней). Restore-дрилл пройден.
- Документация для агентов: `AGENTS.md` → `docs/MAP.md`, `docs/ARCHITECTURE.md`, `docs/CONNECT.md`, скиллы `.claude/skills/`.
