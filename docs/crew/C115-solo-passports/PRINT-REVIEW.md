# PRINT-REVIEW — PARTIAL

Poppler отрисовал 7 логических страниц A5, 7 страниц образца с рисунками в тексте, 4 стороны буклета A4 и один лист stand A3. Просмотрены обложки, расположение таблиц, рисунков и талона, добивка буклета. Подробности и ограничения в [сценариях](SCENARIOS.md). [Обзор рендеров](evidence/pdf-contact.png).

Для проверки на бумаге открыть [буклет A4](evidence/passport-v2-print-A4.pdf), выбрать A4, альбомную ориентацию, масштаб 100%, двустороннюю печать с переворотом по короткому краю. В драйвере выбрать одну страницу на сторону и отключить режим «Буклет». Сложить листы и проверить порядок чтения и верх обеих сторон. Для короткого паспорта повторить с его файлом «Для печати». Физический прогон короткого и длинного образца открыт.
