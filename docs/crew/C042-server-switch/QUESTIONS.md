# C042 — вопросы пользователю

1. Старая программа kppdf (CRM) на домашнем сервере нужна каждый день? Она пишет в ту же базу и не замирает при переключении. По умолчанию: на время переключения её выключаем.
2. Устроит ли «только чтение» до 10 минут при переключении и потеря последних до 15 минут работы, если домашний сервер умрёт внезапно? По умолчанию: да.
3. Какая ночь подходит для учебного переключения туда и обратно? По умолчанию: ближайшая, вы пишете «сейчас».
