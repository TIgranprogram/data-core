# C219 — браузерная приёмка

Браузер Chromium, приложение текущего checkout и обезличенная фикстура API. Два сценария прошли полностью.

| Тема и ширина | Проверка | Итог |
|---|---|---|
| Светлая, 1920 px | Доходы, расходы, группы, подстатьи и операции на четвёртом уровне. Ноябрьская сумма открывает ноябрь, стрелка статьи открывает весь отрезок. После раскрытия URL и дерево сохраняются. Escape и «Свернуть всё» закрывают вставку. Статический итог без подсветки. Заказчик → заказ даёт точный документ. | PASS, [отчёт](evidence/articles-light-1920.png) |
| Тёмная, 1440 px | Компактный переключатель, запрос со всеми тремя фильтрами. В «Платежах по дням» пустой день отсутствует, дата раскрывается клавишей Enter, соседняя дата сворачивает предыдущую. | PASS, [платежи](evidence/daily-dark-1440.png) |

На снимках проверены отступы каскада, контраст групп и сумма с акцентом только при наличии раскрытия. Операции и итог различаются по назначению. Сценарии на копии данных проводят в локальном контуре, запись в рабочую базу для этих проверок не требуется.

Открытая панель, тёмная тема, 1440 px. Обе даты помещаются в одну строку, ширина полей совпадает. [Снимок фильтров](evidence/filters-dark-1440.png). На локальной копии проверены три фильтра и раскрытие 195 операций без смены адреса.
