# ТЗ C261 — Карточка материала через API (срез 2)

**Программа:** [C259 PLAN-SLICES](../C259-crm-api-client-plan/PLAN-SLICES.md) · после L-260  
**Класс:** L · **Max agents:** 2 · **Проверки:** smoke; full перед выкладкой  
**Старт:** 24.11.2026 — владелец «давай»

## Зачем
Перевести запись **карточки** `materials` (имя, артикул, единица, категория, цена, размеры; **не** остаток) на хозяина API. CRM после включения флага не пишет карточку в Mongo.

## Что сделать
1. Убедиться: create/patch/archive карточки уже через `stock-writes` / `stock-owner-port` / `MaterialService`.
2. Флаг `c261.materials.card.api` (сид, **выкл**): выкл → запись карточки через API даёт 409 (как C260); вкл — API хозяин. Остаток/`storageitems`/движения **не** трогать.
3. Не блокировать чтения и сценарии, которые не карточка (цена как история — по смыслу карточки; quantity — нет).
4. REPORT: места записи kppdf materials (только чтение списка). Не править kppdf.
5. tsc + jest material / stock-writes затронутого.

## Критерии
- [x] Флаг выкл → 409 на create/patch/archive карточки; GET без изменений
- [x] Запись только через хозяина; quantity/reservations не в этом срезе
- [x] smoke зелёный

## Нельзя
- C262–C265; выкладка без «да»; снятие Mongo `readWrite` у kppdf; остаток склада
