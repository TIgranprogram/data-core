# C241 — выбор способа установки в Inventor

Явное требование владельца 23.11.2026: при отправке картинок паспорта выбирать способ установки прямо в iLogic, чтобы не получать 409 при незаполненной карточке. Класс L: аддитивный API и правило Inventor, стандарт паспортов сохраняется.

Читать: EXPLORER.md этой задачи, docs/PASSPORTS-STANDARD.md, существующие C172/C179/C188 по необходимости; перед кодом — архитектурная политика применимых экземпляров.

Точная дельта: context возвращает текущий выбор и поддержанные живые варианты справочника с применимостью третьего рисунка/глубины; optional confirmed.installationTypeId в существующем POST. Старый клиент без поля сохраняет прежний контракт. Новый VB показывает понятный выбор до UploadPng; отмена не делает записей. Не выбирать способ по рисунку/названию автоматически, не вшивать ID справочника в VB.

Подтверждённый выбор сохраняется вместе с изображениями и применимыми редакциями одной транзакцией, с существующей защитой stale context/CAS/idempotency. Отдельный PATCH перед импортом запрещён. Учесть приоритет legacy installationTypeId над defaults. Не подменять монтажную схему у экземпляра с другим способом; политика существующих/готовых/закрытых паспортов должна быть явно принята архитектором до реализации. Старые PDF, номера, снимки и история сохраняются (ПС-05/07/10); анкеры и бетонирование получают правильный вид третьего рисунка по ПС-04, неприменимая глубина не записывается.

Зоны: backend — DTO/context/import service и адресные unit/e2e, MAP/data-model/openapi; frontend — каноническое backend/pwa/ilogic/passport-images.iLogicVb, существующая книжка только при необходимости и её тесты. Не переписывать остальные разделы паспортов. Пример ошибки относится к product6b03d02fb607f46540f3a892, установка для него не угадывается.

Приёмка: неизвестный/удалённый ID отклонён без изменений; выбор до загрузки, cancel=0writes; анкеры/бетон; наследованный и явно отличный способ существующего экземпляра; готовый PDF и закрытый паспорт; конфликт контекста и повтор; rollback всего импорта; текущие клиенты без нового поля. Полный отчёт и ограничения проверки Inventor записать отдельно. После принятия кода — действующий пункт Пульта для обновления iLogic (не дублировать уже существующий).
