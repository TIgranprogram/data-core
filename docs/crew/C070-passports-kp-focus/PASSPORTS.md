## 4. Где поможет ИИ

**Что есть в коде.** В рантайме data-core (`backend/src`, `backend/pwa`) подключения к ИИ **нет** (grep: только `devlog/kit-prompt.ts` — промпты для внешних исполнителей). В `tools/`: `ai-tester` (проверка сайта локальной моделью) и `local-ai-order` (заказ из писем, локальная модель). Владелец отказался от локальной модели (2026-10-23). Подключать нечего — нужен ключ внешнего сервиса, расход и решение владельца (вопрос 1).

**Сначала правила, потом ИИ.** Правила по названию уже дают 85–94 % (признаки TRN/WRK) и 417 из 476 (назначение). ИИ нужен на остаток и на текст.

| Место | Вход → выход | Польза | Риск | Подтверждает | Кнопка в воронке |
|--|--|--|--|--|--|
| Черновик назначения и описания | Название, группа, признаки, фото → 1–2 предложения «Предназначено для…» | Закрывает 59 вручную + новые | Выдумает свойства (возраст, нагрузка) | Менеджер правит и сохраняет как «свой текст» (C060) | «Предложить текст» в разделе «Назначение» |
| Категория и признаки | Название + фото → категория, признаки с вероятностью | Новые изделия (не по словам) | Неверная категория → неверные обязательные поля | Менеджер: «Похоже: … — верно?» | Шаг «Группа» / «Новое изделие» |
| Габариты и вес из чертежа | Картинка/PDF чертежа → длина, ширина, высота, вес | Для изделий без PDM; сейчас 52 % без размеров | **Высокий:** числа попадают в паспорт (ТР ЕАЭС), ИИ ошибается в единицах | Менеджер сверяет с чертежом рядом; в паспорт — только после «Верно» | «Прочитать с чертежа» рядом с загрузкой |
| Проверка текста на пропуски | Собранный текст паспорта → список «не вписано», странные места | Дешёвая, делает то же, что `passport-blanks.ts`, + смысл | Лишние замечания | Менеджер игнорирует/правит | «Проверить текст» перед выпуском |
| Материалы из названия/описания | Строка «труба 89×3, лист 4» → строки таблицы | 262 пустых | Неверный сортамент | Менеджер сверяет таблицу | В техописании |

Правила для всех: ИИ только предлагает, пишет в изделие **после** нажатия менеджера; персональных данных заказчика в запрос не отправлять; ответ с пометкой «предложено ИИ» до подтверждения; числа — только из чертежа/PDM, не «додуманные».
