# Программа архитектуры data-core (расширенное ТЗ)

**Владелец решения:** пользователь · **Координатор:** ведёт очередь · **Архитектор:** границы и замки · **Backend:** этапы кода

## Цель

Надёжный модульный монолит с хозяевами доменов: фичи добавляются, архитектура не разъезжается, закрытое не переделывают по ошибке.

См. [LOCKS.md](LOCKS.md). Закрытый `[x]` + REPORT = замок. Новый агент не «улучшает» замок без дефекта в ТЗ.
