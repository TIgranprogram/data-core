# C209. Редактирование КП на листе A4

22.11.2026, **PASS** для проверенных компьютерных сценариев. Временное приложение `127.0.0.1:62066`, Nest со строгой валидацией, отдельный MongoDB 4.4 `rs0`, база `datacore-test-c209-browser`. Фикстура из двух вымышленных фирм, бланков и трёх позиций, включая рисунок скамейки. Из пакета редактировали одно отправленное КП. Исходное состояние сохранилось в истории, второй документ полностью совпал с первоначальным ответом API.

Версия `a705cbb6` с правками C209 в `backend/pwa/sections/offers/editor*.js`, `backend/pwa/ui/kit/offer-editor.css`, `backend/src/modules/offers` и e2e КП. Другие изменения рабочего дерева в проверку не входят.

| Действие | Что проверено |
|---|---|
| Двойной щелчок по дате и цене на листе | У даты появилось поле календаря. Дата изменилась на 20.11.2026. Цена `1540,25` принята и дала `3 080,50 ₽` за две скамейки. API до сохранения вернул исходную цену. |
| Щелчок по фото и таблице, перетаскивание угловой и боковой ручек | Изображение выросло до 36 мм. Ширина таблицы уменьшилась до 174 мм. Настройки сохранились вместе с КП. |
| Перетаскивание ручек на листе | Доставка встала перед скамейкой, условия перед таблицей. Этот порядок сохранился после повторного открытия. |
| «Добавить позицию» | Видимая кнопка открыла поле названия на листе и передала ему фокус. Добавилась стойка за `233,50 ₽`. В сохранённом КП четыре позиции, итог `4 164 ₽`. |
| «Добавить текст», правка двойным щелчком, Delete | Поле появилось поверх листа и приняло текст. Escape отменил ввод, отмена подтверждения оставила текст, подтверждение удалило его. `Ctrl+Enter` применил правку другого текста, после повторного открытия на листе осталась версия про гарантию 18 месяцев. |
| Разрыв страницы, «Далее», Enter | Появились два листа. На втором листе Enter открыл цену урны, Escape закрыл поле без изменений. |
| «Скачать PDF», сохранение, повторное открытие и «Печать» | Штатная кнопка напечатала через виртуальное устройство Google Chrome «Сохранить как PDF». У всех трёх документов две страницы A4 595,28 × 841,89 pt. Poppler при 110 dpi дал пиксельно одинаковые пары страниц. |

Проверены и просмотрены заполненные состояния. Светлая тема 1920 × 1080, центральная панель 1208 px, лист в режиме «Лист целиком» 614 px с равным отступом 297 px. Тёмная тема 2560 × 1440, та же центральная панель, лист 869 px с отступами по 170 px. Ручки видны на белом листе, активные поля различимы, верхняя полоса и боковые панели остаются доступны. Во время ввода кнопки сохранения и печати отключены до применения или отмены правки.
