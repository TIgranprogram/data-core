# C208. Редактор коммерческого предложения

Из карточки отдельного КП открыть окно по образцу книжного редактора паспорта. В центре просмотр фактического номерного PDF, слева состав и навигация, справа параметры выбранной строки или блока. Правки сохраняются в выбранном КП штатной операцией и сохраняют пакеты и историю. Печать из того же файла.

- [x] Общая подготовка правок для номерного предпросмотра и сохранения, выбор бланка по фирме, защита от перезаписи соседней правки.
- [x] Разрыв перед строкой, порядок текстовых блоков и таблицы, ширина таблицы, размер фотографий и минимальная высота строки. Раскладка измеряется в PDFKit. Для длинных таблиц повторяется заголовок.
- [x] Заказчик, условия, позиции, ручная цена и наценка на изделия, отдельная классификация доставки.
- [x] Проверить сохранение, повторное открытие, масштабы просмотра, две страницы A4 и совпадение с виртуальной печатью.
- [x] Добавить ручную и каталожную позицию, подтвердить удаление обычной строки, проверить копейки и сохранность юридических строк и соседних КП.
