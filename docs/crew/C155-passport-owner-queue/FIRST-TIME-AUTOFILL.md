# C155 · Первое заполнение краткого описания

- Если в кратком шаблоне есть тип паспорта, но отсутствуют вид и источник описания, действие «Краткое описание» открывает выбор вида. Поля уже известного вида повторно не запрашиваются.
- После выбора и сохранения вида сервер заново разрешает словарный текст. Несколько применимых вариантов дают следующий шаг выбора. Единственный готовый текст сразу отображается в книге.
- Если справочник не дал готового текста или вариантов, показать причину и переход в существующий справочник. «Своя формулировка» открывает отдельный необязательный редактор с поиском частей.
- Регрессия первого заполнения · шаблон вида 1066 без `kindId` и источника, переход из списка обязательного, выбор вида, выбор фразы, готовность и повторное открытие. Отдельно проверить явное открытие своей формулировки и отсутствие словарного покрытия.

## Реализация

- «Сначала → Краткое описание» открывает «Вид изделия» в правой колонке. «Сохранить в шаблон» записывает `kindId` и пересчитывает следующий шаг по ответу существующего API.
- Если однозначный источник уже найден, текст сразу виден на листе. При единственной неподтверждённой конструкции показываются готовая фраза и кнопка «Подтвердить вариант». При нескольких — «Вариант краткого описания» и «Применить вариант». Сохранение записывает выбор словарной фразы, связанный состав берётся из справочника. При открытом шаге второй выбор той же фразы скрыт.
- При отсутствии готового текста справа появляется причина и ссылка на справочник в новой вкладке. Явное действие «Своя формулировка» подставляет уже видимый текст и его части, если они есть. Сохранение собственной фразы требует отдельного нажатия. В редакторе видны выбранные части и поиск добавления с приоритетом частей словарной фразы и короткого списка текущего типа.
- Проверки · 15/15 целевых регрессий на моделируемых ответах, 347/347 PWA guards, ES-синтаксис всех изменённых модулей, 352 импорта без ошибок, design-lint 0 новых. Браузерный сценарий с исходным пустым видом и две темы переданы на стенд в `FIRST-TIME-AUTOFILL-QA.md`.

Замечание владельца «почему своя формулировка обязательна»: обязательность относится только к явному сохранению непустого ручного переопределения. Самостоятельно писать текст для создания паспорта не требуется: основной путь подставляет словарное описание. Старый экран с обязательным ручным стартом заменён. На визуальной приёмке обнаружено обрезание вида в половине form-grid; одиночный select получил штатный `wide:true`, без CSS исключений.
