# C203 — добавление позиции заказа

Две одинаковые кнопки добавляли позицию в один и тот же договор. Оставлена одна кнопка в пустой группе договора. Для нескольких договоров кнопка подписана номером договора, для заполненных вход остался в меню «⋯». Если есть только отменённые позиции, группа по-прежнему позволяет добавить действующую позицию при наличии права.

Edge, тёмная тема, локальный заказ № 22-26: одна кнопка «+ Позиция» видна внутри таблицы. Клик открывает форму с указанным договором. Режим браузера — чтение. [Снимок](proof/22-26.png). Проверены границы прав, договор с позициями и заказ с несколькими договорами на учебных данных.
