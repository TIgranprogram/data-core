# C094 — C086-TEXT: тексты паспортов подходят к изделию

Класс: L (данные прода — только чтение) · агентов: 1 (datacore-analyst, sonnet) · запись на прод: нет.

## Суть
Задача `docs/TASKS.md` «C086-TEXT». Владелец хочет выпускать паспорта всем изделиям. У указателя в PDF остаются чужие фразы: зона безопасности, анкеры, поручни. Нужен план правки условий текстов.

## Сделать
1. Прочитать действующие тексты из БД прода (не JSON кода): `bash deploy/synology/api.sh prod GET /api/…` — справочники текстов паспортов, версии ALL_V2 и по категориям (BLG, WRK, TRN, DIO, DSP). Где лежат — `docs/MAP.md` (passports, passporttemplates), `docs/PASSPORTS-V2.md`.
2. Для 4 эталонов — указатель (заказ 11-26, строка 3), скамья, ограждение, игровой комплекс — собрать, какие пункты попадут в PDF, и отметить неподходящие (пункт · почему · какое условие нужно: категория / признак / элемент).
3. Пройти все категории: таблица «пункт текста → к каким категориям/признакам применим».
4. План правки: только условия применимости (не формулировки требований безопасности); новая версия текста, пользовательские тексты не теряются, выданные паспорта (issued-снимки) не меняются. Нормативные ссылки — отдельным списком «проверить».
5. Источники до этого: `docs/crew/C086-passports-owner-review/TEXT-REVIEW.md`, `POST-RELEASE.md`.
