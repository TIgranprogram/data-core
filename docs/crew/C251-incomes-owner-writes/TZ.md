# ТЗ C251 — Хозяин-операций incomes

**Программа:** [C246/CHECKLIST](../C246-architecture-modularity/CHECKLIST.md) · этап 5  
**Зачем:** чужие места пишут в доходы мимо хозяина.  
**Класс:** M · **Зависит:** C250 · **Проверки:** tsc + юнит incomes + затронутых; smoke списков доходов

## Что сделать
1. **До кода:** закрепить текущее поведение тестами ключевых операций (создание/правка, **отмена**, **частичный сбой** / повтор).
2. По INVENTORY — список писателей `incomes` (включая Mongoose/`bulkWrite`/скрипты/админку).
3. Каждый писатель → метод **бизнес-операции** хозяина (не голый `update`): правила, при необходимости сессия Mongo, аудит, идемпотентность/повтор — описать в REPORT на операцию.
4. Пачками ≤ 3 писателя за коммит при зелёных проверках.
5. HTTP-контракт не менять.

## Критерии
- [ ] тесты «до» зафиксированы
- [ ] чужих сырых записей incomes вне хозяина = 0
- [ ] юнит + smoke; без C252 приложение работает
- [ ] REPORT: таблица операций (транзакция / аудит / повтор)

## Нельзя
- Параллельно переписывать salesorders/products.
- Выкладывать при красных тестах.
