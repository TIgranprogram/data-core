# C138 — только актуальный паспорт, справа перед «Кол-во»

Дата: 2026-11-17. Класс: M.

## Запрос владельца
В «Позициях» заказа 11-26 под названием шли `601`, `601~2`, `601~1`. Нужна одна последняя версия; номер — справа перед «Кол-во».

## Сделано
- `primaryPassport`: не показывает `annulled` и номера с `~` (история C060).
- В строке и в «Документах» — один актуальный паспорт.
- Колонка перед «Кол-во» (`salesorders.js` `positionsPane`).

## Не трогали
Аннулированные `601~1` / `601~2` в базе остаются (нужны для повторного выпуска номера). Чистка «макс. 1 предыдущая» — отдельное серверное задание + «да» на прод.

## Проверка
`node --input-type=module --check` по изменённым файлам. Глазами на стенде/проде после выкладки.
