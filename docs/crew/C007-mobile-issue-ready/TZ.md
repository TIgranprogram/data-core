# ТЗ C007 — Выдача со склада на готовые заказы (телефон)

**Зачем (словами пользователя):** На телефоне кладовщика при выдаче «На заказ» видны только текущие заказы. Часть заказов уже «Готово», но на позицию ещё нужно выдать материал и отправить. Нужен доступ к готовым: выпадающий список внизу → готовые заказы/позиции → выдача фиксируется на эту позицию.

**Класс:** M · **Агент:** Cursor (frontend) · **Reviewers:** designer если новый UI · **Проверки:** smoke

## Shared pack

- Экран: `backend/pwa/sections/stock-mobile.js` → `stepOrder` (сейчас `ordersLookup({ filter: 'active' })`).
- Lookup: `GET /salesorders/lookup?filter=…` — `backend/pwa/core/orders-lookup.js`; сервер — модуль salesorders.
- Не менять API контракт списков; при необходимости расширить `filter` (например `active,ready` или отдельный вызов `ready`) без ломки других потребителей.

## Что сделать

1. В шаге «Заказ и позиция» основной список — как сейчас (активные в работе).
2. Внизу экрана (или после списка) — раскрывающийся блок «Готовые к отгрузке» (этап `ready` / позиции готовы): по нажатию показывает заказы/позиции, на которые ещё можно выдать.
3. Выбор позиции работает так же: `salesOrderLineId` (предпочтительно) или заказ; запись через существующий `/stock/batch` type `out`.
4. Пустое: «Готовых заказов нет» с короткой подсказкой.
5. Язык менеджера, эталоны kit mobile (без новых section-CSS).

## Критерии приёмки

- [ ] Активные заказы по-прежнему сверху / в основном drill.
- [ ] Готовые доступны вторым контуром (выпадающий список / details).
- [ ] Выдача на готовую позицию уходит с `salesOrderLineId` и видна в истории заказа.
- [ ] 390 px: кнопки ≥44px, без горизонтального скролла страницы.
- [ ] node --check / import-check; при правке сервера — юнит lookup.

## Нельзя

- Прод-данные чистить; схемы CRM ломать; отдельное приложение.
