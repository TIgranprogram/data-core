   - `src/modules/showcase/showcase.service.ts` (702) — состав (`composition*`, себестоимость), массовые действия (bulk) — отдельно.
   - `src/modules/product-passport/passport-pdf-v2.ts` (700) — разметка разделов PDF / таблицы / общие помощники — по файлам.
2. `compositionSimilar` (showcase): кэш через `DataVersionService.cached` (`src/common/data-version`) по коллекции `products` и ключу id; плюс `limit` на выборку соседей (например 500 последних по `_id`).
3. Мелочь из SPR-1 (если ещё не сделана в SPR-2 — проверь `git log`): кэш `DataVersionService.cached` для списка справочников металла (`dict_values`, `materials`).

## Часть Б — frontend
1. `pwa/sections/passports.js` (1077) — разрезать на файлы по смыслу (список/галерея, карточка, форма, выпуск `issuePassport`, массовые действия) в `pwa/sections/passports/` или `passports-*.js`; внешний импорт (`issuePassport` и т. п. из других разделов) не ломать. Не забыть `modulepreload` в `pwa/index.html` (скорость С5) и список кэша `sw.js`, если там перечислены модули.
2. Склад целиком (`/stock/items?limit=10000`) сейчас грузится при открытии экранов: `sections/composition.js:24`, `item-orders.js:68`, `ops.js:323`, `requests.js:101`, `ui/facet-filter.js:33`. Сделать один общий кэш склада `core/stock-list.js` (`stockList()` → промис, один запрос на всё приложение; сбрасывать после изменений склада — приход/списание/правка позиции — и по времени, например 5 мин) и звать его **по действию** (фокус поля выбора позиции, открытие «Фильтров», «Добавить строку»), а не при открытии экрана. Признак загрузки — «Загружаю…» (как `f.load` в `ui/form.js`).
3. Телефон: галочки `.pick-cb` в карточках списка — зона касания 24 px → обёртка-label с отступом до 44 px, как `.gc-pick` в галерее (`ui/base.css`).
