## Общие правила панели
1. Отступы — только токены: между блоками `--s4` (16), внутри карточки `--s3` (12), между кнопками `--s2` (8).
2. `.drawer-body` — flex-колонка с gap `--s4`; у блоков своих margin нет.
3. Любой блок панели — карточка (`readonlyGroup`, `section()`, `card()`, `.so-grp`, `k-card-table`); `.section-title` без рамки в панели запрещён.
4. Ряд действий один (`kit.actions()`), gap 8 px, видимых ≤ 3 (одна главная); остальное — `more:true` в «⋯». Переходы («Заказы с этим изделием») — связи-карточки, не кнопки.
5. Вложения — одна секция; категории свёрнутыми строками «Чертежи · 2 ›».
6. Пустой блок — одна строка ≤ 48 px; подсказка — в раскрытой части/title.
7. Секции по умолчанию закрыты, кроме главной; счётчик в шапке; открытое состояние сохраняется.
8. История — последний блок, всегда свёрнут.
9. Группы полей — `readonlyGroup`.
10. Таблицы — в карточке, пустая таблица — строка.
