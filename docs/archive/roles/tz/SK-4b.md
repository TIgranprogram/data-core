# ТЗ SK-4b — «Склад» одной страницей (интерфейс)

**Зачем (словами пользователя):** открыл «Склад» — понял, что делать: крупные «Принять / Выдать / Забронировать», остатки с бронью и свободным, что заканчивается — сверху; без трёх вкладок.

**Роли:** frontend ☑ (по skill `datacore-design`) · designer ☐ (после)

## Что сделать (чек-лист SK-4 и критерии «Аналитика SK-2» §6 SK-4 в `docs/roles/tz/SKLAD.md`)
1. Раздел «Склад» (`sections/stock.js`): сверху кнопки «Принять», «Выдать», «Забронировать», «ещё ▾» (Списать, Пересчитать) — каждая открывает правую панель (существующие формы из `ops.js`, `issue.js`, `reservations.js`, `movements.js` — переиспользовать, не копировать). «Несколько позиций» — режим внутри «Принять» и «Выдать» (сегодняшние «Операции»).
2. Список остатков: колонки остаток / в брони / свободно (`quantity`, `reservedQty`, `free` — уже в ответе `GET /stock/items`); по умолчанию `?priority=1` («заканчивается» и «в брони» сверху).
3. Карточка позиции: последние 5 записей истории (`GET /stock/items/:id/history?limit=5`) + «вся история» (без limit); те же кнопки действий.
4. Меню: убрать пункты «Операции» и «Движения» из меню (`main.js` NAV / side-group «Склад»); старые адреса `#ops`, `#movements` открывают «Склад» с нужной панелью / журналом (не 404). Журнал всех движений — ссылка «Вся история» со страницы «Склад».
5. Списки вариантов грузятся по нажатию (не при открытии страницы). Запись в `docs/DESIGN.md` §8.

## Файлы
- В рабочей копии ожидаются правки: `backend/src/**`, `docs/openapi.json`, `docs/MAP.md`, `docs/UNIFY-SUPPLY-WAREHOUSE.md` (backend, SK-5a) — не трогать.
- читать: `docs/roles/README.md`, skill `datacore-design` → `docs/DESIGN.md`, `docs/CANON.md` §2–3, `backend/pwa/main.js`, `sections/stock.js`, `ops.js`, `movements.js`, `issue.js`, `reservations.js`.
- менять: `backend/pwa/**` (только склад и меню), `docs/DESIGN.md`.

## Критерии приёмки
- [ ] Три кнопки + «ещё» — всё в правой панели, не в окне.
- [ ] В остатках видно остаток / в брони / свободно; заканчивается и в брони — сверху.
- [ ] В карточке — последние 5 и «вся история».
- [ ] `#ops`, `#movements` не дают пустой экран/404; в меню их нет.
- [ ] «Несколько позиций» в «Принять» и «Выдать» работает как сегодняшние «Операции» (одна пачка, отмена пачки).
- [ ] `node --input-type=module --check < файл` для каждого изменённого .js; `npx jest src/pwa-guards --silent` зелёный.

## Нельзя
- Трогать сервер; новые виды окон без записи в DESIGN; удалять формы, которые используются в других разделах.
