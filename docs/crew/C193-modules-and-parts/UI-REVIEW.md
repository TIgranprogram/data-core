# C193 — фотографии и вхождения

**PASS на браузерной фикстуре и при сверке двух записей через API копии.** В коде текущей рабочей копии проверены разделы «Детали» и «Модули». Edge, средняя тема, 1920/2560/3440 × 1080. Адрес фикстуры http://127.0.0.1:41731/app/. Playwright подставляет вымышленные записи и изображения через HTTP. На локальной копии :3102 выполнялись только GET штатной QA-учёткой.

| Запись на локальной копии | Фото | Где используется |
|---|---|---|
| Модуль | В списке и карточке есть один ID фото, задано главное. GET фото вернул метаданные со ссылкой. | Одно вхождение в изделие. |
| Деталь | В списке и карточке есть один ID фото, задано главное. GET фото вернул метаданные со ссылкой. | Шесть вхождений всего. В первых пяти строках тип родителя — модуль. |

Отрисовка этих двух записей и ограничения обычной роли на копии остались за пределами проверки. Файлы фотографий на копии не запрашивались.

Списки используют общую миниатюру с раскрытием по клику. В карточках общая карусель начинает с главного фото, другие снимки и превью доступны в ленте. Импорт PDM записывает PNG/JPEG в photoIds/mainPhotoId и сохраняет главное фото менеджера. Если карточка модуля получила только ID, приложение читает данные снимка через существующий GET /photos/:id. Повтор того же ID не вызывает второй запрос. Карусель и миниатюра берут изображения из локального каталога загрузки. Закрытые файлы PDM и вложения остаются за штатным контролем доступа. Галерея использует ссылки на доступные изображения, подтверждённые данными фото. При пустых данных видна подпись «Нет фото», при отказе загрузки в карточке — «Фото недоступно».

В «Где используется» каждая строка берётся из действующего where-used для материала или модуля. Показаны модули и прямые изделия для детали, изделия и другие модули для сборки. Число относится к одному вхождению на одну сборку или изделие. Ссылка появляется для доступной карточки. Складской остаток и объём задания берутся из своих разделов.
