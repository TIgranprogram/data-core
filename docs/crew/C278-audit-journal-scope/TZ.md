# C278 — общий журнал для директора с выделенным складом

Адресная история C275/C277 уже учитывает область. Общий журнал и список авторов ещё проверяют только открытые разделы. Ограниченный директор не должен видеть заголовок, автора или счётчик чужого складского события.

**Класс** L · **Ответственный** backend · **Приёмка** access, архитектор и QA.

- `GET /audit-logs/app`, `?id` и `GET /audit-logs/app/users` используют один предикат для `SupplyRequest`, `Material` и `StockMovement`. В видимые входят события, чью принадлежность подтверждает текущая запись владельца, включая корректный архив и старый `details.id`, когда `entityId` отсутствует. Ошибочные, осиротевшие и многозначные записи скрываются для ограниченной роли.
- Для остального журнала действуют текущие разрешённые разделы и фильтры. У роли без складских ограничений прежние выдача, явная сортировка, страница, номера записей и список авторов сохраняются.
- Не загружать все ID доступных записей в память. Применить фильтры журнала до адресных join по `_id`, складской фильтр до `sort/skip/limit`, `total` и агрегации авторов. Совместимость Mongo 4.4 проверяется на одноразовой базе. Права определяются по исходной записи владельца.
