# C088 — единый ручной запуск локальных проверок

Класс M; один исполнитель; без дополнительных агентов, коммита и выкладки.
Основание: поручение владельца объединить локальные инструменты C087 с экономией облачных токенов.

## Глубже
- Корень: отдельные кнопки и журналы скрывают непроверенные этапы и повторяют проверки.
- Источник: AGENTS, datacore-verify, DESIGN-WORKFLOW, C087/REPORT, pult/catalog, tools/dc cmdCheck.
- Внешний судья: node:test, реальный единый прогон, отчёт PASS/FAIL/SKIP.
- Планка: одна кнопка, каждый этап один раз, ноль облачных обращений и изменений БД.

## Сделать и принять
- Проверка готовности ПК; типы, юнит, импорты, правила дизайна, циклы и пульт.
- Доступные локальные UI-проверки: браузерная фикстура, axe, тесты сравнения и анализа снимков.
- Сравнение только явно выбранной пары; модель только явно выбранных изображений с существующим кэшем C087.
- Таймаут каждого процесса, защита повторного запуска; единый Markdown/JSON и журналы этапов.
- Пропуск никогда не PASS; общий PARTIAL при пропусках, FAIL при ошибках; тесты этих правил.
- E2E и обход сайта без проверенной изоляции/агента доступа — SKIP с причиной, без секретов и обращений на прод.
- Только ручной запуск: без нового расписания и автоматической установки программ.

## Владение
tools/local-checks.mjs и тест; кнопки pult/catalog, генерируемая справка; документация C088.
Другие агенты работают параллельно; worktree C086 и чужие изменения не трогать.
