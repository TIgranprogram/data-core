# C081 — воронка «Новое КП» (отчёт)

Статус: готово, не закоммичено, не выложено.

**Сервер.** `POST /offers/pack` (`OffersService.createPack`, `OfferPackDto` в `dto.ts`): по одному КП на фирму, наценка у каждой, НДС и тексты — по фирме.
Проверки до записи: заказчик, строки, 1–10 фирм без повторов, наша фирма, бланк. Сбой на k-м КП — созданные этим вызовом удаляются (`collection.deleteMany`), ошибка уходит наружу.
Фирм больше одной — общий `packId`, одна — КП без пакета. Номера сгоревших КП не возвращаются (счётчик общий).

**Экран.** Правая панель `?of=offerfunnel`, кнопка «Новое КП по шагам» в шапке списка КП. Файлы `pwa/sections/offers/funnel/`: `index.js`, `customer-step.js`, `items-step.js`, `firms-step.js`, `api.js`.
Шаги: заказчик (подсказки, молча подтягивает прошлое КП: условия и цены) → изделия + количество → цвет/размер только у изделий с несколькими вариантами → фирмы (метки + наценка, память в браузере) → «Получится N КП: фирма сумма · …» → «Создать N КП». Красным — чего не хватает; жёлтым — нет цены. После создания открывается первое КП.
