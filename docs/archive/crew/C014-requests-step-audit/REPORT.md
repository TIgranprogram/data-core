# C014 — аудит кнопок этапов заявки

**Статус:** P0 правка в коде · полный отчёт аналитика дополняет.

## Язык статусов (путаница)

| Код | Подпись на экране |
|--|--|
| in_progress | Ожидает |
| requested | Заказать |
| ordered | В работе |
| paid | Оплачено |
| received | Получено |

Пользователь «в работе» = `ordered`.

## P0 находка (исправлено)

Правая панель `card.actions`: **«Принять на склад»** стояла `primary` на **любом** статусе кроме Получено/Отменено. Из-за этого на «В работе» без счёта видны и «Счёт оплачен» (nextStep), и «Принять».

**Должно:** одна главная кнопка = `nextStep`; «Принять» только при `paid`.

## Ожидаемые кнопки

| Статус | Доска (foot) | Правая панель (главная) |
|--|--|--|
| Ожидает | В заказ | В заказ |
| Заказать | Заказал у поставщика | Заказал у поставщика |
| В работе | Счёт оплачен → панель №/дата/сумма | Счёт оплачен |
| Оплачено | Принять на склад | Принять на склад |
| Получено / Отменено | — | — (+ «Сменить статус» где уместно) |

## Карточка доски

- Текст `t-sub` вылезал — clamp 2 строки + `title` с полным текстом.
- В «В работе»/«Оплачено» показывать № счёта / «Нет № счёта», дату, сумму.

## Не в этом P0

- C010 «Полностью отгруженные» на телефоне — только ТЗ, кода нет.
- Боевой HA_SELF — не включать (C013).
