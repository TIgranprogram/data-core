## 1. Дорожки (слева направо)
Порядок колонок: A Заказ → B Проектирование → C Снабжение → D Склад → E Производство и отгрузка → F Паспорт → G Деньги. Справочники — колонка H (внизу или справа, пунктиром).

- A Заказ — «Производство → Заказы». Договор принят, позиции, срок. Этапы заказа: Проектирование → Производство → Готово к отгрузке → (Частично) Отгружена → Закрыт; «Отменён» — вне цепочки.
- B Проектирование — «Производство → Проектирование» (доска: На распределении → В работе → Завершены; сбоку Приостановлены, Отменены). Задача = позиция заказа.
- C Снабжение — «Снабжение → Заявки» (вкладки «Заявки», «Счета»). Статусы заявки: Заказать → В работе (заказано) → Оплачено → Получено; Ожидает; Отменено. Счёт: Черновик → Выставлен → Оплачен.
- D Склад — «Склад → Остатки»: Принять, Забронировать, Выдать / «Из брони», Списать, Пересчитать; «Вся история».
- E Производство/отгрузка — внутри «Заказы» (кнопки этапа: «В производство», «Готово к отгрузке», «Отгрузить»).
- F Паспорт — «Продукция → Документация» (вкладки: Нужно сделать паспорт, Паспорта, По заказам, Архив паспортов). Пункт виден, только если есть право правки.
- G Деньги — «Деньги → Позиции и оплаты», «Платёжный календарь» (вкладки Календарь, Сводка, Прогноз, Требуют заполнения). Группа видна только с правом «деньги». ФОТ — за флагом, не рисовать.

## 2. Справочники и служебное (колонка H, пунктир)
Продукция («Продукция → Продукция»; изделие, из которого сопоставляются позиции заказа), Каталог поставщиков («Снабжение → Каталог поставщиков»), Договоры поставщиков («Снабжение → Договоры»), Контрагенты (только «Справочники»), Сотрудники и зоны («Управление → Сотрудники», вкладки «Сотрудники», «Зоны»), Чат (кнопка в шапке, окно справа), «Сегодня» (главная: лента событий и уведомления своей зоны).
Зоны (8): Договоры, Распределение проектирования, Проектирование, Снабжение, Склад, Бухгалтерия, Паспорта, Руководство. Уведомление идёт человеку зоны; зона пуста — Руководству.
