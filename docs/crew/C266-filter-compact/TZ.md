# C266 — эталон фильтров: структура + строгий минимализм

**Зачем:** на складе панель «Уточнить» залита 76 размерами трубы; кнопки и поля слишком «воздушные» для CRM. Нужен плотный, понятный отбор.

**Класс:** M · **Max agents:** 1 (frontend) · **Reviewers:** designer после · **Проверки:** smoke  
**Язык менеджера:** да · **Приёмка:** склад `#stock` (категория трубы), витрина `#kit` фильтры; светлая и тёмная, 1920.

## Глубже
- **Результат:** кладовщик за 1–2 касания выбирает мойку/размер без прокрутки стены кнопок; панель и контролы выглядят строже.
- **Сырьё:** снимок владельца 24.11 (тёмная тема, «Трубы», раскрыт «Профиль и размер трубы»).
- **Метод:** воронка СКФ.3 — длинный список свёрнут; поиск внутри группы; плотность через токены `--control-*`, без своих CSS раздела.
- **Судья:** `node --input-type=module --check` на изменённых js; design-lint; глазами склад + `#kit`.

## Что сделать
1. Inline-facets: не раскрывать `pipe` по умолчанию; `wash` (≤6) — можно открыть. Первый короткий шаг — открыт.
2. У длинной группы трубы: поле «Найти размер…», показ до 24 совпадений + «Ещё N».
3. Чуть сжать контролы CRM: `--control-height` / `--control-compact` / `--topbar-h` / `--fs-h1`; плотнее шапка страницы, чипы, toolbar, `.ff-*` (телефон ≥44px сохранить).
4. Верх всех списков (крошки → заголовок → фильтры → вкладки) — меньше «воздуха», таблица ближе к верху.
4а. «Сбросить всё» — в строке «Фильтры» сверху **слева**, заметная кнопка; без дубля «Склад N» / крошек / «Все N».
4б. Список на высоту окна (скролл таблицы); числа-признаки плитками; без серых подсказок над таблицей.
4в. Все замечания владельца — в `NOTES.md` + DESIGN §3.0; общий CSS на все `.list-screen`, потом проход по страницам.
5. Строка в DESIGN §8; витрина `#kit` без поломки.
6. `UI-REVIEW.md` — снимки или честная PARTIAL.
