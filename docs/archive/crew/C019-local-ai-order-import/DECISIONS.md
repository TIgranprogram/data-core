# Решения C019

1. **Формат Excel** — один лист «Заказ»: шапка ключ|значение, затем таблица позиций. Не формат старых КП для `import-orders-xlsx.js`.
2. **Импорт на сайте** — в браузере (POST salesorders + incomes), не скрипт в Mongo. Человек жмёт «Загрузить» после зелёной проверки.
3. **productionNo** пустой → сервер `nextProductionNo` (уже в create).
4. **Локальный ИИ** — только на ПК менеджера (LM Studio). URL в `settings.json` (не в git).
5. **Цены** — опционально; пусто = 0 на сайте.
6. **Старый** `import-orders-xlsx.js` не меняем.
