# C184 — владельцы участков проекта

**Класс L.** Найти пробелы в охвате ролей, закрепить владельцев за путями и показать нужного проверяющего для каждого изменения. Владелец зоны работает по короткой карте и дельте. Он может устранять подтверждённые дефекты и писать адресные тесты. Изменение границы, общего контракта или постоянного контроля подтверждает архитектор.

- Сверить обе версии профилей, реестр зон, карты, хуки и проверку выпуска.
- Проверить покрытие отслеживаемых путей, новый неизвестный путь, перенос между зонами и приёмку устаревшего результата.
- Привязать проверку к дельте Git и сохранить результаты в коммите и отчёте. Зафиксировать границу технической проверки и оценки специалиста.
