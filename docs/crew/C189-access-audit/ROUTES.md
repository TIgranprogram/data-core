# C189. Доступ к разделам рабочего места

22.11.2026. Меню, поиск, «Сегодня», карта, прямой адрес и вложенная карточка используют одну проверку. Если карточка закрыта, приложение сохраняет экран и его фильтры. Если закрыт сам экран, приложение возвращает человека на доступную стартовую страницу.

| Роль | Что проверено |
|---|---|
| Наблюдатель | Общие списки доступны. Денежный календарь, ФОТ и рабочий раздел паспортов закрыты. |
| Менеджер | Заказы, паспорта и календарь доступны при соответствующих галочках. ФОТ закрыт. |
| Бухгалтер | Может видеть ФОТ при включённых деньгах и открытом разделе. Кадры и история доступны руководству. |
| Директор, администратор | Видят кадры и историю. Администратор также видит каталог компонентов. |
| Своя роль | Права наследуются от базовой роли. Список разделов и галочка «Деньги» действуют одновременно. Старая галочка «Паспорта» открывает документацию и архив. |
| Труборез, Лазер лист | Своё представление склада, журнал, «Сегодня» и карта доступных разделов. Поиск по всему приложению и чужие карточки закрыты. |
| Деревообработка, Кладовщик дерева (C194) | Рабочая таблица выбирает только доступную зону «Деревообработка». В режиме «Смотреть как» таблица доступна для чтения. |
| Только мобильный склад | Прямая ссылка возвращает на мобильный склад. Чужая панель закрывается. |

**Граница HTTP.** Подпись «Труборез» или «Лазер лист» выбирает вид рабочего стола. Разделы HTTP задаёт `appSections`, категории склада задаёт `stockCategoryIds`, денежные поля регулирует отдельное право. Для учётной записи с доступом только к складу следует явно выбрать раздел и нужные категории в роли. Пустой список разделов сохраняет обычные права базовой роли.

**Проверка.** На отдельной MongoDB 4.4 прошли 46 из 46 HTTP-сценариев: разделы 21, категории склада 14, свои роли 6, права на деньги 5. Проверки модели навигации, карты и раскладки прошли 21 из 21. В Edge при размере 1440 × 960 девять синтетических профилей независимо открыли настоящее приложение с тестовыми ответами API.
