# C070 — паспорта и КП: план (приоритет владельца с 2026-11-11)

Разборы: [PASSPORTS.md](PASSPORTS.md) · [KP.md](KP.md) · числа с сайта [PROD-NUMBERS.md](PROD-NUMBERS.md).

## Решения владельца (2026-11-11)

- Все усилия: 1) паспорта, 2) КП. Остальное — постепенно.
- Данные паспорта — максимум сами: из изделия, группы, категории, PDM. Руками — только недостающее, по шагам, без лишних надписей и блоков.
- КП от нескольких фирм: позиции выбираются один раз, фирмы — галочками, у остальных фирм цены выше на свой процент.
- ИИ — позже: сначала подстановка из базы и правил.

## Где мы (числа с сайта, 11.11)

- Паспортов 343, из них сделано на сайте 14; остальные — перенос из таблицы. Изделий 491, с паспортом 240.
- Паспорт на заполненное изделие — 3–4 нажатия. На новое — 25–32 нажатия и 10–17 полей. Заказ из 10 позиций, готова половина — 35–55 нажатий.
- Главная помеха — пустые данные изделий. Заполнения подготовлены, но не записаны на сайт.
- КП на сайте — одно. Пакет из трёх фирм сегодня — около 30 действий.
