# C119 шаг 3 — все правые панели по эталону заказа

Класс: L · агентов ≤ 4 (2 frontend + designer + qa по нужде) · циклов правки ≤ 2.

## Закон
`docs/DESIGN.md` §3.1 «⭐ ЭТАЛОН ПРАВОЙ ПАНЕЛИ» (строки 95–122). Эталон в коде — карточка заказа: `backend/pwa/sections/salesorders.js` (поиск `screenCard(`), kit `backend/pwa/ui/kit/screens/` (`screenCard({ title, sub, side, body })`, `positionsTable` `expand`).

## Что сделать в каждой панели
1. Шапка одним блоком: название + связи ссылками; справа срок/ход (`side`). Этап — один раз.
2. Убрать вкладки, если содержимое помещается: главная таблица — сразу под шапкой.
3. Таблицы — только чтение: без кнопок и «⋯» в строках; правка строки — в «⋯» шапки или панели строки.
4. Всё, что меняет объект («Изменить», «+ …», «Удалить», выгрузки), — в «⋯» шапки.
5. Блоки «Подробнее», пустое «Что дальше» (без кнопки шага), дубли шапки — убрать.
6. Редкое — свёрнутыми блоками под таблицей.
7. Не подходит эталон (длинный текст, график) — НЕ отступать молча: строка в `docs/QUESTIONS.md` «C119: <экран> — почему», панель оставить как есть.
