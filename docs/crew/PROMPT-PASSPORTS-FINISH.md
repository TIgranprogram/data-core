## Шаг 3 — C056 целиком (после коммита C055)
По `C056/TZ.md`, части А, Б, Г, Д, В, в таком порядке: Д (эталон `passports/fill`) → Г (раскладка по разделам) → Б (рисунки в разделах) → А (вкладка «Паспорт» одной карточкой + таблица выпущенных) → В (уборка). Skill `datacore-design` обязателен; в конце — агент/роль `datacore-designer` (приёмка вида), правки по его находкам.
- **Учесть C057:** слоты рисунков в разделах шаблона (Б) могут **предложить файл из PDM**: у изделия в `GET /api/pdm-files?ownerKind=product&ownerId=…` есть `assembly` (сборочный чертёж `_SS`) и `install` (схема установки `_BSUP`) PDF. В разделе «Габариты и виды» и «Установка» — кнопка «Взять из PDM» (первая страница PDF → картинка через существующую загрузку фото). Если файлов нет — кнопки нет. Сервер для этого уже готов (только чтение `pdm-files`); новый серверный код — минимальный и только в `product-passport`/`showcase`, иначе — запиши, что нужно координатору.
