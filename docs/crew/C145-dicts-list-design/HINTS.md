# C145 — описания сверху справочников

**Дата:** 2026-11-18

## Что сделано
- В шапке списка всегда видно `hint` справочника + «Где видно: …» (раньше секции прятали описание).
- Текст подсказок у паспортных справочников: формат «Зачем… Пример…».
- Особенно: признаки / значения признаков, виды, элементы, части, материалы, типы.

## Проверка глазами
`#dicts` → Признаки продукции, Значения признаков, Виды изделий, Функциональные элементы.
