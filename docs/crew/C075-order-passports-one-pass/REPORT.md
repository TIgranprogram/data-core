# C075 — паспорта заказа за один проход

Сделано. Всё в панели «Паспорта заказа», без ухода в шаблон.

- Нет фирмы и наших больше одной: один выбор сверху и вопрос «Записать в заказ?». План отдаёт `firm` и `firmChoices`.
- Директор не правит заказ (PATCH — admin/manager). Если запись отказана, фирма всё равно идёт в этот выпуск (`supplierOrgId`).
- Неготовая позиция раскрывается: те же поля, что при выпуске. После сохранения обязательного позиция становится «готова».
- Сверху «Готово N из M · не хватает: …». Главная кнопка «Выпустить готовые (N)». Когда выпускать нечего — главная «Печать всех».
- Этапы «Готов» и «Отгружено» на доске: кнопка «Паспорта заказа». «Отгрузка» и «Завершить» остаются в карточке заказа.

Проверка: `dc check` зелёный (tsc 0, юнит 3692). Паспорта заказа — 9 тестов. Подсказка следующего шага — 2 теста.

Допущения. «Готово N» — позиции без пробелов (к выпуску и уже выпущенные). Одна наша фирма по-прежнему подставляется сама. Путь API прежний, поле необязательное: `docs/openapi.json` не пересобирался.

Не сделано: выкладка, прод, приёмка глазами.

Глазами: заказ без фирмы при двух наших — выбор и запись; позицию без размера раскрыть и заполнить; «Выпустить готовые», затем «Печать всех»; доска «Готов» и «Отгружено» — кнопка «Паспорта заказа».
