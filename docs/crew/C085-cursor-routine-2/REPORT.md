# C085 · AIT-3 — переход к связанному счёту

В финансовых группах «Требуют заполнения» связанные заявки теперь открывают существующий счёт. Ввод в строке доступен для несвязанных, а направление затрат открывает поле заявки. Правила доступа к денежным группам сохраняются.

Проверка на локальных фикстурах 21.11.2026: воспроизведён прежний HTTP 400 на связанной заявке. Типы, 379 тестов Jest, 3 браузерных логических теста Node и импорты PWA прошли. В Chrome 158 на 1440 × 900 проверены Tab/Enter, переход в карточку счёта без записи, один тестовый PATCH даты для несвязанной заявки и фокус на направлении затрат. Дизайнер просмотрел три кадра с вымышленными данными. Доказательства на ПК: `tools/logs/ait3-*-browser.png`.
