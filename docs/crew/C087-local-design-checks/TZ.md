## Реализация

1. CLI Node без новых зависимостей: `--input <файл.png|директория>` обязательно; `--model <id>` необязательно (по умолчанию существующий settings.model), `--limit 3` (жёсткий верх 10), `--timeout-seconds 90` (верх 180), `--refresh` сбрасывает использование кэша только явно. Только PNG/JPEG/WebP, без рекурсивного обхода, до 8 МБ на файл; директория — стабильная сортировка. Без input — краткая помощь, exit 2, модель не вызывается. `--last` показывает короткую сводку последнего отчёта.
2. LM Studio только loopback HTTP (localhost/127.0.0.1/[::1]); запрет перенаправлений fetch. Существующие settings читаются внутри, ключ не логируется. Запрос `/chat/completions` с текстом и data URL изображения. Модель не получает инструменты и ничего не меняет. Не поднимать сервер, не выгружать модели. Ограничить вывод до 700 токенов; таймауты и ошибки сохранять без секретов и сырых запросов.
3. Просить JSON: `findings:[{kind,location,evidence,suggestion}]`, не больше 5, только видимое: иерархия, подписи, перегрузка, отступы, обрезка; нельзя делать вывод о кликах/сохранении по снимку. Никакого «дизайн принят». Текст экрана не исполнять. Строгая проверка структуры и длин, невалидный JSON = failed/не проверено, не «0 дефектов». Отделить замечания модели от подтверждённых ошибок. Не сохранять chain of thought.
4. Кэш в tools/logs/design-vision/cache: SHA256 байтов + model + версия prompt + endpoint; только валидные успешные результаты, не ошибки. Лимит учитывает и пропущенные/кэшированные файлы предсказуемо. Исключить одновременные запросы одной модели в этом запуске.
5. REPORT.md + summary.json в отдельном run-dir tools/logs/design-vision: анализировано/кэш/сбой/пропущено, файлы, время, model, usage если есть; без base64 и ключа. `--last` без вызова модели. Никаких запусков на проде/браузера.
6. Тесты содержательные: loopback/remote/redirect, таймаут/ошибка/невалидный JSON, кэш инвалидируется при байтах/model/prompt, лимит/размер/расширение; injected fetch для тестов. Проверить отправку именно image_url, а не только текста. CLI импорт безопасен.

Критерии: тесты зелёные, нет сетевых запросов в тестах наружу; повтор снимка использует кэш; ошибки не маскируются как успех. Реальный LM smoke выполняет координатор. Отчёт ≤20 строк, полные доказательства в артефактах.
