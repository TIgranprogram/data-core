# C271 — независимая приёмка C271 и C272

**PASS.** Компьютерные сценарии C271 и регрессия C272 в совместном снимке. Для дельты стилей отдельный **PASS**, отпечаток designer `f9309b28881ae202bc9222eac8eca08963598be3b07609c166a34de80eaf651a` (`kit.css` и `DESIGN.md` в индексе).

Стенд `http://localhost:3102/app/#stock`, основа `6026b9fe`. Все 14 хэшей из [манифеста](evidence/stand/tested-files.json) совпали с замороженными файлами. Использованы заполненные списки стенда и фикстуры для крайних случаев. В [финальном прогоне](evidence/stand/metrics.json) 340/340 проверок, 80 PNG, без ошибок JavaScript. В предыдущем прогоне одноразовый GET 503 поглощался автоповтором клиента, поэтому ожидания отрицательных сценариев истекали. Финальный прогон проверяет ошибку на устойчивом 503 до явного повтора. [Первый прогон](evidence/stand/metrics-before-persistent-get-failure.json).

Сравнение с [эталонами](../../DESIGN.md) проведено для рабочей сетки, карточек контекста, окна с одним полем и правой панели. Дельта липкой шапки использует существующие токены акцента и сплошную поверхность под ними. Design-lint показал 0 новых находок. Обновления извне, появление новой брони, занятый ввод и запоздалый POST подтверждены браузерными тестами через `main`, всего 117/117. [Frontend](REPORT-FRONTEND.md).

Браузерные записи перехвачены. Проверку HTTP и БД провёл QA на изолированной Mongo, 924/924 e2e и 4300 unit/PWA. Для этого отчёта отдельного axe-прогона не было, мобильная приёмка отложена. Подтверждённых блокирующих дефектов нет. [QA](QA-REPORT-C271.md).
