# C086 — применимость вопросов паспорта (по коду)

Источник: `backend/src/modules/product-passport/passport-applicability.ts` (worktree `c086-passports`), обязательные — `passport-rules.ts` `V2_REQUIRED_FIELDS`.
Справочник «Категории паспортов» (`requiredFields`) сильнее кода: поле оттуда — обязательное и применимое.
Сервер отдаёт результат в `GET /showcase/:id/passport-gaps` → `applicable`; экран берёт его же (`fill/paint.js` `appliesOf`).

О = обязательно · н = можно указать · — = не спрашивается ни в каком режиме.

| Поле | DIO | DSP | TRN | WRK | BLG |
|--|--|--|--|--|--|
| maxUsers — пользователей одновременно | О | О | О | О | — |
| ageFrom — возраст от | О | О | н | н | — |
| ageTo — возраст до | О | н | — | — | — |
| heightMin / heightMax — рост | н / н | н / н | О / н | н / н | — |
| weightMax — вес пользователя | н | н | О | н | — |
| fallHeight — высота падения | О | н | — | н | — |
| siteLength / siteWidth — площадка | О | О | О | О | — |
| serviceLifeYears — срок службы | О | О | О | О | О |
| warrantyMonths — гарантия | н | н | н | н | н |
| Элементы («что это за изделие») | О | О | О | О | н |
| «Как поставляется» | О, если в рисунках категории есть «(если разборное)», иначе н | | | | |

Тип изделия — только BLG: назначение → конкретная группа каталога → признак типа (если группа не определяет тип); подсказка по названию типом не считается до «Да, верно».

| Тип BLG | Признаки по типу |
|--|--|
| Ограждение (`fence`) | `blg.fence` |
| Места для сидения (`seating`: Отдых, Зрительские места; группы скамья/трибуна/стол) | `blg.seats`, `blg.seat`, `blg.rail` |
| Прочее (`other`: указатели, урны, навесы, освещение…) | ни тех, ни других |
| Неизвестен | зависящие от типа признаки не спрашиваются; одно уточнение назначения |

Особые случаи: текст изделия использует число (BLG «качели») → сборщик перед подстановкой значений отмечает поле как О; заполнение и повторное открытие не скрывают его. Заменённые и исключённые пункты текста не расширяют применимость. Неизвестная категория → только срок службы и гарантия (н). Признаки других категорий и новые коды справочника не скрываются. Сохранённое назначение удалённого или несовместимого с категорией варианта требует повторного выбора; исходный выбор не стирается.

Не подтверждено / на проверку владельцу:
- Столбцы «н» — принятое по умолчанию (C086), нормативных значений нет.
- Справочник на проде может менять обязательные поля; матрица выше — запасной путь кода.
- Рисунки (обязательные виды) — отдельное правило `imageRules`, этой таблицей не описаны.
- Типы fence/seating на стенде не проходились (есть только юнит-тесты); вживую — указатель, табличка, качели DIO/BLG, «Отдых».
