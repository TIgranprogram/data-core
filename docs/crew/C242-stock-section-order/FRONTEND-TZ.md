# C242 — дельта frontend после C240

Координатор принял REQUIREMENTS/ARCH-PLAN и BACKEND-CONTRACT этапаB. Backend в работе отдельным исполнителем. Прежняя пауза до v2.46 завершена; следующий деплой только после всех задач чата.

Ownership: sections/stock.js,pipe-grid.js,sheet-grid.js,wood-grid.js,metal.js,core/facets.js и адресные stock-list/zonehelpers при необходимости; свои тесты/fixtures, atlas-stock/help-guide. Общийkit не трогать без доказанной необходимости. C240 readonly/mount/role права сохранять: эти файлы уже изменены тем же чатом, это согласованная предшествующая дельта, не откатывать её.

1. Четыре таблицы по матрице REQUIREMENTS: единицы в заголовках, параметры отдельно от названия. В трубах первым предметным столбцом «Сортамент / сечение, мм», далее материал/марка, мойка, длинаединицы(м), исходнаяunit, количественныеостатки/бронь/свободно. Не отображать floor/round(метраж/длина) как физические штуки.
2. Новые серверные sort из BACKEND-CONTRACT, ascending default трубsectionSize, листыsheetSize, деревоwoodSize. Явныйстарый URLsort=name уважать. Никакой сортировки только текущей страницы. Полнота без жёсткого потолка10000, стабильные страницы/дозагрузка/total. Все строки экспорта соответствуют фильтрам/порядку.
3. Существующие нули видны во всехтаблицах/поиске, серый читаемый текст+«Нет в наличии», штатная приёмка доступна. held=1 только явный отборналичия. Полностью забронированные не нули. Не создавать storageitem ради отображения. Кол-во/деньги/выдача/бронь/права прежние.
4. Сеткиpipe/sheet: одна строка наmaterialId предпочтительна; если сетку сохраняют, коллизии хранят всеID и блокируют неоднозначный общий ввод. Марка/форма/оси/мойка/длина/unit различают материалы. Никаких overwrite/sum разныхID. Нестандартные длины и куски видны. Nativeworkerредактирует в исходнойunit, дополнительныйдиректорreadonlyC240.
5. Формы ввода/правки материала: сохранять структурные длину/ширину/высоту/стенку/диаметр, уже поддержанные схемой, вместо их повторного смешивания в названии. Частичная правка не стирает чужие/immutableоси. Существующий lookup включает нули; перед новой карточкой пользователь может выбрать существующую80×60×3 при вводеx/х/×. Не додумывать размеры/марку из свободного имени. Не менятьunit с историей ради удобства.
6. Неизвестное/incomplete/conflict явно показано, не превращается в0/квадрат/AISI304/«не мытая». Сохранять исходное описание, чтобы ошибку можно было сверить.
