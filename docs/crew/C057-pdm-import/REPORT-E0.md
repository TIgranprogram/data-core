## Спорное — решает пользователь
1. **«Расходники»** (87: биты, диски, краска, фрезы) по правилу стали `raw` (сырьё). Это не материал изделий. Предложение координатора: `other`.
2. **Вес:** 100 позиций в граммах без пометки. Перевод в кг — существующий `weight-grams-to-kg.js` после «да».
3. **Сортаменты** (106) появятся в списках CRM kppdf с нулевым остатком — проверить экраны CRM до прода.
4. «Труба профильная нерж. 40×20 / 40×1,5» — толщина записана как 20; проверить глазами.

## Риски
- `--apply` пишет драйвером Mongo напрямую (без аудита и optimistic lock), `updatedAt` не меняет. Это сознательно (массовая разметка); откат — по `--out`.
- `typeName` метизов — как в наших названиях; реальные строки PDM «Сортамент» по метизам проверятся на первой загрузке (ключ сравнения сравнивает их).
