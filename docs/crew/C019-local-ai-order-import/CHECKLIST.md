# Чек-лист приёмки C019

## Пульт

- [ ] Есть раздел «Локальный ИИ».
- [ ] «Открыть входящие» открывает `tools/local-ai-order/inbox`.
- [ ] «Настройки» / сохранение Base URL (файл настроек на ПК, не в git).
- [ ] «Проверить связь» — ответ от `/v1/models` или понятная ошибка.
- [ ] «Собрать Excel» при пустой папке — понятное сообщение.
- [ ] После успеха — «Открыть готовое» показывает файл в `out/`.

## Excel

- [ ] Шаблон с сайта скачивается и открывается в Excel.
- [ ] Формат: шапка ключ→значение, затем таблица позиций.
- [ ] Файл от локального ИИ тот же формат.

## Сайт → Заказы → Импорт Excel

- [ ] Кнопка видна менеджеру/админу.
- [ ] Файл с ошибками: список проблем, кнопка загрузки неактивна.
- [ ] Файл ок: зелёная пометка «Можно загружать», после — заказ открывается.
- [ ] Без № заказа — появился номер last+1.
- [ ] Позиции на месте (название, ед., кол-во), цены 0 если пусто.
- [ ] Лишнее можно удалить в карточке заказа.

## Регрессия

- [ ] «+ Заказ» вручную по-прежнему подставляет №.
- [ ] Старый скрипт `import-orders-xlsx.js` не ломаем (не трогаем в C019).
