## Реализация и остаток

Создание заказчика только при отправке, защита повторов и классификация исходящих счетов — [REPORT-IMPLEMENTATION.md](REPORT-IMPLEMENTATION.md), независимая архитектурная проверка — [ARCH-REVIEW.md](ARCH-REVIEW.md). Восстановление строк спецификации по печатным заголовкам — [ROWS-REPORT.md](ROWS-REPORT.md). Все три договора проходят проверку исходных строк и сумм; исходящий счёт 46 имеет другую раскладку, его импорт не добавлен.

Пульт автоматически применил новую версию; рабочий вход сброшен при перезапуске. Пароль не читался. Владельцу предложен повторный вход, в Пульте добавлен пункт `c233-intake-login`. Повторное добавление PDF не требуется. На момент этого отчёта новых записей на рабочем сайте нет, реальная доставка и квитанции не подтверждены.

Урок: порядок цены и количества проверяется по заголовкам исходной таблицы. Недоступный заказчик не должен блокировать анализ подтверждённого договора, но создавать его можно только в фазе отправки.
