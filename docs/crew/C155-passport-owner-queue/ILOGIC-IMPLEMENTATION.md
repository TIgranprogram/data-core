# C155 · П155-7. Импорт из Inventor

19.11.2026. Правило и подсказка обновлены, статические проверки пройдены.

## Поведение

- Успешный импорт открывает `#products?templateFor=<productId>`. Правило ищет изделие по точному артикулу и подтверждает цель. Дальнейшее открытие шаблона зависит от маршрута PWA из волны B. Вызовы загрузки работают с изделием и его связями рисунков.
- Габариты берутся из видов модели, переводятся из сантиметров листа с учётом масштаба в миллиметры и округляются до целого. В запись идут только три положительных конечных размера. Масса берётся из `MassProperties` детали или сборки, переводится в килограммы и округляется до 0,1 кг. Нулевой или недоступный результат исключает `weightKg` из запроса. Глубина Г вычисляется от линии земли до низа модели, подтверждается отдельно и может быть равна нулю.
- Перед `PATCH /showcase/:id` правило сравнивает подтверждённые поля с карточкой. Уже совпадающие значения пропускаются. При подтверждённой смене единицы габариты записываются в мм. Если изменений нет, PATCH пропускается. Ответ PATCH содержит карточку, прочитанную сервером после записи. Правило сверяет записанные размеры, массу и глубину с этим ответом.
- Порядок замены из C151 сохранён. Правило загружает все три PNG, повторно сверяет прежние связи, добавляет новые и обновляет подтверждённые числовые поля. При ошибке этого этапа оно пытается отвязать новые рисунки. После успеха отвязывает прежние связи только трёх целевых видов и проверяет по API ровно три новые связи и их виды. Ссылка открывается после проверок. Физические файлы остаются в хранилище.

Код: `backend/pwa/ilogic/passport-images.iLogicVb`, `backend/pwa/sections/passports/book-ilogic.js`. Сторона чтения чисел сверена по `showcase.service.ts` и `passport-defaults.ts`. Существенные проверки старого теста C151 по рисункам перенесены в `backend/pwa/ilogic/passport-images.test.mjs`.

Компиляция VB в Inventor, реальный импорт на стенде, переход в браузере и сравнение ранее выданного PDF требуют отдельной приёмки. Правило сайта содержит прежние адреса рабочего API и приложения. Для живого прогона нужна отдельная копия правила с адресами изолированного стенда и ключом стенда.

Случаи для живой приёмки: повторить загрузку к изделию с сохранённой массой и старым выпуском, проверить сохранение массы при недоступном расчёте, отказ от глубины при согласии на размеры, отказ от замены рисунков, совпадающие значения без PATCH. Для первой записи глубины проверить старое изделие с явным `passportDefaults:null`. В прочитанном исходнике общий PATCH использует вложенный путь `passportDefaults.foundationDepth`, поэтому этот случай передан серверной волне. Успешный импорт открывает шаблон того же изделия при прежнем числе экземпляров. Ранее выпущенный PDF сохраняет использованные изображения, текст и номер.
