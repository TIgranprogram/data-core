# C268 — скролл колонок досок после C266

**Класс:** M · **Цель:** снова крутятся колонки досок, страница списка не крутится.

## Симптом
«Проектирование»: карточки обрезаны внизу, вертикальный скролл колонок не работает (снимок владельца 25.11.2026).

## Причина
C266 (`panels.css`) закрыл оболочку списка `overflow: hidden` и скролл таблицы. У досок высота до `.col-body` не доходила; у «Проектирования» ещё вложенный `design-board-layout`.

## Правка
- `base.css` — `.col-body { flex:1; min-height:0 }`
- `panels.css` — цепочка высоты для любой `.board` / `.wk-wrap` под замком C266 (≥721px)
- `design-board.css` — высота split-раскладки проектирования
- `kit.css` / `screens.css` — `.wk-wrap` и обёртки board-pics

## Приёмка
На ≥721px: «Проектирование», «Заявки», «В работе» — `col-body.scrollHeight > clientHeight` при длинной колонке, страница `scrollHeight ≈ clientHeight`, низ карточек доступен колёсиком.
