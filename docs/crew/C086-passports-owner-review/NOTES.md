# C086 — замечания владельца, 2026-11-11

Приоритет: настроить процесс и роли; исправление паспортов передать отдельному Codex. Прод и массовые изменения данных не поручены.

1. Список паспортов перегружен: названия, номера, недостающее слиты; зелёного и капса слишком много.
2. «Упрощённый / Полный» занимает всю ширину; нужен компактный переключатель вверху справа.
3. Категория и тип выбранного изделия должны быть сразу видны; сейчас полезное скрыто среди второстепенного.
4. Поля/списки слиплись, подписи неясны; открытый список должен соответствовать общему компоненту.
5. Деревянному указателю предлагаются элементы ограждения и параметры пользователей. Проверить применимость по категории, группе, типу, признакам.
6. Воронка автоматически использует известное, сужает выбор, спрашивает только недостающее и сохраняет ответы для повторного выпуска.
7. Короткие числовые поля не растягивать как длинный текст.
8. Фото в разных местах имеют разные рамки и действия. Клик по пустой зоне — фокус, Ctrl+V — вставка; выбор файла отдельной кнопкой.
9. Требуется защита от повторений: единые компоненты, проверка дизайнером реальных сценариев, доказательства перед «готово».
